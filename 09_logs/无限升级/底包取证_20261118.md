## 3. RVA 0x2b890d8 是否需要重定位 — 初判

证据（[实测]）：

1. 13.101 的 so 首个 PT_LOAD `vaddr=0x0 off=0x0 filesz=0x5b20000`（R+X）⇒ RVA 0x2b890d8 → 文件偏移 `0x2b890d8`。
2. 该偏移 16 B = `a1 00 00 00` ×4；64 KB 窗口熵 4.58、`0x00` 占 41.7%、`0xa1` 占 14% ⇒ **低熵填充/表区，不是函数入口**。
3. 同 RVA 在 vc1637 官方 so 里是 `db8590c0aea5eb5f07a4b59657bf910c` 起（不同）。
4. 该 so 的 section 头被打乱（`.text` 仅 0x10 B、`.note.gnu.proc` 占 0x5b1fe38、`.dynsym` 在 0x65d23c8 之后）⇒ 盘上静态 RVA 不可信；历史 RVA 来自**运行时** `hook installed @base=…+0x2b890d8`（内存解密后镜像）。

**判断：`libil2cpp.so` md5 已变 + 代际跳变 ⇒ RVA `0x2b890d8` 必须重定位。** 标「**待 mod 手实测**」：只能在真机运行时以 `base+offset` 方式验证，不能拿盘上文件偏移当结论。 [推断 / 待验证]

## 5. 风险与下一步建议

**风险（按严重度）**

1. **全代际换代**：13.x 的功能挂点（`SkillAssets::GetBulletAmount`、`get_damage`、`LegacySystem.LegacyCell` 13 处、`DataManager::AddExp` 等）在 13.x 全部**未验证**；`libil2cpp.so` md5 变化 + RVA 落填充区 ⇒ 现有 `ilpatch` 工程不能直接复用。
2. **元数据加密（HTPX）**：磁盘上 `global-metadata.dat` 不可静态解析 ⇒ 13.x 的符号/类型恢复必须先过运行时 dump（`wxsj_dump_inmemory_dex.py` / `wxsj_mem_dex_scan.c` / `resolve_il2cpp_method_va.py` 是现成入口）。
3. **TapSDK 类不可直接在 dex 里改**：明文 `classes.dex` 只有易盾 stub，`Lcom/taptap/sdk` 命中 0，真 dex 在壳容器内 ⇒ **登录改造不能走「改包法改 TapSDK 类」**，只能走**运行时 SPI**（`Games/<id>/GameHookImpl.java` Java 侧强制网页登录），与 AGENTS §3.3 现行单轨口径一致；坚持改包法须先解壳。
4. **热更基线未知**：设备上没有 `targetfuntional*.dll`，13.x 是否沿用同长度热更（2,028,544/2,030,080）**无证据**；若沿用，`kDllVariants` 需重取 DIAG dump。
5. **12.10701 官方底包不可再生**（本地已删、设备已换代）⇒ 需要 12.x 对照只能渠道重下。
6. **异签名装机**需用户明确同意（官方包现装、签名为官方证书）；走 `install_starry_apk.sh --clean`（自动 `.nxreserve` 外置数据备胎 + 新 uid chown）。当前外置目录条目少、体积小，风险低。

**下一步建议（供 lead 决策，本轮未执行）**

1. **先定代际**：确认按 13.101 做（而不是让用户降回 12.10701）。做 13.x 就要接受「符号恢复重来一遍」的成本。
2. **补热更证据**（低成本、只读）：请用户冷启进一次游戏 → 再 `logcat` 抓 `Exec call len=` 与 `files/` 复查 DLL 落盘。这一步决定「热更通道是否沿用」。
3. **运行时符号恢复**（交 mod 手）：优先 `wxsj_dump_inmemory_dex.py`（拿壳解密后的真 dex，确认 TapSDK/Unity 类可达性）+ 运行时 dump `libil2cpp` 内存镜像后跑 `resolve_il2cpp_method_va.py` 定位新 RVA。
4. **台账登记**：建议在 `底包再获取台账.md` 追加 13.101/vc1650 一行（本轮**未改**该共享文件，等 lead / 单一写者处理）。
5. **口径确认**：功能面（11 项 or 14 项）与 `game_id`（`wxsj` / `wxsjdz2`）需用户拍板，13.x 换代不自动继承 12.x 定制号口径。
