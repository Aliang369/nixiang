## 3. 开关通道（为什么 Java/native 只做搬运）

```
星光菜单（NativeMenuController）
  │ 玩家拨开关
  ▼
ModBridge.onToggleChanged → StateMirror.mirror(featNum, value)
  │ 写两份
  ▼
/data/user/0/com.wbxxm.wbxxm/files/starry_state.txt    ← 单行 8 个空格分隔 int，下标 = featNum
  │ jsb.fileUtils.getWritablePath() + "starry_state.txt"（就是 filesDir）
  ▼
assets/main.js 注入段（400ms 节流读盘）→ feat#1/#2/#3 判定
```

- native 侧（`WbxxmMod.cpp`）**零 hook**：本作无 il2cpp，玩法全在 jsc；native 只保证 `isReady()=true` 与 featNum 透传。
- 复用框架现成件（与群侠传：幸存者同一条通道），**没有自建配置文件、没有改框架类**。
