### 2.1 免广告（2026-11-03 追加，用户点名新增）

斌哥包未启用本功能（`isChecked_RET4` 是模板残留），按游戏自带「免费广告」分支等价实现：

| 落点 | 明文锚点（唯一） | 补丁 |
|---|---|---|
| 激励视频 | `t.prototype.ShowVideo = function(e, t, n, i, a) {\nvar o = this;`（**616 行**） | 入口处：开关开 → 复刻 `FreeADActive` 分支 `this.OnVideoAdEvent_OnClose(!0,e); n&&n(!0); return;`（直接发奖，不拉广告、不走冷却） |
| 插屏 | `t.prototype.ShowInter = function(e, t, n) {\nvoid 0 === t && (t = 0);` | 入口处：开关开 → `return;`（不弹插屏；插屏不发奖，无需回调） |

- 判定依据：`ShowVideo` 内 `GetDataByType(SaveDataType.AD).FreeADActive` 为真时的既有分支就是「跳过广告直接发奖」，补丁只复用该行为，不改奖励结算
- **踩过的坑（已修，勿重犯）**：`Hurt` 的锚点覆盖到了 `if (...Invincible)) {` 这一行的 `{`，直接 `anchor + 补丁` 会把代码插进「无敌分支」里 ⇒ 倍率永不生效且不报错。正确姿势＝`_at_head()`：只取函数头一行，把补丁插在函数头之后、原逻辑之前
- 菜单：`Slider_伤害倍率:1:100:1`（1=关闭，2..100=倍率）+ `Toggle_免广告`（featNum=4）；Java `YsjdohHooks` 的 JSON 增加 `"noad"`，`clamp` 上限从 50 改 100
- ⚠️ 门禁局限（实测）：`pre_install_gate --needle` 只查 dex，**native 菜单中文串在 `libstarry_magic.so` 里**，用中文 needle 打 `--apk` 会假 FAIL。native 串自检改用：`unzip -p <apk> lib/arm64-v8a/libstarry_magic.so | LC_ALL=C grep -ac '免广告'`（应 =1）

## 8. TapTap 登录（已按双轨制改包法处理，2026-11-03）

**症状**：改签后冷启，TapSDK 3.29 拉起客户端 SSO（`TapLoginHelperActivity` → `com.taptap.sdk.ui.TapTapActivity`），客户端返回
`taptap_authorization_fail, login_error_msg=signature not match`（改签必然，客户端按官方签名校验，进程侧无法伪造）。

**本包是「老 SDK / Block-Handler 结构」**（无 `ClientLoginUtils`、无 `GatekeeperRepository`），所以现行「新 SDK」改法不适用。
实际链路（`smali2` 反编译实测）：

```
LoginClient.sendLoginRequest(request)
  try { ActivityHandler.authorize(request) }        // 起客户端授权 Intent
  catch (Exception) {
      TapTapLoginTrackerHelper.authorizationBack()
      handlePhoneVerify() -> handlePhoneVerify2() -> webViewHandler.authorize(request)   // WebBlock 网页登录
  }
```

**改法**（`04_scripts/异世界当欧皇/ysjdoh_patch_taptap_login.py`）：
锚点 `com/taptap/sdk/ui/ActivityHandler.smali` 的 `.method public authorize(Lcom/taptap/sdk/LoginRequest;)V`
→ 方法体整块替换为 `throw new ActivityNotFoundException("starry_force_web_login")`（保留原 Exception 注解与 `.registers 4`）
⇒ 命中 `catch` ⇒ 走 SDK 自带 `WebBlock` 网页授权，**不改 URL、不改路由、不加伪签**。

- 产物：`13_scratch/ysjdoh_taptap/classes2.dex`（7,791,980 B，sha256 `2066d3e5…`）；含自检（反编译回读确认 authorize 只剩抛异常）
- 外科：只替换 `classes2.dex` 一个官方 dex，其余官方条目仍逐字节断言一致；`classes.dex/classes3.dex/arsc/so/jsc` 不变
- **实测证据**：`trackerData … page_id=page_taptap_authorization_web, login_type=webview, page_name=TapTap网页授权`；`signature not match` 出现次数 **0**
- ⚠️ 门禁盲区（已核实）：`pre_install_gate` 查12 的 TapTap 判据基于 `GatekeeperRepository`（新 SDK），对**老 SDK 包判 SKIP**，不能作为「TapTap 方案已落地」的证据；本包靠 tracker 日志与 `authorize` 产物自检闭环
