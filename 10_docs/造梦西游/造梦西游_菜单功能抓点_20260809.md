### 4.5 三功能如何生效（结论）

| 功能 | native（cocos/so） | JS（evalString） | 证据 |
|------|-------------------|------------------|------|
| 百倍伤害 | ❌ cocos **0×主段 B-stub** | ✅ | prefs `"0"` + `get_ret(1)`；JS 改最终伤害 / 玩家×100 / 敌人→0 |
| 无敌 | ❌ | ✅ | prefs `"1"` + `get_ret(2)`；`isDead()` / 受击分支（片段在 BSS，无中文名） |
| 无限技能 | ❌ | ✅ | prefs `"2"` + `get_ret(3)`；绕过 `isCanReleaseSkill` / CD / MP 校验 |

**机制链（与镇邪人 / Blzz 同构）：**

1. WebView `Changes(...)` → 写 **`{pkg}_preferences.xml`** `"0"`–`"2"`。  
2. 同步 **`shell_rw_bss_1` +0x1798..+0x17A0** 三枚 `int32=1`。  
3. **`libSDKloading`** 内 **Dobby** 钩 **`evalString` / `jsb_run_script`**，按 `get_ret` **eval 战斗 JS**（正文在 BSS rw 段，非持久 heap 明文）。  
4. **`libcocos2djs` 主映像无改字节** — 星光走 **JS hook**，非 Keypatch so。

**未确认：** 各 toggle 完整 JS 函数名 / 类名（需 **Frida evalString** 或解密 `1129.html` 的 `exp`）。
