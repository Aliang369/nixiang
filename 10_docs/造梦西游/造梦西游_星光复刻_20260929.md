## 3. 机制链（与 2026-08-10 相同，未变）

1. `FNApplication.attachBaseContext` → `SignSpoof.install()` + `System.loadLibrary("starry_magic")`
2. `AppActivity.onCreate` → 早载 so + `MenuService.start()`
3. native `Dobby hook se::ScriptEngine::evalString`（符号 `_ZN2se12ScriptEngine10evalStringEPKclPNS_5ValueES2_`）
4. 命中战斗 JS（`getMainPlayer` / `isCanReleaseSkill` / 承伤函数头）→ 原地插入两段拼接体 → 交回原 eval
5. 拼接体经 `jsb.reflection.callStaticMethod("com.xm4399.zm6.AppActivity","get_ret"/"get_val",…)`
   → AppActivity 静态转发 → `com.starry.magic.cocos.ZmxyHooks`（classes7.dex）

**锚点（沿用旧版，本轮未改）**

- 伤害/无敌：`if (0 == e || this.isDead()) return 0;`（含无空格压缩变体）
- 无限技能：`if (this.mPlayer.isDead() || …!isCanReleaseSkill()) return "1";`（含压缩变体）

**热更分流（2026-09-29 设备只读核查）**

- 设备存在热更目录 `files/zm6-remote-asset/`：`assets/main/index.jsc` **4,475,472 B** md5 `2e152885bffa04f1b34c5dc84f7ac95c`（22:05 落盘）+ `project.manifest` 2,840,299 B
- 包内同名件 `assets/assets/main/index.jsc` **3,542,840 B** md5 `1c437bd1f47c457ea7bf357368aa4fed` → **两者不同**，运行时加载的是远端热更脚本，不是包内副本
- 两份 `.jsc` 均为加密件（高熵头，非明文）；设备盘上无明文 JS；进程 28588 的 rw 段（1,115 MB 候选）内存扫描未命中锚点，且连必定加载过的 `HotUpdateSearchPaths`（main.js 明文）也扫不到 → 说明该路径不适用（JS 文本在 V8 侧非候选段/UTF-16/瞬时缓冲），**不是**“锚点不存在”的证据
- 结论：包内与盘上都无法离线确认锚点。锚点是否命中只能由 native hook 的真机日志分流（装机后首次进战斗看 `combat splice … dmg=`）。若未命中 → 需按 `skill/re-extract/hotupdate-fingerprint-recheck.md` 重新抓点（在 hook 侧转储明文 JS）；同签名重打**无需**再次卸载
