## 4. 768 三个必须记住的差异（下一轮直接照做）

1. **`.text` 段 `p_offset ≠ p_vaddr`（差 `0x4000`）**：`kRva*` 是 **file offset**（`HookAtRva` → `FileOffToVa()` 按 file offset 查
   `/proc/self/maps`），取值＝dump.cs 的 **Offset 列**；填 RVA/VA 列会整体偏 `0x4000` 挂空页。
   验证手法（本轮用过）：`llvm-readelf -l` 看 `LOAD` 的 Offset/VirtAddr 差，`llvm-objdump --start-address=<VA>` 确认函数真入口首指令。
2. **序言首指令不再是「跨版本不变」**：768 有 6 条变化，`kIns*` 必须同步改；不改会让 `HookAtRva` 序言校验失败并静默回退按名。
3. **字段偏移 7 项漂移**（含 `NpcStatus.type 0x18→0x20`）：凡 `kOff*` 一律按当轮 `rva_targets.json` 回填，禁止沿用上一版。

## 5. 首次启动 SIGSEGV（记录，非功能故障，759 已出现、768 复现）

- 现象：卸载重装后**首次**冷启 `19:56:54.681`（pid `18144`）在 MOD 后台线程 SIGSEGV
  （`Zygote: Process 18144 exited due to signal 11`），最后一条 MOD 日志为 `[Il2Cpp] api loaded from libil2cpp.so (xdl+dynsym)`，
  即崩溃在 `ResolveRuntimeBits()` 首个 il2cpp 类查找阶段；crash buffer 为空（无 tombstone）。
- 复现性：同一安装的第二次冷启（pid `18501`，19:57:44 起）走同一路径**未再崩**，8/8 挂点与六项功能正常；用户实测六项全部正常。
- 定性：**推断（待验证）** = 卸载重装后首启时游戏自身 IL2CPP 元数据仍在初始化，MOD 后台线程抢先调用 il2cpp API 的竞态。
- 处理决定：本轮范围是「照既有实现 1:1 复刻」，未加「等 il2cpp 就绪再探」前置门（属机制变更，需用户拍板）。
  如要消除，另开一轮并先在 `路线锁定.md` 记偏离。
