## 4. 首次启动 SIGSEGV（记录，非功能故障）

- 现象：卸载重装后**首次**冷启 `00:50:48`（pid 1065）在 MOD 后台线程 `tid 1505` SIGSEGV，最后一条 MOD 日志为
  `[Il2Cpp] api loaded from libil2cpp.so (xdl+dynsym)`，即崩溃在 `ResolveRuntimeBits()` 首个 il2cpp 类查找阶段；
  crash buffer 与 dropbox 均无对应 trace（tombstone 文件 0 字节，系统未落盘）⇒ **无栈证据**。
- 复现性：同一安装的后续启动（pid 2141，含用户登录前后）走同一路径**未再崩**，8/8 挂点与六项功能正常。
- 定性：**推断（待验证）** = 卸载重装后首启时游戏自身 IL2CPP 元数据仍在初始化，MOD 后台线程抢先调用 il2cpp API 的竞态。
  反证支持：崩溃时进程尚未进入 Unity 主循环；随后同一路径多次成功。
- 处理决定：本轮任务范围是「照既有实现 1:1 复刻」，未加「等 il2cpp 就绪再探」的前置门（那属于机制变更，需用户拍板）。
  如用户要求消除该首启崩溃，另开一轮并先在 `路线锁定.md` 记偏离。
