## 5b. TapTap 登录与验签核查（2026-11-11 追加，用户当轮点名）

用户问「TapTap 签名校验 / TapTap 登录改网页登录这两项有做吗」。核查结论：**此前两项都没有真正生效**，本轮修掉登录那项。

### 5b.1 签名校验：本作无门闩，运行时替换空转

- 原包 784 `classes*.dex` 内 `GatekeeperRepository` 命中 **0** ⇒ 本作没有 TapTap 新版验签门闩，也就没有「验签失败弹窗」链（装机门禁查12 因此 SKIP，属适用面限制而非放行）。
- B 轨触发点已挂：`StarryInitProvider` 第 79 行调 `SignatureKillerBootstrap.install()`。
- 但它要触发包内 `bin.mt.signature.KillerApplication193` 的 `<clinit>`，**包里没有该 killer dex**。设备取证：
  `files/sigkiller.txt` = `fail: java.lang.ClassNotFoundException: bin.mt.signature.KillerApplication193`；
  日志 `I StarrySigKiller: no signature killer dex (ignored)`。
- 判定：对本作无实际影响（无门闩类），保持现状不动；若日后版本引入验签门闩，须补 killer dex 或改包法。**不做无依据的「顺手补上」。**

### 5b.2 网页登录：补丁在包里但入口断了（本轮修复）

**断点**：`GameHooks.resolve()` 只认两条路 —— `LegacyTapTapGames.uses(gid)` 或存在 `games.<gid>.GameHookImpl`。
yntt 两条都不满足，返回空实现 ⇒ `TapLoginForceWeb.onPreCreated/onCreated` 从未被调用。
运行期实证（修复前）：`I GameHooks: game hook 未提供: com.starry.magic.games.yntt.GameHookImpl`；`TapLoginForceWeb` 相关日志 **0 行**。

**规范依据**（2026-11-11 框架收口）：
- `TapLoginForceWeb` 类头铁律：白名单**只减不增**，新游戏写自己的 `games/<id>/GameHookImpl`，不要加包名（基线 47 条，`check_framework_isolation.sh` [6/6] 校验）。
- `LegacyTapTapGames.GAME_IDS` 同为存量垫片，只减不增（基线 8，[4/5] 校验）。
- `SWITCH_GAME.md`：需 Java 侧补丁时写 `com/starry/magic/games/<game_id>/GameHookImpl.java`。

**本轮还查出更底层的坑**：`app/inject-dex-rules.pro` 的 2b 节已写明「SPI 类被 R8 改名 ⇒ `GameHooks.resolve()` 永远 ClassNotFound ⇒ 补丁静默失效」，
并给了 `-keepnames class com.starry.magic.games.**`；**但这份规则没接进 gradle** —— `app/build.gradle` 的 release 只引 `proguard-rules.pro`，
后者只有 `-keep,allowobfuscation class com.starry.magic.**` + `-repackageclasses 'com.starry.magic.o'`，没有 games 保名。
实测印证：修复前 dex 内 `com/starry/magic/games/` 命中 **0**、`com/starry/magic/o/` 命中 154 ⇒ SPI 类全被改名。
即「只加 `GameHookImpl.java` 不补 keep 规则」= 表现与未加完全一样。

**改动（3 处，均符合规范，未动任何基线）**：

| # | 文件 | 改动 |
|---|---|---|
| 1 | `app/proguard-rules.pro` | 新增 2b 节：`-keepnames class com.starry.magic.games.** { *; }` + 保无参构造，与 `inject-dex-rules.pro` 对齐（修 gradle 路径的配置漂移） |
| 2 | `app/src/main/java/com/starry/magic/games/yntt/GameHookImpl.java` | 新建；`onActivityPreCreated/onActivityCreated` 转调 `TapLoginForceWeb.onPreCreated/onCreated`，自带包名校验与 `targetPackage()` |
| 3 | — | `PKG_WHITELIST`（基线 47）与 `GAME_IDS`（基线 8）**均未改动**，`com.qinglv.Immortal` 仍在白名单内，故内部自检可过 |
