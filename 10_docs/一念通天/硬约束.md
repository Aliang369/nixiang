## D. 技术事实与已验证经验

| # | 事实（实测证据位置） | 适用范围 | 反例/失效条件 |
|---|---|---|---|
| D1 | **`kRva*` 是 file offset，不是 dump.cs 的 RVA/VA 列**：768 起 `.text` 段 `p_offset≠p_vaddr`（768 差 `0x4000`：`LOAD 0x1bbeb9c → vaddr 0x1bc2b9c`），`HookAtRva` 走 `FileOffToVa()` 按 file offset 查 `/proc/self/maps` 换算 VA ⇒ 填 RVA/VA 列会整体偏 `0x4000` 挂空页。证据：`10_docs/一念通天/星空落地_768_20261030.md`「重定位」段、`06_dumped/一念通天/official_768/rva_targets.json`（`file_offset`/`va`/`seg_delta` 三列）、`yntt_rva_extract.py` 不等列警告 | 本游戏（口径来自本作 hook 实现）；其他游戏须先确认其 HookAtRva 语义 | 若某版本恢复 `p_offset==p_vaddr`（如 759 及更早），三列相等、警告不触发 |
| D2 | **序言首指令不保证跨版本不变**：759 轮 8 条 `kIns*` 与 747 逐条相同，但 768 有 6 条变化（MonsterReduce `0xD10303FF→0xD102C3FF`、NpcReduce `0xD102C3FF→0xD10283FF`、MonsterDot `0xD103C3FF→0xD10443FF`、PlayerDamage `0xD10343FF→0xD102C3FF`、GameUpdate `0xF81D0FF6→0xD100C3FF`），沿用旧值会让序言校验失败并静默回退按名。证据：同上文档「重定位」表 | 本游戏换版本时 | 序言未变的版本（如 759 对 747）不受影响 |
| D3 | **字段偏移漂移量不稳定**：759 只 1 项变（`adRequest 0x450→0x458`），768 有 7 项变（`gas 0xA8→0xB0`、`tili 0xB0→0xB8`、`lingshi 0xB8→0xC0`、`money 0xC0→0xC8`、`NPCData 0x2E8→0x2F0`、`fumodata 0x2F0→0x2F8`、`adRequest 0x458→0x470`、`NpcStatus.type 0x18→0x20`）。证据：`official_768/rva_targets.json` field_offsets + `dump.cs` 类字段注释逐条复核 | 本游戏换版本时 | — |
| D4 | **卸载重装后首启 SIGSEGV 是可复现的已知竞态**（759、768 两轮均出现）：崩溃在 MOD 后台线程 `ResolveRuntimeBits()` 首个 il2cpp 类查找，最后日志 `[Il2Cpp] api loaded from libil2cpp.so`，无 tombstone；同一安装第二次冷启不复现、挂点与六项功能正常。证据：`星空落地_768_20261030.md`「运行期实锤」、`09_test/一念通天/precheck_20261030_195647/` | 本游戏（推断，待验证；未加前置门＝未改机制） | 若后续证实与 MOD 时序无关，或加「等 il2cpp 就绪」前置门后消失，本条须改写 |
