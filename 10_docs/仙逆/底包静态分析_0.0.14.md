## 三、引擎与壳判定

- **引擎 = Cocos Creator 3.x + JSB（非 IL2CPP，无 global-metadata / 无热更 DLL）**
  - `lib/arm64-v8a/libcocos.so` = 28,798,216 B（md5 `7ad5451d988a57b52e189d4fdc359e83`）
  - JS 资产明文：`assets/main.js` 4,306 B、`assets/application.js` 1,269 B、`assets/config.json` 193 B、`assets/src/settings.json` 97,802 B、**`assets/src/cocos-js/cc.js` 1,486,810 B**、**`assets/src/chunks/bundle.js` 480,080 B**、`assets/src/system.bundle.js` 8,319 B、`assets/src/import-map.json` 37 B、`assets/jsb-adapter`、`assets/src/assets/scripts/framework/{zlib/zlib.min.js, msgpack/msgpack.js}`、`assets/localsource`（75 项）
  - ⇒ **游戏逻辑很可能在 JS 层**，阶段② 的候选路线偏 JS 层（`se::ScriptEngine::evalString` hook + 文本 splice，光阴之外同型）而非 native RVA
- **无加固壳**：20 个 arm64 so 全清单 = libEncryptor / libEncryptorP / libPglbizssdk_ml / libapminsighta / libapminsightb / libavmdl_lite / libcocos / libfrankie_sh_util / libhdiffpatch / libkeva / libpanglearmor / libpangleflipped / libsecsdk / libtapsdkcore / libthemis / libtobEmbedEncrypt / libtt_ugen_layout / libttmplayer_lite / libvolc_log / libzeusflipped —— 无 libjiagu / libnesec / libtup / libmobisec / libDexHelper / libshell / libexec
- **注入点选择＝分支 B（StarryInitProvider）**，不替换 `application@name`。理由：官方 `com.cocos.game.GameApplication` 负责 `System.loadLibrary("cocos")` 与引擎 native 初始化，且清单无 `appComponentFactory` 可借道；用 ContentProvider（`onCreate` 早于 Activity.onCreate）注入生命周期回调更稳，也不需要动游戏 smali。

### classes7.dex 的两处补丁点（baksmali 2.5.2 反编译 /tmp/xnbz/dec7/ 实证，各命中 1 次）

1. `com/taptap/sdk/kit/internal/utils/TapSignKit.smali`
   `.method public final getSign(Landroid/content/Context;)Ljava/lang/String;`
   原实现：`pm.getPackageInfo(pkg, 0x40)` → `PackageInfo.signatures[0].toByteArray()` → `CommonUtils;->getMD5([B)Ljava/lang/String;`（异常返回 null）。
   ⇒ 重签后返回星空证书 MD5，TapTap 内部校验失败 ⇒ **必须固定返回原厂 MD5 `82c51c4ac68ac5d3197ef4c2b19e1ef6`**（替换体带标记 `# starry_sign_bypass`）。
2. `com/taptap/sdk/login/impl/utils/ClientLoginUtils.smali`
   `.method public final isClientLogin(Landroid/app/Activity;Lcom/taptap/sdk/login/impl/data/model/Actions;)Z`
   原实现：`new Intent(action.getAction()).resolveActivity(pm) != null`
   ⇒ 恒返回 false 即**强制走网页登录**（替换体带标记 `# starry: force WebLogin`）。

> 替换 smali 方法体时用 `.locals 1` **不要用 `.registers`**：`.registers` 会把 outs 需求算错，dex2oat 校验 `outs_size > registers_size` 时直接拒绝，表现为装机后启动即崩。

> `GET_SIGNATURES` / `getPackageInfo` 在 classes7.dex 内被 20+ 处第三方代码使用（mqaw / windmill / volcengine / ss.android / TapSDK DeviceUtils 等），**不是游戏侧签名校验**，无需额外处理。
