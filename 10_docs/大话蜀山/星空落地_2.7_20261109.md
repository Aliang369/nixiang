## 3. 与 2.5 的关键差异：TapTap 方案换轨

2.5 用 `SignSpoof`（运行时证书回灌）+ `TapLoginForceWeb`（反射强制网页）——**两者已于 2026-10-28 按用户指令删除/停用，禁止复活**。
2.7 按 2026-10-29「双轨制」只做 **A 轨改包法**（静态改 classes2.dex），包内实测无 `Lcom/starry/magic/sign/SignSpoof;`、无 `bin.mt.signature.KillerApplication193` 的 dex 实现（只有框架引导类的字符串常量，运行时 ClassNotFound 被 catch 忽略）。

四处 smali 补丁（`04_scripts/大话蜀山/dhss_patch_tapsdk_dex.py`，锚点按 2.7 / TapSDK 4.10.7 现取）：

1. `GatekeeperRepository.isGatekeeperLoadedSuccessfully()Z` → 恒 true（门闩放行）
2. `GatekeeperRepository.showErrorToast(TapNetworkException)V` → `return-void`（保留 .registers 5）
3. `DefaultTapLoginFragmentProvider.provide(LoginRequest)Fragment` → `aget v2,v3,v2` 后插 `const/4 v2, 0x3` ⇒ 恒 WebLoginFragment
4. `ClientLoginUtils.isClientLogin(Activity,Actions)Z` → 恒 false

另在打包时把 `TapLoginForceWeb` 白名单里本包名改写成 `com.cylj.rogue.tp479.disabled`（dex 级字符串，不动共享 Java 源码）⇒ 反射路径天然失效，登录只走 A 轨一条链，无「双修」。

## 5. 加速解锁实现（本轮新增）

游戏内置只有 2 倍这一档：`VipCardPrivilege.BattleSpeedX2=4`、`VipCardFlagEnum.BATTLESPEEDX2=15`，无更高倍率配置 ⇒ 倍率按内置最高取 2 倍，不额外放大。

hook（`DhssMod.cpp`）：

- `Hooked_HasVipCardPrivilege(self, privilege, method)`：`privilege==4` 且开关开启 ⇒ 返回 true；其余特权调原函数
- `Hooked_GetAvailableVipCardPrivilege(self, method)`：返回值 `|= 4`（防 UI 走位掩码判断）
- 只补 4 位，不动 `NoAD(1)/ResetPartnerLevel(2)/WorldBossFast(8)/InitialSkill(16)`，避免连带解锁月卡其它权益
