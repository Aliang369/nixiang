## 6. 静态解密方法（可复现）

1. `WBText` 结构：`BLOB`(11864 B) = 12 × `blob_fillN`(`.array-data 1`)；`OFF`(183 int) = `off_fill0`；`PART_A`(16 B) = `part_a_fill0`。
2. 密钥：`key32 = PART_A[0..16] || wbKeyPart()`（`wbKeyPart` 由 `libwbtext.so` 三表 XOR 生成：`key[i] = ((i*29+7) ^ C[A[i]] ^ B[i]) & 0xff`，表在 vaddr 0x2d990/0x2d9a0/0x2d9b0）。
   - 实测：PART_A=`9f679846f639756664f80696f0352c11`，wbKeyPart=`29305af35c5e4a8a4d0b1636b63ca630`
3. `encKey = SHA256(key32 || "WBText/enc/v1")`，`AES/CTR/NoPadding`，每条记录 = 16 B IV + 密文 + 32 B tag（密文长度 = off[i+1]-off[i]-0x30）。
4. 脚本：`13_scratch/extract_wbtext.py`、`13_scratch/decrypt_wbtext.py`（产物 `wbtext_strings.json`）。

## 7. 运行时实测（2026-11-09 16:36–16:37，真机 OPD2404）

用户操作：进存档 → 打开菜单 → 三个战斗开关各点开 → 资源项输入 9999 执行。日志取自 `adb logcat -s WBMOD`（进程 25809）。

### 7.1 开关型（已闭环）

| 功能 | 日志证据 | 实际行为 |
|---|---|---|
| 玩家无敌 type=5 | `COMBAT god on baseMaxHp 100 -> 100000（合成后 200）`；`DIAG curHp=200 hpCount=0`；每秒 `COMBAT hb god=1 ... hp=100100` | 把 `_baseAttributes` 的 maxHp(attr[3]) 写成 100000，后台线程按 ~1 s 周期把 curHp 拉满；`curHpOff=1140`、`hpCountOff=964`（运行时解析的字段偏移） |
| 百倍伤害 type=6 | `COMBAT atk base 5.00 -> 846.50（bonus 3.50，合成后 8.50）`；`verify atk=850` | 把 base atk 直接放大到 ×100 写回 `_baseAttributes`（attr[1] 8.50→850） |
| 游戏加速 type=7 | `COMBAT ts fn=0x773949761c`；`ts target 1.80（线程每 100ms 重设）`；`hb ... ts=1.80` | hook/调用 `UnityEngine.Time::set_timeScale`，后台 100 ms 重设为 **1.80**，关闭时 `ts restored 1.00` |

### 7.2 资源型（已闭环，含一处错位）

```
cheatNative type=2 → HYBRID: AddItem ok id=2 n=9999 q=7 bagCount=9999  (+9999，重复点叠到 19998)
cheatNative type=3 → HYBRID: points 0 -> 9999 (+9999) dirty=1
                    → AddItem id=3 n=9999 rc=0 path=3
cheatNative type=4 → 无任何后续动作（仅 AccountMgr.instance 查询）
```

- 资源三项走 `AddItem(id = type, 9999)`；`type=3` 额外把 `AccountInfo.points` 写 +9999（`dirty=1` 触发存档）。
- **`type=4` 无实现**：UI 第 4 个资源按钮点了没反应（native 只处理 1/2/3），对应功能表里"积分×9999"需要自己补。
- 物品表（`kyzt_items.tsv`，244 条，首次打开道具面板时由 native 导出）：`id 1=金币 / 2=钻石 / 3=积分 / 101=血瓶1 …`，字段 `id\t名称\t分类`。
- 注意：日志里 `AddItem id` 与 UI 按钮存在一位错位（type=2 落到表内 id2 钻石），移植时直接按表 id 实现即可，不要照抄 type。

### 7.3 物品面板

- `ITEMEXPORT: 244/30000 -> /data/data/com.xf.kyzt/files/kyzt_items.tsv`，`items from game table=244`，`items loaded=244`。
- 添加道具上限 9999/次，装备类不支持（文案 135），走 `AddItem` 验签路径（`path=2/3` 表示不同实现分支）。

### 7.4 副作用记录（供移植时避坑）

- 菜单打开后 `ItemManager.instance field offset=0` 每 ~16 ms 刷一条日志（面板轮询未做节流），长时间挂机会刷爆 logcat。
- `get_nowPlayerInfo 返回 null（存档还没加载完）`：未进存档时点开关只置旗标，不生效；进存档后再点才生效。
