## 6. GM 只读核查（新版证据，未发任何服务端请求）

- **客户端候选入口（实测）**：`global-metadata.dat` 中 `IngameDebugConsole` 出现 36 次，含 `Assets/Scripts/ThirdParty/IngameDebugConsole/{Android/DebugLogLogcatListener.cs, Scripts/DebugLogConsole.cs, MiniGameConsoleInput.cs, ConsoleMethodAttribute}` 与场景引用 `Loader/UI/IngameDebugConsoleLoadingLoading`；dex 侧有 `com.yasirkula.unity.DebugConsole`。⇒ 游戏确实**打包了第三方运行内调试控制台**（命令式，靠 `[ConsoleMethod]` 注册），这是现成的客户端**显示入口候选**。
- **但未见 GM 命令表**：metadata 中无 `GMCommand`/`gmcmd`/`gm_panel` 等标识；`GM` 命中 7 次均为 `GMT`/`GMonth` 日期类噪声；dex 中 `GM` 命中为 `GMSCore`/`SEGMENT`。⇒ **没有证据**表明存在「GM 面板/GM 指令」这类功能入口。
- **权限归属**：metadata 出现配置字段 `enableTimeValidation / enableOnlinePlay / enableCheatBans / enableServerVerification / enableAuditReporting / serverHttpsUrl / clientId / clientToken`，并有文案「Enable Cheat Bans - 是否开启封号」「命中仍上传规则标记及数量，不阻断或弹作弊提示；开启后执行本地账号限制并提示退出」。⇒ 存在**服务端校验/封号与审计上报**能力；客户端本地改数值的持久性与风险由服务端决定，客户端无法单方面赋予 GM 权限。
- **结论**：GM 属**服务端权威**，客户端只有调试控制台这种「本地日志/命令台」候选；在拿到游戏侧 GM 命令表或后台权限前，**不做接入、不加权限门闩**，也不以服务端请求试探。

### 25.1 更正：`int32` 参数并非「非类无法比对」

### 25.2 Init 重试口径（取代「固定次数」示例）
- 失败时**不得发布 ready**；仅成功路径置 `g_ready=true`。
- 重试采用**时间节流**（如 `steady_clock` 记录下次允许时间，间隔 500ms–2s 递增/固定），不采用「早期 N 次耗尽即永久关」。
- 不得使用「`tries%8` 判定」这类在 tries 不递增时会永久卡死的写法。
- 允许在失败后继续尝试，但需有并发安全（atomic/一次性标志），避免多线程同时解析。

## 28. 撤回：RAII 返回时序判定错误（2026-11-14）

**撤回**：§27.1 称「`:944` Init 失败早退在作用域内 ⇒ **dtor 先复位再调 orig**」——**错误**。

C++ 语义：`return orig(self, mi, argBase);` 位于 scope 内时，**先求值 `orig(...)` 并完成调用**，随后才析构 `ReentryGuard`。因此该路径上：
- `orig`（真正的 `EnterFrameFromInterpreter`）执行期间 `t_inHook` 仍为 **true**；
- 若 `orig` 内部（解释执行）再次进入本 hook，会看到 `t_inHook==true`，按新结构应走外层快路径直接 `orig` —— 也就是说**行为仍正确**，但不是「先复位」；
- 结论：判 PASS 的理由须改为「结构正确」，不得再写「dtor 先复位」。

### 28.1 正确结构（intake 待落，作为最终验收判据）
```cpp
// 外层快路径 1：双 flag 关
if (!g_bGod && !g_bX100) return orig(...);
// 外层快路径 2：已在本 hook 内（重入），不改写
if (t_inHook) return orig(...);
// 主路径
{
    ReentryGuard guard;                     // ctor: prev=t_inHook; t_inHook=true
    if (g_ready.load() || Init()) {         // Init 失败则不查询、不决策
        ... queries / match / Decide / field_set ...
    }
}                                           // 此处析构，t_inHook 复位为 prev
return orig(...);                           // 唯一正常出口，作用域外
```
要点：**scope 内绝不出现 `orig(...)`，也不出现 `return`**；所有早退通过布尔/条件表达；`orig` 只在两处外层快路径与末尾各出现一次。
