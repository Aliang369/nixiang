## 说明

- 商品枚举中没有 `zhmr_herostyle_*`：风格不由 IAP 直接售卖；英雄解锁的
  `Archive.HeroArchive.isUnlock` setter 会自动解锁该英雄全部技能与默认风格。
- 运行版热更（v3.4.0.7）若枚举与 CDN 反编译版本有差异，个别 ID 可能被
  `Enum.Parse` 拒绝，但该路径发奖在解析前完成，不影响大部分解锁。
- 该操作只改本地存档；云存档上传可能触发服务端 `CheckForbid`（gem/item 数量）
  与 `fake_receipt_cheat_detected` 埋点，正式账号慎用。

## 更正（2026-08-06 实测）

- 上述 `sendPaySuccess` 只在 Java/logcat 层面确认送达 Unity；C# 侧发奖回调
  在该热更版本中未实际执行（现代支付流程已不走旧 `recvPaySuccess` 路径），
  因此角色并未真正解锁，商店货币变化也来自内存改值而非回调。
- 直接内存改 `Archive.HeroArchive._isUnlock=true` 有效，但当时用**堆扫描**
  只碰到约 7 个对象，误判为「dic 只实例化了 7 个」。
