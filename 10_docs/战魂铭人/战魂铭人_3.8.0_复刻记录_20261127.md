### 3.2 解密（AES-256-CBC / PKCS7）

- 函数：`AOTScripts.LoadSceneLauncher::DecryptDll`，**RVA `0x216757C`**（`libil2cpp.so` 未加壳，RVA 与文件偏移同构，IDA 按 RVA 跳转即可）。
- 算法：**AES-256-CBC + PKCS7**。key 32 B / iv 16 B 由 `Resources.Load<TextAsset>` 在运行时提供，**安装包内不含该 TextAsset** ⇒ 只能运行时一次性取证。
- 取法：frida attach 游戏进程后按「模块基址 + RVA」下 `Interceptor.attach`；ARM64 AAPCS 下 `x1`=密文 Il2CppArray、`x2`=key 数组、`x3`=iv 数组，数组布局为 `+0x18` 长度、`+0x20` 数据。取到的 key/iv 只在本机临时环境变量里使用，**不写入本仓任何文件**。
- 解密并落盘（脚本自带校验，判据全部打印在 stdout）：

```bash
export ZHM_KEY=<32 字节十六进制>   # §3.2 运行时取证所得，仅本机临时使用
export ZHM_IV=<16 字节十六进制>
python3 - "$WORK/bpewsmdwurww.dev" "$WORK/bpewsmdwurww.pkg" "$WORK" <<'PY'
import sys, os, struct
from Crypto.Cipher import AES
key = bytes.fromhex(os.environ["ZHM_KEY"]); iv = bytes.fromhex(os.environ["ZHM_IV"])
def dec(path):
    d = open(path, "rb").read()
    assert len(d) % 16 == 0, (path, len(d))
    out = AES.new(key, AES.MODE_CBC, iv).decrypt(d)
    pad = out[-1]
    return out, 1 <= pad <= 16 and out[-pad:] == bytes([pad]) * pad
for src, name in [(sys.argv[1], "3.8.0.1"), (sys.argv[2], "3.8.0.0")]:
    pt, ok = dec(src)
    e = struct.unpack_from("<I", pt, 0x3C)[0]
    soi = struct.unpack_from("<I", pt, e + 24 + 56)[0]
    print(name, "pt_len", len(pt), "pad_ok", ok, "mz", pt[:2] == b"MZ",
          "pe", pt[e:e+4] == b"PE\x00\x00", "SizeOfImage", soi)
    if name == "3.8.0.1":
        open(os.path.join(sys.argv[3], "GameLogic_3.8.0.1.dll"), "wb").write(pt)
PY
```

判据：`3.8.0.1 pt_len 20307472 pad_ok True mz True pe True SizeOfImage 20332544`；`3.8.0.0 pt_len 20304400 pad_ok True mz True pe True`。任一 `pad_ok` 为 False 或 `mz/pe` 为 False ⇒ key/iv 取错，回本节重新取证。
