## 7. 续修（2026-09-23 22:2x–22:52）：科技立即完成失效 = 乐变负载被 `install -r` 清掉

### 7.1 现象与首轮取证

### 7.2 根因

`/proc/<pid>/maps`：il2cpp 来自 **APK 内置** `/data/app/…/lib/arm64/libil2cpp.so`
（199,563,384B md5 `d7c2b719a9e56d54479a017862751c57` = 3.8.280 原始构建），
而 RVA 表是按乐变 OTA 负载（201,381,272B md5 `76e4418958efd53128d4eaeb4b7b4f60` sha256 `c04afff4…` = 3.8.295）校订的。

静态复核：`python3.11 04_scripts/无悔华夏/whrhx_check_kexpect.py --so <APK内置so>`
⇒ **命中 0 / 失配 46**（常量 51、kExpect 46），整张表在内置版上全失配；
按名兜底救回大部分，但 4 个方法的**参数签名随热更漂移**（`ExecutePolicy` 3→4 参、`UpdatePolicyTime` 2→3 参），
`kExecuteArgcs[] = {4}` / `kUpdateArgcs[] = {3}` 按名也找不到；`CountryData.GetResCnt` / `CheckPolicyDisable`
当时只有 `HookAtRva`（无按名兜底）。

**不是 so / 菜单改错，是它要钩的那份 il2cpp 当时不在**：`install -r` 让乐变删掉负载却保留版本记账 ⇒ 不重下。
