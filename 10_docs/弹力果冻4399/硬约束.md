## 工程硬约束（由上述约束推导 + 历史实锤，违反即崩/返工）

| # | 约束 | 依据 |
|---|---|---|
| G1 | `libil2cpp` 解释器公共点文件偏移：**4399 = `0xBAAB0C`**，TapTap = `0xBABB0C`。两值不可混用；由 `-DSTARRY_TLGD_M4399` 在 `Android_tlgdm4399.mk` 切换，`Games/TlgdM4399Entry.cpp` 有 `#error` 编译期护栏。 | 斌哥 memdiff 实锤 + 2026-08-20/24 用户验收；2026-10-07 本轮 so 反汇编复核（`mov #0xab0c` + `movk #0xba,lsl#16`，全文件无 `0xbb0c`） |
| G2 | 鉴权 `game_id` = **`tlgd`**（4399 独立），**禁止**复用 TapTap 的 `tlgdtt`。四点同步：`Games/TlgdM4399Entry.cpp` `.authGameId` / 后台卡密 / `10_docs/弹力果冻/tlgd_menu_template.json` / 本文档。 | 无悔华夏 4399 事故（临时复用 `whhx` → 后台模板错位返工） |
