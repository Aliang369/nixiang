## 3. 三个目标方法：新旧 RVA 与序言对照

口径：本 so 实测 `PT_LOAD` 全部 `p_vaddr − p_offset = 0`（4 段：`0x0/0x1598000/0x371B000/0x3970000`）⇒
**RVA == file offset**，dump.cs 三列（RVA/Offset/VA）全等；`HookAtRva()` 把常量当 file offset 用（`FileOffToVa`），与此自洽。

| 方法 | 旧热更构建(62,235,240) | **新热更构建(63,343,272)** | Δ | 旧序言 | **新序言（实测字节）** | 序言变? |
|---|---|---|---|---|---|---|
| `C6Game.BattleCoreSys::OnUpdate()` | `0x250307C` | **`0x25D288C`** | +`0xCF810` | `0xD10103FF`（`sub sp, sp, #0x40`） | `0xD10103FF`（`ff 03 01 d1`） | **未变** |
| `C6Game.BattleCoreSys::SelectRandomSkill(uint,uint)` | `0x2508CF0` | **`0x25D8510`** | +`0xCF820` | `0xA9BE53F5`（`stp x21,x20,[sp,#-0x20]!`） | `0xA9BE53F5`（`f5 53 be a9`） | **未变** |
| `C6Game.BattleCoreSys::SendThreeStarSelectSkill(uint,List<sbyte>)` | `0x250A5D4` | **`0x25D9DF4`** | +`0xCF820` | —（非挂钩，按名解析） | `0xA9BE53F5`（同款 prologue，仅记录） | 方法名/签名**未变** |

- 三个方法签名均未变（`SendThreeStarSelectSkill` 仍是 `public bool (uint uid, List<sbyte> idxList)`，类 `BattleCoreSys : BaseLogicSys<BattleCoreSys>`，TypeDefIndex 258 → **260**）⇒ `EnsureGameApi()` 的按名解析无需改动。
- 反汇编复核（capstone）：
  - `0x25D288C` = `sub sp,sp,#0x40 / str x22,[sp,#0x10] / stp x21,x20,[sp,#0x20] / stp x19,x30,[sp,#0x30] / adrp x21,… / mov x19,x0`（与旧版同款 OnUpdate 序言体）。
  - `0x25D8510` = `stp x21,x20,[sp,#-0x20]! / stp x19,x30,[sp,#0x10] / ldr x8,[x0,#0x20] / cbz … / ldr x8,[x8,#0x10] / cbz … / ldrb w8,[x8,#0xb0]` ⇒ 与 `BattleCoreSys` 的 `+0x20 m_currBattle` 链一致。
  - `0x25D9DF4` 同款结构，失败分支 `mov w0,wzr` 后 `ret`（bool 返回），与 `SendThreeStarSelectSkill` 签名吻合。
- **结构自洽证据**：`SendThreeStarSelectSkill − SelectRandomSkill` 在新旧构建**同为 `0x18E4`**（两函数相邻、代码未增删）；
  `SelectRandomSkill − OnUpdate` 由 `0x5C74` → `0x5C84`（+0x10，OnUpdate 与 SelectRandomSkill 之间新增 16 B 代码）。
  ⇒ 三个落点同向漂移 `+0xCF8xx`，不是单点误匹配。
- 序言非唯一指纹：`0xD10103FF` 在本 so 出现 11 次、`0xA9BE53F5` 1 次 ⇒ 序言只作「防错位」兜底，**真锚是 dump 的类内方法归属**（`BattleCoreSys` 类体行 11315–11684）。

## 5. 结论

| 项 | 判定 |
|---|---|
| 是否「挂点搬迁」 | ✅ 是。纯 RVA 漂移（+`0xCF810`~`0xCF820`），**不是路径变更**，机制与挂点无需改 |
| 序言是否变 | ❌ 未变（`0xD10103FF` / `0xA9BE53F5` 两个 expectInsn 原样保留） |
| 方法名/签名是否变 | ❌ 未变（按名解析兜底无需改） |
| metadata | 必须用热更 `StreamingAssets/ab/global-metadata.dat`（现 14,567,296 B / `19fd7021…`）；APK 内嵌那份与新 so **不同代**，不可用 |
| dump 路线 | Il2CppDumper 自动模式即可（不依赖导出符号；`No symbol is detected` 那步是 metadata 配错，不是 so 被保护） |
