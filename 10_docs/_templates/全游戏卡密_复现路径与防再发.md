# 全游戏卡密 · 复现路径清单（防再修五次）

> 状态：活文档 · 2026-08-12  
> 关联：`经验_卡密设备指纹跨包一致.md`、`DeviceFingerprint.java`、`ensure_starry_device_id_seed.sh`

服务端规则极简单：`card.device_id` **整卡绑一个**，与 `game_id` 无关。  
客户端只要同机算出另一个 `dev_*`，必 403「卡密已绑定其他设备」。

## 已证实复现过

| # | 原因 | 表现 | 对策（已落地） |
|---|------|------|----------------|
| 1 | v1 `ANDROID_ID` 按包隔离 | 换游戏必换设备 | 不用 |
| 2 | v2 Widevine ColorOS 仍按应用隔离 | 同上 | 不用 |
| 3 | v3 哈希含 `DISPLAY`/`FINGERPRINT` | OTA 后新 `dev_*` | v4 去掉 |
| 4 | 共享种子只在 sdcard，宿主无存储权限 | 霓虹算出 `5c09`，卡仍 `760f` | `/data/local/tmp/starry_magic` + 装机 seed 脚本 |
| 5 | 只换 so / 旧 dex | 新算法不进包 | 全游戏卡密相关必须重打含菜单 DEX |

## 仍可能复发（按危险度）

| # | 场景 | 为何会炸 | 硬约束 |
|---|------|----------|--------|
| A | **错误 hardware 写进 tmp，覆盖/抢先于正确种子** | 无权限包读不到 sdcard → 算 `5c09` → su/写盘成功毒化 tmp；其它包优先读 tmp | **禁止 clobber**；冲突时 **sdcard > tmp**；写前再 collect 一次 |
| B | **游戏在 KSU/Magisk 拒绝列表，进程内 `su` 全失败** | 读不到 sdcard、也写不了/读不了需 root 的路径 | **装机脚本**必须跑 `ensure_starry_device_id_seed.sh`；勿指望游戏内 su |
| C | **只装了某一个 inject，其它 inject 没跑 seed** | 新包首启无 tmp | 所有 `inject_*.sh` / 一键安装 **post_install 统一** `starry_post_install.sh` |
| D | **机上仍有旧算法包（v1/v2/v3）** | 旧包登录/写种子用另一套 id | 旧包卸掉或全部换成含 v4+防毒 dex；不要混用 |
| E | **种子文件被删，但 prefs 里还有** | 若只信文件会重算 hardware | 有 Root 时 **harvest 其它包 `auth_device_id` prefs** |
| F | **种子全丢 + 无 Root + 无存储权限** | 只能 hardware；若卡绑的是旧 v3 id（`760f`）而 v4 hardware 是 `5c09` | 只能：后台解绑一次，或 adb 把卡上的 id 写回 tmp；**无法纯客户端自愈** |
| G | **`so_only` / zip 只换 so** | Java 指纹逻辑不更新 | 改指纹必须 assemble + 注入 dex |
| H | **清机 / 删 `/data/local/tmp` / 卸光所有星光包** | 无种子无 prefs | 重新 seed 或解绑；清理脚本**不得**删 `starry_magic` 种子 |
| I | **双用户 / 工作资料** | 存储与 data 隔离 | 当另一台设备；需各空间各自 seed 或解绑 |
| J | **UUID fallback**（硬件字段异常） | 每次随机 | 已打日志；真机几乎不触发，触发即必炸 |

## 装机 / 换游戏检查（每次）

```bash
bash 04_scripts/_common/ensure_starry_device_id_seed.sh
adb shell "su -c '
  echo SEEDS; cat /data/local/tmp/starry_magic/device_id
  cat /sdcard/Android/starry_magic/device_id /sdcard/.starry_magic/device_id
  echo PREFS; grep -h auth_device_id /data/data/*/shared_prefs/starry_magic_prefs.xml
'"
adb logcat -s DeviceFingerprint:V AuthClient:V | grep -E 'fingerprint|CONFLICT|device_id|403'
```

期望：**所有 SEEDS/PREFS 同一 id**；log 为 `source=shared`（或首次 `hardware` 且随后各包一致）；**禁止**出现 `CONFLICT` 后仍登录用另一套。

## 代码红线

1. 发现已有合法 `dev_*` → **只补齐空洞，绝不覆盖成别的值**。  
2. 多源冲突 → sdcard 优先，并尽量 heal。  
3. 新游戏注入安装后 → 必须 `starry_post_install` / seed。  
4. 改 `DeviceFingerprint` → 禁止只跑 `*_so_only.sh`。  
5. `cleanup_device_re_residue.sh` → 不得删除 `*/starry_magic/device_id`。
