# 台账（{游戏}，append-only）

> 用途：把**已确认的事实**与**已否证的假设**钉在文件里，抵抗长会话 prune 稀释。
> 落点：`10_docs/{游戏}/台账.md`（一游戏一份；**只追加，不删行**，失效只改状态）。
> 回读：开工 preflight `bash 04_scripts/_common/session_start.sh {游戏}` 会打印本文件的
> **「已否证（禁止重试区）」** —— 那是硬性禁止重试清单，不是参考。
> 配套：`硬约束.md`（用户原话约束）、`路线锁定.md`（移植对照）、`10_docs/_state/games/{游戏}.md`（会话交接）。

## 列含义（写不出来的行 = 还没得到结论，别写）

| 列 | 要求 |
|---|---|
| 结论 | 一句话、可判真假。禁止「可能 / 大概 / 应该」；不确定就写进「未验证」 |
| 决定性证据 | **原始证据行**（日志原文带时间戳，或「命令 + 输出」）；禁止只写「实测过」「已验证」。必须让下一个会话能复算 |
| 状态 | `成立（日期）` / `已否证（原因 + 日期）` / `未验证（等什么）` / `先例已否证（勿重试）` |
| 归属 | 首次得出结论的**消息号**或 `文件:行`；来自先例文档的写清文档路径 |

## 三条纪律

1. **结论先行**：得出任何「客户端如何判定 / 机制如何工作」的结论，当轮落一行。晚落 = 下个会话重推一遍。
2. **否证也算产出**：被证伪的假设必须进「已否证」区，并写清否证证据 —— 它省掉的是**下一次**的时间。
3. **不覆盖旧行**：结论变了就新追加一行，把旧行状态改成 `已否证（被 #N 取代 + 日期）`。
