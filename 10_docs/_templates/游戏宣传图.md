# 游戏宣传图模版（1:1）

换游戏只换 **icon、游戏名、功能介绍、主色、底纹题材**。版式、字号层级、固定标签位置不动。

**出图前必须先把文案发给用户确认，禁止自己加副标题、口号、重复句。**

主色和底纹是两条，不要混：

| 从哪取 | 用在哪 | 不要当成 |
|--------|--------|----------|
| **icon 像素主色**（1～2 个） | 标题、描边、分隔线 | 不要拿 icon 里最响的图形当整张底纹 |
| **游戏名/主题** | 深色底上的淡纹样 | 不要复用上一款游戏的底；不要把 icon 角色再画进背景 |

例：山河 → 底纹淡墨山水（名），描边金褐（icon 帽/镜）。魂坠深境 → 底纹深渊/魂气/纵深（名），描边亮黄（icon）。骑士和带角角色只出现在 icon 里。

禁止：无关装饰（星空、随意光点）、照抄别的游戏水墨/纹样、把 icon 放射底铺满海报。

## 版式（正方形 1:1）

**整张画布必须铺满，禁止中间留大块空白。** 上半区左 icon+三标签、右功能列表要占满高度；底栏只占最下约 10～15%。ASCII 里的空行是示意底栏位置，不是让中间留白。

```
┌─────────────────────────────────────┐
│  [ICON 圆角]     功能介绍            │
│                    · 功能1           │
│  仅安卓设备        · 功能2           │
│  包售后            · 功能N           │
│  包更新                              │
│         24H全天自动发货              │
└─────────────────────────────────────┘
```

| 区域 | 内容 | 谁改 |
|------|------|------|
| 左上 | 游戏 icon（官方 launcher，圆角+细描边） | 每游戏 |
| icon 下三行 | 固定标签，顺序不可改 | 全游戏相同 |
| 右上小标题 | `功能介绍` | 固定 |
| 右列条目 | 菜单功能名，一条一行，前加 `·` | 每游戏 |
| 底部通栏 | 只一句 `24H全天自动发货` | 固定 |
| 主色 | 从 icon 取 1～2 色，只用于描边/标题/分隔 | 每游戏 |
| 底纹 | 深色底 + 按**游戏名/主题**来的淡纹样 | 每游戏 |
| 游戏名 | 可放右上或 icon 旁小字，不超过一行 | 每游戏 |

## 固定文案（不要擅自加减）

- `仅安卓设备`
- `包售后`
- `包更新`
- `功能介绍`
- `24H全天自动发货`

禁止再写：付款后自动发卡、全天在线、月卡、安卓设备（无「仅」）。

**「固定文案」只约束文字字面，不禁止配套 UI 装饰**（见下节「系列装饰」）。文字必须一字不差；图标、分隔线、底栏纹样属于版式，不算「擅自加文案」。

### `仅安卓设备` 死写（跨游戏反复翻车，必须照抄）

Prompt 里固定标签必须用下面整段，**禁止**临场改写成别的中文/英文，也禁止「解释含义」式改写：

```
Fixed left labels (exact glyphs, Simplified Chinese only):
1. 仅安卓设备
2. 包售后
3. 包更新
FORBIDDEN wrong forms for line 1: 仅安装设备 / 仅安裝设备 / 仅限移动设备 / 仅ANDROID设备 / 仅Android设备 / 安卓设备 / ANDROID / Android
```

若生成结果把第 1 行写成任何 FORBIDDEN 形式：只允许 **再 GenerateImage 一次**，且 **只改这一处**（仍粘贴上面整段）；不得借机重写整段 prompt、不得 OCR/手绘涂改像素。

## 系列装饰（全游戏统一，照此出图）

以下装饰**每款游戏都要有**，是系列标准版式，不是「额外加字」。参考成图：`12_images/无悔华夏/无悔华夏_宣传图.png`（第一版）。

| 元素 | 做法 |
|------|------|
| 左栏三标签 | 每行左侧加**小单色线稿图标**（盾=仅安卓设备、耳机=包售后、循环箭头=包更新），文字仍为固定三句 |
| 标签行间 | 细朱红横线 + 中央小菱形/圆点装饰 |
| `功能介绍` 标题下 | 同色细横线 + 中央小装饰（与左栏风格一致） |
| 底栏上方 | 一道传统几何边饰（回纹/菱形纹），横跨画布 |
| 底栏文案 | `24H全天自动发货` 或 `24H 全天自动发货` 均可；两侧可加小菱形装饰 |
| 右上 | 游戏名一行小字（可选，不超过一行） |

**禁止的简化版式**（第二版教训，以后不要出）：

- 三标签各自套**厚重金框矩形按钮**、纯文字无图标
- 左右栏之间拉**整根竖分割线**
- 底栏只有纯色条、**无底栏上边饰**
- 整体「扁平清单风」、缺少分隔线与装饰层次

## 每游戏填写（出图用）

```yaml
game_name: ""              # 例：山河旅探
icon: ""                   # 官方包 launcher png 路径
features: []               # 例：["解锁所有章节", "解锁所有服饰"]
accent_from_icon: ""       # 从 icon 取的主色，只用于描边和标题
bg_motif_from_name: ""     # 从游戏名/主题来的淡底纹，不是 icon 构图
layout_ref: ""             # 可选；默认 12_images/无悔华夏/无悔华夏_宣传图.png（系列装饰标准）
```

## 出图流程

1. 填上面 YAML，把完整成图文案发用户（固定标签 + 功能列表 + 底部一句）。
2. 用户回复确认后再生成 1:1 图。
3. **必须用 `GenerateImage`**，`reference_image_paths` = `[官方icon, layout_ref成图]`。Prompt **短而稳定**，按下面「Prompt 骨架」组装；换游戏只替换 YAML 里那几项，**禁止**每次重写成长篇、禁止叠床架屋加互相打架的字号指令。
4. 参考图必须用该游戏官方 icon，不要另画角色。上一款宣传图只当**版式**参考，不抄它的底纹和主色；**系列装饰层级**以 `无悔华夏_宣传图.png`（第一版）为准（仓内缺失时用最近一款已定稿成图作 layout_ref）。
5. 成品放到 `12_images/{游戏名}/{游戏名}_宣传图.png`。
6. 宣传图不算 06/07 中间产物；用户没说删就留在 `12_images/`。不要放进 `10_docs/`。

### Prompt 骨架（复制后只填 `{}`，不要擅自加段）

```
1:1 square promo poster. Fill entire canvas — NO large empty void under the feature list.
Use official icon from reference (rounded, thin accent stroke). Characters ONLY inside icon.
Series ornaments: left labels with line icons (shield/headset/refresh) + vermilion dividers with tiny diamonds; 功能介绍 underline ornament; bottom geometric fret above footer; side diamonds OK. NO gold button frames, NO full vertical divider, NO starfield, NO slogans.

Accent colors: {accent_from_icon} for titles/strokes only.
Background: dark + faint {bg_motif_from_name} watermarks (not icon art).

Typography hierarchy:
- Right: 功能介绍 large; feature lines · {features} larger, filling right column height.
- Bottom: 24H全天自动发货 largest line, filling the bottom 10–15% banner.

Fixed Chinese (exact):
仅安卓设备
包售后
包更新
功能介绍
· {feat1}
· {feat2...}
24H全天自动发货
Game title small: {game_name}
FORBIDDEN for first label: 仅安装设备 / 仅安裝设备 / 仅限移动设备 / 仅ANDROID设备 / Android
```

### 硬停与验收（2026-09-07 教训：连环重出 / OCR 涂改 / 好图还继续改）

| 规则 | 做法 |
|------|------|
| 次数 | 同一次任务默认 **最多 2 次** `GenerateImage`。第 1 次交用户看；仅当用户指出具体问题，或第 1 次固定文案明显错（尤其「仅安卓设备」）才第 2 次。 |
| 第 2 次怎么改 | **只改用户点名的那一条**（或只修固定文案），其余 prompt 骨架不动。禁止「顺便」重开字号战争。 |
| 停 | 版式大致对 + 固定五句字面正确 → **落盘并停**，等用户说改什么。用户贴出/点名某张图 = 定稿，立刻拷到成品路径，**禁止再生成**。 |
| 禁止 | OCR/Vision 事后涂字、PIL/脚本手排、用检测框盖字重画、把「我觉得还能更好」当成重出理由。 |
| 字号投诉 | 用户说「功能介绍太小 / 下面空白 / 24H 太小」→ 第 2 次只加强 Prompt 骨架里 Typography 三行，不要重写整段故事。 |
