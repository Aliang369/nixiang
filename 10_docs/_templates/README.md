# `_templates/` 目录说明（先读这份再找文件）

> **本目录是"要复制的骨架"与"要检索的结论"两堆东西共用的历史落点**（2026-11-10 加注）。
> 目录名 `_templates` 只对其中 12 个文件成立；另外 25 个是**经验卡**（知识，不是模板），
> 7 个是跨游戏共用的记录格式。
>
> **为什么不拆目录**：全仓 97 处引用指向本目录（含 `10_docs/_state/history/**` 与 12 个
> `04_scripts/**` 脚本注释），其中 Markdown 链接 18 处。`AGENTS.md` §7 与
> `规范变更日志.md` 规定**归档件里的旧路径保持原样不改写**（改写会破坏逐字节可校验性），
> 一旦搬迁，历史归档里会留下修不掉的死链。故本批只加分类，不搬迁。
> 将来若要真拆，需同批改写全部现役引用（`_state/history/**` 除外），并跑
> `python3 -B 04_scripts/_common/audit_workspace_docs.py audit` 验到 0 issue。

## 二、经验库（25 个 `经验_*` / `经验候选卡_*`，**是知识不是模板**）

这些是**单次事故/机制的长结论**，按主题检索用，不要复制进游戏目录。
索引真源＝`skill/re-lessons/SKILL.md`（表格逐条列了「文件 / 首次发现 / 核心教训」）。
当某条经验的机制已被提炼成通用章节（`skill/re-implement/**`、`stages.md`），
经验文件只作**来源证据**保留，执行时以技能正文为准。

> 新经验请不要再落这里：登记走 `_state/pending_experience.md`，合并后并入
> `skill/**` 已有章节；`class: policy` 只提案不改。
