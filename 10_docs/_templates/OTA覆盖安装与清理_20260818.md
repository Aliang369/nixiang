# 星光 OTA so 与覆盖安装优先级（2026-08-18）

## 行为（改前）

`StarryNativeLoad.ensureLoaded`：有 `files/starry_ota/{game_id}/libstarry_magic.so` 就**只** load OTA，不 load 包内 so。  
覆盖安装新星光 APK **不会**删应用私有目录 → 旧 OTA so 仍在 → 包内新 so 进不来。

## 行为（改后）

1. **自动**：load so 前比较 `PackageInfo.lastUpdateTime`；APK 更新过且本地有 OTA → 删 `starry_ota/`，再 load 包内 so。
2. **手动**：设置页「清除游戏补丁」→ 删 OTA，须完全杀进程再开。

清理逻辑在 **Java**（`classes4`），只发 OTA so 带不上；须打进星光包。
