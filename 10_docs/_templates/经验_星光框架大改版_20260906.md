## 一、后台（auth-server，Docker/Postgres，宝塔部署）

部署目录 `/www/wwwroot/starlight-auth/auth-server`，`ssh starlight` 直达。
**部署铁律**：本地 scp 覆盖 → MD5 逐一核对（**含全部 css/js，不许凭记忆跳过**）→ `docker compose up -d --build --force-recreate api` → 容器内标记+接口探针验证。服务器永不手改代码。compose 环境变量会盖过 config.py（`OFFLINE_CACHE_SECONDS` 必须写在服务器 `.env`，现值 86400）。

### 1. 心跳 → 冷启动对账（菜单框架侧联动改动，见二.1）
旧 60s 心跳删除。详见 `skill/starry-mod/auth-chain.md`。

### 2. 票 TTL
`offline_cache_seconds` 600→86400（grant 票 TTL = 离线宽限 1 天）。老客户端兼容（服务端下发）。

### 3. 看板
- 统计边界 UTC→北京时间（`STATS_TZ=+8`），凌晨 0 点翻日；数字与旧账不可直接对比（旧逻辑每天少算 0-8 点）。
- 活跃卡片小字：卡密/游客（游戏项 presence_rows 统计已按用户要求删除）。

### 4. 时间显示与选择器
- SQLite isoformat 裸串按 UTC 解析（`parseServerTime`/`fmtLocal`）——修复前卡密到期显示/回填/续期全偏 8 小时，**编辑保存一次吃 8 小时**。
- 自研 `.time-picker` 组件（`static/admin/js/time-picker.js` + `css/time-picker.css`，已从 index.html 外移）：日历+时分+预设（清除/此刻/+1小时/+1天/+7天）一体；空值显示"未设置"；`tpISOString(id, endOfDay)` 本地→UTC，结束时间选 00:00 自动扩到当天末尾。
- **坑**：浮层面板挂 body 后，内部元素查询必须走 `root._panel` 而非 root（否则翻月/高亮静默失效）；防御守卫会把 bug 变哑巴，守卫须配日志。
- cache-bust：引用带 `?v=N`，改文件必须递增。

### 5. 游戏删除
`DELETE /v1/admin/games/{id}`：有卡密引用 409 需 force；级联清功能/在线/事件/会话；写审计。在线客户端心跳会重建 presence 行（幽灵记录，无害）。

### 6. 模板→游戏单向联动
`POST /menu-templates`（JSON 导入+手建）：无同 id 游戏→自动建（启用+需卡密+绑定+同步功能）；未绑→补绑；已绑他模板→不动。反向不联动。审计标"模板联动自动创建并绑定"。

### 7. scope=global 归一化
公告（创建+PATCH）与卡密（PATCH）global 强制 game_id=None、单游戏无 game_id 400。前端切 global 隐藏并清空选择器（Toast 模式为参照）。

### 8. 卡密管理四项
- **自定义卡密**：`custom_keys`（多行/分隔符，≤500 条，`[A-Za-z0-9_-]{4,64}`），**整批拒绝**语义——批内重复/库内重复/格式非法都 400 并列出具体条目；`normalize_custom_keys` 只清洗不去重。
- **统一编辑弹窗**：卡密只读；范围/游戏/类型/到期/次数/备注可改；换游戏=下次心跳失效。
- **操作下拉**：编辑/解绑设备/封禁·解封/删除（红色）。

### 9. 状态派生化
`refresh_card_status`：banned/unused 保留人工语义；active/expired/exhausted 由到期+次数实时推导——**过期延期、用尽减次数自动恢复 active**。编辑弹窗状态只读（保存不提交 status）。

### 10. 422 人话化
`_human_validation_message` + `_FIELD_LABELS`：字段中文名+原因（账号至少4位/游戏不能为空/数量须为数字…），errors 仍留 data。

### 11. 解绑改版
自助解绑**不限次数**：首次免费，之后每次扣 3 天（剩余<3 天照扣→过期；永久/次数卡不扣；管理端强制解绑免费不占额度）；403 设备不匹配保留；每次记 AuthEvent(unbind)。**`can_unbind` 语义=已绑定即可解绑**（device_bound），客户端门禁同步读 `device_bound`。

## 二、菜单框架（starly-mod-menu，客户端）

### 1. 心跳删除 → 冷启动一次对账
`grantBgRenewRunnable` 60s 循环→冷启动有界重试（3s 首跑/30s×5/`grantRenewCycleDone` 每进程一次）；硬拒（`isHardAuthFailureJson` 关键字命中）cold-start 才踢回登录，expand 只刷 UI；续票成功仅"会话从死变活"才 `reapplySavedFeaturesToNative`；登录成功不再触发。
**native 契约**：`nativeApplyGrant` 被拒且会话本活 → 不清（日志 `grant rejected (session kept)`）。
诊断标签：`cold-start renew` / `renew ok` / `renew auth fail (..., authoritative=...)`。旧 `heartbeat ok (bg-heartbeat)` 不存在了。

### 2. CrashHandler（借鉴 LGL）
`com.starry.magic.crash.CrashHandler`：Java 层未捕获异常 → `Android/media/<宿主包名>/files/crash_logs/crash_*.txt`（玩家文件管理器可取，弹 toast 告知路径）；报告含菜单构建标识（`MENU_BUILD`）/宿主版本/auth game_id/设备/堆栈/全线程；保留 10 份。挂载：MenuService.onCreate + StarryApp。**只覆盖 Java 层**，native 段错误走桩纪律。真机 am crash 实测通过。

### 3. OBFUSCATE 字符串混淆
新增 `Includes/SecStrings.hpp`（五个目标库名 cached getter）；全 jni 35 处字面量 + 18 处日志措辞替换；`grant_pepper` 缓存化（修潜在悬垂指针）。
**锚点保留**：游戏标签/功能名明文——装机自检 `strings | grep 游戏标签` 仍可用。
**坑**：GameConfig.h `constexpr TARGET_LIB` 不能接运行时 getter（已改 static 启动期初始化，用法全在函数内）；日志整句嵌库名也是泄漏点。

### 4. RegisterNatives
17 个 `Java_com_starry_magic_bridge_ModBridge_*` 导出 → `static mb_nativeXxx` + `registerBridgeNatives()`（OBFUSCATE 的类名/方法名/签名），JNI_OnLoad 触发、可重入（dlopen 构造+loadLibrary 双路）。符号表仅剩 `Preferences_Changes` 空兼容桩。
**桥接自检**：`ModBridge.runBridgeSelfTest()` 14 项逐一调用（无副作用方法+垃圾票/验签拒绝），`StarryNativeLoad` 加载成功钩子触发（**勿用定时器**——赌不准 loadLibrary 时序）。真机 18/18 注册 + 14/14 PASS。
**踩坑**：注册表函数名必须与机械改名逐一 diff（`grep -oE 'static \w+ mb_\w+\('` vs 表引用），手抄必错大小写；`mb_bridgeRegistered` 定义放注册表前。
**部署注意**：本轮 ModBridge.java 有新增声明（`nativeBridgeRegistered`）——游戏包需重打 APK（dex+so），仅 OTA so 不够。

### 5. 并行会话竞争（硬规则）
共享 `Android.mk` / `jniLibs/libstarry_magic.so` 与山海幻境会话竞争：他们构建会覆盖 so、mk 会被切走。**星光自测构建用私有 `Android_self_test.mk`（SELF+Main.cpp），重编后立即 gradle 打包**；共享 mk 不触碰（本轮我误改过一次，并行会话已自愈）。部署比对清单必须含全部静态资源。

### 6. 客户端遗留
- 解绑确认/成功文案已改（首次免费/扣3天，toast 取服务端 message）——**v18+ 自测包生效，已发旧包仍固定文案**（扣时靠账号页到期时间体现），建议发公告告知。
- 老包不受本轮任何框架改动影响（服务端兼容旧客户端已验证）。

## 三、验证方式速查

- 后端：TestClient e2e（临时库），`docker compose exec api` 查容器内实际配置；
- 桥接：启动看 `RegisterNatives 18/18` + `桥接自检 PASS=14 FAIL=0`；
- 崩溃日志：`adb shell am crash com.starry.magic` → 查 media/crash_logs；
- 混淆：`strings so | grep libil2cpp`（应 0）、`grep starry_self`（应≥1，自检锚点）；
- 时间：凌晨 0 点后看板翻日；卡密编辑弹窗时间=列表显示时间（北京时间）。
