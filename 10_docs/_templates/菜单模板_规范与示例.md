# 菜单模板 JSON — 唯一规范与示例

> 用户 2026-09-26 定死：「以后的菜单模版都按照示例模版去写，每次都乱写」。
> **规范示例（唯一参照物）**：`10_docs/_templates/menu_template.example.json`。写模板前先打开它照抄字段，不要凭记忆加字段。

## 1. 铁律：顶层只有 5 个字段

```json
{
  "template_id": "zzbx2",
  "name": "正中靶心2",
  "package": "com.openew.monster",
  "source": "Games/Zzbx2Entry.cpp GameMod_Get",
  "features": [
    {"feat_num": 1, "name": "攻击倍率"},
    {"feat_num": 2, "name": "解锁月卡特权"}
  ]
}
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `template_id` | 小写短 id，等于管线 `game_id`（`04_scripts/{游戏}/pipeline.json` 的 `params.game_id`） | 后台主键，与菜单 so 的 `.tag` 保持一致 |
| `name` | 游戏中文名，与 `04_scripts/{游戏}/` 目录名一致 | |
| `package` | 完整包名 | |
| `source` | 菜单项声明处的源码出处 | 格式 `Games/{Xxx}Mod.cpp {函数名}` 或 `Games/{Xxx}Mod.h {枚举名} / Main.cpp g_featureList(STARRY_GAME_XXX)`，多个用 `+` 连接；可用 `@ v7.13` 之类的版本后缀 |
| `features` | 数组，**按菜单从上到下顺序** | 每项**只有** `feat_num` 与 `name` 两个键 |

**禁止出现**：`version`、`version_code`、`notes`、`note`、`game_id`、`id`、`default`，以及 feature 里的 `type`、`min`、`max`、`default`、`note`、`title`、`feat`、`desc`。
后台不读这些字段，加了就是「乱写」。（历史模板里出现过这些字段，属遗留，不要照抄。）

## 2. `feat_num` 与 `name` 的写法

- `feat_num` = 该功能在 C++ `featureList[]` 里的**真实下标**（`Zzbx2Entry.cpp` 的 `kZzbx2_Features`、`WxsjMod.h` 的枚举等）。**保证与菜单/后台对齐，不要自己重排。**
- 菜单里的分组行（`Category_*`）**不写进 features**；功能项的 `feat_num` 仍按真实下标（例如分组占 0，则第一个功能是 1）。
- `name` 写**纯功能名**，与菜单显示文字一致：`攻击倍率`、`解锁月卡特权`、`无敌`、`免广告`。
  **不要**带控件前缀或参数（`Slider_攻击倍率:1:10:1`、`Toggle_解锁月卡特权` 是运行时下发串，不是模板内容）。
- 名称用中文、不加编号与括号注释。

## 3. 落地位置与自检

- 位置：`10_docs/{游戏}/{id}_menu_template.json`（如 `10_docs/正中靶心2/zzbx2_menu_template.json`）。一游戏一份，随收尾一并提交。
- 写完必须自检（字段集严格相等，多一个都算不合格）：

```bash
python3 - <<'PY'
import json
p="10_docs/正中靶心2/zzbx2_menu_template.json"
d=json.load(open(p))
assert set(d)=={"template_id","name","package","source","features"}, sorted(d)
assert all(set(x)=={"feat_num","name"} for x in d["features"])
print("OK", d["template_id"], [x["name"] for x in d["features"]])
PY
```

## 4. 正/反例对照

正例（照抄这个）：

```json
{"feat_num": 2, "name": "解锁月卡特权"}
```

反例（都是踩过的坑）：

```json
{"feat_num": 2, "name": "Toggle_解锁月卡特权", "type": "toggle", "default": 0, "note": "ON = 放行 outStatusAdvip…"}
```
```json
{"feat_num": 3, "name": "解锁战斗加速"}      // 名称与菜单实际显示不一致 + 下标错位
```
