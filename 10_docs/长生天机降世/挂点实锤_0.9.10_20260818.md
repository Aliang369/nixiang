## 结论

0.9.9 壳的 ABI（`x1=MI, x2=args`）在 0.9.10 上 **仍然对**，但函数挪了：不是 Execute `0x265875C`，而是 `EnterFrameFromInterpreter` file **`0x2656920`**。  
独桩 / Execute 看不见 C# 互调；必须钩建帧函数再按 `RoleValue_Health` 过滤。

### ABI 实锤（反汇编）

- Health 独桩：入口 `x2=MethodInfo`，`BL` → 解释器 `0x…775c`
- MoveNext/Refresh2 共享桩：入口 `x1=MethodInfo`，`BL` → **同一**解释器

### 结论（已纠偏 2026-08-18 17:40）

Execute 入口 file `0x265875C` **只承接 native→C#**。扣血链全是热更 IL 互调，走 HybridCLR `CallInterp` → **`EnterFrameFromInterpreter`**，不重进 Execute 序言，所以 Health 名永远 0。

0.9.9 壳 ABI `x1=MethodInfo, x2=args` 对上的就是这个函数，不是 Execute。

| 函数 | 0.9.10 file | 证据 |
|------|-------------|------|
| `EnterFrameFromInterpreter` | **`0x2656920`** | `sub w1, maxStack, argSize` 后 AllocStackSlot+PushFrame；Execute 内 CALL IR **16 处** BL |
| `EnterFrameFromNative` | `0x2656A58` | 拷参数；Execute 序言只 BL 这一处 |
| `Interpreter::Execute` | `0x265875C` | 已否：`interp live` 但 Health/BeAttack 名 0 |

星光改钩 `0x2656920`，过滤 `RoleValue_Health`，改 args `[+8]` 负 delta（RoleSide 2→×10 / 1→0）。
