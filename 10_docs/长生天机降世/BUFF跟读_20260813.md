## Handler 改点（已反汇编）

挂点：`libil2cpp` file `0x2656658`（函数序言 `STP` 被改成 `B`）。

解析名（壳配置区）：
- 类：`CBRoleValueSystem`
- 字段/键：`RoleValue_Health`

在调原函数前（`BR X3`），对 `X19` 指向的变更包做手脚：

| 功能 | 条件（摘要） | 改写 |
|------|--------------|------|
| 十倍伤害 `#728` | `*(int*)(*X19 + 0x74) == 2` 且 flag 开 | `*(X19+0x8) *= 10`（`MOVZ #10` + `MUL`） |
| 无敌 `#72c` | flag 开 | `*(X19+0x8) = 0` |

含义推断：`X19+0x8` 是本次 RoleValue/血量变化量；类型 `==2` 时十倍放大；无敌则把变化量清零（受击不掉血）。

- Dobby 仍打在 guest `libil2cpp` file `0x2656658` / ELF RVA **`0x265A658`**
