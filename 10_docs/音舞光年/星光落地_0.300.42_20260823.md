## 构建

```bash
cd mod菜单/starry-mod-menu
# Android.mk：STARRY_GAME_YWGN
STARRY_INSTALL=1 bash scripts/ywgn_so_only.sh
# 仅 native、不要菜单 dex：STARRY_UPDATE_MENU=0 …
# 从官方原包重来：STARRY_USE_CLEAN_BASE=1 …（需 02_apks 原包）
```
