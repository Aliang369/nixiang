## 四、壳的 IL2CPP 解析机制（已确认）

1. 壳内置 **Dobby**：`shell_rx_bss`（匿名 rx 段）含全套符号串

2. **壳不自己解析 metadata，而是拦截 Unity 的符号解析**（这是它能拿到 il2cpp API 地址的原因）：
   - `libunity.so` 有个内部函数（VA `0x7408E59610`，文件偏移 `0x5E3610`，介于导出符号 `UnitySendMessage`@0x431C50 与 `UnitySwappy_version`@0x697EB8 之间）签名形如 `f(handle, const char* name, int)`。

### 5.2 hook #2 —— 全局加速施力点：`UnityEngine.Time::get_deltaTime()`

- **挂点**：RVA/VA **`0x54553E4`**（内存 `0x6fec05f3e4`），磁盘原指令 `str x19,[sp,#-0x20]!`
- **归属硬证据**：该 wrapper 内 icall 名串位于文件偏移 `0x6f96c30` = **`'UnityEngine.Time::get_deltaTime()'`**（模式：`ldr x0,[x19,#0x1d8]; cbnz x0,done; adrp x0,#0x6f96000; add x0,x0,#0xc30; bl 0x163307c; str x0,[x19,#0x1d8]; done: … br x0`，即 il2cpp icall 懒解析+缓存）。
- **跃迁链**：`b` → trampoline 页 `0x6fe4060000` 的 `+0xC` → **detour `0x7438AACA14`**（shell+0x413A14）
- **detour 反汇编**：

```asm

7438aaca18: stp x29,x30,[sp,#0x10]
7438aaca1c: add x29,sp,#0x10
7438aaca20: adrp x9, #0x7438b64000
7438aaca24: adrp x8, #0x7438b66000
7438aaca28: ldr  s0, [x9, #8]      ; s0 = *(int32*)[0x7438B64008]  ← 加速倍率
7438aaca2c: ldr  x8, [x8, #0x48]   ; [0x7438B66048] = hook#3 的原函数 trampoline
7438aaca30: mov  x19, x0           ; 保存 MethodInfo*
7438aaca34: scvtf s0, s0           ; int → float（倍率）
7438aaca38: blr  x8                ; ★ 调 set_timeScale 原函数 → Time.timeScale = 倍率
7438aaca3c: adrp x8, #0x7438b66000
7438aaca40: ldr  x1, [x8, #0x50]   ; [0x7438B66050] = hook#2 的原函数 trampoline
```

- **门控语义（已定论）**：`get_deltaTime` 被 **每帧高频调用**，detour 借这个调用点**无条件**把 `Time.timeScale` 写成整数倍率 `[0x7438B64008]`，然后尾调原 `get_deltaTime` 返回。
  → **「全局加速」的施力方式 = 强制 `Time.timeScale = 倍率`**（不是自己乘 deltaTime；也没有读功能旗标）。
  ⚠️ 副作用推论（**待实测**）：倍率为 `1` 时等价于「每帧把 timeScale 钉在 1」，会覆盖游戏自身的 timeScale 设置（若有暂停/慢动作则被压掉）。
- **原函数回填指针**：`[0x7438B66050] = 0x7645198030` → 桩 `+0x30`（首指令 `str x19,[sp,#-0x20]!`）跳回 **`0x6FEC05F3E8` = 挂点+4** ✓

### 5.3 hook #3 —— 全局加速占位：`UnityEngine.Time::set_timeScale(System.Single)`

- **挂点**：RVA/VA **`0x5455560`**（内存 `0x6fec05f560`），磁盘原指令 `str d8,[sp,#-0x20]!`
- **归属硬证据**：icall 名串文件偏移 `0x6f96d46` = **`'UnityEngine.Time::set_timeScale(System.Single)'`**

- **原函数回填指针**：`[0x7438B66048] = 0x7645198048` → 桩 `+0x48`（首指令 `str d8,[sp,#-0x20]!`，与磁盘原指令一致）跳回 **`0x6FEC05F564` = 挂点+4** ✓
