## 4. `ReceiveDamage` 替换逻辑（秒杀+无敌）

伪代码（与 `hook_bodies/ReceiveDamage_hook*.bin` 一致）：

```c
// x1=target, x2=damage
if (!target || damage < 1) goto orig;
camp = *(int32*)(target + 0x2C);

if (camp == Player || camp == Pet || camp == Phantom) {
    if (switch2 /*0x4C4*/) damage = 0;          // 超级无敌
} else if (camp == Npc) {
    if (switch1 /*0x4C0*/) {
        // 防溢出：damage = min(damage, INT64_MAX/100) * 100
        const int64 CAP = 0x0147AE147AE147AE; // = INT64_MAX/100
        damage = min(damage, CAP) * 100;       // 倍率 N=100
    }
}
goto orig;  // br 原 ReceiveDamage
```

要点：

- **倍率 N = 100**（`mov w11, #0x64`）
- 无敌覆盖 Player / Pet / Phantom，不只 Player
- 秒杀只打 Npc

## 5. `OnDamageEffect` 替换逻辑（全屏）

1. 先 `blr` 原 `OnDamageEffect`（保留本次正常结算）
2. 若 `switch3` 关 / target 空 / 重入锁 → 返回
3. 要求 **主目标** `m_Camp == Npc(2)`
4. 取怪列表（已钉死，战斗中 BSS `+0x540` 解析）：
   - `Battle.Logic.MonsterMgr$$get_Instance` **RVA `0x16D8E40`**
   - `List<BattleEntity>* list = *(MonsterMgr* + 0x18)` → 基类 `m_EntityList`
   - `_size = *(int*)(list + 0x18)`，`_items = *(void**)(list + 0x10)`
   - 元素从 `_items + 0x20` 起、步长 8（标准 IL2CPP 数组）
   - 合法性：`2 ≤ _size ≤ 500`（`_size-2 ≤ 0x1F2`）
5. 遍历：跳过主目标；只要 `m_Camp == Npc`；再调原 `OnDamageEffect(this, launcher, other, …)`
6. **最多额外扩散 40 个**（`cmp w11, #0x27; b.gt` → 成功次数可达 `0x28`）

壳文案 `最多扩散%d个` 的 `%d` = **40**。
