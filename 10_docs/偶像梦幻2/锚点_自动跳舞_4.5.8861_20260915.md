## 2. 映射与方法论

`libil2cpp.so` 的第二个 RX `LOAD` 段满足：

```text
runtime VA = file offset + 0x4000
```

因此源码的 `FileOffToVa(GameUnity::TARGET_LIB, fileOff)` 使用 **file offset** 常量，不能用反汇编器显示的 VA 常量。

重定位步骤：

1. 从 4.4.8684 文档提取三个旧函数序言。
2. 在 4.5.8861 全量 `libil2cpp.so` 中搜索机器码。
3. `get+0x24` 单独有 101 个泛命中，`get+0x28` 有 174 个泛命中，不能按单点命中直接选。
4. 第三个 getter 的完整序言组合只命中 **1 处**。
5. 检查三候选的相邻布局与相对间距；新版保留旧版 `+0x10/+0x20` 关系，且三候选整体平移量完全一致。
6. 反汇编确认函数边界与旧语义一致。
