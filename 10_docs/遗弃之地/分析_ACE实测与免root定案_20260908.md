## 六、ACE Root 检测执法（实证，隔离实验）

- 现象：**登录成功进战斗后**弹「ACE安全风险提示：检测到您的设备已经被Root…」（[截图](evidence_20260908_jspatch/ace_root_dialog.png)），点「确定」→ 进程自杀（`Process com.hortor.yqzd has died`，00:45:13）
- 隔离实验：还原**干净缓存（无补丁）**重跑 → 照样弹窗 → **触发源=root 环境（MuMu adbd root / su），与 JS 补丁无关**（补丁对 ACE 完全隐形）
- 检测时机在登录后（会话绑定策略），启动/登录阶段不拦
- 结论：**root 路线整体不可用**——root 开着被杀；关 root 则写不了缓存/配置（死结）
