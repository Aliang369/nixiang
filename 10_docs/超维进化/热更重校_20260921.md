### 3.3 实测坑（新，值得入经验卡）

`CWJH_GATE(i)` 用 `#i` 字符串化宏参数，**只能喂字面量**。首版把 ① 写成 lambda 传 `int idx`：

```cpp
auto gated = [](int idx, const char* fn){ return std::string("if(") + CWJH_GATE(idx) + ...; };
```

→ 宏把参数名 `idx` 字符串化，产物 JS 变成 `jsb.reflection.callStaticMethod(…,"(I)Z",idx)`，**未定义标识符**，`_timer()` 每 tick 抛异常（回血/回蓝必失效），但 `node --check` 只查语法**查不出来**。

**发现手段 = 运行时 splice 长度比对**：运行时日志 `2202886→2205175`（+2289），离线模拟 `+2277`，差 12 B = 6 处 gated 调用 ×（`idx` 3 字符 − 数字 1 字符）。修正后运行时 `2202886→2205163`，与模拟**逐字节一致**。

> 结论：**splice 类改动必须用「离线模拟 delta == 运行时 splice delta」做闭环**，`node --check` 不够。
