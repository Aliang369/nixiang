## 8. 已知坑

1. **雷电（houdini 转译）跑不了本包**：原版正常，一装星光包即进死亡循环——进程在 `cocos_jni_env_init` 后约 10ms 被 `signal 9` 杀，无 tombstone、无 Java 异常、无 `neutralized` 日志（中和抢不过检测），AMS 立即重启 → 黑屏。**该游戏只看真机（arm64 原生）**。
2. **④/⑤ 门牌错位**：0.3.51 两行钳制串同形，必须用「累减行 + 钳制行」整块锚，任何单行锚都会串改。
3. **① 暂停守卫**：注入必须落在 `if (!e || !e.pause)` 内，否则暂停期也回血。
4. **本机 gradle 不可用**（SDK 缺 platforms）→ 复用 `app/build/outputs/apk/release/app-release.apk` 取框架 smali；`build-tools/android-15` 需 junction 成 `35.0.0` 才不被 AGP 判为缺失。
