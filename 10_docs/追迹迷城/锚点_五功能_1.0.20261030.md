## 2. 与上一版（1.0.20261009）的位移判据

- 跨版本**恒定**间距逐条相等（0912 / 1009 / 1030 三版同值）⇒ 同源代码线性位移，Hook 语义可直接复用：
  - `LocalPlayer.CheckSkillUse_Dodge − CheckSkillUse_2` = `+0x2C`
  - `AttackBattleData.CheckCurSp − CheckCurrentIsCanUse` = `+0x1C`
  - `MonsterPartnerSkillBattleData.CheckCurSp − CheckCurrentIsCanUse` = `+0x34`
  - `ATGameManager.GetFreeSkipAdsUsedCount − GetFreeSkipAdsRemainingCount` = `+0x17C`
  - `ATGameManager.UseFreeSkipAds − GetFreeSkipAdsUsedCount` = `+0x24`
- 本版**确有代码改动**（只影响间距，不影响语义）：
  - `LocalPlayer.CheckSkillUse_2 − CheckSkillUse_1`：1009 为 `0xA8`，本版 `0x2C`（函数体变短）
  - `Monster.ChangeHP − Monster.ProcessDamageOrHeal`：1009 为 `0xA20`，本版 `0x2444`
  - 结论依据：两个目标各自仍按类名+方法名命中、签名不变，且其余 5 组恒定间距全等。
