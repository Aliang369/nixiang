## 3. 玩法语义（星光复刻用）

> 对照改包只借玩法，不抄壳 UI。推荐 **DobbyHook + 原函数尾调 + 星光 Toggle 门控**。

### 3.1 秒杀 ≈ `Monster.ChangeHP`

- 签名：`float ChangeHP(float hp, bool isShowDamageText)`  
- 推定：当 `hp < 0`（扣血）且功能开 → 放大 `|hp|`（壳「百倍」）或直接改成致死量。  
- 备选：若实机发现只放大己方输出，再核对 `LocalPlayer.ProcessDamageOrHeal`（本轮 **未** stub）。

### 3.2 无敌 ≈ `LocalPlayer.ChangeHP`

- 同签名。  
- 推定：对玩家的负向 `hp` 置 `0` / 直接 return 当前血（壳文案「敌人伤害」= 挡敌方伤）。

### 3.3 全屏秒杀 ≈ `BattleManager.Update`

- 每帧：若旗标开 → `GetCurWaveAliveEnemyList()` → 对每个 `Monster` 调 `ChangeHP(-极大)` / 死亡接口。  
- `GetCurWaveAliveEnemyList` RVA（dump，未 hook）：`0x2F9E234`（Offset `0x2F9A234`）。

### 3.4 无限技能 ≈ 一组 bool 闸门全放行

对下列方法：功能开时 **强制 `return true`**（或 SP 检查直接通过）：

- `LocalPlayer.CheckSkillUse_{1,2,Dodge,ActionState}`  
- `AttackBattleData.CheckCurrentIsCanUse` / `CheckCurSp`  
- `MonsterPartnerSkillBattleData.CheckCurrentIsCanUse` / `CheckCurSp`
