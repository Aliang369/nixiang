## 3. 免广告定案

- `ATGameManager.ShowRewardADS(...)` 已内置 `FREE_SKIP_ADS_DAILY_MAX=3` 的免费跳过广告分支。
- `<>c__DisplayClass167_0.<ShowRewardADS>b__0` 在 `hasFreeSkip` 为真时调用 `UseFreeSkipAds()`、`RecordAdsUsage()`，然后走与正常广告完成相同的 `successDel`。
- 本版免广告不伪造 `CSJAdsManager` 回调，不直接调用托管委托；仅 hook `GetFreeSkipAdsRemainingCount()`，开启时返回 `3`，让游戏自己的官方免费跳过分支持续可用。
- 关闭功能后恢复原函数返回值，按游戏原始每日 3 次逻辑运行。

## 4. ELF 与结构

- `libil2cpp.so` 的 RX LOAD: `file_off=0x26D157C`, `vaddr=0x26D557C`, `delta=0x4000`，运行时 `ELF_BIAS` 仍为 `+0x4000`。
- 当前包含官方 `classes.dex` 至 `classes6.dex`，`resources.arsc` 独立。
- Unity Activity 位于 `smali_classes3`：
  - `com/unity3d/player/PrivacyActivity.smali`
  - `com/unity3d/player/UnityPlayerActivity.smali`
- TapTap 类位于 `smali_classes5`：
  - `com/taptap/sdk/kit/internal/utils/TapSignKit.smali`
  - `com/taptap/sdk/login/impl/utils/ClientLoginUtils.smali`
- `classes6` 可用作星光 smali 合并目标，避免新增 `classesN.dex` 后依赖自动发现。
- 官方 `AndroidManifest.xml` 的 application 仍未声明 `android:name`。
- 当前广告 service 槽为 33 字符：
  - 旧: `com.byazt.b.DownloadHandleService`
  - 新: `com.starry.magic.menu.MenuService`
- 当前 Manifest 已含 `SYSTEM_ALERT_WINDOW`，补丁器不得重复添加。
- 当前 Manifest 不含 `FOREGROUND_SERVICE_SPECIAL_USE`，需要添加；替换后的 service 需要补 `foregroundServiceType=0x40000000`。

## 5. 登录与完整性检查

- 官方签名证书未变，现有 `TapSignKit.getSign()` 回灌原证书 MD5 的策略可复用。
- `ClientLoginUtils.isClientLogin(Activity, Actions)` 仍存在，当前类路径是 `com/taptap/sdk/login/impl/utils/ClientLoginUtils`，继续强制 WebLogin。
- 未发现 `com.actk`、TSS、ACE、tprt、tersafe、kwprotect 等已知强制完整性组件；当前样本没有可直接证明会阻断外科包的检测点。
- TapTap SDK 和支付 SDK 内存在通用安全/完整性类，但在本版未形成已确认的游戏启动阻断点。该结论限于当前样本，不代表运行期无服务端校验。

## 6. 本版构建方案

1. 更新 `ZjmcMod.cpp` 中原四功能的 13 个 Hook / 辅助 RVA 常量，并新增免广告 Hook。
2. 不新增 dex，将星光 smali 合并进官方 `classes6.dex`。
3. 只 patch `classes3.dex` 的 Unity Activity 注入点和 `classes5.dex` 的 TapTap 登录绕过。
4. 替换 Manifest service 槽为 33 字符 `MenuService`，插入 `StarryApp`、`FOREGROUND_SERVICE_SPECIAL_USE` 和 service `foregroundServiceType=specialUse`；保留 `resources.arsc`。
5. 用官方原包做外科底包，保留未修改 dex、`resources.arsc` 和游戏 so；新增 `libstarry_magic.so`。
6. 装机前确认：包内 so 标签为 `[Zjmc]`、包内 so 与构建产物 MD5 一致、Manifest aapt 树只有预期变更、`resources.arsc` 字节未变。
