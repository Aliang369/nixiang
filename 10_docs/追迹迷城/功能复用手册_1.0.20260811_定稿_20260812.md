## 1. 菜单功能（定稿）

| feat | 名称 | Hook | 行为 |
|------|------|------|------|
| 1 | 秒杀 | `Monster.ChangeHP` | `hp < 0` → `-999999` |
| 2 | 无敌 | `LocalPlayer.ChangeHP` | `hp < 0` → `0` |
| 3 | 全屏秒杀 | `BattleManager.Update` | 调 `GetCurWaveAliveEnemyList`，对列表怪 `ChangeHP(-999999)` |
| 4 | 无限技能 | 一组 bool 闸门 | 开时强制 `return true` |

引擎：Unity IL2CPP，**AOT 有符号**（非 HybridCLR）。`ELF bias = +0x4000`（`RVA = file_off + 0x4000`）。

命名空间：`Teamelo.ActionEngine`。

## 3. 登录 / 过签（必做）

| 项 | 值 |
|----|-----|
| 原版 cert MD5（TapSign） | `4684a2b2249e978c74230f8895635894` |
| SignSpoof | Activity `onCreate` 尽早 `install` |
| **强制网页登录** | `com.taptap.sdk.login.impl.utils.ClientLoginUtils.isClientLogin(Activity, Actions)` → 恒 `false` |
| 正式签 | `01_tools/starry_release.jks`（勿 Debug） |

有 TapTap 客户端时默认走 Client SSO，**改签必挂**；必须 force WebLogin（见 `TapTap登录_强制网页_20260812.md`）。本包无旧版 `ClientLoginHandler`，只改 Utils 即可。

另有 ACTk / Genuine：过签勿只信 PM 签名（大更时再扫）。

## 4. 游戏更新后怎么复用

1. `Android.mk` → `STARRY_GAME_ZJMC` + `STARRY_AUTH_GAME_ID=zjmc` + `Games/ZjmcMod.cpp`
2. 新包跑 Il2CppDumper，按类/方法名重算上表 12 个 RVA（含 `GetCurWaveAliveEnemyList`）
3. 核对 TapSign MD5、是否仍有 `ClientLoginUtils.isClientLogin`
4. 整包：`surgical_zjmc_*.sh`（禁止 `inject_zjmc` 对游戏 `apktool b`）；只改 native 可另做 `zjmc_so_only.sh`
5. log：`auth game_id synced from native: zjmc`、`[Zjmc] 初始化成功`
