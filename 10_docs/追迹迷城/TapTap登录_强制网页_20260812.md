# 追迹迷城 — TapTap 登录强制网页（2026-08-12）

## 现象

改签星光包后无法登录：本机装有 TapTap 客户端时走 **Client SSO**，签名与原版不一致 → 失败。  
用户反馈：**不是**强制网页登录。

## 原因

新版 SDK（本包）路径：

- `com.taptap.sdk.login.impl.utils.ClientLoginUtils.isClientLogin(Activity, Actions)`  
  用 `Intent.resolveActivity` 判断是否能拉起 TapTap → 有客户端则 `true`
- `LoginTypes.Companion.from` → `CLIENT` → `ClientLoginFragment`

旧消消英雄2 用的是 `internal.util.ClientLoginUtils` + `ClientLoginHandler`；追迹迷城 **没有** 那套 Handler，只改 TapSign 不够。

## 修法

`inject_zjmc_1.0.20260811.sh`：`isClientLogin` 恒返回 `false` → `LoginTypes.WEB` → `WebLoginFragment`。

仍保留：TapSignKit.getSign → 原版 MD5 `4684a2b2249e978c74230f8895635894` + SignSpoof。

## 构建

```bash
# Android.mk 已切 zjmc
STARRY_INSTALL=1 bash mod菜单/starry-mod-menu/scripts/inject_zjmc_1.0.20260811.sh
```

登录应出现 **网页/内嵌 WebView**，不再跳转 TapTap App SSO。
