# 追迹迷城 · 签名与安装（高风险）

## 原因

`uber-apk-signer` 默认 **Android Debug** 证书。ColorOS / 安装器会标「高风险应用」并拒绝手动安装。

## 处理

- 仓内正式签名：`01_tools/starry_release.jks`（CN=StarryMagic）
- 注入脚本默认用该 keystore；环境变量可覆盖：`STARRY_KS` / `STARRY_KS_ALIAS` / `STARRY_KS_PASS`
- 真机装机：`su -c 'pm install -r -d -g --user 0 …'`（绕过安装器 UI）

成品：`08_output/追迹迷城/追迹迷城_1.0.20260811_starry-releaseSigned.apk`
