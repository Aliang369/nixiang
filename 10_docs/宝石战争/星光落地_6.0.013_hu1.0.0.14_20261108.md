```
pull(真机 base.apk + 外部 HotUpdate 增量)          # 手工等价 pull_bszz_current.sh；该脚本要求

```

- **底包来源变化**：历史上底包是 TapTap 官方原版；本轮按用户口径改用**真机已装成品包**
  （含 classes3/4.dex、libstarry_magic.so、已注入补丁的 Network DLL、已改 AndroidManifest）。
  因此 `surgical_hotupdate_only` 的 `untouched` 断言等于「与底包逐字节相同」，只证明**本轮没动这些项**，
  不证明它们等于官方原件 —— 这一点与 10-30 轮（底包为官方原版）不同，登记为边界。
- **dex/so 未重编**：`mod菜单/` 自 10-30 起无 bszz 相关源码变更（近期改动集中在 Dwdlm/Sf3g），
  本轮变量单一（只换热更），沿用底包内 10-30 构建产物。
- **外部 HotUpdate 清理**：装机后主动删掉设备外部 `files/HotUpdate`（9 个文件）。理由：其中
  `System.Network.dll.bytes` 是**官方未补丁**版本，运行时会覆盖包内补丁（1.0.0.06 事故同型）。
  包内已内嵌 1.0.0.14 全量，删除后游戏按包内版本判定无需下载，实测保持 0 文件。
