## 6. 登录卡死二次修复（2026-09-20）

### 6.1 真正根因

上一版 APK 把包内 `assets/Android/manifest.json` 改成了 `1.0.0.01` 的补丁版本，
但包内 87 个 Unity3d resources 仍是旧资源。热更管理器只比较“包内 manifest 声明”和
“服务端 manifest”，不校验包内 Unity3d 实际 hash，因此判定所有资源已存在并跳过下载。

实锤差异：

| 资源 | 旧包实际值 | 1.0.0.01 清单要求 |
|---|---:|---:|
| `Android/Main.unity3d` | 70,742,138 B，md5 `19cbffde…` | 26,294 B，md5 `f9a53005…` |
| `Android/Dlls/System.Platform.dll.bytes` | md5 `47129196…` | md5 `97a3e275…` |
| HotUpdate 文件数 | 包内仅 87 个 Unity3d | 142 个全量文件，439,377,833 B |

登录日志已到 `U8SDK onAuthResult / Login Success`，但 Unity 启动页不再前进。

### 6.2 修复策略

1. 从 `https://bszzcdn.acingame.com/gow/HotUpdate/1.0.0.01/` 下载清单中的 142 个文件，
   逐文件校验 size + md5。
2. 外科替换 APK 内全部 `assets/Android/*`，不再混用旧资源。
3. 包内 `manifest.json` 与 `RuntimeAssembliesReceipt.json` 保持官方 `1.0.0.01` 值，
   防止热更将补丁 DLL 当作旧文件重新下载。
4. 仅替换 `assets/Android/Dlls/System.Network.dll.bytes` 为星光注入版。
