# 独奏骑士 · 技能先例（dex-only「菜单源码换新」）

> 用途：本文件承接从 `skill/starry-mod/SKILL.md` 迁出的**单游戏实例细节**（技能只留通用机制，实例落本文件）。

> 通用机制（先证 native 面没动、再外科置换唯一 `classesN.dex`、两个必踩坑）见 `skill/starry-mod/SKILL.md`「存量游戏快速重打」。

## 六段脚本的实际形态（本游戏版）

1. **底包校验**：zip 结构 + `classes2.dex` 内含 `StarryApp`（单 dex 官包 ⇒ 星光 dex 落 `classes2.dex`）。
2. **取新 dex**：HEAD `./gradlew assembleRelease --offline`。
3. **宿主改写**：`apktool d` 后改 `StarryApp.smali` 四处 —— `.super` / `<init>` / `attachBaseContext` / `onCreate` → `Lcom/sgsdk/core/SGGlobalApplication;`。
4. **汇编 + 断言**：`smali assemble` 出新 dex，断言之。
5. **外科置换**：只换 `classes2.dex`，逐条目 sha256 审计 + **so 与底包逐字节相同**断言。
6. **签名与门禁**：`zipalign` / `apksigner` + 证书钉 + 门禁 + 可选装机。

## 反例记录（本游戏暴露的真实缺陷）

- 旧 dex 只有 **v5 SSAID 单路径**，SSAID 不可用即抛错 ⇒ **菜单整块不可用**。
- 换新后 `DeviceFingerprint.getOrCreateDeviceId()` 变 **v5 优先 + v4 硬件指纹兜底**。
- 推论（通用）：凡是「取号 / 授权类」的单点路径，都要检查有没有兜底分支（该推论已在技能侧保留）。
