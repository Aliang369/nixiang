## 构建

```bash
# Android.mk 已切 STARRY_GAME_NEON / STARRY_AUTH_GAME_ID=neon
STARRY_INSTALL=1 bash mod菜单/starry-mod-menu/scripts/inject_neon_3.2.860_jiuyou.sh
```

| 脚本 | 何时用 |
|------|--------|
| `inject_neon_3.2.860_jiuyou.sh` | 九游正式包 / 改菜单·smali |
| `inject_neon_3.2.860.sh` | TapTap 渠道 |
| `neon_so_only.sh` | 只改 `NeonMod.cpp`（两渠道 RVA 相同时可共用 so） |

装机后看：`auth game_id synced from native: neon`、`StarrySignSpoof installed pkgs=…aligames`、`[Neon] 初始化成功`。

**注意**：apktool 拆 dex 必须连续 `classes`/`classes2`/`classes3`（不可直接跳到 classes5，否则 starry smali 不加载会闪退）。

## 菜单无悬浮窗授权（斌哥对照）

详见同目录 `斌哥菜单_无悬浮窗权限实现_20260812.md`。本轮结论：无权限 Activity/Decor 路径对 HTML 菜单太脆（切屏 / 穿透 / 闪退），已恢复为**仅 TYPE_APPLICATION_OVERLAY**（需给悬浮窗权限；装机脚本 root `appops allow`）。等原生菜单再议无授权方案。
