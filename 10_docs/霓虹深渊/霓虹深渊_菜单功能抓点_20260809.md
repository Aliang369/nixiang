### Starry 移植建议（无敌 / 秒杀）

不必搬 `libSDKloading`；用星光菜单两个 Bool，直接 Hook 已确认 RVA：

| 功能 | Hook | 建议逻辑 |
|------|------|----------|
| **无敌**（玩家免伤） | `Hearts.DeductHP` @ `0x3544DCC` | 开时直接 `return false` / 不扣心；可选同步写 `isInvincible`（字段 `0x148`）或 `UnKillable` |
| **秒杀**（怪秒死） | `HitPoints.DeductHP` @ `0x34697C0` | 开时把伤害放大 / `CurrentHp→0` / 强制走致死分支；注意只打怪物 `HitPoints`，勿误伤玩家 `Hearts` |
| **过检（必做）** | `DbgPoint.BuildPassCheckInfo` @ `0x3674A38` | 与战斗同批移植；旁路/改写通关校验组装，避免原包自签或完整性上报失败。星光注入后必须挂此点，非可选 |

实现要点：

1. 用 `Il2CppResolver` / `DobbyHook`（或星光现有 IL2CPP hook）按 **RVA** 挂接，版本 `3.2.845`。  
2. 菜单 Bool 本地保存即可（不必复刻 prefs `"0"`/`"1"` 键名，除非要兼容斌哥存档）。  
3. 先验证战斗局内：开无敌挨打不掉心；开秒杀怪一击死。  
4. `DoDeductHP` / `MultiDeductHP` / `FixDeductHpValue` 为同簇后备，主路径优先两个 override `DeductHP`。
