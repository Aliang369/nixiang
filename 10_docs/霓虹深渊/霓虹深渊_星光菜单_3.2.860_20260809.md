## 构建方式

整仓约定见根目录 **`WORKFLOW.md` 阶段 6b**（勿把流程只写在本笔记）。

| 脚本 | 何时用 |
|------|--------|
| **`surgical_neon_3.2.860.sh`** | **首选**：新版原生菜单（无 `assets/web`），外科 zip 合并 |
| `neon_so_only.sh` | 只改 `NeonMod.cpp` 等 native（底包须已是外科成品） |
| `inject_neon_3.2.860.sh` | 遗留整包 apktool 重建（不推荐；易慢/易踩 dex 限制） |

```bash
# 首包 / 菜单升级
bash mod菜单/starry-mod-menu/scripts/surgical_neon_3.2.860.sh
STARRY_INSTALL=1 bash mod菜单/starry-mod-menu/scripts/surgical_neon_3.2.860.sh

# 仅 native
STARRY_INSTALL=1 bash mod菜单/starry-mod-menu/scripts/neon_so_only.sh
```

签名：默认 **uber-apk-signer 内置 debug 证书**（与旧 inject 包一致，可覆盖安装）。自定义 keystore：`NEON_SIGN_KS=/path/to.jks`。
