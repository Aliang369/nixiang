## 3. 引擎与保护

- Unity **2022.3.62f2c1**，标准 **AOT IL2CPP**（无 HybridCLR 热更 DLL 路线）。
- 业务逻辑在 AOT `Assembly-CSharp`（image 索引 1）。
- `libil2cpp.so` 体量 66MB 级，符号与注册表有保护/混淆：Il2CppDumper、Cpp2IL 自动流程**均未找到** CodeRegistration/MetadataRegistration。
- `global-metadata.dat`（包内）头部伪标 v16，实际按 v31 解析；字符串池做了轻量混淆（每个 4 字节块有字节被替换）。**不要用字符串区间删除法**（已证实会产生 duplicate key）。
- 游戏运行时会自行解码元数据，落盘在设备：
  `/storage/emulated/0/Android/data/com.qxjc.fcxyxzj/files/il2cpp/Metadata/global-metadata.dat`
  → 已由运行时 dump 得到可用版本（11,833,344B），`MetaInspector` 可解析：images 88 / types 12,863 / methods 100,774 / fields 55,893。

## 4. 运行时可用的 IL2CPP API（实测）

可用（Frida 枚举 + 调用正常）：`il2cpp_domain_get`、`il2cpp_thread_attach`、`il2cpp_domain_get_assemblies`、`il2cpp_class_get_name`、`il2cpp_class_get_fields`、`il2cpp_class_get_methods`、`il2cpp_field_get_offset`、`il2cpp_method_get_name`、`il2cpp_runtime_invoke`。

可疑（枚举到的地址调用返回空/异常，**不可信**）：`il2cpp_image_get_name`、`il2cpp_assembly_get_image`、`il2cpp_class_from_name`、`il2cpp_class_get_method_from_name`。
→ 处置：正规解析 `DT_SYMTAB` / `DT_STRTAB` / `DT_HASH` 自行还原符号地址，或改用已确认可用的 image/class 枚举路径。

ELF 动态段实测：`DT_SYMTAB=0x4b8`、`DT_STRTAB=0x13f50`、`DT_STRSZ=111855`、`DT_HASH=0xe588`。

## 6. 风险与边界

1. **签名**：改包必须重签（自签 CN=StarryMagic）。TapTap SSO 可能校验签名 → 需 `SignSpoof` 或网页登录兜底；`libthemis-v8.so` 含安全/反调试/异常上报能力，是否会因改包触发**尚未证实**。
2. **云存档**：TapTap 云存档可能回写本地存档，需先确认触发条件。
3. **未授权项**：不卸载、不清数据；覆盖安装若因签名冲突失败，先报告再定。
