### 5.6 解析面真实落地：`Api::ImageOf` 静默失败与三级兜底（2026-10-10 第二轮，**必读**）

§5.3 的结论「by-name 解析在本版不存在已知阻塞」**实测被推翻**：装机后七项一个都没装上，`[mrfzz] status hooked=0/7 assemblies=88 entity=0x0`。

判据（可复现的三步）：
```bash

LC_ALL=C grep -acF '[Il2Cpp] ImageOf asm=' <so>                       # 1 ⇒ 串在
# ② 但整份 logcat 里它一次都没出现 ⇒ 死在日志之前的静默守卫
```

源码口径（`mod菜单/starry-mod-menu/app/src/main/jni/Unity/Il2CppApi.cpp:992-1020`）——`Api::ImageOf` 在自己日志之前有三道**只 return 不报错**的守卫：
1. `if (!assembly || !IsValidHeapPtr(assembly)) return nullptr;`
