## 六、本轮踩坑与修法（可复用）

1. **★gradle 白包不含星光 so（rc=11 事故，根因级）**：AGP 的 jniLibs 默认源目录只有 `app/src/main/jniLibs`，**该目录不存在时 gradle 静默编出不含 so 的白包**；而 `fkssj_build_so.sh` 原同步循环 `[[ -d "$d" ]] || continue`（不 mkdir）⇒ 静默跳过却仍打印「jniLibs 已同步」，属**假成功**。
   **修法**：`JNI_DIR=…/jniLibs/arm64-v8a; mkdir -p "$JNI_DIR"` 强制存在 + 两条硬门禁（`-f` 在位、md5 == 构建产物）。`04_scripts/仙逆/xnbz_build_so.sh:73-85` 同源潜在缺陷。
2. **★sign 的 dex 归属断言恒假**：原写 `grep -aq "Fkssj" classes5.dex`，但 **`[Fkssj]` 是 native so 的日志标签，dex 里根本没有**（实测 `Fkssj`=0、`fkssj`=1 且落在包名串内、`FKSJ`=2）。
   **修法**：改查 **dex 是否字面携带官方 changwan 证书 base64 前缀**（由底包 `META-INF/*.RSA` → `openssl pkcs7` → `x509 -outform DER` → base64 现场提取，不写死），实测命中 1 次 —— 本作独有、别的游戏 dex 不可能有，且与 so 的 `[Fkssj]` 互补。对照 `04_scripts/仙逆/xnbz_sign.sh:146` 只查 so 标签，dex 侧不查。
3. **pipeline.json 三坑**（`04_scripts/疯狂水世界/pipeline.json`）：① stage `inputs` 必须是 **`{绝对路径: md5}` 字典**（`04_scripts/pipeline.sh:288 _stale_inputs` 用 `.items()`，写成 list 直接 `AttributeError`）；② 所有 `inputs`/`verify.path` **必须绝对**（`pipeline.sh:251,267-268` 相对路径会并到 workdir 下 ⇒ 误判「上游已更新，本阶段过期」）；③ stage `command` 以 `cwd=workdir` 执行 ⇒ 必须写 `bash "$NIXIANG/04_scripts/..."`，写仓库相对路径会 rc=127。
4. **★预检崩溃误报（已修共享脚本）**：native 侧致命信号兜底装处理器会打 `[Fkssj] fault guard armed (SIGSEGV/SIGBUS/SIGILL, altstack=65536)`，含**裸 SIGSEGV** 且带本进程 pid，连进程范围校验也拦不住 ⇒ 每次预检都误判「运行中崩溃」。该行是**所有星光改包游戏**共有的初始化日志。
   **修法**：`04_scripts/_common/post_install_precheck.sh` 的 `RE_CRASH_IGNORE` 全局加入 `fault guard armed`（附 2026-10-12 教训注释），并为本作建了 `10_docs/疯狂水世界/预检标记.txt`。
5. **surgical 脚本细节**：`zip -u` 按 mtime 判是否覆盖 ⇒ 暂存树必须 `find … -exec touch {} +` 先刷 mtime，否则**静默跳过且 rc=0**；`grep -q`/`awk exit` 会给上游 `unzip` 发 SIGPIPE，在 `set -o pipefail` 下变假阴性 ⇒ 条目清单先落盘再判、awk 内禁 `exit`。
6. `pm uninstall -k`（保留数据）与 `pm uninstall`（清数据）二选一由**用户授权决定**；本轮机型为小米真机、渠道原版（H7），用户选择**清数据**。

## 七、留待阶段②（需用户放行口令）

- 三功能 = 【无敌】【伤害倍率】【战斗加速】（H5）。当前 `Games/FkssjMod.cpp` 为**零 hook 环境版**：`kSlots[]` 空表 + `HookSlotInstall` 桩，开关只写日志、不动游戏（H2 设计，非遗漏）。
