## 三、项目政策约束（AGENTS.md，同等强制）

- **P-APK**：APK 一律不留本地（官方包 / 渠道包 / 上一轮星光包均可再生）；用完即删，只在 `10_docs/_state/底包再获取台账.md` 登记「包名 + 版本 + 体积 + md5/sha256 + 再获取路径」。构建产物（NDK 中间件、暂存 so、Gradle 输出、脚本缓存）收尾清理。
- **P-NOSCR**：真机交互零截图。禁 `screencap`、禁 `adb input tap` 猜坐标；**所有点按输入由用户手动完成**；需要用户操作时出「操作请求卡」三项。
- **P-MECH**：机械操作一律走该游戏脚本（`04_scripts/疯狂水世界/*.sh`、`mod菜单/starry-mod-menu/scripts/surgical_fkssj_1.11.6.sh`）；禁手敲 adb / apktool / zip / ndk-build。
- **P-GATE**：装机前必过 `04_scripts/_common/pre_install_gate.sh`；装机后 `verify_installed_apk.sh` 校验设备包 md5 == 本地产物。
- **P-WAIT**：装机后停下等用户反馈；人不测完不许改代码、不许基于「日志里还没出现 X」幻想出错。
- **P-SHARE**：共享文件（`sign/SignSpoof.java`、`sign/TapLoginForceWeb.java`、`_state/current.md`、`_state/底包再获取台账.md`）禁路径级 `git add`，须 `stage_shared_file.py` 内容级暂存 + `archive_scoped_git.sh --staged-only`。
- **P-DEL**：删除禁通配符；先核实解析后的绝对路径是目标本身。
- **P-DOC**：用户「必须/禁止」原话当轮落盘（本文件）；收尾走 `finalize_game_delivery.sh` + `archive_scoped_git.sh`（含推送）。
