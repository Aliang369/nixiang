# 伯吉的温馨厨房 — 初判与可改点（2026-08-27）

## 1. 样本

| 项 | 证据 |
|---|---|
| 真机包名 | `com.hnyg.bjdwxcf.topon`（aapt label：伯吉的温馨厨房） |
| 版本 | `1.0.1` / versionCode `1` |
| Application | `com.mar.sdk.MARApplication` |
| 启动链 | MAR 权限页 → TapTap 登录 → Unity |
| 引擎 | `libil2cpp.so` + `global-metadata.dat`（Metadata/Il2Cpp v31） |
| 热更 | DummyDll **无** HybridCLR / `*.dll.bytes` → **AOT IL2CPP** |
| 保护 so | 无 `libtersafe2` / `libtprt` / `libbaiduprotect` / `libqkcheck` |
| 广告 | 穿山甲 Pangle + TopOn 痕迹 + 广点通 + TapAD + 友盟 |
| 登录 | TapTap SDK（`libtapsdkcore.so` / Themis） |
| 斌哥包 | 否 |

Il2CppDumper 有 `JNI_OnLoad / may be protected` 警告，但 dump 成功，玩法类齐全。

## 2. 存档与在线边界

核心经济结构 `SteamCloudPrefs`（字段含 `currentCoins` / `unlockables` / `adCoupons` / `cardList` 等），本地文件名：

- `SteamCloud_Burgies.sav`
- `SteamCloud_Burgies_Autosave.sav`

经 `SaveLoadFile` 序列化；`SaveManager` 读写 `SaveableData` 枚举。

**云存档风险（⚠️ 待验证）**：`MarsSdkService` 有 `CloudSaveEnvelope` / `ProcessCloudQueue` / `UploadAfterDebounce`，改本地后可能被云端覆盖或上传。排行榜 URL（`SetBurgerScore` 等）偏成绩展示，不像战斗服权威结算。

真机当前未见 `.sav`（进度浅，仅 PlayerPrefs 设置项）。

## 3. 推荐可改点（按价值）

### A. 货币（金币）— 高优先

| 挂点 | RVA（dump） | 说明 |
|---|---|---|
| `UnlockableSystem.set_currentCoins` | `0x16C05D0` | 直接改余额字段 `_currentCoins` @0x40 |
| `UnlockableSystem.AddCoins` | `0x16C087C` | 加钱入口 |
| `UnlockableSystem.SustractCoins` | `0x16C0A04` | 扣钱入口（商店消费） |
| `SaveableData.CurrentCoins = 2` | — | 持久化键 |

UI：`UICoinManager.UpdateCurrentCoinsText`。柜台上展示用 `CounterCoins`（物理硬币模型，非钱包本体）。

商店计价：`UIShopItem.CanAfford` / `ConsumeCost`；货币类型 `Coins` 或 `AdCoupons`。

### B. 全解锁（厨具/配料/装饰）— 高优先

`UnlockableSystem`：

- `UnlockItem(Unlockable)` RVA `0x16C0E28`
- `IsUnlocked` / `LockItem` / `HasUnlockedEverything`

`Unlockable` 枚举（节选）：Bun/Meat/FryingPan/Tomato/Lettuce/Onion/Cheese/Vegan、Grill/GrillTurbo、Cards/CardAlbum、各酱料、DrinkMachine/Cola/Lemon/Orange 等。

存档字段：`SaveableData.Unlockables`、`SteamCloudPrefs.unlockables`。

### C. 广告 / 激励奖励 — 高优先（手游渠道核心）

`AdRewardSystem`（静态）：

| 能力 | 常量/方法 |
|---|---|
| 永久免广告 | `GrantPermanentAdFree` RVA `0x16333C0`；看 15 次解锁（`AdFreeWatchRequirement=15`） |
| 发广告券 | `GrantAdCoupons` |
| 券兑金币 | `TryRedeemAdCouponForCoins`（`CoinValuePerAdCoupon=50`） |
| 跳过广告发奖 | `GrantAdFreeReward` / `CanClaimRewardWithoutAd` |
| 顾客双倍小费 | `CustomerDoubleReward`，时长 900s |
| 立即补货 | `InstantKitchenRestock` |

`AdRewardType`：`AdCoupon=0` / `CustomerDoubleReward=1` / `InstantKitchenRestock=2`。

渠道桥：`MarsSdkService.TryShowRewarded` → `CompleteReward`；另有插屏 `TryShowInterstitial` / `SimulateInterstitialCloseNextFrame`（可模拟关闭）。

UI：`UIExtraMealCanvas`、`AdsPanel`、`UiCanvas_RewardVideo`、`GetRewardCanvas`。

### D. 卡片收集 — 中优先

- `CardSaveData.AddCardAsOwned` / `CardInfo.isOwned`
- 稀有度：`Common` / `Rare` / `Golden`
- 存档：`SaveableData.CardList`、`SteamCloudPrefs.cardList`
- 需先解锁 `Unlockable.Cards` / `CardAlbum`

### E. 商店免花 / 券购 — 中优先

- `UIShopItem.CanAfford` → 恒 true，或 `ConsumeCost` 空操作
- 字符串字面量有 `1000coins` / `2000coins` / `5000coins`（广告/内购相关礼包文案）

### F. QoL（经营向）— 中低

| 方向 | 线索 |
|---|---|
| 补货 | `RestockButton` / `GrabbableItemsRestocker` / 广告奖 `InstantKitchenRestock` |
| 双倍顾客付款 | `AdRewardSystem.CustomerRewardMultiplier` + `CounterCoins.DisplayCustomerPayment` |
| 季节 | `GameSeason`：Normal / Halloween / Christmas（`GameManager`） |
| 模式 | `Gamemode`：Tutorial / Frenetic / Normal / Pomodoro |
| 任务 | `MissionManager` + `SaveableData.CurrentMission` |
| 加速 | Unity `Time.timeScale`（通用，需评估广告/SDK） |

### G. 不优先 / 慎改

| 项 | 原因 |
|---|---|
| CDK 兑换码 `CDKCanvas` → `MarsRedeemResult` | 渠道服务端校验 |
| Halloween DLC `UIPurchaseHalloweenDLC` | 可能走商店/渠道支付 |
| 排行榜 `ScoreDisplayer` / `URLs.SetBurgerScore` | 服务端成绩，改本地无奖励意义 |
| `UI_Cheat_Mobile` | 名含 Cheat，实际是移动端 UI 适配，非内置金手指 |
| 聊天指令 `CommandManager` | 顾客点单语义，不是作弊指令 |

## 4. 实现路径建议（尚未动手）

1. **首选**：自注入 `libstarry_magic.so` + Dobby hook `UnlockableSystem` / `AdRewardSystem`（本仓标准）。
2. 短探针：无 ACE，Florida 短挂可行，但仍优先自注入。
3. 首包：外科 zip（禁止对游戏包 `apktool b`）；Application 需继承 `MARApplication`（落地时再定）。
4. TapTap 改签：按 `skill/re-analyze/login/taptap-web-login.md` + SignSpoof。
5. 落地前必做：Trace 证实 `AddCoins`/`UnlockItem`/`GrantReward` 命中；再评估云存档是否回滚。
