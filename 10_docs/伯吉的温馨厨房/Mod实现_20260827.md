## 推荐使用顺序（用户实测有效）

1. 启动游戏到**开始/主菜单界面**（尚未进厨房）
2. 开星光菜单 → 开启「无限金币」/「无限广告券」
3. **再点进入游戏**
4. HUD 加载时会走 `GetSavedInt` + `UpdateCurrentCoinsText`，被动 hook 生效 → 显示 999999 / 9999

⚠️ 若**先进游戏再开开关**，HUD 不会立刻刷新（游戏不再调 UI）；需退出到开始界面重进，或完全重启游戏。

**Trace 实锤（2026-08-27 18:50 log）：**

| 观察 | 日志 |
|---|---|
| 进游戏广告券 9999 | `GetSavedInt key=13 orig=9999` **开关未开** — 是存档里已有 9999，不是 mod 即时生效 |
| 金币 HUD 200 | `UpdateCurrentCoinsText hits=1 newCoinValue=200` 仅加载时一次 |
| 开无限金币后内存已改 | `fieldCoins=999999`，但 **UpdateCurrentCoinsText 未再调用** |
| UI 不读 getter | `get_currentCoins hits=0` 全程未命中 |

**反复闪退根因（v8–v10）：** 开开关时在 **菜单 Java 线程** native 调 `UpdateCurrentCoinsText` / `set_currentCoins`（`method=nullptr` 或错误线程）→ 必崩。

**v11 硬规则：**
- `OnFeatureChanged` **只改 atomic 标志**，不碰游戏对象、不调 IL2CPP、不 hook UI 文本
- 字段写入仅在 `Tick` / 游戏 hook 回调内
- 功能靠 `CanAfford` + 跳过 `ConsumeCost` + `SubtractCoins` 空操作（v7 已验证稳定）
**v12 被动 HUD（2026-08-27）：**
- 仅 hook `UpdateCurrentCoinsText` / DOTween 起始 closure，游戏自己刷新 UI 时改显示为 999999
- **仍禁止**开开关时 native 调 UI（v8–v11 闪退根因）
- **用法：** 开始界面开无限金币 → 再进游戏 → HUD 显示 999999（用户实测）；中途开开关需退回开始界面重进
