## 三、签名校验与强制网页登录

- **实际症状**：本作「签名校验」不是游戏侧校验（`dump.cs` 内 `getPackageInfo`/`PackageManager` 命中 0；`classes.dex` 无 `GET_SIGNATURES`/`checkSignatures`），而是 TapTap 客户端 SSO 的 `signature not match`，与 Phigros 同构。
- **签名伪装**：`com.starry.magic.sign.SignSpoof` 假证书表新增本作（证书 DER = 官方 `O=tianyu`，MD5 `364ce198321c256af2df5f930c01deda`）。实测 `StarrySignSpoof: spoof hit pkg=com.aiyue.wscq md5=364ce198321c256af2df5f930c01deda` ✓
- **强制网页登录**：`TapLoginForceWeb` 白名单加入 `com.aiyue.wscq`；外科阶段把 `yntt_smali/com/starry/magic/sign/YnttLoginRequest(.$1).smali` 合入星光 dex。原理 = 在 `TapTapActivity.onCreate` 之前把 intent extra `"request"` 换成 `YnttLoginRequest`（其 `getRequestCode()` 恒抛 `IllegalStateException`）→ `LoginClient.sendLoginRequest` 走 catch → 官方 `WebViewHandler.authorize()` **包内内嵌网页登录**，不进 TapTap 客户端、不触发签名校验。
- 实测 `MenuService: activity-resumed:TapTapActivity → show ACTIVITY overlay host=TapTapActivity`：TapTap 登录 Activity 在**本进程内**起来（未跳客户端）✓

## 四、实施要点与坑（复现必读）

1. ★ **新增 smali 的 dex 名必须是 base.apk 中「最小空闲下标」**。官包是单 dex（只有 `classes.dex`），第一次误用 `classes8.dex` → ART 的 `BaseDexClassLoader` 从 `classes.dex` 顺序扫到第一个缺口即停止 → `RuntimeException: Unable to get provider com.starry.magic.StarryInitProvider: ClassNotFoundException` **启动即崩**。脚本已参数化 `DEX_NAME`（本作 = `classes2.dex`），`wscq_sign.sh` 按「最大下标 + 无缺口断言」复核。
2. **官包无 ACE/libtprt.so** → `Android_wscq.mk` 必须含 `Games/NoAceStubs.cpp`（补偿 `SignalQuarantine_Start` / `FgoBoot_InjectEarlyFromOnLoad`），否则 `ld.lld: undefined symbol`。
3. **模块内部日志 tag 是 `Mod_Menu`**（`Includes/Logger.h` 的 `#define TAG OBFUSCATE("Mod_Menu")`），菜单/桥接日志才是 `StarryMagic`。抓 hook 日志必须 `adb logcat -s Mod_Menu:V`，只盯 `StarryMagic` 会误判「钩子没装」。
4. **不调 orig 的钩子槽也必须给非空 `origPtr`**（`HookSlotInstall` 幂等判据 = `s.origPtr && *s.origPtr`），否则每 Tick 重复 DobbyHook 同一地址 → 叠钩 SIGSEGV。本作 AntiSpeed/Ban1/Ban2 三槽各有专用 `g_orig*` 变量。
5. **冒烟开关**：`WSCQ_SMOKE_ALL_ON=1`（`Android_wscq.mk` `ifdef` → `-DWSCQ_SMOKE_ALL_ON=1`，`wscq_build_so.sh` 已把该变量纳入 CFG_HASH）会让 5 功能启动即 ON，仅供「钩子能否装上」的实机验证；**正式包已断言 so 内无 `SMOKE ALL-ON` 串**。
6. 全部钩子**懒装**（默认 0 hook）：开关 ON 才 `SyncHooks()`，`Tick` 只同步状态 + 兜底安装。
7. 装机需卸载官方包（签名冲突 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，破坏性，须用户确认）；装后另跑 `appops set com.aiyue.wscq SYSTEM_ALERT_WINDOW allow`（悬浮球必需）。
