## 2. 壳结构（对复刻有用）

- 开关链：菜单 WebView `Changes(n,true)` → prefs `com.aiyue.wscq_preferences.xml` boolean → **壳数据段旗标字节** → Dobby 跳桩内 `ldrb` 读旗标决定分支。
- 跳桩形态（每处 hook 把目标函数前 12 字节替换为）：
  ```
  ADRP X17, <shell_rx 页>   ; ADD X17, X17, #imm   ; BR X17
  ```
  本次 15 个跳桩的 trampoline 全部落在 **`0x782C391014 ~ 0x782C3921FC`**（libSDKloading r-xp 内）。
- trampoline 逻辑：读旗标 → 命中则记日志（`[圣翼…]`）并改参/改行为 → 调**原函数**（原函数指针表在壳 BSS `0x782D789A70…0x782D78AC0`，形如 `ldr x8,[x8,#0xa78]`）。
- 壳自身诊断串暴露了全部语义（`sdk_rx_1.bin` 内），本次已据此一一对上（见 §4/§5 的「壳内日志」列）。
- 无中文符号（`llvm-nm -D` 2797 个定义符号全 ASCII）→ 历史阿瓦隆那条「符号表露中文桩名」捷径**在本变体不成立**。

### 机制细节（反汇编实证）
- **功能1 百倍伤害**：`0x782C391074` 起 —— `ldrb w8,[0x782D7664E0]`；`mov w9,#0x64; mul x9,x1,x9`（×100）；条件 `flag!=0 && 伤害>0` 时 `csel x19,x9,x1`，把 `x1`（bloodNum）换成 ×100 后传给原函数；命中/未命中分别打 `[圣翼]怪 伤害 %lld -> %lld 已改(第%d条)` / `未改(开关关, 第%d条)`（节流上限 15 条）。
- **功能2 玩家无敌**：`0x782C3912B4` —— 读 `0x782D7664E4`；`fcmp s0,#0.0; cset w9,mi`（HurtNum<0）与旗标取与 → `fcsel s8,s1,s0,ne`，`s1=0`，即**把负伤害改判为 0**，再 `br x3` 回原函数。
- **功能3 战斗速度**：`Time::set_timeScale` 桩把传入 timeScale 换成设定倍数；`PlayerCtr::FixedUpdate` 桩做**心跳主动钉住**（游戏战斗中不主动调 set_timeScale，故必须心跳），日志 `[圣翼速度] 心跳钉住: timeScale %.2f -> %.0f`。
- **功能4 刷怪**：`EnemiesCtr::FixedUpdate` 把刷怪倒计时钉 0（日志 `[圣翼刷怪] 小怪倒计时 %.2f -> 0 (仍受同屏上限约束)`）；`复活BOSS` 走「**借复活CD**」：写 `-1` → 调原函数 → 还原原值，并带「上次借的 CD 没还成则补还」的异常分支（日志 `[圣翼刷怪] BOSS复活CD 借用: %.0f -> -1 -> 已还原 %.0f`）。
- **功能5 全屏秒杀** = **活体登记表 + 伤害扩散**：
  - `EnemyCtr2::FixedUpdate()` 桩（`0x782C3916CC`）**无条件**维护登记表：指针数组基址 `0x782D78A8B8`（= `0x782D78A000+0x8B8`），条数 `0x782D78A8B4`（= `+0x8B4`），时间戳数组 `0x782D78B0BC`（= `0x782D78B000+0xBC`），当前 tick `0x782D78B0B8`；上限 **0x100**，满了按时间戳 **LRU 淘汰**最旧项 → 再 `br x2`（原函数）。
  - `Enemy::GetHurt` 桩内：若 `[0x782D7664F0]!=0`，则遍历登记表，把本次伤害**扩散给表里每一只怪**（跳过自己），单次上限 **0x3F(63)** 只，并受节流计数器限制；日志 `[圣翼全屏] 这一下 %lld 伤害扩散给 %d 只怪 (表里共%d条, 第%d条)`。

## 6. 移植（星空版）要点清单

1. **锚点口径**：`RVA = file_off + 0x4000` 只对**本包本版本**成立（程序头实测）；`dump.cs` 的 `Offset` 才是 file offset。锚点必须绑定 `libil2cpp.so` 的 **md5 `563b40a8…`**（换版即失效，须重新抓）。
2. **15 处序言字节**已在 JSON 里逐条记录（`prologue16`），可直接做版本漂移校验。
3. **只需复刻 15 个钩点**（5 功能 + 3 屏蔽 + 4 反作弊 + 1 登记表）即可等价于斌哥包；`GameObject::Find/SetActive`、`Time::get_timeScale` **本条包未装**，移植时可自己评估要不要补。
4. 必须实现的**非钩点**逻辑：活体登记表（上限 0x100 + LRU）、BOSS 借 CD、伤害扩散节流、`adcode="4444"` 清除、字段按名解析。
5. **免广告不做**（本作无广告系统）。
6. 禁用 Frida（壳带反调试/反变速检测）；动态分析走 KernelSU + `/proc/pid/mem`。
