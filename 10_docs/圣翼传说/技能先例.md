# 圣翼传说 · 技能先例（外科 dex 落位 / SDK 桩）

> 用途：本文件承接从 `skill/starry-mod/SKILL.md` 迁出的**单游戏实例细节**（技能只留通用机制，实例落本文件）。
> 来源：2026-09-24 外科组装实测踩坑；迁出日 2026-10-15（用户 m00007）。
> 通用机制（dex 名取最小空闲下标、ARM/ART 的 dex 扫描语义）见 `skill/starry-mod/SKILL.md`「外科组装 dex 落位铁律」。

## 1. 写死 `classes8.dex` ⇒ 启动即崩（实测）

- 新增 smali 编出的 dex 名**必须**是 base.apk 里最小的空闲下标（单 dex 官包 ⇒ `classes2.dex`）。
- 写死 `classes8.dex` 时：ART 的 `BaseDexClassLoader` 从 `classes.dex` 顺序扫、**遇到第一个缺口即停止** ⇒ 星光 dex 永不加载 ⇒ `StarryInitProvider` `ClassNotFoundException` **启动即崩**。
- 求解工具：`python3 04_scripts/_common/next_free_dex.py <官包.apk>`。

## 2. 本游戏 SDK 侧两条（已升格为技能侧通用规则）

- 官包无 `libtprt.so` / ACE 时，`Android_<tag>.mk` 必须含 `Games/NoAceStubs.cpp`，否则 `ld.lld: undefined symbol: SignalQuarantine_Start`。
- hook 日志 tag 是 `Mod_Menu`（`Includes/Logger.h` 的 `TAG=OBFUSCATE("Mod_Menu")`），**不是** `StarryMagic`。
