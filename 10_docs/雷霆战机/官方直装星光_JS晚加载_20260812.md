## 阻断：JS → System.load
Cocos `jsb.reflection.callStaticMethod("java/lang/System","load",...)`：

```
java.lang.NullPointerException:
  Attempt to invoke virtual method 'java.lang.ClassLoader java.lang.Class.getClassLoader()'
  on a null object reference
  at java.lang.Runtime.load0(Runtime.java:939)
  at java.lang.System.load(System.java:1729)
```

JNI 桥调用时 **caller Class 为 null**，`System.load` 必炸。  
`System.loadLibrary` 能调通，但走 **system ns / caller=\<unknown\>**，找不到 app `lib/arm64` 里的 `libstarry_magic.so`。

星光侧已有正确姿势：`NativeLinker.load`（Java 帧内 `System.load`）须由 PathCL 上的 `DexInstaller` 触发；该类在 `assets/starry_dex/starry.dex`，**不能**被 `callStaticMethod` 直接 FindClass（未进 PathCL）。
