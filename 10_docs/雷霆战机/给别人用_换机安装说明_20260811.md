## 为什么不能「装完就有菜单」

- 往 APK `lib/` 加 so / 改 dex / apktool 全量重建 → ACE **SIGBUS**
- 只 zip `assets/`（菜单 so/dex/web）→ **能进游戏**，但 so **不会自动 JNI_OnLoad**
- 电脑 Frida 冷启后再 load → 曾可活；**2026-08-11 夜已复现晚加载后进程直接死**，不能再当给别人的用法

下一步交付（开发中，不是今晚脚本）：**设备端晚加载**（Zygisk / 自研 delayed inject），用户只装 APK+模块，不用电脑。

## 卡密「绑定其他设备」

不是卡坏了。同机 id 被 OTA/`FINGERPRINT` 算飘过；v4 已修。  
换手机本来就会变 id → 后台解绑一次，或菜单自助解绑（每卡限 1 次）。
