# 雷霆战机官方 jsc XXTEA 解密（2026-08-16）

## 结论

| 项 | 值 |
|---|---|
| 引擎 | Cocos Creator **3.8.8**（`settings.2f299.json`） |
| 主脚本 | `assets/assets/main/index.f8365.jsc`（~10MB） |

## 取钥步骤（可复现）

1. 官包进游戏，等 `libcocos` 映射（**读 `/proc/pid/mem`，不开 Frida**）。
2. dump 主 `r-xp`（foff=0）→ 找 XXTEA（`MOVZ #0x79b9` + `MOVK #0x9e37`）。
3. 追 `BL` → wrapper → 两处调用均从 **同一全局 string 对象** 取 key。
4. 读该 VA 的 SSO 内容 → `fdL/X2CBpMD7P8i4`。
5. `xxtea.decrypt(jsc, key)`；本包主 index **无需 inflate**（小 bundle 偶发也是明文 JS）。

## 战斗相关挂点（明文已可见，待接星光）

- 玩家：**`XPlane.ts`** `hurt(t,e,i=!0)`（战斗里 `this.plane.hurt(...)`）。
- 箱体示例：`ShelterBoxEntity.ts` `takeDamage` / `_invincible` / `isDead`。

- 斌哥 `get_ret` **不在**官方 jsc（壳 prefs→eval）；官方玩法用星光 **eval 覆盖上述原型**。

## 注意

- 磁盘 `libcocos` 与内存前 1MB **几乎一致**（本节区未整段加密）；密钥在 **可写全局/BSS**，不是磁盘字符串表。
- `libEncryptor*.so` 与 jsc 密钥无关（ACE/腾讯侧）。
- 改包仍禁 `apktool b`；玩法走星光 `evalString`/`CocosJsBridge`，不 Keypatch cocos。
