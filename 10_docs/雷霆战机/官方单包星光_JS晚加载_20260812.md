## 阻断根因（MenuService 未自动起）

1. **`jsb.reflection` → `System.load(absPath)`**  
   ```
   NullPointerException: Class.getClassLoader() on null
   at Runtime.load0 / System.load
   ```
   JSB 从 native 调静态方法时 `VMStack.getStackClassLoader()` 为 null，绝对路径 load 必炸。

2. **`System.loadLibrary("starry_magic")`**  
   走 **system ns**（`caller=<unknown>`），找不到 app `lib/arm64` 里的 so。  
   `c++_shared`「成功」实际加载的是 `/system_ext/lib64/libc++_shared.so`，不是我们的拷贝。

3. **正确路径仍是** `NativeLinker.load`（PathClassLoader 栈）或 Frida `Module.load`+`JNI_OnLoad`（已验证可起菜单）。  
   `NativeLinker` / `DexInstaller` 在 `assets/starry_dex/starry.dex`，需先有 so 的 JNI 引导才能挂 PathCL——与 JS 晚加载形成鸡生蛋。

4. 改 dex 提供 `hello(path){System.load(path)}` 可解 NPE，但 **改 classes2 内容 → SIGBUS**。
