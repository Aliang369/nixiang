## 2. 斌哥启动链（静态+历史动态，已有证据）

```
CloverApplication
  → AceApplication（保留 ACE initialize）
      → KillerApplication193     ← 签名旁路，尽量早于 tersafe
      → loadLibrary(tersafe2 / tprt)
      → loadLibrary("sdk")       ← libsdk.so：与该版 ACE 配套的 native 过检体
libSDKloading.so                 ← 打包小壳（~3.7MB 高熵）；运行时 Dobby
AppActivity.onCreate
  → Main.StartWithoutPermission(Context)   ← 斌哥菜单秒出入口（Java）
  →（内部）远程/本地菜单 + prefs "0"/"1"/"2" + get_ret
战斗：SDKloading Dobby 钩 evalString，按 get_ret 推 JS（可晚于菜单）
```

证据来源：

- Application / Killer / `libsdk`：`雷霆战机_星光移植_20260810.md` §2  
- maps：`SDKloading + cocos + tersafe2 + libsdk`：`雷霆战机_菜单功能抓点_20260809.md`  
- 菜单入口：`AppActivity` 调 `com.android.support.Main.StartWithoutPermission`（星光移植时曾 **删掉** 该调用，因与星光双 Dobby 冲突）  
- 玩法：prefs → BSS 旗标 → `get_ret` → evalString JS，**不是** Keypatch `libcocos`

## 3. 「秒加载」到底秒的是什么

| 层级 | 时机 | 组件 |
|------|------|------|
| 过检 so | Application，冷启 ~0–15ms | Killer + `libsdk` + Ace `tersafe2/tprt` |
| 菜单 UI | **立刻**（可开浮窗） | `Main.StartWithoutPermission`（Java / classes7） |
| 过检等待 | 菜单内文案 **「过检测中」+ 60s 倒计时** | UX 明示；倒计时期间是否武装 hook **待抓** |
| 玩法 hook | 倒计时结束后才可用（推断） | `libSDKloading` Dobby / eval / `get_ret` |

所以：**别人不是「整包 Frida 晚载菜单」**；是 **过检 so 早进 + 菜单秒开 + 菜单里再等 60s 过检 → 再开玩法**。

## 7. 冷启实测时序（2026-08-16，真机斌哥 999999）

> 产物：`08_output/雷霆战机/binge_maps_timeline_154324.txt`  
> `binge_logcat_load_154324.txt` / `binge_logcat_load_filtered_154324.txt`  
> 脚本：`04_scripts/雷霆战机/ltzj_capture_binge_load_timeline.sh`

`nativeloader` 精确顺序（pid 14690，单位 ms 相对首条 Load）：

| Δms | so | caller dex |
|-----|-----|------------|
| 0 | `libtersafe2.so` | `classes2.dex`（Ace） |
| +12 | `libtprt.so` | `classes2.dex` |
| +15 | **`libsdk.so`** | `classes2.dex`（Ace 链上额外 load） |
| +31 | （log）`NativeUI: DobbyHook` egl | 疑似 **libsdk JNI_OnLoad** 已开始 hook |
| +690 | **`libSDKloading.so`** | **`classes7.dex`（斌哥菜单 dex）** |
| +801 | `libcocos.so` | `classes2.dex` |
| +824 | `libBugly_Native.so` | `classes4.dex` |

maps 抽样：`t=0s` 已见 sdk+tersafe+tprt；`t=1s` 已齐 SDKloading+cocos。

结论（别人怎么加载）：

1. **过检先**：Ace/`classes2` 里 `tersafe2 → tprt → sdk`，毫秒级连载；`libsdk` 与 ACE 同批进进程。  
2. **菜单壳次之**：约 **0.7s 后** 由 **`classes7`** `loadLibrary(SDKloading)`（不是塞进 `assets` 晚载）。  
3. **引擎再次之**：紧接着 `libcocos`。  
4. **秒出菜单** = Java 菜单 dex（classes7）+ `SDKloading` 早挂在 **`lib/arm64`**，且此时 `libsdk` 已在；**不是** Frida 晚载整菜单。  
5. 「等 60s」= 菜单 **过检测中倒计时**，不在冷启 1s so 加载轴上（见 §8）。
