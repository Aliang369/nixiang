### 4.5 三功能如何生效（结论）

| 功能 | native（cocos/so） | JS（evalString） | 证据 |
|------|-------------------|------------------|------|
| 100倍伤害 | ❌ cocos **无玩法 B-stub** | ✅ | prefs `"0"` + `get_ret(1)`；JS 改最终伤害 / 玩家×100 / 敌人→0 |
| 无敌 | ❌ | ✅ | prefs `"1"` + `get_ret(2)`；`isDead()` / 受击分支（BSS 片段） |
| 免广告 | ❌ cocos | ✅ / Java SDK | prefs `"2"` + `get_ret(3)`；标签在加密 `exp`；BSS 模板注释为「无限技能」属复用 |

**机制链（与造梦西游 / 镇邪人 / Blzz 同构）：**

1. WebView `Changes(...)` → 写 **`{pkg}_preferences.xml`** `"0"`–`"2"`。  
2. 同步 **`shell_rw_bss_1` +0x1798..+0x17A0** 三枚 `int32=1`。  
3. **`libSDKloading`** 内 **Dobby** 钩 **`evalString` / ScriptEngine**，按 `get_ret` **eval 战斗/广告 JS**（正文在 BSS rw，非持久 heap 明文）。  
4. **`libcocos` 副段无改字节** — 星光走 **JS hook**，非 Keypatch so。

**未确认：** 免广告完整 JS（广告 SDK 类名/hook 点）；各 toggle 完整函数名（需 **Frida evalString** 或解密 `1129.html` 的 `exp`）。

## 6. Starry 移植计划（Blzz 式）

对齐 `mod菜单/starry-mod-menu/.../BlzzMod.cpp` → 新建 **`LtzjMod.cpp`**（Creator3 / `libcocos`）：

| Starry Bool | 映射 | 实现 |
|-------------|------|------|
| 100倍伤害 | prefs `"0"` / `get_ret(1)` | `CocosJsBridge.evalOnGLThread` 钩最终伤害 / 玩家×100 |
| 无敌 | prefs `"1"` / `get_ret(2)` | JS 改 `isDead()` / 受击 HP |
| 免广告 | prefs `"2"` / `get_ret(3)` | JS/Java 旁路激励视频 / 插屏（Frida 抓点后固化） |

**步骤：**

1. 菜单 3 Bool；**不必**写斌哥 prefs 键名。  
2. **优先** GL 线程 **`evalString`**（Creator3 JNI：`CocosJavascriptJavaBridge_evalString`）；备选 Frida 观测斌哥 `get_ret` 脚本。  
3. Frida：`evalString` 日志 + 单开 toggle，固化 3 段 JS（含免广告）。  
4. **不要** Keypatch `libcocos`（memdiff 证明无玩法 stub）。  
5. **过检 P0 并行**：**MT Killer** + **`libtersafe2`/ACE** + SDKloading Dobby + `libsdk.so`；无 BuildPassCheckInfo 可抄。
