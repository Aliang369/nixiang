## 1. 帧格式（应用层 byte[]，非原始 TCP 粘包）

**上行 TX（SendMessage）**

```
[0..1] u16 LE  total_len（含头）
[2..3] u16 LE  cmd / msgId
[4..]  payload
```

例：

| head | 解读 |
|---|---|
| `04001127` | len=4，cmd=`0x2711`（心跳，反复出现） |
| `24008027` | len=36，cmd=`0x2780`（战斗期上行，疑似攻击相关） |
| `24008f27` | len=36，cmd=`0x278f` |
| `1400a728` | len=20，cmd=`0x28a7` |

**下行 RX（MessageQueue）**

```
[0..3] u32 LE  total_len
[4..5] u16 LE  cmd
[6..]  payload（多见 protobuf 字段）
```

例：心跳应答 `0f0000001227...` → len=15，cmd=`0x2712`。

## 3. 加密判断

- 采样包长几乎都不 `align16`
- RX payload 可见可读 protobuf wire type  
→ **本局战斗流量不像整包 AES**；`CRYPTO.Crypto` 可能用于登录/其它，不用于这条战斗 TCP 应用层（仍可能有部分字段混淆，但不是整包密文）。
