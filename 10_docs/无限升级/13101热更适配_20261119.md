## 4. 「禁止热更」的语义（本轮复核，供后续排障）

- 本项目的「禁止热更」＝**变体命中后强制覆写**（`HOTFIX MISMATCH -> FORCED PATCH: hot-update neutralized, save safe`），不是版本号骗客户端；
- 此机制只能救「同长度、不同字节」的换代（第二轮按长度匹配）；**长度一变就 PASSTHROUGH**，这是本次失效的唯一原因；
- 现行链路**只有 `BlockVersion` 一条版本门**（`ilpatch` 0 处、`ilpatch_delta(_13101)` 各 1 处），完整版本钉死族只在 vc1637/断网版线；**lead 裁决本轮不移植**（理由见方案文档 §10）。
