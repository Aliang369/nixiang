副作用与处置：
- 该脚本会把 DIAG so 写到 `app/src/libs/arm64-v8a/libstarry_magic.so`；已备份原正式 so 并在建完后**原样还原**（`07_patched/无限升级_断网版/probe/backup_libs_wxsj_release.so`）。

- 这份 so 是 **legacy wxsj 构建**（`auth game_id=wxsj`、`[Wxsj]` tag），不是 wxsjdz2 —— 探针只需要 hook + dump，够用；正式包仍须走 `wxsjdz2_so_only.sh`（加密载荷 + `[Wxsjdz2]`）。
