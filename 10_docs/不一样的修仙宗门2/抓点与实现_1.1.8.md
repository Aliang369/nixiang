## 3. 开关下发通道（最大的坑）

- Cocos 在 Android 的 cc.sys.localStorage 落在 databases/jsb.sqlite（表 data(key TEXT PRIMARY KEY, value TEXT)），不是 SharedPreferences；写 SP 完全无效
- 通道：菜单点击 → native OnFeatureChanged → Java Byydxxzm2Hooks.setFeature → SQLiteDatabase.insertWithOnConflict("data", …) 写 key starry_byydxxzm2（JSON {"yu":0/1,"ling":0/1,"noad":0/1}）→ 游戏内 3s 轮询生效
- 启动期同步只调 syncFeature（不落库），避免框架默认 false 覆盖玩家选择
- 自证日志：D/jswrapper: JS: [sby] init <ling> <yu> <noad> <cfg>、JS: [sby] cfg …

## 4. 雷电/houdini 三条死路（实测，勿重复）

| 方案 | 结果 |
|---|---|
| native Dobby inline hook se::ScriptEngine::evalString | 启动约 2s SIGSEGV，栈全在 libhoudini.so（fault 0x1930） |
| Java 反射 CocosJsBridge.evalOnGLThread（evalString） | SIGSEGV，GLThread，fault 0x40 |
| 改 jsc 后 JS 自己调 jsb.fileUtils + cc.director.getScheduler().schedule | 同样 SIGSEGV（fault 0x40） |

结论：本包只有 arm64 so，雷电靠 houdini 转译；native hook 与 Java→native eval 都不稳。唯一可靠路径是改 assets/src/project.jsc + 纯 JS 定时器。
