## 3. 存档与账号（实测，关键!）

- **玩家数据存服务端**：本地 `jsb.sqlite`(cc.sys.localStorage) 只有设置/红点/聊天缓存/账号凭据；无任何 Player 存档。
- 游戏为 **pomelo 长连接在线游戏**：`main.heroHandler.dealHero`(29 处)、`main.playerHandler.*`、`main.shopHandler.*`、排行榜/跨服等全部服务端 handler。
- **结论（按 PLAYBOOK §8 服务端校验规则）**：货币/门客/进度等核心数值**不可客户端硬改**，可改面=客户端侧功能（广告链路、本地表现层）。
- 账号：真机已登录账号 `689s22651990`，**已绑手机号**（USERNAME=137****848, user_login_type=0），卸载重装可手机号+密码找回；仍应先备份 `/data/data/com.hdg4.g4qlfh/databases/jsb.sqlite` 双保险。

## 4. 广告链路（客户端可控，抓点详见抓点定稿）

- 真广告：JS `SdkMgr.Ad.showRewardVideoAd` → `AndroidToJs.showRewardAd(adUnitId)`（穿山甲）。
- 本地广告（灯影阁）：`UIDengYingGeLocalAD` 弹窗倒计时（时长=System(1476)），倒计时结束即视为"看完广告"。
- 渠道门控：`System(1715)` 决定本渠道走真广告还是灯影阁；`AdvModel.isNoAd()`（月卡判定）为真时直接发奖不看广告。
- `Player.adFreeData`（免费广告次数）为服务端数据，但**次数门控判定在客户端**（`getAdFreeCount(type) <= 0` → toast）。
