### 6.2 敌我区分依据（实测）

- 全部单位**共用同一个类**（klass 前缀 b4000071dd），类指针不能用来分敌我。
- **阵营键 = *(void**)(unit + 0x48)**：玩家/队友共一个键，敌人共另一个键（实测两只不同怪物键相同，玩家键不同）。
- 链路：**unit + 0x48 → 阵营对象；阵营对象 + 0x10 = 阵营 id（int32）**。
- 实测值：玩家阵营 **1001**（由治疗事件交叉确认）；普通怪 **6**（两只不同怪物共用同一阵营对象）；boss/召唤物等一律非 1001。
- 判据：teamId != 0 且 teamId != 玩家阵营 id（默认 1001，治疗事件可校准）⇒ 敌方，扣 9999999。
- 读不到 teamId（指针不可信）⇒ 不动手（不按敌方处理），保证永不误杀玩家。
- 该判据**第一帧即生效**，不依赖任何学习事件；boss 与普通怪同规则。

### 6.3 事故记录（必须保留）

- 2026-11-02 曾用 sh_bgqq1 采集「敌方阵营键」，假设「该入口只有怪物走」——**假设错误**：
  sh_bgqq1 对玩家也会调用，玩家键被收入敌方集合，开启秒杀后**玩家被怪秒杀**。
- 结论：**禁止用任何「只对怪物触发」的推测入口采集阵营键**；玩家身份只能由治疗/受击等可证实路径学习，学习前一律不生效。
