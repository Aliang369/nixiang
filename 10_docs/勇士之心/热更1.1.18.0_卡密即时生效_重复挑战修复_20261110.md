热更产物取得（本次踩坑已记）：`adb exec-out "su -c 'cat …'"` 在 Windows 上会因 pty 把 `\n` 转 `\r\n`，**加密 js 是二进制，不能按文本还原**（按行还原会把密文里的 `\r\n` 一起改掉，解密全失败）。正确通道是设备端 `base64` + 本地解码：

```bash
adb -s $SERIAL exec-out "su -c \"base64 $RES/$f\"" | tr -d '\r' | base64 -d > "$OUT/$f"
```

24 个 js 全部 md5 与设备端一致后才解密（`decrypt_hotupdate_ysxz.py`，key 未变）。

## 3 卡密首次登录需重启（方案 A）

```cpp
// 改前（YsxzMod.cpp）
if (!StarrySessionLive()) {                 // 冷启动那一刻没有票
    LOGW("no valid ticket -> skip splice …"); // 整轮不注入
    return g_origSeEval(…);                  // 游戏跑原版 JS
}
```

时序：无票启动 → 不注入 → 用户登录卡密 → 票写成 → **但 JS 早已加载完** → 必须重启，第二次启动带票才注入。

改后（用户选 A）：
- splice **永远做**，会话状态只用于日志：`splice gate: session=live|no-ticket inject=NNNN B（不阻断注入）`；
- 保留保险：`patchJs.empty()` ⇒ 原样放行（否则 registry 调用被改写却缺 `window.__starry_capture` ⇒ TypeError 卡加载页，2026-10-27 事故）；
- 功能侧安全边界：未授权时 `ModBridge.lockAllFeatures()` 把 1..13 号开关全部强制关 + `nativeSetAuthorized(false)`，JS 侧 `FEAT()` 读到的全是 false ⇒ 注入≠可用；
- **已知代价（用户已知悉并同意）**：未授权启动时补丁 JS 也会随 bundle 进内存，可被 dump。

小米实测证据：`splice gate: session=no-ticket inject=125403 B #1/#2（不阻断注入）` → 登录后**不重启**直接进战斗，伤害即刻生效。
