## 5. 唯一存活失败面：测量/布局相位（候选两处）

相关代码（源码行号；装机 e$e.onMeasure 与源码 1430-1476 逐条一致）：

- NativeMenuController.java:1358 首次探测 `measurePanelContent(frame.cardWidth(), 0)` ← bodyLimit 传 0
- :1411 `panelBodyLimit = bodyLimit;` ← 字段被 0 污染
- :1435-1436 `maxH = (UNSPECIFIED) ? panelBodyLimit : min(panelBodyLimit, size)`
- :1456-1465 contentH<=maxH ? EXACTLY(contentH) : EXACTLY(maxH)
- :1379-1383 终测 + `layoutParams.height = panelContent.getMeasuredHeight() + frame.top + frame.bottom`
- :1420-1428 `applyFrame()`：`shell.setForeground(frame.drawable())`（前景 9 宫格画在子视图之上）

候选 A（内容区被测量/布局成 0 高，最可能）：探测调用把 panelBodyLimit 压成 0 → 该轮三个 ScrollView 全 0 高 → 若切 tab 时窗口高度/版面相位按这轮结果定格，新页就是「有容器、无高度」= 空白，而 tab 栏（不走 ScrollView）照常显示。与「页面里什么都没有、控件都不见了」逐字吻合。

候选 B（控件在但被盖住）：applyFrame 用 MenuFrameRes.menuFrame(width)+fitHeight(bodyH) 生成前景；矮页面下 9 宫格中心若不透光会盖住内容（功能页内容高、frame 不同，故不受影响）。

两条都能解释「功能页正常、账号/设置空白」，只读代码无法二选一。
