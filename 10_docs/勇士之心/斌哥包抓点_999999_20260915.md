## 3. 注入机制

斌哥壳不修改 `libcocos2djs.so` 的游戏逻辑。运行时通过 `se::ScriptEngine::evalString` 注入一段自愈式 JS：

```js
window.__require = function t(e, i, n) {
try { MOD_boot(e); } catch (MOD_err) {}
```

`MOD_boot` 从 `window.__require` 的模块注册表遍历模块源码，通过明文锚点正则发现混淆名，再包装目标函数。所有功能判断都放在包装函数内部读取 `MOD.featureN`，所以菜单开关无需重启游戏。

共同发现字段：

| 语义 | 运行时名称/路径 | 依据 |
|---|---|---|
| 是否玩家 | `ent.hx.bjY` | `case "isPlayer": return t.hx.bjY` |
| 阵营组件 | `ent.hD` | 与 `isPlayerCamp` 判断同屏 |
| 阵营值 | `ent.hD.biI` | `v.hD.biI === ...cXQ` |
| 战斗上下文 | `context.blc` | `this.context.blc.fF[0].cXQ` |
| 队伍列表 | `blc.fF` | 同上 |
| 玩家阵营值 | `blc.fF[0].cXQ` | 同上 |
| HP 字段 | `ent.hv.beu` | `beu = Math.max(beu - u, lockMinHP)` |
| 当前/最终伤害字段 | `finalDamage`、`finalHurtValue` | 扣血口与飘字链 |
| 时间缩放组件 | `ent.hy` | 含 `worldTimeScale`、`hitPauseTimeScale`、`hTimeScale` |

## 4. 功能位与抓点

### feature1：秒杀

菜单位：`mod_sw.f[0] = 1`

真实钩子：

- 混淆函数：`battleLogic` 模块的 `t.FV`
- 明文锚点：`maxApDefRate` + `baseCritDamage`
- 明文行：`06_dumped/勇士之心/jsc_decrypted/assets/battleLogic/index.js:8157`

实现语义：

```js
var d = oFV.apply(this, arguments);
if (MOD.feature1 && hit && d > 0 && isMine(hit.atkEntity) && !isMine(hit.target)) {
    d = Math.ceil(d * 100);
    if (d > 1e9) d = 1e9;
}
return d;
```

结论：不是直接写敌血，而是在唯一最终伤害公式中对我方攻击敌方的伤害乘 100，飘字和结算共用该结果。

### feature2：无敌

菜单位：`mod_sw.f[1] = 1`

真实钩子有两个：

1. 实体扣血口
   - 类导出：`$gq`
   - 方法：`$gq.prototype.hX(atk, dmg, hit)`
   - 明文行：`06_dumped/勇士之心/jsc_decrypted/assets/battleLogic/index.js:10478`
   - 判定：`isMine(this)` 时令 `hit.finalDamage = 0` 并直接 return

2. 死亡例程
   - 函数：`BattleLogic.GJ(ent, force, dir)`
   - 明文行：`06_dumped/勇士之心/jsc_decrypted/assets/battleLogic/index.js:9061`
   - 原函数会把 `ent.hv.beu = 0`
   - 判定：`isMine(ent)` 时直接 return

结论：同时封住普通扣血和绕过扣血口的死亡写零，避免只剩一个钩子时仍被死亡例程击杀。

### feature3：无限技能

菜单位：`mod_sw.f[2] = 1`

真实钩子有两个：

1. 技能门
   - 函数：`BattleLogic.Ff(ent, skill)`
   - 明文行：`06_dumped/勇士之心/jsc_decrypted/assets/battleLogic/index.js:7412`
   - 判定：技能已解锁且 `isMine(ent)` 时直接返回 `true`

2. 技能消耗
   - 函数：`BattleLogic.Fg(ent, skill)`
   - 明文行：`06_dumped/勇士之心/jsc_decrypted/assets/battleLogic/index.js:7415`
   - 保存 `Da`、`Db`
   - 释放时临时清零蓝耗/血耗
   - 调原函数后恢复原值
   - 将 `cd = 0`
   - `CZ > 0` 时将当前充能 `CY = CZ`

结论：同时放行客户端技能门并补满 CD/充能，战斗逻辑和 UI 技能按钮共用同一个门函数。

### feature4：移动速度

菜单位：`mod_sw.f[3] = 1`

真实钩子：

- 模块：`$DQE`
- 类导出：`$jR`
- 方法：`$jR.prototype.update(list)`
- 明文行：`06_dumped/勇士之心/jsc_decrypted/assets/battleLogic/index.js:5034`

实现语义：

- 进入 `update` 前，对我方英雄的 `ent.hy.hTimeScale *= 3`
- 调原 `update`
- `finally` 中 `/3` 还原

结论：只放大水平运动时间缩放，垂直/跳跃分支使用 `vTimeScale`，不受影响。当前值为 3 倍。
