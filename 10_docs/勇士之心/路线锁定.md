## 4. 防御校验点处置

| 防御点 | 处置 | 依据 |
|---|---|---|
| `fancy/` 加固壳（外层 dex/so + `origin.apk`） | **不动**：外层未改 dex/so，`origin.apk` 原样留在包内 | 改它＝动真 dex，风险远大于收益 |
| 服务端 `version_update_md5`（校验热更 4 个文件的 md5） | **不改磁盘 bundle**，补丁只在 `evalString` 内存注入 | `Mac出包避免模拟器问题_规约_20261004.md` 行 G（改磁盘即 `exitProgram`） |
| `libtersafe2.so`（ACE） | 不动、只观测；若实测触发再评估 | 1.0.3 历年交付未触发 |
| TapTap 签名 / SSO | 重签星光钥匙（与线上星包同一把）；若弹包名/签名走 1.0.6 已验证的 `TapLoginForceWeb` 路线 | 1.0.6 文档 §12 |
| `SignSpoof` 隐藏 API 豁免 | Android 14 上 `setHiddenApiExemptions` 不存在 ⇒ 打 E 日志后继续（已知噪声） | 本轮实测（真机 96f0d883 / Android 15? 见日志） |
