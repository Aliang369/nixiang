## 6. 最小修法（只动 JS 补丁层，不动 native）

1. **战斗五项 / 加速 / 自动战斗 / 金卡：不改。** 复现器 `OK`，改动只会引入风险。重出包只为下面两条。
2. **自动穿戴（唯一需要真改的功能）**：不要再对 `$eZ.equip` 的方法体做 `WORE_EQUIP/items:` 过滤，改成**从 BagComp 反查**（`"暂无可穿戴的装备"` 全包唯一、两代都在）：
   ```js
   // 找到含 "暂无可穿戴的装备" 的函数 → 取两个 equip 调用名
   var src = 该函数体;
   var getter = /$eZ\.equip\.(\w+)\(\)/.exec(src)[1];      // 1.1.22.0 = fSs（1.1.18.0 = fKf）
   var setter = /$eZ\.equip\.(\w+)\(t\)/.exec(src)[1];     // 1.1.22.0 = fUG（1.1.18.0 = fMt）
   ```
   行为与游戏原生「一键穿戴」一致（列表 → 请求 → `roleAttr` 刷新），符合硬约束 #11 的「用游戏自己的机制」。
3. **倒计时字段诊断**：删掉 `inst.epU`，改为从已发现的 tick 方法体取 `/this\.(\w+)--/`（1.1.22.0 → `euk`）。只影响日志。
4. **结算面板**：不改。`wz→wA` 由 `battleMgr+btn_toNext` 结构发现吸收；如果将来连这个都失配，兜底仍可走 `1e3`+`, -1` 找「起倒计时」方法（v22 = `eum`）后直接调它。
5. **funcOpen**：不改。结构发现「所有方法 + 入参 26 放行」仍成立，枚举值 26 未变；日志里只是 `ckw` 取代 `ciX`。
