## 9. 复刻要点（事实性结论，不含建议）

1. **根对象唯一入口是 `globalThis.$eZ`**，就绪判据是 `$eZ.battleMgr` 存在（`F()`，L3105）。模块加载 `__require` 通道在本段完全没用上。
2. **职业名不硬编码**：`RoleDesTable.findByKey(id).nameText|name` → `i18n.Mv|Mw` → 兜底 `"职业#" + id`。职业列表来自 `role.fBe(role.fBb.fAU)`，解锁判据 `RoleDesTable.unlockLevel`。
3. **进副本唯一入口 `battleMgr.bFo({id, playMode})`**（L3608）——同步返回 true 不等 Promise。
4. **主线任务固定 `taskType = 3`**；读组 `task.cvs({taskType:3})`，拉组 `task.cvo({taskType:3})`（4s 节流），配置 `task.cvg.cva(id)` 回落 `TaskTable.findByKey`。
5. **提交必须优先 `task.cvk({taskType[,actId,actCycle]})`**（`oneClickReceive=7426`）；`task.cvi({taskIndex,taskId,adsDouble:false})`（`getTaskReward=7425`）对主线会被判参数错误。`taskIndex` 必须来自 `grp.taskIndex` 原对象，不能自己拼 `{taskType:3}`。
6. **任务完成不需要 status==2**，只要 `status !== 3` 就能提交（官方 `dBL/dBJ` 逻辑）。
7. **上报两个接口**：NPC 对话 `task.cvr(npcId)`（裸数字）；客户端事件 `task.cvq(evType, params||[])`（返回 Promise，透传）。
8. **1008 必须先校验 `InstanceTable`**，否则会把 `InstanceTypeTableEnum.TOWER=1200` 当副本硬进（历史 bug）。
9. **1101/1102/1103/1308 属于 ReddotTableEnum，不是 EventTableEnum**——旧代码把 11xx 当任务事件是映射错误。
10. **结算只在 `battleMgr.bEu.mz.bDK.b` / `battleMgr.bEv.bDK.b`**，`battleMgr.bAB`/`bCK` 是旧版字段（会恒 false）。
11. **出售/分解品质取"游戏内位 ∪ UI 勾选"的并集**，开关开着但品质空时兜底 `[1,2,3]`；接口 `bag.bYK(list)` / `bag.bYJ(list)`。
12. **附魔是列表级提交**（`equip.fsy()` → `equip.fsE(list)`），刻印石和宝石是逐件提交（`equip.fuU` / `equip.fvS`），三者都有 Busy 重入保护。
13. **寻路优先 `gameHelper.chL(jumpCfg)`**，兜底 `townScene.fGW({actType, ...})`（章节 `actType:1 + chapter`，NPC `actType:2 + npcId + jumpId`）。`townScene.fAJ` 在新版是"秘密副本判断"，不能用来寻路。
14. **`autoStop` 只写 localStorage 不推 `__WX_AUTO_TASK__` 给 UI**，避免 switch 回传自激。
15. **日志节流 2000ms（去重）+ 1000ms（UI 推送）**；文件日志落 `<writablePath>/wx_auto_log.txt`，上限 8000 截尾 6000；包名 `com.fightingstars.games.warrior`。
