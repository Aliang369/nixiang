### 1.1 服务端地址与密钥（L93–L106，配置区原文）

### 1.2 请求拼法（`doLogin → sendAttempt`，L1277–L1290）

每次尝试（每次重试）**重新生成时间戳/签名/随机值**，不复用旧请求（L1280 注释明确写了这条理由）。

```js
var tm = Math.floor(Date.now() / 1000);                        // 秒级时间戳
var signs = hex_md5('kami=' + kami + '&markcode=' + mark + '&t=' + tm + '&' + sk);
var request = WX.loginAPI + '&app=' + WX.appId + '&kami=' + encodeURIComponent(kami)
            + '&markcode=' + encodeURIComponent(mark) + '&t=' + tm + '&sign=' + signs;
var random = (Math.random().toString(16).slice(2) + Date.now().toString(16)) + sk + mark;
var data = 'data=' + encodeURIComponent(rc4(request, sr, true)) + '&value=' + encodeURIComponent(random);
var postUrl = request + '&app=' + WX.appId;                    // 注意：POST 地址末尾再带一次 app
xhr('POST', postUrl, data, cb);
```

精确规格：

| 项 | 值 |
|---|---|
| 方法 | `POST` |
| URL | `https://wy.llua.cn/api/?id=kmlogon&app=44846&kami=<urlenc>&markcode=<urlenc>&t=<秒>&sign=<md5>` **再追加 `&app=44846`**（即请求串里 `&app=44846` 出现**两次**，第二次在末尾） |
| `Content-Type` | `application/x-www-form-urlencoded`（xhr 内 POST 分支设置，L904） |
| body | `data=<urlenc(RC4密文hex)>&value=<urlenc(random)>` |
| `sign` 明文 | `kami=<原卡密,未urlenc>&markcode=<mark,未urlenc>&t=<tm>&85PvP3tH5tZR4P5D` |
| `sign` 算法 | `hex_md5(明文)` → 32 位小写 hex |
| `random` | `(Math.random().toString(16).slice(2) + Date.now().toString(16)) + appKey + mark`（**注意 `.slice(2)` 的括号位置**：它是 `random` 十六进制串切掉 `"0."` 前缀，再直接拼接十进制 `Date.now` 的 hex，再拼 key 与 mark；不参与服务端校验，只作 `value` 字段） |
| `sk`/`sr` | `var sk = WX.appKey, sr = WX.rc4_2;`（L1260） |

`request` 字符串本体（含 `sign` 与 `t`）被整体 RC4 加密后作为 `data`；`request` **同时**又是 POST 的 URL——注释 L1288 明说是「微验这个应用的历史可用版本要求 POST 地址末尾再次携带 app；request 本身仍必须保持不变，因为它同时参与 RC4 数据和 sign 校验」。

### 1.3 RC4（L831–L849）

```js
function rc4(data, key, encrypt) {
    if (encrypt === true) return strToHex(rc4Core(utf8Bytes(String(data)), key));
    data = String(data == null ? '' : data).trim();
    if (/^[0-9a-fA-F]+$/.test(data) && data.length % 2 === 0) data = hexToStr(data);
    return utf8Text(rc4Core(data, key));
}
```

- 加密方向：`encrypt === true` → `utf8Bytes(明文)` 走 `rc4Core`，输出 `strToHex`（**小写 hex**，每字节 2 字符）。
- 解密方向：先 `trim()`；若满足 `/^[0-9a-fA-F]+$/` 且长度为偶数 → `hexToStr` 还原二进制；再 `rc4Core`；最后 `utf8Text`（`decodeURIComponent(escape(s))`）。
- `rc4Core(data, key)`（L837–L848）：**标准 KSA/PRGA**，`s[256]` 初始化 `s[i]=i`；`j=(j+s[i]+key.charCodeAt(i%key.length))&255` 做交换；PRGA 输出 `String.fromCharCode((data.charCodeAt(y)&255) ^ s[(s[i]+s[j])&255])`。**无 drop、无 IV、无 KDF**；密钥就是 `rc4_2` 那 32 个 ASCII 字符本身。
- 辅助：`strToHex`（L885）、`hexToStr`（L886）、`utf8Bytes = unescape(encodeURIComponent(s))`（L849）、`utf8Text`（L887，try/catch 失败回落原串）。

### 1.4 XHR 封装（L889–L918）

- `x.open(method, url, true)`；`x.timeout = 15000`（15 秒）。
- 请求头（L901–L905）：`User-Agent: Dalvik/2.1.0 (Linux; U; Android 12)`、`Accept: */*`、POST 时 `Content-Type: application/x-www-form-urlencoded`。注释 L900 明说：**微验会检查 UA，缺了/不对容易被判「网络环境异常禁止登录」**，这几行照参考工程 `jsdex新.js`。
- 完成回调只走一次（`finished` 标志）。

**判定顺序（逐条硬门禁）**：

1. `code !== WX.okCode`（L1315）→ 失败分支。`msg = msg || '服务端拒绝请求（代码 ' + code + '）'`；若 `msg` 命中 `/网络|超时|连接|繁忙|稍后/` 且 `attempt < maxAttempts` → `retry(msg)`；否则 `setMsg('登录失败：' + msg)` 并复位 `__loginBusy=false`。注释 L1313–L1314 明确：此分支**绝不进入授权成功流程**，因此不校验签名字段。
2. `!(timee > 0) || !/^[0-9a-fA-F]{32}$/.test(check)`（L1325）→ `setMsg('登录失败：服务器响应签名缺失')`，不重试。
3. 时间窗：`if (timee - tm > 30 || timee - tm < -30)`（L1330）→ `retry('数据已过期')`（仍有余次时），否则 `'登录失败：数据已过期'`。**窗口 ±30 秒**。
4. **反签名校验**（L1334）：
   ```js
   if (check === hex_md5(String(timee) + sk + WX.appId)) { ... '登录失败：服务器响应签名校验失败' }
   ```
   注释 L1323–L1324 解释：该应用所用微验服务返回 32 位 check，但**当前服务端算法与旧公开公式不同**；原生 DEX 的实际判定是「check **等于**旧公式时视为非法；**不等**时继续验证成功码和时间窗」。所以这里是**相等即拒绝**（黑名单式），不是常规的相等即通过。可复刻要点：真正的放行条件是 `code===74945` + `check` 是 32 hex + 时间窗通过 + `check !== md5(String(timee)+appKey+appId)`。
5. 成功分支（L1339–L1362）：

   - `vip` 取的是 `jo.msg.vip`（**对象形态的 msg**，不是顶层 `jo.vip`），单位是**秒级到期时间戳**（`fmtDate` 按 `ts*1000` 转 `new Date`）。
   - `fmtDate(ts)`（L850–L853）：`YYYY-MM-DD`，月/日 `<10` 补零。

### 1.7 `doLogin` 的重试 / `sendAttempt`（L1252–L1370）

- 全局忙标志 `var __loginBusy = false;`（L1252）。进入前若已忙 → `setMsg('网络正在重连，请稍候...')` 直接返回（L1259）。
- 入参校验：`kami` 为空 → `'请先输入卡密'`；`androidId()` 返回空 → `'拿不到设备码，请把状态文件里 mark 字段发我'`（L1262）。
- `var attempt = 0, maxAttempts = 4;`（L1263）。
- `retry(reason)`（L1266–L1275）：
  ```js
  if (attempt >= maxAttempts) { __loginBusy = false; setMsg('卡密验证失败：' + reason); return; }
  var delay = [800, 1600, 3000][attempt - 1] || 3000;
  setMsg('网络已切换，正在重连（' + (attempt + 1) + '/' + maxAttempts + '）...');
  setTimeout(sendAttempt, delay);
  ```
  **退避序列 800 / 1600 / 3000，之后一律 3000 ms**；`attempt` 从 1 开始，故第 1 次失败退 800。
- `sendAttempt()`（L1277）：`attempt++`；提示文案随次数切换 `'正在提交验证，请稍候...'` / `'正在重新验证，请稍候...'`；重新生成 `tm/sign/random/request`。
- 触发 `retry` 的四种情况：① `xhr` 层 `err` 且 `isTransientLoginError(err)`（L1292）；② 服务端 msg 含 `网络|超时|连接|繁忙|稍后`（L1317）；③ 时间窗越界（L1331）；④ `JSON.parse`/解析抛异常（L1364，`retry((e && e.message) || '响应解析失败')`）。
- 非瞬时 `xhr` 错误（不匹配 `isTransientLoginError`）→ `setMsg('卡密验证失败：' + err)`，**不重试**。
- `sendAttempt()` 在 `doLogin` 尾部**立即同步调用一次**（L1369）。

### 1.8 `isTransientLoginError`（L1253–L1255）

```js
function isTransientLoginError(err) {
    return /HTTP\s*(0|408|425|429|5\d\d)|网络|超时|连接|中断|Failed to fetch/i.test(String(err || ''));
}
```

分类为「可重试（瞬时）」的正则：`HTTP` 后跟 `0` / `408` / `425` / `429` / `5xx`，或含 `网络`、`超时`、`连接`、`中断`、`Failed to fetch`（大小写不敏感）。其余（如 `HTTP 403`、`HTTP 200` 之外的 4xx 非上列、解析错误以外的业务拒绝）视为**不可重试**。

## 3. 存储层

### 3.1 双写模型（L744–L777）

v66 的动机（L745–L746 注释原文）：**鸿蒙兼容层里 `cc.sys.localStorage` 可能是空壳（读回 null / 写入不落盘），所以每次读写都再过一份 `wx_cfg.json`，两边取到哪个算哪个。**

```js
var __KV = { file: '', mem: null };
function kvFile() {
    if (!__KV.file) { var w = writablePath(); __KV.file = w ? (w + 'wx_cfg.json') : ''; }
    return __KV.file;
}
function kvLoad() {
    if (__KV.mem) return __KV.mem;
    __KV.mem = {};
    var f = kvFile();
    if (f) { try { var t = readFile(f); if (t && t.charAt(0) === '{') __KV.mem = JSON.parse(t) || {}; } catch (e) { __KV.mem = {}; } }
    return __KV.mem;
}
```

- 落盘路径 = `jsb.fileUtils.getWritablePath() + 'wx_cfg.json'`（`writablePath()` 见 L163–L165；`readFile/writeFile` 走 `jsb.fileUtils.getStringFromFile` / `writeStringToFile`，L156–L162）。
- 格式：**JSON 对象文本**；仅当首字符为 `'{'` 才解析，否则视为无效。
- 内存缓存 `__KV.mem` 一旦装载就不再重读文件（`if (__KV.mem) return __KV.mem;`）。**注意**：空对象 `{}` 是 truthy 仍会命中缓存。

### 3.2 `storageGet(k, d)`（L764–L771）——读优先级

```js
try { var v = cc.sys.localStorage.getItem(k); if (v !== null && typeof v !== 'undefined') return v; } catch (e) {}
var m = kvLoad();
return (m[k] === undefined) ? d : m[k];
```
**先 `cc.sys.localStorage.getItem`，取不到才回落 `wx_cfg.json`；再取不到返回默认值 `d`。**

### 3.3 `storageSet(k, v)`（L772–L777）——双写、任一成功即 ok

```js
var ok = false;
try { cc.sys.localStorage.setItem(k, String(v)); ok = true; } catch (e) {}
```

两条路径**都写**（不是二选一）；值统一 `String(v)`；`.json` 每次整体 `JSON.stringify` 重写。

## 4. 心跳（`startHeartbeat`，L1372–L1383）

```js
function startHeartbeat() {
    // 微验这套只要求校验服务器时间差，这里按参考文件的做法对时
    setInterval(function () {
        xhr('GET', 'https://vv.video.qq.com/checktime?otype=json', null, function (err, res) {
            if (err || !res) return;
            try {
                var m = String(res).match(/"t":\s*(\d+)/);
                if (m) window.__WX_SERVER_T__ = parseInt(m[1], 10);
            } catch (e) {}
        });
    }, 300000);
}
```

- **周期 `300000` ms = 5 分钟**（`setInterval`）。
- 请求的是**腾讯视频对时接口** `https://vv.video.qq.com/checktime?otype=json`（不是自己的服务器，也不是 `wy.llua.cn`）。
- 正则 `/"t":\s*(\d+)/` 抠出 `t` 字段 → `window.__WX_SERVER_T__`（秒级）。
- **失败处理：静默**（`err || !res` 直接 return；异常 catch 吞掉），**不重试、不提示、不影响授权状态**；无失败计数、无降级。注释说明它只用于「校验服务器时间差」。
- 调用点：仅登录成功分支 L1350 `startHeartbeat()`（`startFeatures()` 紧随其后）。**没有** stop/清理函数，重复登录会叠加 setInterval。

## 5. 公告（`notice` / `noticeTextOf` / `currentNoticeText` / `refreshNoticePage`）

### 5.1 `notice()`（L1414–L1434）

```js
var now = Date.now();
try { if (now - (window.__WX_NOTICE_FETCH_T__ || 0) < 15000) return; window.__WX_NOTICE_FETCH_T__ = now; } catch (e) {}
xhr('GET', WX.noticeAPI + '&app=' + WX.appId, null, function (err, res) {
    if (err || !res) return;
    try {
        var jo = JSON.parse(rc4(res, WX.rc4_2));       // RC4 解密（用默认 encrypt 未传 → 解密方向）
        if (jo && parseInt(jo.code) === 200 && jo.msg) {
            var text = noticeTextOf(jo.msg);
            if (!text) return;
            window.__WX_NOTICE_TEXT__ = text;
            storageSet('__WX_NOTICE_CACHE__', text);
            refreshNoticePage();
            log('公告：' + text);
        }
    } catch (e) {}
});
```

- URL：`https://wy.llua.cn/api/?id=notice&app=44846`（GET，body 为 null）。
- **节流 15000 ms（15 秒）**，节流时间戳 `window.__WX_NOTICE_FETCH_T__`（在发请求**之前**就打点）。
- **成功码是字面量 `200`**（`parseInt(jo.code) === 200`），与登录的 `WX.okCode=74945` 不同。
- 响应同样 RC4 解密（密钥 `WX.rc4_2`），但**不校验 `check`/`time`**。
- 错误处理：`err || !res` 静默 return；解析异常 catch 吞掉；`noticeTextOf` 返回空则不覆盖缓存。
- 调用点：L7202（文件末尾启动时调一次）、L1981（切到公告页时 `if (isNotice) { refreshNoticePage(); notice(); }`）。

### 5.2 `noticeTextOf(msg)`（L1385–L1397）——取文本的字段优先级

```js
if (typeof msg === 'string' || typeof msg === 'number') return String(msg);
if (!msg || typeof msg !== 'object') return '';
var keys = ['app_gg', 'notice', 'content', 'message', 'text'];
```
按序取第一个**非空字符串/数字**字段，取到后 `String(value).replace(/^\s+|\s+$/g, '')` 去首尾空白；全空返回 `''`。`app_gg` 是微验公告惯用字段，优先级最高。

### 5.3 `currentNoticeText()`（L1399–L1404）

```js
var text = '';
try { text = String(window.__WX_NOTICE_TEXT__ || ''); } catch (e) {}
if (!text) text = String(storageGet('__WX_NOTICE_CACHE__', '') || '');
return text || '公告加载中…';
```
优先级：**内存 `__WX_NOTICE_TEXT__` → `storageGet('__WX_NOTICE_CACHE__')` → 默认文案 `'公告加载中…'`**（注意是省略号 `…` U+2026，不是三个点）。

### 5.4 `refreshNoticePage()`（L1406–L1412）

```js
if (!UI.noticeLabel || !nodeOk(UI.noticeLabel)) return;
var label = UI.noticeLabel.getComponent(cc.Label);
if (label) label.string = currentNoticeText();
```
- 目标节点 `UI.noticeLabel`（在下一段 L1968 由 `UI.noticeLabel = noticeBody;` 赋值；L1441 初值为 null）。
- 守卫：节点存在性 + `nodeOk()`；`getComponent(cc.Label)` 为空则不动。

## 6. 设备指纹（`androidId` 五路 + 落盘兜底）

### 6.1 `localFingerprint()` / `devFile()`（L653–L667，前置段定义）

```js
var DEV = { id: '', src: '', file: '' };
function devFile() { if (!DEV.file) { var w = writablePath(); DEV.file = w ? (w + 'wx_dev.dat') : ''; } return DEV.file; }
function localFingerprint() {
    var f = devFile(), s = '';
    try { if (f) s = nstr(readFile(f)).replace(/[^0-9a-zA-Z]/g, ''); } catch (e) {}
    if (s && s.length >= 16) return s.slice(0, 32);
    // 首次生成后落盘：同一台机器 mark 保持不变，卡密不会被判成"换机"
    var seed = prop('ro.build.fingerprint') + '|' + prop('ro.serialno') + '|' + prop('ro.product.model') + '|' +
               (ENV.serial || '') + '|' + Date.now() + '|' + Math.random();
    s = hex_md5(seed).slice(0, 24);
    try { if (f) writeFile(f, s); } catch (e) {}
    return s;
}
```
- 文件：`<writablePath>/wx_dev.dat`（纯文本，内容是被 `[^0-9a-zA-Z]` 过滤后的 hex 串）。
- 已存在且净化后长度 ≥16 → 取前 32 字符复用（**稳定**）。
- 首次生成：`md5(ro.build.fingerprint|ro.serialno|ro.product.model|ENV.serial|Date.now()|Math.random()).slice(0,24)` → 写盘。**含时间与随机数，所以只能靠落盘保持稳定**，这就是「必须在第一次装完就落盘」的原因。
- `ENV.serial` 由 L264 `jcall('android/os/Build','getSerial','()Ljava/lang/String;')` 填充。

### 6.2 `androidId()`（L919–L998）——优先级链

返回值同时写 `DEV.id`、`window.__WX_MARK__`，并且**只要非空就 `storageSet('__WX_STABLE_MARK__', id)`**（L996）。

**第 0 优先级：已固定 mark（L925–L933）**
```js
var savedMark = String(storageGet('__WX_STABLE_MARK__', '') || '').trim();
if (savedMark.length >= 6 && savedMark.length <= 128 && /^[0-9A-Za-z_.:-]+$/.test(savedMark)) {
    DEV.id = savedMark; DEV.src = 'saved-mark'; window.__WX_MARK__ = savedMark; return savedMark;
}
```
注释（L925）：mark 一旦成功使用就固定到本地；**切换 Wi-Fi/移动网络后加载器提供值发生抖动，也不能被当成换机**。校验：长度 6–128，字符集 `[0-9A-Za-z_.:-]`。

**路 0（L936）**：`window.__WX_ANDROID_ID__`（dex 加载器已喂入）→ 直接 `String()`。此路**不设** `DEV.src`。

**路 1（L939–L948）**：`jsb.reflection.callStaticMethod('org/cocos2dx/lib/Cocos2dxHelper','getActivity','()Landroid/app/Activity;')` → `act.getContentResolver()` → `Settings$Secure.getString(cr,'android_id')`。

**路 2（L951–L960）**：同上但用 `Cocos2dxHelper.getContext()` 的 `()Landroid/content/Context;`。

**路 3（L963–L971）**：`android/app/ActivityThread.currentApplication()` → `app.getContentResolver()` → `Settings$Secure.getString(...)`。

**路 4（L973–L979）**：
```js
var ser = nstr(jcall('android/os/Build', 'getSerial', '()Ljava/lang/String;'));
if (ser && ser !== 'unknown' && ser.length >= 6) { id = hex_md5('wx|serial|' + ser).slice(0, 16); DEV.src = 'build-serial'; }
```
注释：API 26+ 静态方法，鸿蒙/安卓 16 上只要有 `READ_PHONE_STATE` 就能拿到。

**路 5（L984–L992）**：落盘装机指纹兜底
```js
var lf = localFingerprint();
id = hex_md5('wx|' + (cc.sys.platform || '') + '|' + prop('ro.build.fingerprint') + '|' + lf).slice(0, 16);
window.__WX_DEVICE_ID__ = lf;
DEV.src = DEV.src || 'local-fp';
```
注释（L981–L983）原文要点：**原来这里是 `Date.now()+Math.random()`，每次启动都变 → 同一台机器每次进游戏 mark 都不一样，卡密系统会当成换机；鸿蒙上 android_id 取不到时这条就是主路径，所以必须稳定。**

**`DEV.src` 取值集合**：`'saved-mark'` / `'build-serial'` / `'local-fp'`（路 0/1/2/3 不设 src，保持空串；路 5 用 `DEV.src || 'local-fp'` 不覆盖已有的 `'build-serial'`）。该值进诊断（`__WX_LAST_LOGIN__.markSource`，L1309；`diagObj().dev.src`，L707）。

**mark 的两种长度**：路 4/路 5 生成 `hex_md5(...).slice(0,16)`（16 字符）；`localFingerprint()` 自身是 `.slice(0,24)`；保存后回读则原样。服务端用 `markcode` 参数接收（URL 编码后发送）。

## 9. 可复刻的最小事实清单（按调用顺序）

1. 读本地已固定 mark：`storageGet('__WX_STABLE_MARK__')`，命中即用（长度 6–128，`^[0-9A-Za-z_.:-]+$`）。
2. 否则 `androidId()` 五路补齐；无论如何最后 `DEV.id = id; window.__WX_MARK__ = id; storageSet('__WX_STABLE_MARK__', id)`。
3. `tm = floor(now/1000)`；`sign = hex_md5('kami='+kami+'&markcode='+mark+'&t='+tm+'&85PvP3tH5tZR4P5D')`。
4. `request = 'https://wy.llua.cn/api/?id=kmlogon&app=44846&kami='+enc(kami)+'&markcode='+enc(mark)+'&t='+tm+'&sign='+sign`。
5. `body = 'data='+enc(rc4hex(request,'007938632b3354adf3c37db48bb0aab2'))+'&value='+enc(random)`；`POST request + '&app=44846'`，`timeout 15000`，UA `Dalvik/2.1.0 (Linux; U; Android 12)`。
6. 解密响应 → JSON；放行条件：`code===74945` 且 `check` 匹配 `^[0-9a-fA-F]{32}$` 且 `|time - tm| <= 30` 且 `check !== md5(String(time)+appKey+appId)`。
7. `vip = parseInt(msg.vip)`；`fmtDate(vip)` 得 `YYYY-MM-DD`；`storageSet('kami', kami)`；`setCardAccess(msg, vip)`（写 5 个全局，永久卡阈值 `vip >= 3786912000`）；`window.__WX_AUTH_OK__ = true`。
8. `startHeartbeat()`（5 分钟一次腾讯对时）+ `startFeatures()` + 建菜单并销毁卡密窗。
9. 失败重试：`maxAttempts=4`，退避 `[800,1600,3000]` 之后 3000；仅 `isTransientLoginError` 或 msg 命中 `网络|超时|连接|繁忙|稍后` 或时间窗越界或解析异常才重试。
10. 公告：`GET https://wy.llua.cn/api/?id=notice&app=44846`，15 秒节流，`code===200`，`msg` 按 `app_gg→notice→content→message→text` 取串，缓存到 `__WX_NOTICE_TEXT__` + `storageGet/Set('__WX_NOTICE_CACHE__')`，默认文案 `'公告加载中…'`。
