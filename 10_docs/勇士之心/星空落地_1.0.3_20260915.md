## 3. 移速修复

原斌哥脚本的移速分支是 `if (MOD.feature4)`。星光菜单的 `Slider` 会把数值
写入 `getVal(4)`，不会设置 `getRet(4)`，所以分支一直不进入。

当前生成器已将移速分支改为：

```js
if (MOD.speed > 1) {
    var _sp = (MOD.speed > 0 ? MOD.speed : 1);
    hy.hTimeScale = hy.hTimeScale * _sp;
    touched.push([ hy, _sp ]);
}
```

`finally` 还原改为按实际倍率除法，并对还原写入加 `try/catch`，避免异常
从菜单包装层向战斗更新循环传播。

生成器：`04_scripts/勇士之心/gen_ysxz_patch_header.py`
静态回归：`04_scripts/勇士之心/verify_ysxz_patch_js.py`
后台菜单模板：`10_docs/勇士之心/yszzx_menu_template.json`（`template_id=yszzx`）

## 4. 自动战斗解锁

### 客户端门槛

`assets/game/index.js` 中金卡管理器：

```js
t.prototype.fsl = function() {
    return $fc.buff.bVy.bVs(a.$fe.tblEnum.BuffTableEnum.AUTO_BATTLE);
};
```

`assets/battleRender/index.js` 的自动战斗按钮处理：

```js
if ((...mw.bAO?.d) || $fc.monCard.fsp.fsl()) {
    $fc.battleMgr.bBv = !o.cYg;
    u.default.Ji.nb.bAh(!o.cYg);
}
```

`bAh()` 会向本地战斗命令队列发送 `$ug.L`；命令 `L` 在
`battleLogic` 中设置 `e.cYg`，开启时调用 `a.default.Et(n)`，关闭时清除 AI
并回到玩家控制。也就是说，放行 `fsl()` 后按钮会走官方自动战斗链，不是只改
按钮外观。

### 星光实现

`fsl()` 不在 `battleLogic` bundle，而在独立的 `assets/game/index.js` bundle。首版 native
只 patch `assets/battleLogic/index.js`，所以战斗四功能可以安装，但自动战斗特权不会挂。
首次真机测试已复现：菜单日志 `feature #5=ON`，点击自动战斗仍得到 `MONTH_CARD_OPEN`
对应任务提示。

修正后 native 同时接受 `assets/battleLogic/index.js` 与 `assets/game/index.js`，同一自愈 payload
会分别捕获两个 bundle 的模块注册调用。

二次包冷启动运行证据：

- `logic splice #1 len 6144404->6164591 file=assets/game/index.js`
- `[MODMOD] auto-battle privilege hooked = .prototype.fsl`
- `[MODMOD] REPORT ... auto=yes`

注入器运行时按明文指纹查找同时包含 `AUTO_BATTLE` 与 `bVs(` 的原型方法，
仅在 `MOD.feature5` 开启时返回 `true`，关闭时调用原方法。未写死混淆函数名。

对应源码：

- `mod菜单/starry-mod-menu/app/src/main/jni/Games/YsxzPatchJs.h`

## 5. 异常兜底

已完成：

- `se::ScriptEngine::evalString` splice 构造块有 C++ `try/catch`；异常回退执行
  原脚本，不拼接补丁。
- `window.__starry_capture` 包裹 `MOD_boot`，自愈安装异常不会阻断游戏加载。
- 各功能包装函数内部读取开关和字段访问均有局部 `try/catch`。
- 无限技能消耗包装补齐成本字段保存/还原的异常回退；包装自身失败时回退原函数，
  还原写入也已独立捕获。
- 移速倍率和还原均有异常保护，避免异常沿战斗 update 向外抛出。
- 自动战斗特权包装同理，异常时回退原特权函数。

边界：原始游戏函数自身抛出的异常仍按原逻辑处理，不把游戏原有错误伪装成成功。
装机后当前进程未启动，运行期长时间防闪退证据仍为 `NOT PROVEN`，需要真机实测。
