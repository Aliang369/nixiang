## 3. 调用链反推（恒 false 仍是唯一单点）

- 唯一引用点：`LoginTypes$Companion.smali:82` → `from(Landroid/app/Activity;Lcom/taptap/sdk/login/impl/data/model/Actions;)Lcom/taptap/sdk/login/impl/data/model/LoginTypes;`
  逻辑：`isClientLogin()==true → LoginTypes.CLIENT`；否则 `CloudGameUtils.isCloudGame(activity)` 真 → `CLOUD_GAME`；否则 `WEB`。
- `from(Activity,Actions)` 的调用点 3 处，全在 `com/taptap/sdk/login/impl/core/LoginCoordinator.smali`（282 / 385 / 528 行，对应 `auth()`、`getLoginType()`、`login()`）⇒ 每个登录入口吃同一判据。
- 下游分流：`DefaultTapLoginFragmentProvider.provide()` 用 `LoginTypes.from(String)` + `WhenMappings` 枚举序号分支：1 → `ClientLoginFragment`、2 → `CloudGameFragment`、3 → `WebLoginFragment`（`WebLoginFragment$Companion.newInstance`）。
- 云游戏旁路：`CloudGameUtils.isCloudGame` 会 `bindService` 到包 `com.cloud.taptap.gaming` + action `com.cloud.taptap.gaming.daemon`；设备无该包则不命中 ⇒ 落到 WEB。

⇒ 「恒 false」仍是正确的单点开关，**无新增门闩、无需换落点**。
