## 6. 待验证 / 风险（不得当已通过）

1. **r33 的 `libil2cpp.so` / `global-metadata.dat` md5 无任何文档记录**（题面已注「b-未记」）；本地也无 r33 底包或正式包可回溯（`08_output/霓虹深渊2/` 不存在、`/tmp/nhsy2` 无 apk）。⇒ 本轮只补了**本轮值**，r33 值只能靠 size 差异判「必变」。
2. **`libpuerts.so`（Puerts/TypeScript 运行时，17 MB）为新面孔**：`strings` 见 `CreateJSEngine`/`CreateJSEngineWithExternalEnv`/`CreateInspector`/`puerts_log`/`_ZN6puerts4PLogE…` ⇒ 确认是 Puerts。包内无 `.js`/`.mjs` 条目（`unzip -l` 只命中该 so 本身），脚本应在 `assets/bin/Data/` 内容寻址资源里。`libil2cpp.so`/`libunity.so` 的 `strings` 均 **0 次** 命中 `puerts`（P/Invoke 名来自 metadata，故 0 命中不能证明「未接入」）。**影响面**：若玩法/数值层搬到 TS，IL2CPP 按名挂点可能不再覆盖全部功能 —— 需在「开始做功能」后先核 metadata 类型面与 puerts 装载路径。本轮**不猜结论**。
3. `libVkLayer_khronos_validation.so` 21.9 MB（Vulkan 校验层）出现在**发行包**里属异常体积项；是否 r33 已有、是否被运行时加载：**待验证**。
4. r33 的全量 so 清单/条目数未留档 ⇒ 表里「lib 条目数」「libthemis-v8」「libVkLayer」只能与更早（10.12）记录比尺寸，**不能断言 r33→r34 的增删**。
5. 本轮**未做**（超出只读底包任务且需口令）：IL2CPP 符号面/dynsym 导出数核对、metadata 离线解析、pipline/挂点迁移。
