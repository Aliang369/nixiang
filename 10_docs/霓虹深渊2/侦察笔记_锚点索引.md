## §3 铁律级结论（踩过坑，禁止重试）

1. **入口 16 字节补丁必须查邻居**：`Attri.get_Item`（4 字节转发器）与 `StandardEditionAccessPolicy.IsRestrictedEvolution`（12 字节）都因 Dobby 固定改写 16 字节而改写邻居入口 ⇒ 见 §⑤.1/§⑤.4 的两道闸门（转发器链解析 + 短函数跳过）。真机判据：`install skip: N 个槽位因「入口形态不安全」主动跳过`。
2. **枚举实例不能整个喂 `il2cpp_field_static_get_value`**：只用 `value__`，否则 `fault addr 0xb8`（`memcpy(dst=…, src=0xb8, n=0x110)`）。
3. **滑块项只有 `nativeSetValue` ⇒ `g_features[]` 恒假 ⇒ 0 hook**：滑块值即开关（`DmgMulActive()/SpdMulActive()`）。
4. **不要在热路径做「扫同类实例」**：1 ms 内 SIGSEGV（已删能力，见 :1418-1442）。
5. **async_safe 坏格式串会 assert 杀进程**：任何新增日志格式串都过 §⑦.6 护盾自检。
6. 崩溃定位只认 tombstone + `addr2line`（带符号 so 用 `Android_nhsy2dbg.mk`，布局与 release 逐字节一致）+ 当轮 logcat 切片；**先探针，后改码**（hook-rules §29）。
