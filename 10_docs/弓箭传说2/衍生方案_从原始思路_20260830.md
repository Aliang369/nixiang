# 弓箭传说2 衍生方案 v2（基于《功能排查》实证校正）

> 校正说明：v1 误把"偷技能同方法 replay 补授"当可行，已被《功能排查》实证否决；全屏也误判 b 为数组。
> 本版以《功能排查_20260830.md》实证为准，区分"可忠实衍生"与"需补实证"两部分。

## 一、实证已定（来自《功能排查》，非假设）

- **PushHurtDataArray** 活（94–7347 次/局）：`a=HabbyIm_GameProxy` 恒定单例；`b`=**单条**伤害对象 `{klass, monitor, int 值, ptrA, ptrB}`。ptrA/ptrB 在部分伤害类是 target/attacker 指针，在另一些类是 `{skillId,skillId}` 打包 int（非指针，野读会崩）。
- **AddSkill(this,int skillId,c,d)** 活但**有前置校验**：`AddSkill(a,非选中id,c,d)` 与选中调用参数形态一致，但新局静默无效、恢复局直接崩溃 → 原始"对每个候选补授"在此方法上**走不通**（三选一 pending 状态机前置）。
- 旧路径 `UpdateHp/ChangeHp/SetHp/BeforeHurtTarget/AddSkillToCharacter` **全 0 命中**。
- **`_skills` = `Dictionary<int,SkillData>`**（diag22-23 活体）：buckets `int[17]` @+0x10、entries `Entry[17]` @+0x18、count @+0x20；Entry stride=0x18；key=skillId；value={来源,等级}；**hash 算法未破译**（非 identity、非 key%17）。
- **GM 命令裸调已实证无效**（废弃）：`GMAddSkillCommand` object_new+填 SkillId@0x20/PlayerId@0x24+直调 Exec 执行但游戏不授予（缺命令管理器注册/上下文）。
- `AddPlayerSkill` **不属于** HeroComponentRandomSkill（metadata 串属其它类），签名未验证。

## 二、三个功能的衍生结论

### 1. 隐身（feat1）— 一字不改 ✅
`Hooked_SetTarget` / `Hooked_TrySetTarget` 原样保留。热更未动这条链，至今生效，证明原始思路未失效。

### 2. 全屏（feat2）— 可忠实衍生（意图不变，机制换落点）
- **原始意图**：玩家命中时把同一次伤害扩到所有怪（"一次打一片"）。
- **新机制**：hook 活体 `PushHurtDataArray(a,b)`，orig 转发后遍历其它怪，对每只：
  1. 复制 b 到 scratch；
  2. 把 b 的**目标指针字段**改写为该怪；
  3. 再调一次 orig `PushHurtDataArray(a, scratch)`（reenter 保护）。
- 这就是原 `Hooked_UpdateHp` 里"对其它怪 replay damageData"的等价实现，只是落点从死掉的 UpdateHp 换到活的 PushHurtDataArray。
- **待 dump 定准**（§三）：b 内哪个偏移是目标指针，且需**按 b 的类判别**——仅对"target 指针类"重定靶；打包-int 类跳过或另行处理（避免野读崩）。

### 3. 偷技能（feat0）— 原始 replay 补授已死，须改注入归属结构 ⚠️
- **原始意图**：三选一拿全部技能（"三个都拿"）。
- **新现实**：授予点 `AddSkill` 被状态机门禁，非选中 id 补授被拒。**不能纯 1:1 衍生**。须把技能直接写进"归属结构"，候选路线：
  - **(A) `_skills` Dictionary 直写**：布局已知（§一），只差 **hash 算法**。需从 dump 反推（buckets 各桶→key 映射）。直写风险：hash 错=查找失败白写；写坏=战斗崩。**必须先在某条"已选中技能的 Entry"上做只读验证**。
  - **(B) `AddPlayerSkill`**：metadata 属"其它类"，需定类+签名，验证是否绕过门禁（名字即语义，最可能是真正的无条件授予入口）。
  - **(C) `_playerCachedSkillId` 缓存改写**：结构未验证（`BattleWorldContext._playerCachedSkillId` + Get/SetCachedSkillId）。
- 推荐顺序：先验 (B) `AddPlayerSkill` 是否绕过门禁（若绕过，则忠实衍生为"在活体授予时机对候选每个 id 调 AddPlayerSkill"）；否则走 (A) 字典直写（需先破译 hash）。
