## 玩家隐身实抓（2026-08-17）

**用户确认：开 feat1 后「怪不理我」。**

| 观测 | 结果 |
|------|------|
| 菜单名 | `Toggle_玩家隐身`（不是「无敌挡伤」） |
| 英雄 `UpdateHp` | **0 次**（不掉血是因为根本挨打不到） |
| `SetTarget` → 英雄 | **0 次** |
| `SetTarget` 其它 | `null` / `EntityMonster` 为主 |
| 英雄 `get_IsDead` | 一直返回 **0**（不是伪装死亡） |
| 壳 inline hook | `get_IsDead`、`SetTarget` 入口已被 Dobby；`UpdateHp` 亦有 B stub |

**结论：** 效果 = **仇恨/索敌排除玩家（隐身）**，不是改 `HurtValue` 的硬无敌。  
**复刻方向：** 阻断怪对玩家的索敌（`SetTarget`/`TrySetTarget` 过滤英雄，或改索敌/可见性字段）；可选再给英雄 `UpdateHp` 挡伤作兜底。

日志：`06_dumped/弓箭传说2/probe_feat1_隐身/`


## 偷技能实抓（2026-08-17 Florida 只读探针）

**签名（运行时解析）：**

| 方法 | 签名 |
|------|------|
| `SelectSlotCommand.Exec` | `()` → bool/int |
| `RandomSkillResult.get_ShowSkills` | `()` → `Int32[]` |
| `BattleWorldContext.AddSkillToCharacter` | `(EntityCharacter entity, int skillId, int addToComponent)` |

**一次点选实测调用序：**

1. `get_ShowSkills` → `Int32[]`（三选一候选）
2. `SelectSlotCommand.Exec` ENTER
3. `AddSkillToCharacter(EntityHeroNormal, 10106, 1)`
4. `AddSkillToCharacter(EntityHeroNormal, 10411, 1)`
5. `AddSkillToCharacter(EntityHeroNormal, 14003, 1)`  ← **一次选中触发 3 次授予**
6. `Exec` LEAVE

**复刻要点：** 开 feat0 时，在 `SelectSlotCommand.Exec` 路径上把 `get_ShowSkills` 返回的每个 `skillId` 都对玩家 `AddSkillToCharacter(..., 1)`（不只发选中的那一个）。日志：`06_dumped/弓箭传说2/probe_feat0_skill/steal_skill_chain.txt`
