### 2.2 关键机制实锤

1. **MP 槽位钩法有效**：Exec/PushHurtDataArray/AddSkill 的桩都正常命中——8-17 的钩法本身没过时
2. **`AddSkill` 会消费并清空候选数组**（get_ShowSkills 返回的 Int32[]）：orig 后读数组=空壳 → 快照必须在 get_ShowSkills 命中点抓
3. **补授调用被游戏拒绝**：`AddSkill(a, 非选中id, c, d)` 与选中调用参数形态一致，但新局静默无效、**恢复局直接崩溃**——授予有内部状态机/前置校验，非无条件函数
4. **玩家拥有技能不以 id 存于 HeroComponent**：选中 10613 后全对象/全堆扫描均无该值（堆内 6 处均为定义表）——内部转对象引用存储
5. **`0x7866906790+0x10`**：全部可刷出技能定义表（16 个：10410/10624/13001/10611/10201/10806/10203/10613/10301/10630/10509/10621/10603/14003/10634/14001，每 id 相邻重复两次）
6. **MP 槽位永不漂移**：对局前后 291 个方法快照零变化（无 transform 机制）
7. **"全技能定义表"的字符串元素**：`1_016`/`1_015` 等配置 key 与 id 对混排（0x78acfa88d0，配置容器）
