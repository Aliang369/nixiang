## 1 三条路径

### 路径 A：覆盖安装（取证「确认异签」，不是交付路径）

```bash
adb -s emulator-5554 install -r -d "E:/nixiang/08_output/阿比斯少年冒险团/abssnmxt_2.36_v1.apk"
```

预期（不是故障）：`Failure [INSTALL_FAILED_UPDATE_INCOMPATIBLE: Package com.wks.abyss signatures do not match previously installed version]`，adb 退出码非 0。

按硬约束 A6：**看到这一行就停手回报 lead**，不得自动 uninstall、不得 `pm clear`。

### 路径 B：卸载重装（会清本地数据，需用户授权）—— 推荐

走统一入口（自带外置数据备胎 + uid 归位 + restorecon，比手敲 uninstall/install 安全）：

```bash
# 先空跑看判定（不写任何东西）
bash 04_scripts/_common/install_starry_apk.sh \
  --apk "08_output/阿比斯少年冒险团/abssnmxt_2.36_v1.apk" \
  --pkg com.wks.abyss --so-tag '[Abssnmxt]' --game-id abssnmxt \
  --serial emulator-5554 --clean --dry-run

# 判定无误后真跑
bash 04_scripts/_common/install_starry_apk.sh \
  --apk "08_output/阿比斯少年冒险团/abssnmxt_2.36_v1.apk" \
  --pkg com.wks.abyss --so-tag '[Abssnmxt]' --game-id abssnmxt \
  --serial emulator-5554 --clean
```

该脚本做的事（摘脚本头，非我推测）：先试覆盖安装 → 报 UPDATE_INCOMPATIBLE 才走卸载 → 卸载前把 /sdcard/Android/data/<pkg> 同卷 rename 成备胎并**核对非空才允许卸载** → 装完归位 + `chown` 新 uid + `restorecon` → 跑 `ensure_starry_device_id_seed.sh`。
退出码：`0`=成功 / `1`=校验或闭环核对失败 / `2`=用法错 / `3`=备胎失败且未加 `--allow-resource-loss`。

### 路径 C：手动兜底（仅当路径 B 不可用）

```bash
adb -s emulator-5554 shell am force-stop com.wks.abyss
adb -s emulator-5554 uninstall com.wks.abyss
adb -s emulator-5554 install "E:/nixiang/08_output/阿比斯少年冒险团/abssnmxt_2.36_v1.apk"
```

手动路径**没有外置数据备胎**：/sdcard/Android/data 26 MB 会被系统连带删除，游戏需重新落地热更（推断：重新下载 files/AssetBundles + 重写 files/il2cpp/Metadata）。

## 2 卸载会清掉什么（给用户看的风险清单，实测文件清单）

| 位置 | 体量 | 内容 | 卸载后 |
|---|---|---|---|
| /data/data/com.wks.abyss/shared_prefs | 48 KB | tap_sdk_sp.xml、taptap_sharepreference.xml、TapSdkCore_SP.xml、com.taptap.sdk.GATEKEEPER_SETTING.xml、[hex=278b8cc4…]_timing_file_suffix.xml、com.wks.abyss.v2.playerprefs.xml、com.wks.abyss_preferences.xml | **全清** ⇒ TapTap 登录态丢失，需重新登录（可能再次弹授权/实名） |
| /data/data/com.wks.abyss/files | 116 KB | tapsdk/events.db、tapsdk/logs、TapEvent_persistedData | 全清（埋点日志，无价值） |
| /data/data/com.wks.abyss/app_THEMIS | — | THEMIS 运行时数据 | 全清（重装后重建） |
| /sdcard/Android/data/com.wks.abyss | 26 MB | files/AssetBundles/、files/il2cpp/ | 路径 B 有备胎可回；路径 C 全清需重下 |

**给用户的确认项（人工步骤，装机前必做）**：
1. 先确认游戏内是**已登录 TapTap 账号**状态，且记得账号密码（或 TapTap App 已登录）。
2. 进度若在服务器侧（账号绑定）则卸载不影响；若只在本机 playerprefs 则卸载即丢——本机 com.wks.abyss.v2.playerprefs.xml 仅 937 B，像设置项而非进度，但**未验证**，按「可能丢」告知。
3. 接受「重装后重新登录 + 首次进游戏重新热更」这两条代价后再授权。
