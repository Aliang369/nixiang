## 5. STL 链法（2026-11-15 定稿：c++_static）

`APP_STL` 在共享的 `Application.mk` 里是 **app 级**设置（`c++_shared`），本游戏不改共享文件，
改用私有 app mk `07_tmp/app_abssnmxt_static.mk`（`APP_STL := c++_static`）由出包脚本自动生成，
经 `NDK_APPLICATION_MK=<绝对路径>` 覆盖。

理由（避免装机暴露）：
- 动态链时 so 的 `DT_NEEDED` 含 `libc++_shared.so`，底包**没有**这个库；虽然可通过"同目录搜"被
  dlopen 解析到，但一旦包内漏带即 `UnsatisfiedLinkError`。静态链把它彻底去掉。
- 静态链实测：`NEEDED` 只剩 `liblog.so / libandroid.so / libc.so / libm.so / libdl.so`（系统库），
  `llvm-nm -D --undefined-only` 内 **零 `_Z...` C++ 未定义符号**、零 `__emutls_get_address`。
- 代价：so 从 181 KB（动态）涨到 381 KB（静态），包体 +约 200 KB，可接受。
- 换 STL 必须清 `NDK_OUT`：ndk-build 不跟踪编译开关，旧 `.o` 仍带 c++_shared 引用，链接后 NEEDED 会复发
  （脚本段6 已 `rm -rf` 并断言 NEEDED 不含 `libc++_shared.so`）。
