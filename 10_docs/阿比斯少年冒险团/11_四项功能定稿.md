# 阿比斯少年冒险团 2.36 — 四项功能定稿

> 定稿版本：星光菜单 v2.0（`abssnmxt_2.36_v2.0.apk`）
> 定稿日期：2026-11-15　｜　功能项以用户点名四项为准，一项不多（AGENTS §4 功能边界）。
> 详细过程与探针轮次见 `09_v1.5设计_血量0x198.md`（§15 G6 属性系统、§16 v1.9、§27 无CD、§30 v2.0）。

## 1. 无敌

| 项 | 内容 |
|---|---|
| 落点 / RVA / 偏移 | 属性 **id 62 = DAMAGE_GUARD**：`unit+0x120 → state → oknd`；容器实现在 `oknd+0x50`（运行时类 `AGNKCIDBODI`）；写入走 `NBOPCNCOKLD(enum,int)` RVA 0x36B6260（GGLI 分支走 `JCHJIBOHDEL` 0x36B26F0） |
| 依据 | G6 静态闭环：减伤路径只读 id62；三实现类判别（GGLI/AGNK/EHKMOK）由 `il2cpp_class_get_name` 运行时确认；实测日志 `attr impl=AGNKCIDBODI` + `attr62 set=1 before=0 after=1` |
| 验证方式 | 开关打开后玩家受击不掉血（用户实测）；日志 `attr62 set=1 before=0 after=1`；关闭后还原 before 值 |
| 备注 | 关闭开关「保持当前血量、不退回旧值」；每 tick 只对 `faction==PLAYER` 写入 |

## 2. 伤害倍率

| 项 | 内容 |
|---|---|
| 落点 / RVA / 偏移 | `Unit::BLKEJBDMGAB` RVA **0x354B388** 的 Dobby inline hook；载荷结构副本 `+0x24`(int) / `+0x28`(int64) / `+0x38`(int64) 三分量各乘倍率；`+0x40`(float) 不动 |
| 依据 | `JJFBPGNPMKB::LMBHNAMDIL` 0x3642390 填充载荷；`delta = +0x28 + +0x38`；guard 清零作用在 `+0x24`/`+0x38`；v1.9.2 实测 `p24 1→39 / p28 8→312 / p38 8→312`（倍率 39） |
| 验证方式 | 打怪伤害数字成倍增长（用户实测）；日志 `dmgx payload-copy mult=.. p24=..->.. p28=..->.. p38=..->..`（v2.0 起 5s 节流） |
| 备注 | 栈副本 0x60 字节，绝不原地改；三分量全 0 时 `zero-payload skip=1` 透传；倍率上限 100；滑块 1 = 关闭（直接透传） |

## 3. 移动速度

| 项 | 内容 |
|---|---|
| 落点 / RVA / 偏移 | `oknd+0x48`（float，移动速度倍率）；滑块 1..10 → mult = 1.0 + (slider-1)×0.25 |
| 依据 | v1.2 起定位，v1.4 修「基准值捕获时机 / 滑块 1 未还原 / 派生值覆盖」三个 bug；用户原话「移动速度没问题了」（L3 PASS） |
| 验证方式 | 滑块改变实际移动速度、滑块 1 恢复正常（用户实测）；日志 `speed base captured` / `speed restore ok` / `drift` |
| 备注 | 基准值在写入前锁定（连续 2 tick 稳定）；还原带读回校验（≤3 次重试）；漂移检测保留 |

## 4. 无限技能（无 CD + 无限蓝）

| 项 | 内容 |
|---|---|
| 落点 / RVA / 偏移 | **无 CD**：5 个 bool 判定入口恒 true —— `IAGGDOCLNND::OIKKANJOLNC` 0x35546B0、`IDNHEGOKGNA::OIKKANJOLNC` 0x3608534、`PFNDCCBPLGI::OIKKANJOLNC` 0x349EB1C、`POBKCDEHPNK::OIKKANJOLNC` 0x359516C、`IDNHEGOKGNA::KFFALNFHHJL` 0x35FD1E8；另 `FEJHANBJNCK` 0x35547E4 为 void 桩直返（不写冷却）；**能量门禁** `ActionButton::NLGNPKOALJP` 0x3006D98 → `ActionButton+0xE8 = 1`；**无限蓝** `state = *(unit+0x120)` → `FJDABAEBLJG(10000)` 每 500ms |
| 依据 | recon 整函数反汇编：`Unit+0x128` 为真技能容器（`DFNAOICKOJP` 0x354A530）；5 个入口返回 bool 且都取 `HClock::NMHDPNKKNBP` 的 now；`NLGNPKOALJP` 中 `+0x54` 取当前能量、`+0x58` 取需求能量、`+0x6C` 写 `+0xE8` bool；能量侧 `IHHHPKIGIBN` 0x3641CD0 给出 id48 绝对值 / id49 万分比 |
| 验证方式 | 技能可连续施放、冷却图标不再转、能量不掉（用户实测 v1.9.12，v2.0 逻辑一致）；日志 `hooktable ok n=7 kinds=0x11C` + 首次 `hook installed tag=skidX` / `hookset tag=energygate` / `energy-fill uid=..` |
| 备注 | 5 个判定 + 门禁仅开关打开时生效，关闭时透传原逻辑；`attr36/51/52/57/48/49` 属性写入保留为对照但**不参与**效果解释；`HGCKACANGHC`(0x34A40C4) 已证不是技能 CD，v2.0 不挂 |
