## 四、出包复现

```bash
cd "$NIXIANG_ROOT"
ENDFIELD_SKIP_DEXPATCH=1 ENDFIELD_SIG_KILLER=1 \
  bash mod菜单/starry-mod-menu/scripts/surgical_endfield_1.7.2.sh
```

必须看到的断言（缺一条即失败）：

```text
merged ok; entries≈1759; classes7.dex=657712 bytes; A轨替换=; protected keep=38 sha256 match
[endfield_killer_dex] ok  pkg=com.hypergryph.endfield  dex=…/endfield_signature_killer.dex
[verify] PASS（dex 可解析 + 类/包名/证书三项均正确）
```

- 判据是**断言集**，不是 md5：smali assemble 非确定性，同源码重跑 md5 可能不同，md5 不一致不算回归。
- opt-in 开关（默认 0＝原行为）：`ENDFIELD_SKIP_DEXPATCH`（`surgical_endfield_1.7.2.sh:104`）、`ENDFIELD_REASSEMBLE_DEX5`（`:107`，仅二分用，**不得进正式包**）、`ENDFIELD_SIG_KILLER`（`:113`）、`ENDFIELD_NO_MENU_SVC`（`:116`，诊断用，**不进正式包**）。脚本现 744 行。
