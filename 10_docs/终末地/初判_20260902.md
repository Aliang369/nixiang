## 引擎 / 保护

### 原版

- Unity **IL2CPP**：`libil2cpp.so` + `assets/bin/Data/Managed/Metadata/global-metadata.dat`
- Application：`com.u8.sdk.U8Application`（非 `AceApplication` 名，但 so 侧仍有 ACE）
- **腾讯 ACE/TSS**：`libtersafe2.so` + `libtprt.so`（高风险；星光落地必须外科组装，禁止 `apktool b`）
- 登录：Manifest 可见 TapTap / 微信等（待细化）

### Buff 包（斌哥 + 朋友双开）

- 斌哥特征齐：`libSDKloading.so`（~23MB，偏大变体）、签名 binge2、壳内 Dobby + IL2CPP API 字符串
- 另有 `libbaiduprotect.so`（壳自身百度加固）
- 入口为 `pengyou.cloneapp` → 虚拟机内拉起原版包名进程，菜单/Hook 注入 guest
- `libSDKloading.so` 内可见方法名线索：`CalculateDamage`、`CheckCd`、`CheckSkillCd` 等（待 memdiff 证实）
