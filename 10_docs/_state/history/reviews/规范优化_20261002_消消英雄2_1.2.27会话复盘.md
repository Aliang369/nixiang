## §2 已验证、可复用的关键事实

### 2.1 定制头 Lua 5.3 字节码格式（本会话最贵的发现）

| 字段 | 值 |
|---|---|
| magic | `1b 4c 75 61`（`\x1bLua`） |
| version | `0x53` |
| **format** | **`0x01`**（标准 5.3 是 `0x00` ⇒ `luac -l` 必报 `format mismatch`） |
| 校验串 | `19 93 0d 0a 1a 0a` |
| **size 字节个数** | **4 个 `04 04 08 08`**（标准 5 个 `04 08 04 08 08`） |
| `LUAC_INT` / `LUAC_NUM` | `0x5678`(8) / `370.5`(8) |
| 头长 | **32 B**，body 从 `0x20` 起（`sizeupvalues`(1) + source 串：1B 短长度、`0xFF` 转 8B） |
| 指令 | code 段前是 `int32` 计数（4 字节），指令 4 字节 |
| 常量 tag | `0`nil `1`bool `3`float8 `19`int8 `4`短串 `20`长串 |
| `sBx` | `GETARG_Bx - 131071`（`MAXARG_sBx = MAXARG_Bx>>1`） |
| class 方法表 | `CLOSURE R -> proto#N` 紧邻 `SETTABLE R R "名字"` ⇒ **名字行 k 对应 CLOSURE 行 k-1** |

### 2.2 运行时解密 Lua dump（静态面拿不到）

- 诊断宏（`#if MATCH2_LUA_DUMP_TRACE` + `MATCH2_DUMP_ALL`）令 `ShouldDumpModule()` 恒真，
  dump 目录 `/sdcard/Android/data/<pkg>/files/starry_lua_dump`，文件名
  `m_<fnv1a32(源路径)>_<len>.lua.bin`（同名 `.path` 只有 `SignatureLoader.load_and_verify` 路径才有）。
- 模块内嵌源路径串形如 `Assets/Application/Scripts/Lua/Application/Fight/View/GameViewUpperUI.lua.txt`，
  可据此反查模块用途；中文 UI 文案**不在 Lua**（在 C#/文本表侧）。
- 日志量必须封顶（本次 `n <= 400 || ShouldDumpModule(name)` / `n <= 400 || (n % 500) == 1`），否则刷屏丢事件。

### 2.3 opcode 序「未混淆」自证（别凭记忆抄 5.3 表）

包内 `lib/arm64-v8a/libxlua.so` **未 strip**：`.symtab` 有 `luaP_opnames`@`0x666e8`（384 B = 48 指针）与
`luaP_opmodes`@`0x10888`（47 B），`.rela.dyn` 提供 addend ⇒ 读出的名字序 = 标准 5.3
（`0 MOVE … 44 CLOSURE 45 VARARG 46 EXTRAARG`）。

### 2.4 门控定位套路（「解锁型需求」）

1. 从 UI 提示文案 key 找调用点：`GameViewUpperUI:OnAutoPlayButtonClicked`（`m_eef4907f_19129` proto#14，行 206-222）
   先调 `UserInfoManager.HasUnlockSpeed3()`，`TEST R1 0 1` + `JMP +19 -> 24`：未解锁不跳、直接
   `UIManager.OpenWindow("InstructionWindow", nil, GameText.GetText("auto_play_open_tip", GameConfig.GetAutoPlayOpenChapter() .. "-" .. GameConfig.GetAutoPlayOpenSection()))` 后 `RETURN`；解锁才跳到 24 执行真正的 `InputManager.SetCurrentMode` 切换。
2. 确认判定函数唯一：`UserInfoManager.HasUnlockSpeed3`（proto#104，行 1617-1620）＝
   `MainLevel.Create(GetAutoPlayOpenChapter(), GetAutoPlayOpenSection()) <= _accountMaxMainLevel`；
   同模块 `OnSpeedUpButtonClicked`（proto#12）首句也调它 ⇒ 自动战斗与 3 倍速**同一门控**。
   全库只有这两个调用点；`Utility:ShowAutoPlayButton`（proto#39）与章节进度**无关**（按钮本来就显示）。
3. 落地＝**覆盖该函数**（幂等 + `rawget` 守卫，`AN_x` 为真时 `return true`，关开关逐帧回退原判定），
   而不是改数值、不是替换战斗逻辑。
4. 边界（用户 m00812 明确）：**只解锁门控，不搬/不仿写游戏内置逻辑**；dump 只为定位门控。
