## 统计

- 扫描范围：`git ls-files '*.sh'` 全部 508 个
- 硬错误：93 处，分布在 71 个文件
- 性质：`$VAR` 紧跟全角标点（`（`/`）`/`，`/`；`）），bash 3.2 把全角字符并进变量名
- 危害分级：脚本有 `set -u` → 该行直接 unbound variable 退出；无 `set -u` → 变量展开为空，
  echo 输出静默缺值（不炸但输出错，最难察觉）
- 为什么现在才暴露：这些脚本多写于门禁建立（2026-09-30）之前，此后未再改过，
  preflight 是"改哪个查哪个"，从未对存量全量跑过
