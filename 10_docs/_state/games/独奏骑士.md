## 本轮改动

- `app/src/main/java/com/starry/magic/auth/DeviceFingerprint.java`
  - 将 v5 主设备 ID 收敛为 SSAID（`Settings.Secure.ANDROID_ID`）；非法或已知异常 SSAID 不再静默生成新 ID，而是显式报错。
- `app/src/main/java/com/starry/magic/menu/Preferences.java`
  - 保存并读取 `auth_legacy_device_ids`；旧共享种子和 v4 硬件哈希仅作为服务端迁移候选，不再作为 v5 主绑定 ID。
- `app/src/main/java/com/starry/magic/menu/NativeMenuController.java`
  - 卡密激活/校验请求携带 `legacy_device_ids`，供 auth-server 把历史绑定迁移到当前 SSAID。
- 新增 `mod菜单/starry-mod-menu/scripts/dzqs_payload_swap_1.1.768.sh`
  - 直接以现有过验星光包为底包，构建 dex/so 后仅替换 `classes2.dex` 与 `libstarry_magic.so`。
  - 执行逐条目 zip 审计、zipalign、apksigner、安装门禁、`pm install -r -d --user 0` 和设备 md5 回读。
- `mod菜单/starry-mod-menu/app/src/main/jni/Games/DzqsMod.cpp`
  - 增加 `FileOffToVa()` 按 `/proc/self/maps` 的文件偏移解析，不依赖 ELF base + RVA。
  - 将旧挂点切换到 1.1.768 的 `FILE_ENTER_INTERP = 0x20B5A40`。
  - 1.1.768 无限技能修正：`zCd` 是 `Game_RoleSkill_Property[81]`，值偏移 `baseData+0x2AC`；索引 82 是 `damage_ex_p`。
  - `isCdOK/isManaOk` 命中后必须继续 `musttail` 调用原函数，禁止假返回。
- `mod菜单/starry-mod-menu/app/src/main/jni/Android.mk`
  - 仅在 `STARRY_GAME_DZQS=1` 时选择 `Games/DzqsMod.cpp`，未改变 WDYz 默认分支。
- 新增 `mod菜单/starry-mod-menu/scripts/surgical_dzqs_1.1.768.sh`
  - 官方 `resources.arsc` 保持字节一致，替换 patched `classes.dex`，新增紧邻的 `classes2.dex` 与星光 so。
