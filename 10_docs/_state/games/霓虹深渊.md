## 当前摘要

- 包：TapTap `com.shangyoo.neon` 3.2.860 / vc104，Unity IL2CPP + xLua + iFix。官方原包无壳、无 `assets/web/`。
- 架构：modern 注册表（`MainModern.cpp` + `Games/NeonEntry.cpp` + 私有 `Android_neon.mk`），`Main.cpp` 未改。
- 菜单 12 项：无敌 / 秒杀 / 技能无CD / 移速 1-5 / 攻速 1-5 / 金币 / 钥匙 / 彩色钥匙使用不减 / 无限跳跃 / 伤害倍率 1-50 / 丝血无敌 / **全屏攻击**。
- 2026-11-26 新增第 12 项【全屏攻击】：用户确认「全屏攻击可以了」。实现要点＝触发点 `HitPoints.DoDeductHP`、玩家判定沿 `typeHierarchy` 比 `PlayerActor`、房间取 `MapManager.curRoom(+0x20)` 或 `EhiEntity._currentRoomMb(+0x48)`、列表取 `RoomMB+0x78/+0x80`。
- 同轮删除【武器等级】：用户要求「武器等级不做了直接删除」，菜单从 13 项回到 12 项，后台需同步删除 feat 13。

## 构建入口

```bash
cd mod菜单/starry-mod-menu
NEON_BASE_APK=../../02_apks/霓虹深渊/霓虹深渊_3.2.860_vc104_原版_20261126.apk \
  bash scripts/surgical_neon_3.2.860.sh                       # 正式版（neon）
NEON_VARIANT=dz … bash scripts/surgical_neon_3.2.860.sh       # 定制版（nhsy-dz）
```

切换 variant 必须先 `touch Games/NeonEntry.cpp` 或删 `obj_neon`——ndk-build 不检测 `LOCAL_CFLAGS` 变化，否则 game_id 会串版。
