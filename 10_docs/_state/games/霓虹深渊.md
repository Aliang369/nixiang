## 当前摘要

- 包：TapTap `com.shangyoo.neon` 3.2.860 / vc104，Unity IL2CPP + xLua + iFix。官方原包无壳、无 `assets/web/`。
- 架构：modern 注册表（`MainModern.cpp` + `Games/NeonEntry.cpp` + 私有 `Android_neon.mk`），`Main.cpp` 未改。
- 菜单 8 项：无敌 / 秒杀 / 技能无CD / 移速 1-5 / 金币使用不减 / 钥匙使用不减 / 彩色钥匙使用不减 / 无限跳跃。
- 菜单不含：`攻速`、`伤害倍率`、`丝血无敌`、`全屏攻击`；`Neon_TryInit` 不安装其钩子（攻速 7 点、丝血 4 点、全屏房间 7 点、玩家类型槽），实现代码不可达。
- 菜单项可核验：so 内已无 `Toggle_攻速` / `Slider_攻速:1:5` / `Slider_伤害倍率:1:50` / `Toggle_丝血无敌` / `Toggle_全屏攻击` 字面量。
- **RVA 基准**：`g_libBase` 只由锚点决定（`Abs(RVA_GRAPH_ATTACK_MN) - RVA`），`/proc/self/maps` 的最小 start 可能是前置保护段（差 0x46DCB000），拿它当 base 会让所有 RVA 栈判据恒不命中（无限跳跃就栽在这里）。装机日志 `libil2cpp base` 与 `libRange base` 必须相同，详见实现口径 §2b。
