冷启自杀（无 FATAL / 无 tombstone / SIG:9）已定位为 C# AOT `ET.AndroidPackageIntegrity`：3.5 把 `AndroidManifest.xml` 的 sha256 纳入 `assets/NativeIntegrity/<abi>.audit`（128 B 哈希 + 384 B RSA）⇒ 任何 manifest 注入必触发，`ExitModifiedPackage` 直接 `killProcess`。解法 = 三处放行钩（ReadInstalledIdentity / VerifyCurrentSigner / VerifyPackageContents）**在 Unity `<Start>` 之前装好**：Entry `onLoad` 起 5 ms 轮询线程（实测 31 ms 见到库），框架 initDelay 比校验晚 340 ms 用不了。killer dex 仍保留（Java 侧回灌官方 DER）。
