- **1.0.4 新加固与破法**：`lib/arm64-v8a/` 已无 `libcocos2djs.so`，cocos so 改放加密资产
  `assets/apksecuresolib/arm64-v8a/libcocos2djs.so`，由 `libsecret.so` **以「签名+包名」派生密钥**解密后 `android_dlopen_ext`。
  解法三件套：`SignSpoof.java` 增本包条目（`YSXZ_PKG`/`YSXZ_CERT_B64`，运行期 `spoof hit … md5=79a6a62f…`）

- **启动 5~13 s 干净退出（本轮最大障碍）**：根因＝保护线程主动 `_exit(0)` → bionic 内联 `exit_group(94)`。
  解法 `jni/Games/YsxzExitTrace.cpp`：libc 钩子定位 + seccomp `SECCOMP_RET_TRAP` 只拦 94 + SIGSYS 处理器
  **仅结束该线程**。教训：① 绝不能拦 `exit(93)`（普通线程退出；拦了会让线程落进 `udf` → SIGILL 整进程陪葬）；
  ② `RET_ERRNO` 拦法留 destroyed-mutex 二次崩溃，只能 TRAP；③ 各类退出调用必须独立计数。
- **新增功能「伤害倍率」滑块 1..50**（`MOD.damage = V(1)`，乘最终伤害）；用户要求换位后的菜单：
