# 不一样的修仙宗门2 状态摘要

- 用户目标：去签名 + 网页强制登录 + 无限仙玉 / 无限灵石 / 免广告，出星光包
- 结论（2026-11-02）：**已交付并 L3 通过**，用户原话「功能都没问题了」
- 技术要点见 [抓点与实现_1.1.8.md](../../不一样的修仙宗门2/抓点与实现_1.1.8.md)：

  - 免广告：window.donghuaFuhao = !1 → TdFuzhu.kaishiDonghua 直接回调发奖
  - 开关通道：databases/jsb.sqlite 的 data 表（Cocos localStorage 不是 SharedPreferences）

- 验签/登录：SignTool.CheckSign 无调用者；包内无 TapTap 登录 SDK；改签名实测不弹框不退出（用户提的「去签名/网页强制登录」本包未遇到阻断）
