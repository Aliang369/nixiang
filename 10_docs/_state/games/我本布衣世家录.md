## 2026-09-28 v3

### 问题与修复

1. **免广告必须先开其他开关才生效**：`Wbjy_TryInit` 只在开关触发时才加载 IL2CPP API。
   修复：`TryInit` 里主动调 `api.Load()`， delegate invoke 独立生效。
2. **货币显示大数但实际判定不够花**：旧版只 hook `ItemProtocol` 的 static 方法（3 个），
   漏掉了 `ItemManager` instance 的 CheckItemEnough / ForceRemoveMoney / ForceRemoveCopper /
   TryRemoveItem / ItemMoneyComponent.GetCount 等 7 个真正消费入口。
   修复：加 7 个 @rva hook，全部真实序言匹配。
3. **GetMaxAP RVA 错了 4 字节**：旧版填 `0x12F82F4`，正确为 `0x12F82F8`。
4. **CanAffordBuyLand Vector3Int 按 AArch64 ABI 传参**：旧版当指针转发 → 必崩。
   Vector3Int 是 12-byte struct，正确传法是 X1=int_x, X2=int_y, X3=int_z。
5. **InitAd 缺 this 参数**：旧版 typedef 无 self → orig 调用丢失 this。
6. **AddItem ×1000 放大移除**：改为 GetCount 钉大值 + 扣费拦截，不做数据放大。
7. **全部序言从 ELF 文件偏移提取**：不再占位值。
