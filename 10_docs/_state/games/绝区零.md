  输入＝用户提供的 MuMu 官方原版（491,239,711 B，md5 `e94dfa28…`，签名 `CN=nap,OU=mihoyo`，无 debuggable）。
  池鸳相对官方只动 4 处：① `libtersafe2.so` 仅 **16 B 差异**（.rodata `0xa24bc` 起全零，TP2 字符串异或解密常量）；

  `libil2cpp.so`（`a7845b28…`）/`global-metadata.dat`（`071eafef…`）/`libmain`/`libtoyger`/`libxhook` 与官方逐字节相同。
  **MuMu 打不开根因（实证）**：libChiy 导出 `_Znwm/_ZdlPv` 等 C++ 运算符，MuMu 转译注入库 `/system/lib64/libtcb.so`

  崩溃栈 `libChiy.so+0xb3234 (operator delete+4)` / `libtcb.so+0xfc4fc`（2026-10-05 20:16:12）。
  **保护面**：官方在 MuMu 上同样 0 个腾讯保护 so 加载（tersafe/toyger/themis/aliyunaf/msaoaidsec/facedevice/zkfv/APSE/tapsdk）；
  池鸳对 TP2 的 16 B 手术是预防性阉割，不是必要条件。
  报告＝`10_docs/绝区零/对照报告_官方vs池鸳_MuMu崩溃根因_20261005.md`；约束更新＝`硬约束.md` #5–#7。
