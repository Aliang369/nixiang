## 大包外科组装四坑（已在脚本内固化）

1. **dex 下标**：ART 要求 `classes*.dex` 连续，写死下标遇缺口即 `StarryInitProvider` ClassNotFoundException 启动崩；用 `04_scripts/_common/next_free_dex.py` 复核。
2. **zip64**：python zipfile `ZIP64_LIMIT = 2^31-1`（**不是 4 GiB**）⇒ 2.47 GB 产物被写 zip64 EOCD + 晚期条目 extra（`hoff=0xFFFFFFFF`/`vneed=45`），build-tools 36.0.0 zipalign 报 `Unable to open as zip archive: Undefined error: 0`。`normalize_zip()` 本次修复 **519 条**。
3. **utf8 flag**：APK 所有条目 GP flag 带 0x800，python `_open_to_write` 会清零 ⇒ `RawNameZipInfo._out_flags = flag_bits & ~0x08` 保留 0x800、有意丢弃 0x08（否则 Unity AssetBundle `Unable to open archive file`）。
4. **磁盘峰值** ≈ 5 GiB（unsigned + aligned 两份并存）⇒ 前置 `df -g ≥ 6`，zipalign 后立即删 unsigned。

保护条目 11 项 sha256 断言（`classes.dex`..`classes8.dex` + `resources.arsc` + `libil2cpp.so` + `libxlua.so`）+ 全量 3,022 条 `CRC/size/ctype/名字字节/utf8 flag` 一致（mismatch=0）。

## 装机铁律（本轮踩坑，换签名必读）

1. **换签名场景绝对不要 `pm uninstall -k`**：它返回 `Success` 但残留带旧签名的 `PackageSetting`（`Key Set Manager: Signing KeySets` 仍在），此后 install 永远 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，`rm -rf /data/data/<pkg>` 也救不回，再 `pm uninstall --user 0` 只回 `Failure [not installed for 0]` —— **包被卡死**。
2. **正确解（实测 4 min）**：推官方原包 → `pm install -r -d --user 0 <官方apk>`（同证书覆盖残留）→ `pm uninstall --user 0`（**不带 `-k`**）→ `pm install -r --user 0 <星光apk>`。
3. 装机前先备份 `/data/data/<pkg>` 与 `/sdcard/Android/data/<pkg>` 到 `/data/local/tmp`（本游戏 680 MB + 2.2 GB，内容为乐变插件解包与热更缓存，无存档价值）。
4. 装机后必跑 `source 04_scripts/_common/starry_post_install.sh; starry_post_install "$PKG"`（`SYSTEM_ALERT_WINDOW` + 卡密设备指纹种子 + force-stop）。
5. 首启 `topResumedActivity` 可能停在 `GrantPermissionsActivity`，`am force-stop` + `monkey` 重启即进 MainActivity。`adb shell` 直呼 `pm grant` 会 SecurityException，须 `su -c`。
