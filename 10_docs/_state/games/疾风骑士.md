- **v5 用户反馈 3 项**（m02582）：免广告仍弹广告 / 技能仍有 CD / 无限跳跃变自动连跳。
  - 定位：`ADXManager` 是**另一套未启用**的广告系统（日志实证广告走 MarSDK Java `com.mar.sdk.gg.topon.ToponAd`，`KSRewardLandScapeVideoActivity` 全屏播放；服务端 `adSwitch` 仅 `videoSwitch:true`，`intersSwitch/splashSwitch/bannerSwitch` 全 false）；技能真门禁 = `PlayerMovement + 0x588` 武器技能冷却；`PlayerJumpCooltime` 恒 true 是自动连跳元凶。
  - v5 落地：挂 `MarSDKManager.ShowReward`（argc6/7）；拦 `[this+0x588]` 写入；回退 `PlayerJumpCooltime`；加 `JFQS_TRACE` 诊断探针。
- **v6 用户反馈 1 项**（m02751）：无限跳跃开着一落地就自动无限跳，用户判断「游戏原生只允许跳两次，去掉限制即可」——**反汇编证实用户判断正确**：`GetMaxMoreJumpCount()` 默认返 1 ⇒ 共 2 跳。v6 只 hook `GetMaxMoreJumpCount` → 999，删除 `CanMoreJump`/`CheckCanJump`/`PlayerJumpCooltime` 三条。用户实测通过。
- **两次闪退根因**（已修）：
