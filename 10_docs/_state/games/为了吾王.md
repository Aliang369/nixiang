## 卸载重装纪律（用户 2026-10-30 明确）

- **存档不保留**：卸载重装时不要把 `/sdcard/Android/data/com.ftk1.m3839` 拷贝/备份出来，直接删。
  （本作是删档测试期，存档无保留价值；`install_starry_apk.sh` 的备胎机制对本品可加 `--allow-resource-loss`，
  或装完直接 `rm -rf` 该目录让游戏重建。）
- 装完若游戏弹 `Not enough storage space to install required resources`，不是磁盘满，是**外置目录 owner/SELinux 类别
  与当前 uid 不匹配**（多半是手工 chown 抄了旧 uid）⇒ 删掉该目录让游戏自己重建即可。
