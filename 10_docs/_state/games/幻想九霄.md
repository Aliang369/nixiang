## 2026-11-28 斌哥改包抓点（真机 f9a116a2）

- **样本**：`com.hundunjidian.hxjx` `1.0.212`/`611150841`，389,761,267 B，sha256 `ff38f5676b06…`，签名 `CN=binge2.keystore`，Application = `bin.mt.signature.KillerApplication193`（MT 签名杀手），归档 `02_apks/幻想九霄/base.apk`。Unity 2022.3.62f3 + IL2CPP metadata v31 + **HybridCLR**，仅 arm64-v8a、无 split。
- **改包结构**：菜单 UI 在 `classes4.dex`（`bin.wb` 73 类，悬浮窗）；实现体 `libwbmod.so` = 装载器（RC4 解 `.main`）+ 运行期落 `.bss` 的加密子模块（324 KB r-xp，7 个 `Java_bin_wb_*` 入口）。菜单只有 1 项：「战斗 → 无敌」（文案索引 52/51，131 条文案已离线解出）。
- **Hook 链**：`JNI_OnLoad` 起 `hack_thread` → `HT_FindInterpEntry` 用 opcode 掩码扫描定位 **libil2cpp 解释器入口** → `DobbyHook(entry, myhook)` → 同时注册 `HT_InstallFramePoints` 帧点；myhook 内再装两处 AOT 硬 RVA：`+0x6CA8900`(`HUDBloodSystem.Execute`)、`+0x6C9FE10`(`HealthViewComponent.get_ratio`)。
- **【无敌】语义**：解释器层 = 解释器实参块改参（不是写对象字段）：`AttackSy*/EnemyAtt*` 命中时把伤害实参（1..999999）清 0；`UnitUpda*/AttribCh*` 命中时负值归 0。表现层 = `get_ratio` 里 `hp:=maxHp` 后放行（血条恒满）+ `HUDBloodSystem.Execute` 巡检纠偏。⇒「调用边界改参 + 表现层回填」型无敌，只对**解释执行的热更方法**生效。
- **控制面**：`cheatNative(1)` 翻总开关 `0x…cd88`；`cheatNative(>=1000)` 设 level；dex 每 900 ms 的 `cheatNative(9)` 在实现里返回 -1（空转）。
- **阻塞/未证实**：热更 DLL 未取得（APK 内无 `Code/*.dll`，设备 `files/il2cpp/` 只有 Metadata/Resources）；metadata 不含热更类型 ⇒ 目标类只有 8 字节前缀；`HT_FindInterpEntry` 命中函数符号名未证实；未做原版对照（是否补丁过 `libil2cpp.so` 未知）。
