**关键教训（已实证，勿再踩）**
1. **雷电模拟器（x86_64 + houdini）不能做 RVA inline hook**：arm64 的 `libil2cpp.so` 在内存里全段 `r--`（无 `r-x`），Dobby 装钩 9/9 全失败（日志 `not in RX`）。必须用 arm64 真机。
2. **`basicbase.enemyhurt` 是「敌人施加伤害」不是「敌人受伤」**：改它会放大怪打人（实测踩过）。
3. **`getadcheck` 尾部无条件 `b LoadRewardAd`**：开关开时直接 return true 会切断整条广告链，表现为「点击无反应」。
4. **`data` 单例静态字段名是 `d`（不是 `i`），`data.sd` 也是静态字段**：按实例偏移 `data+0x4F0` 读永远拿不到。
5. **`libc++_shared.so` 必须随 `libstarry_magic.so` 一起注入**：否则 `dlopen` 失败，Java 菜单能弹出但所有 native 方法缺失（表现为「暂无功能列表」）。
6. TapSDK 三处静态补丁（门闩恒真 / 强制 WebLogin / 签名回灌 `e570e78604a0a3cb40e41e9aa3d4811b`）为改包必需，否则登录失败。
