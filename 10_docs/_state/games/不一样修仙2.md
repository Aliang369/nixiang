## 2026-11-02 第2轮补丁（寿元自增修符号 / 免广告上线）

- **寿元自增暴死（用户报）**：实证 `LifeTimeIncSpeed ON orig=-1.00 x1000 -> -1000.00`，游戏自身日志 `陌杰 获得寿元自增速度 : -1`
  ⇒ 该字段语义是「寿元**流逝**速度」（负=每秒扣寿元），我按「增速」×1000 变成 -1000 ⇒ 寿元见底暴死。**是我的语义错误**。
  修法：该槽 `forcePositive=true`，取绝对值放大（-1 → +1000 = 寿元增长），并对 target 做 ±1e6 钳制。
- **免广告（用户点名新增）**：不 hook `ShowRewardVedio`，改钩游戏自带的**「判断能否屏蔽广告」** `Immortal.GeneralInfoLogic::JedgeCanBlockAd`
  @RVA **0xF7A5C0**（序言 `0xA9BE4FF4`）。证据：`ADMgr::ShowRewardVedio` 0xE7B5D4 `bl JedgeCanBlockAd` → `tbz w0,#0` 才去播广告；
  为 true 直接 `b 0x15b46c8` 派发奖励 ⇒ 恒真 = 游戏自认已购去广告，奖励视频/广告宝箱/广告装备跳过播放直接发奖。
  另 `ADMgr::ShowInterAd` @0xE7B734 本身只是 `ret`（空函数），插屏无需处理。
- 菜单现 14 项（新增 `Toggle_免广告` = feat 13）。so 200,376 B md5 `b8dec037738ffcead6eded63a2d47e1e`；
  正式包 md5 **`d29a72862163ca17112150b4ea1e41e4`**（设备 base.apk md5 已核对一致，`adb install -r` 原地升级、存档保留）。
- 冷启取证 `09_test/不一样修仙2/logcat_byyxx2_cold2.log`：`GameMgr::Update hooked @rva 0xF6F788` + `JedgeCanBlockAd hooked @rva 0xF7A5C0`
  + `resolve ok 偏移全一致` + `update hit=600 player=0x7210263800`；无崩溃。
- **上限机制（本轮新发现，非 bug）**：`Exp add=1000000 before=30 after=60000` 后不再变 ⇒ 受 `ExpLimit`（境界上限）；
  `LifeTime add=1000000 before=172 after=186` ⇒ 受 `LifeTimeLimit`。突破上限需另立功能（`set_ExpLimit`@0xF69154 / `SetExpLimit`@0xF69BB4 / `get_LifeTimeLimit`@0xF6CD2C），已向用户报备待点名。
