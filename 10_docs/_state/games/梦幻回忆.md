# 梦幻回忆（梦幻封神）

> 2026-11-03 单会话完整逆向。游戏内名「梦幻封神」，包名 `com.example.noname`，Godot 4.7.2 自研 GDVM 字节码，仅 arm64-v8a。

## 结论：客户端功能不可实现（服务端权威）

战斗为「命令-结算-快照」三段式：客户端发 `ReqBattleCommand`（target + skill_id）→ **服务端算伤害/暴击/死亡** → 回 `NotifyBattleSnapshot` 全量覆盖本地。`damage` 字段仅存在于 4 个纯 UI 脚本（`ui/battle.gd`、`world_boss_presentation.gd`、`world_boss_ranking.gd`、`battle_floating_text.gd`），无任何伤害公式。另有 `network/speed_detection.gd` 加速检测与 `server_rejection` 校验。

实测：进程 TCP 直连 `182.106.136.15:29110`；`NETWORK_CLIENT_BUDGET` 的 `intents_sent` 随操作递增、`local_apply_ms_peak` 记录快照应用耗时。

## 已掌握能力（可复用）

- **密钥链**：`mbedtls_hkdf(md=9, salt=<"godot-resource-kdf-v1"+3字段>, ikm=<master 32B>, info, okm)`，注意 salt/ikm 位置与直觉相反
- **解密**：AES-256-GCM；**GCM 明文只依赖 key+nonce，AAD 仅参与 tag** → 用 CTR(nonce=前12B, initial_value=2) 绕过 MAC，2545 块全解（45.96 MB）
- **容器**：GDRC；chunk 表 61 B/项 `[0:4]pad [4:8]offset [8:16]size [16:48]digest [48:52]=1(压缩) [52:56]=分片数 [57:61]=序号`
- **重打包**：改内容 → CTR 重加密（nonce 沿用）→ 从 0x449C3 起重排 → 回写 manifest offset/size；index 块（0x25F59 起 125546 B）原样保留
- **打包红线**：必须沿用原包每个条目的 `compress_type`；`assets.sparsepck`/`gdke` 为 Stored，`resources.arsc` 须 Stored+4B 对齐
