### 本轮新踩坑（可复用）

1. 私 mk 缺 `Games/NoAceStubs.cpp` ⇒ `ld.lld: undefined symbol: SignalQuarantine_Start / FgoBoot_InjectEarlyFromOnLoad`（MainModern 无条件引用）。
2. 1.34 原包自带 `classes7.dex`（140B 空壳）⇒ starry dex 必须改名（本轮 `classes27.dex`），同级重名会让 ART 读到空壳。
3. 1.9GB 包生成 manifest 用 `apktool d -s --no-assets`；`apktool b` 会把 `<uses-sdk>` 从文档尾挪到开头，**位置 diff 会误报丢失**，改行多重集比对 + 断言 min16/target30。
4. `post_install_precheck.sh` 会把 `E libsigchain: Setting SIGSEGV to SIG_DFL` 判成崩溃 —— 看 pid 存活与后续日志延续，属 Dobby 改信号处理器的良性副产物（本轮两次误报）。
5. **注入串括号不配平 ⇒ 整包黑屏**（实锤）：多一个 `}` 让 18MB 脚本 eval 抛 SyntaxError、splice 日志全绿但引擎不渲染。已加运行期 `BracesBalanced()` 自检 + 构建期 `04_scripts/造梦无双/zmws_splice_syntax_check.py`（从 so 抠注入串 → 插入明文 index.js → `node --check`）。
6. `pre_install_gate.sh` 查5 只 grep `classes*.dex`，so 侧门禁串（如 `starry_zmws_timepad`）走 `--apk` 会假 FAIL ⇒ 拆两次：`--apk` 查 dex 串、`--dex <so>` 查 so 串。
