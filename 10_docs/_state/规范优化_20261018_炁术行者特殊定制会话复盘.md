### 2.2 H5 服务端热更 → 补丁器锚点重导（同游戏第 3 次复发，实测）
- **事实**：炁术行者 `index.js` 已 4 次重压缩（5,406,779 → 5,414,360 → 5,415,708 → **5,416,633 B / md5 37d25ff6**），每次压缩器随机化局部变量名，本轮 17 锚点 3 miss：⑧`p.hurtRate→m`、⑨`p.apipath/p.dbid→m`+`m.alert→p`、⑬`n.createHurtLog→i`。核心功能锚点（①②③④⑭⑮⑯）从未 miss，miss 的多是「取证/反作弊」锚点。
- **历史锚点**：`games/炁术行者.md` 10-08 第二轮（5 锚点 miss 重导）、10-09 第三轮（锚点⑥再重导）、本轮（3 锚点 miss）。
- **经验**：H5 游戏「游戏更新」= 服务端 `index.js` 重压缩下发；重打前**必跑只读体检**（`qsw_patch_js_star.py --src <新index> --dst /tmp/probe`）量化 miss，再逐处重导，不许放宽断言。

### 2.3 减伤 100% 折算除零保护（实测，通用）
- **事实**：dr=100（减伤 100%）= 真无敌（`__QSW_DMG` 受击分支 `Math.max(1, v*(1-1))=1`），且 ⑬ 结算回流折算 `totalBeHurt/(1-dr)` 在 dr=1 时**除零**。修法＝`_d>0&&_d<1` 才折算，`_d>=1` 保留原值不上折算。
- **证据锚点**：`04_scripts/炁术行者/qsw_patch_js_star.py` ⑬ 替换体（`tbh:_d>0&&_d<1?…`）；离线闸门 speed_check L96 断言 dr 下界。
- **边界**：dr 接近 100% 时服务端必然 9998/9988 拒判（硬约束 #4/#9），除零保护只防崩溃/NaN，不规避检测。

### 2.4 底包缺失 → 增量重打包（实测，跨游戏可复用候选）
- **事实**：原始壳 `02_apks/炁术行者9.15.apk`（md5 f528339a）不在，只剩已装星光的 10-09 正式包 `炁术行者_1.0.apk`。标准 `qsw_build_star.sh` 硬校验底包 md5 会 die。新增 `04_scripts/炁术行者/qsw_repackage.sh`：基于正式包（dex 注入/框架/Manifest 已就绪）只换 so + qsxz_patch.js + main.js 重签；bundle.js 服务端未变（md5 d34c251f）不动。
- **证据锚点**：`04_scripts/炁术行者/qsw_repackage.sh`（162 行）；出包 md5 0110146e，L1/L2 全过。
- **状态**：单游戏脚本；「增量重打包」可升格为通用模式候选（先查 `prior_art.sh 增量重打包` 是否已有）。

## 4. 优化方案（可执行，按价值排序）

### P0-1 `stage_shared_file.py` 对「他人改行」无恢复路径
- 问题：current.md 等共享文件的并行改动常见「改行」（如别会话把索引行从长版缩到 <400 字符），而 `stage_shared_file.py --drop-pattern` 语义是「命中整行丢弃」＝**删除该行**，无法「该行恢复 HEAD 旧版」。本会话只能手动构造「HEAD + 本轮行」写索引绕行。
- 方案：给 `04_scripts/_common/stage_shared_file.py` 增 `--restore-head-pattern <正则>`（命中该正则的工作区行，用 HEAD 对应行替换，而非删除）；或至少在文件头 docstring + `archive_scoped_git.sh` 报错提示里写明「改行场景请手动构造 content 写索引」。
- [落点] `04_scripts/_common/stage_shared_file.py` docstring + `main()` argparse；`archive_scoped_git.sh:222` 报错提示。
- 状态：⬜ 未做（游戏执行会话只提案；属 `_common` 通用脚本，待优化会话落地）。

### P1-1 硬约束更新前区分「永久改口径 / 一次性偏离」

- [落点] `10_docs/_templates/会话复盘模板.md` 或 `AGENTS.md` §6 硬约束段（属通用规则，游戏执行会话只提案）。
