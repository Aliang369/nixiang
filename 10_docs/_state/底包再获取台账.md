## 再获取优先级（从高到低）

1. **游戏渠道重下**：TapTap / 4399 / 好游快爆等渠道搜包名，按版本号核对；渠道已滚动到新版时用第 2 条。

3. **设备只读拉取**：设备上仍装着**官方原版**时 `adb shell pm path <pkg>` → `adb pull`（设备已换星光包则此路不通，必须先卸星光包再装官方）。
4. **重新研究**：以上都不通时，按 `skill/re-analyze/SKILL.md` 重新接手（用户已接受这一代价）。

> ⚠️ 第 3 条只在设备仍是官方包时有效；换过星光包后官方包无法从设备拉回，这是原「不可再生」标签的来源。现在改为：**接受重下/重研代价，不留 APK**。
