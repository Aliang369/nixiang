### 本会话 token/时间黑洞（按代价排序）

1. **第三次预检的 SIGTRAP 追因**（最贵）：先按「我们挂了 `il2cpp_init`」怀疑自己，查 ACE、查 `SignalQuarantine`、反汇编 libunity（该段 TP 加密，白跑）——最后一行日志给出答案：`E Unity: [Critical] HG_ALWAYS_ASSERT failed … VK_FORMAT_UNDEFINED`。**教训：崩溃追因应先扫「崩溃前 3 秒的全部 E 级日志」，再谈机制**（我花了 10+ 次调用才做这一步）。
2. **5 次 3 分钟预检串行跑**（约 20 分钟挂钟）：为拿「1 挂 3 过」的复现率。属必要成本，但本可在首轮就并行两台机。
3. **中文串 grep 假阴性**：`grep -a -c "就绪门"` 在默认 locale 下返回 0，一度误判「新代码没编进去」。**教训：so 内中文串一律 `LC_ALL=C grep -a`**（本仓外科脚本早已如此，我没照做）。
4. **3 轮完整构建**：其中 1 轮纯粹为刷新构建戳（`Utils.o` 被 ndk-build 缓存，只改 `-D` 不重编）。

## 2. 已验证、可复用的关键事实

### 2.1 「首启幸存 / 重开必崩」是「init 前触碰 il2cpp」的指纹（两例实锤）

`ZhmrMod` 3.6.0 与本作 v14.5→v14.6 同型：mod 线程在 `il2cpp_init` 完成前碰 il2cpp ⇒ 线程进 GC
「未知线程」毒态 ⇒ UnityMain 触发 GC 即 `abort()`。**处置：必须有真就绪信号**（hook `il2cpp_init`
取返回值），固定延迟与「捕获异常」都不算。

### 2.2 无 root 也能拿全证据（不必换设备）

`logcat` 的 DEBUG 块含系统 `debuggerd` 的**完整 27 帧**；`dumpsys activity exit-info` 给完整崩溃史
（status 11/6/5 = SIGSEGV/SIGABRT/SIGTRAP）。root 只多给 tombstone 文件（0600）与 `/data/data`，
本轮**不需要**。

### 2.3 「打开就闪退」常是多层，修好一层会露出下一层

本作实测三层：`SIGSEGV`（我们 so 内，v14.5 修）→ `SIGABRT`（FW-20，v14.6 修）→
`SIGTRAP`（游戏自身 Vulkan 断言，仅在「装机后首次启动的慢启」窗口出现，**未修**）。

### 2.4 其它

- `ModEntry` 的 `*Ms` 字段实际单位是**微秒**（`usleep`）；本作写 `2000/2000/300` ⇒ 实等 2ms/2ms/0.3ms（FW-22）。
- ndk-build **只改 `-D` 不重编** ⇒ 构建戳长期陈旧（v14.4/v14.5/v14.6 共用同一戳），需 `touch Includes/Utils.cpp`。
- MIUI 的 `ScoutManager/DumpScoutTraceThread` 抓栈会让预检的裸 `tombstone` 关键字误判 FAIL_A（FW-21）。

## 4. 优化方案（按价值排序）

- **P0-1（FW-21 根治）**：`post_install_precheck.sh` 默认 `RE_CRASH_IGNORE` 追加 MIUI 抓栈三行，并把
  `crash_ignore` 从**覆盖**改为**追加**（现语义会把默认四项冲掉，本作已被迫手抄默认值）。
- **P0-2（FW-22 根治）**：`ModEntry.h` 的 `*Ms` 改名 `*Us`（或 `MainModern.cpp` 改 `usleep(v*1000)`），
  并加机器关：`.tickIntervalMs < 10000` 即告警。同仓另有多款按毫秒写。
- **P1-1（FW-20 通用化）**：把「首次触碰 il2cpp 必须有真就绪信号」写进框架契约/`MainModern.cpp` 注释，
  并把本作的 `ArmIl2cppInitGate()` 抽成可复用头（现只在 `EndfieldMod.cpp` 内）。
- **P1-2（构建戳）**：外科脚本在 `ndk-build` 前 `touch jni/Includes/Utils.cpp`（或修 `Android.mk` 依赖），
  消除「同源不同提交共用一戳」。
- **P1-3（残留）**：`MenuService`/`NativeMenuController` 的 overlay 挂载避开宿主引擎 init 窗口
  （慢启时宿主 `SurfaceView` 被重建 ⇒ Unity Vulkan 断言 ⇒ SIGTRAP）。**共享层，影响全部游戏，需用户拍板。**
