## 2. 已验证、可复用的关键事实

### 2.1 该品类（Unity IL2CPP + HybridCLR + 加固壳）——静态路线必死
- 真 IL2CPP 库不是 `libil2cpp.so`：APK 内是 157,376 B 的 7z 壳 `com.moba.unityplugin.Z7Extractor`，首启解出 `/sdcard/Android/data/com.gf.cxswz/files/dragon2019/assets/comlibs/arm64-v8a/liblogic.bytes`（177,216,216 B），由 `DynamicSOLoader` 复制到 `/data/user/0/com.gf.cxswz/app_libs/liblogic.so` 再 `System.load` ⇒ **目标库名 `liblogic.so`，RVA→VA 必走 `/proc/self/maps` 或 xdl**。
- Il2CppDumper 直接失败：`Il2CppDumper.Il2Cpp.Init / AutoPlusInit / Elf64.PlusSearch` → `System.IO.EndOfStreamException`；`Metadata Version: 24.4`、`CodeRegistration : 1690740`、`MetadataRegistration : a0ae708`。
- 结论：**同品类开局直接走按名 Hook**（`skill/re-extract/il2cpp-from-scratch.md` §八），不试 dump。

### 2.2 运行时定类（版本漂移下的唯一稳态）
- `ClassByNames` 链：`SweepClassByExport(ns)` → `SweepClassByExport("")` → `SweepClassByExport("CSharpBattle.Battle")` → `FindClassByShortNameCI()`（短名索引，命名空间无关，`EnsureGameShortIndex()` 只建一次）。
- `Il2CppRuntimeUp()` 门控：`g_il2cppInited && now - g_initDoneMs >= 800`，兜底 `now - g_firstAsmMs >= 6000`；**`il2cpp_init` 未返回前禁调任何 metadata API**（`il2cpp_domain_get` 有 0x30 B Domain 单例副作用，pre-init 调用实测 `SIGABRT`）。
- 返回值是 MTE 标记指针（`0xb400…`）：`IsReadableRange`/`IsExecutableRange` 首行必须 `starptr::Untag`（`u & 0x00FFFFFFFFFFFFFF`，`kTagHintTop=0xb4`），否则 `ImageOf` 恒 null 且每次退化成 `fopen("/proc/self/maps")` 全扫（实测 `resolve=8381ms` → 修后 17 ms/12 ms）。
- 值类型内联布局：`stHpChangeData` 内联字段整体 **+0x10**（`fValue` 0x00→0x10、`src` 0x08→0x18、`settle` 0x0C→0x1C、`show` 0x10→0x20、`skill` 0x28→0x38、`formula` 0x2C→0x3C），判据 `slotGap=0x78 == cn 长度 0x78`；自校验双条件不成立就安全退回（只打 `hotpath: layout not ok`，不改写）。
- strip 后的 `.so` **不含函数名** ⇒ 构建自检只能 grep 字符串字面量（本轮曾因自检写函数名而误报失败）。

### 2.3 测试与取证的前置条件
- 锁屏/后台是「零日志」的头号假因：`mDreamingLockscreen=false` + `mWakefulness=Awake` + 焦点在游戏，三者缺一不要开始实测。
- 崩溃只认这几处：`Android/media/<pkg>/files/crash_logs/crash_*.txt`（免 root 最可靠）、`logcat -b crash`、`dumpsys activity exit-info <pkg>`；`/data/tombstones/*` 通常 `-rw-------` 且 `cmd dropbox --print` 不存在、`dumpsys dropbox` 只有 Java 层 `data_app_crash`。
- 设备时间与宿主差 >5 s 会让 logcat 切片窗口错位；`adb -s <不存在> logcat` 会阻塞等设备（不退出），采集侧必须自己探活。
