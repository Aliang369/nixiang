### 2.3 授权链与 prefs 事实（已固化成工具）
`starry_magic_prefs.xml`（`/data/data/<pkg>/shared_prefs/`）是授权 + 开关的唯一载体；**Android SharedPreferences 解析规则**：`string` 用文本体、`int/long/float/boolean` 用 **`value=` 属性**、`set` 的子元素是 `<string>`、根是 `<map>`、每项必须有 `name`。违反 ⇒ 抛异常 ⇒ App 拿**空 map** ⇒ 代码缺省重写 9 个键（`auth_game_id`/`feature_list_sig`/`auth_device_id*`/`auth_card_required`/`auth_menu_enabled`/`auth_bootstrap_json`/`auth_legacy_device_ids`）并把 `auth_*` 全丢。`auth_backup_*` 键**不存在** ⇒ 不是 `clearAuthSession()` 干的（该函数一定先写备份）。
链路：`POST https://47.100.216.101:8443/v1/auth/login` → `grant=1|device|game|exp|1|1|kid.sig` → `ModBridge.syncNativeAuthorized()` → `nativeApplyGrant` → `MainModern.cpp:113 apply_grant_utf8()`（pepper `sg-grant-v1-7f3a9c2e` 验签）→ `g_rt_ok`；开关 `Preferences.loadPrefBool(<N>)` → `reapplySavedFeaturesToNative()`（需活会话）→ `nativeSetFeature`（`MainModern.cpp:297` 无会话即拒绝）→ `SyncHooks()` → `install pass`。
本轮实测值：`grant ok exp=1792080205`（服务端 24h 续票 `1792081149`）→ `Toggle #5/#7/#8/#9/#10/#11/#12 = true` → `reapplied saved features to native` → `install pass: ok=69 dead=0/72` + `install skip: 3`（与 r18 完全同口径）。

### 2.4 收尾链的机械事实
`reset build_surgical` + `next --loop 6` 可整链重跑；`archive.prune` 会删 unsigned ⇒ `sign` 被打回 pending ⇒ `pipeline.sh <游戏> verify sign` 复位后再 `next` 走 `archive_close`（git 推送）。`git status` 必须带 pathspec；共享文件（`current.md`、`底包再获取台账.md`、`SignSpoof.java`）只能内容级暂存（`stage_shared_file.py`）。
