## 使用

```bash

python3 -B 04_scripts/_common/audit_workspace_docs.py artifact /absolute/path/to/file --expect-sha256 EXPECTED_SHA256
```

第二条输出文件路径、大小和 SHA-256；需替换实际文件与 64 位十六进制预期值。哈希匹配只能证明文件字节身份，不能证明包签名或功能有效。
