## 1. 为什么本作"清理"只清滚动物

炁术行者是**服务端 H5 游戏**：APK 只是 1.4 MB 纯 WebView 壳，玩法逻辑全在服务端 `/assets/main/index.js` 里明文下发。**每次服务端重新压缩该文件，JS 补丁锚点就会失效**（本轮就是 12 处锚点里 5 处命中 0 次）。因此：

- `04_scripts/炁术行者/`（含本轮新增的 `qsw_diag_build.sh`）与 `mod菜单/starry-mod-menu/…` 的 `Qsxz*` 源码是**长期复用资产**，下一轮热更还要用；
- `10_docs/炁术行者/` 全部保留（含 10-07 / 10-08 两份 evidence README 与两份裁剪清单）。
