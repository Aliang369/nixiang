## 三、实例获取（本节是本作最大坑）

三个人们会首选、但真机实测**全部拿不到实例**的锚点：

| 候选 | RVA | 实测结果 |
|---|---|---|
| `GameMgr::get_Player` | `0x10469EC` | 内存字节 `00 14 40 f9 c0 03 5f d6`（`ldr x0,[x0,#0x28]; ret`）正确，钩子装上了，但**游戏中 10 分钟 0 命中** |
| `GameMgr::OnApplicationFocus` | `0x1046BDC` | 钩子装上，**0 命中**（收放菜单不触发 Unity 应用级回调） |
| `GameMgr::Init` | `0x1046A10` | 钩子装上，未触发 |
| `CharacterLogic::GetAttr` | `0xE0CF18` | 钩子能触发，但收到 `self=0x1 type=-251321024`（实参错位），**不能用来捕获** |

**最终可行方案（已实现，真机验证）**：
1. 菜单按钮线程 `il2cpp_thread_attach(domain)` 后**同步调用**，不等任何钩子；
2. 玩家实例解析顺序：`PlayerLogic`/`CharacterLogic` 类静态单例（`Api::StaticRefField` 试
   `Instance/instance/Inst/inst/Cur/current/Player/Main` + 同类型校验）
   → 失败则 `GameMgr` 静态单例 → `runtime_invoke(get_Player)`；
3. 三个钩子（`get_Player` / `OnApplicationFocus` / `Init`）仅作兜底队列。

## 四、免广告（W 家族激励视频）

- 拦截 `ShowAds`，只调 **a1（成功回调）**，然后不调 orig ⇒ 不播视频、奖励照发。
- **踩过的坑**：a1/a2 顺序认反时调了 a2（失败回调）⇒ 游戏弹「广告播放失败，请重试」。
  判断依据不是猜，而是真机 `LogSig` 打出的参数类型表。
- 该包广告源本身也常空（`onAdSourceLoadFail ... Return Ad is empty`），所以免广告同时解决了“看不了广告”的问题。

## 五、TapTap 双轨（2026-10-29 口径）

| 轨 | 做法 | 产物 |
|---|---|---|
| B 轨 签名/完整性 | `bin.mt.signature.KillerApplication193`（烘焙 `com.wingjoy.toWest` + 官方证书 DER 678 B / sha256 `9112ddf1…`）随 `classes4.dex` 注入；Manifest `appComponentFactory` → `com.starry.magic.sign.StarryAppComponentFactory`；`instantiateApplication` 里 `Class.forName` 立即跑 `<clinit>` 完成 `PackageInfo.CREATOR` 替换 + 清 PM/Parcel 缓存。真机日志：`StarryAppFactory: SignatureKiller mounted` | `04_scripts/不一样西游/build_killer_dex_byyxy.sh` → `assets/byyxy_signature_killer.dex`（md5 `f8b243e4d711c6765a521b3c55f71e69`） |
| A 轨 登录方式 | 本 SDK 是老 `com.taptap.sdk.ui.Block` 形态：`LoginBlock.onViewCreated` 里 `new LoginClient + sendLoginRequest`（客户端 SSO）→ 改成 `new WebViewHandler + authorize(request)`（SDK 自带完整 web 通路，含 `setLoginCallback` + `startBlock`）。**同一链条禁双修**：TapSignKit 官方原样 | `04_scripts/不一样西游/patch_taptap_login_byyxy.sh` + `patch_loginblock.py` → `07_patched/不一样西游/classes2_patched.dex` |

**A 轨两次错法（勿重犯）**：
1. 在 `LoginClient.sendLoginRequest` 里提前 `return` ⇒ 跳过 `cloudGameHandler` 的 bind 记账，销毁时
   `unbindService` 抛 `IllegalArgumentException: Service not registered` ⇒ 点「开始游戏」闪退；
2. 把 `TapTapActivity` 的 `new LoginBlock` 换成 `new WebBlock` ⇒ 绕过
   `WebViewHandler.authorize` 的 `setLoginCallback`/`startBlock` ⇒ 登录页永远转圈。
