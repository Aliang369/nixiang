## 3. 菜单一致性审计（PASS · 实测；路径一条未验）

```bash
unzip -o -j mod菜单/starry-mod-menu/app/build/outputs/apk/release/app-release.apk classes.dex lib/arm64-v8a/libstarry_magic.so
bash 01_tools/smali/baksmali d classes.dex -o smali
grep -rn 'starry_state' smali     # → com/starry/magic/o/S0.smali（R8 把 StateMirror 改名 o/S0）+ app/MainActivity.smali
```

**写入侧（`com/starry/magic/o/S0`，dex 字符串池仍留 `StateMirror` 作日志 tag）**
- `h(II)V` = `mirror(featNum,value)`：`if-ltz p0` + `const/16 v1,0x8 / if-lt p0,v1` ⇒ **下标只接受 0..7**；`sget-object d:[I` → `aput p1, v1, p0`（**数组下标 = featNum**）→ `invoke-static k()V` 落盘。
- `k()V`（序列化）：`StringBuilder(0x20)`，循环 0..7，`if-lez` 时先 `append(' ')` 再 `append(d[v2])` ⇒ **单行 8 个十进制整数、单空格分隔、下标升序**。
- 落盘：先写 `d().getParentFile()`（外部 media 副本），再写 **`Context.getFilesDir()` + starry_state.txt**。`d` 在 `<clinit>` 里 `new-array [I(8)`，初值全 0。
- 初始化：`ModBridge.<init>(Context)` 内 `invoke-static S0.a(Context)` ⇒ 注入游戏后拿到的是**游戏** Context；`ModBridge.reapplySavedFeaturesToNative()` 遍历每个 featNum（toggle 走 `G0.Y(idx)`、slider 走 `G0.Z(idx)` 或 `menu/a.d(spec)`），再 `S0.h(idx,value)` ⇒ 菜单一打开就把持久值同步进文件，**不会因为 d[] 初值 0 把倍率写成 0**。
- 调用方：`menu/d.smali:65808`、`menu/d$c.smali:449`（菜单界面创建/刷新时）。

**功能表下标**（native `jni/Games/QxzxczEntry.cpp` + so 内字符串 `qxzxcz`/`Category_`/`Slider_`/`Toggle_`）：

| featNum | 菜单项 | GDScript 读取 | 一致 |
|---|---|---|---|
| 0 | `Category_功能`（占位） | 不读 | 是 |
| 1 | `Slider_伤害倍率:1:100:1` | `StarrySwitch.num(1, 1.0)` | 是 |
| 2 | `Toggle_无敌` | `StarrySwitch.on(2, 0)` | 是 |
| 3 | `Toggle_无限银钱` | `StarrySwitch.on(3, 0)` | 是 |

slider 默认值：`menu/a.d(String)` 在 `segments.length >= 3` 时取 `segments[2]` = `"1"` ⇒ 默认 1（原样），与 `num(1,1.0)` 兜底一致。

**state 文件路径（未验）**
