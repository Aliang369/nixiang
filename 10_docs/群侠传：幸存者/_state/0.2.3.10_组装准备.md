## 4. 负向测试与本轮修掉的 3 个脚本 bug

1. **负向**：`QXZXCZ_LOGIN_DEX=<底包 dex 副本>` ⇒ 2/9 阶段按预期 exit 1（`登录 dex md5 == 底包 classes.dex md5`）。
2. 修 bug：7/9 误把 apksigner 新生成的 `META-INF/STARRY.SF/.RSA` 判成「未预期条目」⇒ 改为按签名文件白名单比对。
3. 修 bug：`META-INF/MANIFEST.MF` 是新 v1 签名必需项，原断言把它当「旧签名残留」⇒ 改为只查官方 `.SF/.RSA` 是否残留。
4. 修 bug：`QXZXCZ_SKIP_GDC=1` 分支仍断言 starry_switch 必须存在 ⇒ `NEW` 集合改为按 SKIP_GDC 条件构造。
