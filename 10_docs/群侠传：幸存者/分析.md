## 2. 引擎：Godot 4.6.1（非 IL2CPP）
- lib/arm64-v8a/libgodot_android.so = Godot Engine v4.6.1.stable.official
- lib/arm64-v8a/libqx_native.android.template_release.arm64.so（游戏 GDExtension 原生模块，qx=群侠）
- lib/arm64-v8a/libtapsdkcore.so + libthemis.so（TapTap SDK / Themis Lite）
- 游戏逻辑在 GDScript，编译为 .gdc（magic "GDSC"），**未加密、未打包成 .pck，直接展开在 assets/scripts/ 下**（788 个 .gdc + 788 个 .gd.remap）
- .gd.remap 内容 = path="res://scripts/.../xxx.gdc"，即 .gdc 就在原路径

## 3. 保护：无游戏级壳/加固
- 无易盾/ACE/TSS/KwProtect；libthemis = TapTap SDK 的 Themis Lite（GameSecurity/themis，mprotect），非游戏壳
- 无 GDRC 加密容器（对比：梦幻回忆是自研 GDVM+GDRC，本作是标准 Godot .gdc，明显更简单）

## 4. 登录：TapTap（改包法路线）
- dex 内 Lcom/taptap/sdk/* 可直接搜到（可达）→ 按 taptap-web-login.md 现行口径走「改包法」
- 游戏侧另有一层 GDScript 登录封装：autoload/platform/taptap_android_backend.gd / taptap_play_access.gd / taptap_sync_ledger.gd / taptap_sim_backend.gd + addons/qx_taptap_android/export_plugin.gd
