# 群侠传：幸存者 · 功能挂点（无敌 / 伤害倍率 / 银钱）

> 反编译工具：GDRE Tools v2.7.4，`--headless --bytecode=4.5.0 --decompile=<.gdc>`（bytecode version 101 兼容 Godot 4.6.1）。
> 源码在 03_decompiled/群侠传：幸存者/gd/。

## 0. 实现路线（Godot 静态改包）
游戏逻辑全在 GDScript(.gdc)，无 native hook 面。功能走「反编译 .gd → 改 → GDRE --compile 回编 .gdc → 替换进 APK」的静态改包路线。
mod 菜单（星光 Java 悬浮菜单）注入后，功能开关若要联动，需在 GDScript 里读一个运行时配置（后阶段再做；首版可先做「恒开」）。

## 1. 无敌（玩家免伤）
- `components/health_component.gd`：
  - `var invulnerable: bool = false`
  - `func take_damage(amount, publish_signals=true) -> float: if invulnerable: return 0.0`（已有无敌分支）
  - 同一 HealthComponent 既管玩家（`bind_player_vitals(store)`）也管敌人（`bind_row_storage(sim, slot)`）——**必须只对玩家生效**
- `components/player.gd`：
  - `func set_invulnerable(enabled): health_component.invulnerable = enabled`（已有现成开关）
  - `apply_status_dot_damage` 也会检查 `health_component.invulnerable`
- **最小改法**：在 `health_component.bind_player_vitals(store)` 末尾加 `invulnerable = true`（仅玩家绑定时置无敌），或改 `take_damage` 为「`_vitals != null` 时 return 0.0」。

## 2. 伤害倍率
- 伤害数值中心：`hit_event.gd` `func settle_damage() -> float: return fold_damage if fold_count > 1 else damage`
- 结算处：`systems/combat_hit_pipeline.gd`（约 396-417 行）：
  ```
  var damage_multiplier = build_power_multiplier
  damage_multiplier *= cast_plan.cast_damage_modifier
  var target_damage = hit_event.settle_damage() * damage_multiplier   # ← 在这里乘倍率
  ...（后续还有共振/暴击/标题倍率等连乘）
  ```
- **最小改法**：在 `target_damage` 算完后统一乘一个倍率常量（如 `target_damage *= 10.0`），注意要放在暴击等后续连乘之前或之后按需求定。

## 3. 银钱（无限货币）
- 货币字段：`core/model/economy_store.gd` `var silver: int = 0`（银钱）
- 写入函数：`func set_silver(value: int): silver = value; bump_wallet()`
- 消费判定：`autoload/run_state/title_economy.gd` `can_afford(silver_price)` / `pay(silver_price)`（`_rs.silver >= silver_price`）
- 存档序列化：economy_store `capture_draft()` / `apply_draft()`（silver 会进存档）
- **最小改法**：把 `silver` 初始值/读取值设大（如 `set_silver(999999999)` 或 `_init` 里置值），或改 `can_afford` 恒 true + `pay` 不扣钱。

## 4. 待确认

- 银钱是否有服务端/云存档校验（本作单机 Roguelike，大概率纯本地，但要在真机确认）。
