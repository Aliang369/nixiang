## 3. ★钩子语义（shell handler 反汇编，ARM64）

三个 handler 都位于壳匿名可执行段 `shell_rx_bss = 0x74312cb000-0x74313c6000`，统一通过 **flag 页 `0x74313c7000`** 取「原始函数指针 / 开关字节 / 参数值」。

### H0 `0x74313a0300` ← `PlayerAttackColl.GetNormalAttackDamage`（输入伤害）

```asm

ldr  x8, [flag+0x118] ; ldr x8,[x8]   ; = 0x763aa8b000 (原始跳板)
```

**语义 = 自定义伤害**：把用户输入的整数（flag+0x120 指向的 int）以 float 形式加到 `GetNormalAttackDamage()` 的返回值上。取证时该 int 实测 = `1`（默认态）。

```bash
  /tmp/jfs/shelldump --apk 02_apks/疾风骑士_60.0.1_com.emay.wxsy.topon.apk

       skip=499042246656 count=20480 iflag=skip_bytes,count_bytes'

# 5) 方法名解析（libil2cpp.so 已 stripped，必须走 metadata）
mkdir -p /tmp/jfs/il2cppdump/out
cd /tmp/jfs/il2cppdump && dotnet ~/Documents/nixiang/01_tools/Il2CppDumper/Il2CppDumper.dll \
  libil2cpp.so global-metadata.dat /tmp/jfs/il2cppdump/out
```

**教训 / 坑**：

1. `diff_il2cpp_mem.py` 必须按**数字索引**排序 `il2cpp_rx_*.bin`，否则 `rx_10` 排在 `rx_2` 前导致整段错位，产生百万级假差异。
2. Il2CppDumper 的**输出目录必须先 `mkdir -p`**，否则静默不产出任何文件却仍打印 `Done!`。
3. `dump_binge_shell_mem.sh` **不覆盖 `libSDKloading` 的 file-backed `rw-p` 段**（flag 页就在这里），需单独 dd。
4. 壳字符串全部经 `ay::obfuscated_data` 加密 + Virbox 保护 ⇒ 静态 `strings` 只能看到少量明文（`.rodata` 0x3b5ff 起的备份槽名表、0x2e1f9 起的 11 个「伤害」）。
5. `grep` 量化符上限 255（`grep: maximum repetition exceeds 255`）；设备 toybox `strings` 不支持 `-e`（UTF-16），需本地解码。
6. 界面取证**不得自行点屏**（用户硬约束）；需要开菜单/拨开关时向用户提人工配合。

## 7. ★免广告分析（星空版必须新增）

### 7.1 斌哥改包**没有**免广告

- 壳的补丁函数池（`伤害×11`、`时间`、`能量`、`更新方法`、`加密值`、`IsInvincible`、`xue`…）**没有任何广告相关函数**；
- 运行态实测 `patch_regions=3`，三处全部是战斗/时间钩（H0/H1/H2）；
- 菜单 `exp` 4 个槽里也没有广告条目。

⇒ **斌哥这个改包不含免广告功能。**

### 7.2 但本游戏广告位密集 ⇒ 按用户规则「需要新增免广告」

`shared_prefs/` 与 `lib/arm64-v8a/` 广告 SDK 证据：穿山甲 `pangle_com.byted.pangle_5439606_*` / `libPglbizssdk_ml.so` / `libpanglearmor.so`、快手 `ksadsdk_*`（约 50 个文件）/ `libkssdk`、优量汇 `com.qq.e.*` / `gdt_plugin`、TapTap `tap_sdk_sp.xml` / `com.taptap.sdk.*` / `TapAD_OAID_Manufacturer_SP_NAME.xml` / `libtapsdkcore.so`、Unity Ads `unityads-installinfo.xml`、`COUNTLY_STORE_tap_adn.xml`、`bdxadsdk.jar`。

`menu_375.html` 自身还有一个 `div.ad_box` 浮层（`#dtime` 30 秒倒计时 + `closeAD()` + `iframe#ad-iframe` 点击 `openUrl(window.ad_url2)`），`app1.js` 里 `ad_time`/`ad_time2`/`ad_stop`/`ad_ok`/`ad_url`/`ad_url2` 冷却 86400 s（24 h）。这是**斌哥菜单页自己的广告**，与游戏内广告是两回事；星空版自建菜单时不应保留。

## 8. 与同族壳先例的差异 / 结论

| 游戏 | 壳手法 | 抓点形态 |
| --- | --- | --- |
| 伊莫 | xLua：hook `libdl.so` 的 `dlopen` → `luaL_loadbuffer` 整份替换 Lua chunk | Lua 源码明文内嵌 `.rodata`；开关走 `lua_setglobal("AN_i")` |
| 爆裂防线 | HybridCLR 热更 DLL + il2cpp 反射读写 | `patch_regions=1`（与功能无关）；配置表在 `shell_rw_bss` 含 `ChangeHp zbMonster SetSpeed` |
| **疾风骑士（本包）** | **KittyMemory/MemoryPatch + Dobby 内联钩，补丁表经 `ay::obfuscated_data` 加密 + Virbox 保护** | **`libil2cpp.so` 内 3 处 `LDR X17; BR X17` 16 字节补丁；开关/参数走 flag 页 `0x74313c7000`** |

**结论**：

1. 斌哥改包对疾风骑士**真的生效**（对比 2026-09-14「一念通天」719 那次 `patch_regions=0`、Hook 实际未生效，本轮必须做双向取证 —— 已做）。
2. 菜单**声明** 2 个功能（输入伤害、超级无敌），运行态**实际** 3 个钩（多出一个未暴露的「变速」通道），两者已完全对齐解释。
3. 星空版需要移植的抓点 = **H0 + H1**；**免广告需自行新增**（斌哥原包没有），首选 `GameSetting.IsNoAd()`。
4. 移植时**不要带** `libtoolChecker.so`（RootBeer 反 root），也不要带斌哥菜单页自带的 `ad_box` 广告浮层。

## 9. 未决 / 待用户配合

1. **待人工配合（可选，用于 100% 坐实开关映射）**：用户手动开启「超级无敌」→ 我重新 dump flag 页并比对 `0x74313ca161` 是否由 `0` 变 `1`；再手动输入伤害值并保存 → 比对 `0x74313c9ee8` 的 int 是否随输入变化。当前推断已由 handler 反汇编闭合，此项仅为交叉验证。
2. H2（`Time.get_deltaTime` → 每帧 `set_timeScale(flag+0x168)`）在本游戏取值恒为 1，**是否在特定 VIP/版本下会变成可变值**未验证。
3. `libunity.so` / `libmain.so` 的内存 dump 曾出现「内存侧全 0 / dump 尺寸异常」问题（`dd` 补齐 + 设备 shell `$((16#...))` 算术），**il2cpp 之外是否另有补丁尚未 100% 排除**；不过 `patch_regions=3` 且三处均落在 libil2cpp，加上壳的补丁函数池里没有广告函数，风险低。
4. `CodeRegistration : 6e69658` 在 Il2CppDumper 输出中显得可疑（疑似自动搜索失败），但三个 hook 的 `Offset` 列与内存 diff 的 `file_off` **逐字节精确吻合**，且 RVA→符号解析结果自洽 ⇒ 判定 dump 可信。
