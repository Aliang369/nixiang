# 消消英雄2 1.2.27 — 菜单第 3 项「瞬间结束战斗」→「解锁自动战斗」（2026-10-02）

## 需求（用户原话）

> 功能都没问题，但是需要改改，瞬间结束战斗改成解锁自动战斗，游戏内不是有一个自动战斗功能，打开提示"通关主线4-10后解锁且自动战斗功能和3倍速功能"，开启功能后就直接可以打开使用自动战斗和3倍速度

即：**不要**开战替玩家按 5 倍速 + 强制 Autoplay，而是把游戏自带的「自动战斗 + 3 倍速」的
主线 4-10 解锁墙拆掉，让玩家自己点。菜单仍是 3 项，第 3 项改名为 `Toggle_解锁自动战斗`。

## 结论（PROVEN）

- 游戏内自动战斗与 3 倍速**共用同一个门控函数**：`UserInfoManager.HasUnlockSpeed3()`。
  1.2.27 全量 Lua 模块里 `HasUnlockSpeed3` 只出现在 `GameViewUpperUI` 与 `UserInfoManager` 两处。
- 覆盖该函数（`AN_3` 为真时恒返回 `true`）= 弹窗消失、按钮可用；关掉开关逐帧回退原判定。
- 原实现（`UserInfoManager` proto#104，源行 1617-1620）：
  `return MainLevel.Create(GameConfig.GetAutoPlayOpenChapter(), GameConfig.GetAutoPlayOpenSection()) <= UserInfoManager._accountMaxMainLevel`
  ⇒ 判定「4-10 这一关的 MainLevel ≤ 账号已通关最高 MainLevel」，与玩家当前章节无关，所以改存档/换号都能绕，唯独没有 API 侧入口，只能覆盖函数。

## 怎么找到门控的（运行时 Lua dump）

官方包静态面无 Lua：`unzip -l` 无任何 `.lua`，`assets/bin/Data/` 是 182 个哈希名 bundle，
`assets/*` 全量解出（121 MB）后 grep「自动战斗 / 通关主线 / 倍速」**零命中** ⇒ 脚本是加密下发、
运行时才解密。因此给诊断 so 开宏 `MATCH2_LUA_DUMP_TRACE=1`（内部 `MATCH2_DUMP_ALL` 令
`ShouldDumpModule()` 恒真），挂 `luaL_loadbuffer` + `SignatureLoader.load_and_verify`，
把每个已解密 chunk 落到 `/sdcard/Android/data/com.blina.match2.tt/files/starry_lua_dump/`，
文件名 `m_<fnv1a32(源路径)>_<len>.lua.bin`。用户点一次目标界面后拉回 **2204 文件 / 1102 模块 / 16 MB**。

### dump 出来的不是源码，是「定制头 Lua 5.3 字节码」

`luac -l` 直接报 `format mismatch in precompiled chunk`（`lundump.c:247-248` 校验的就是 format 字节）。
定制点只有头部 12 字节，body 与标准 5.3 `DumpString`/`DumpCode` 完全一致：

| 偏移 | 标准 5.3 | 本游戏 | 说明 |
|---|---|---|---|
| 0 | `1b 4c 75 61` | 同 | `\x1bLua` |
| 4 | `53` | 同 | 版本 5.3 |
| 5 | `00` | **`01`** | format 字节被改成 1 |
| 6 | `19 93 0d 0a 1a 0a` | 同 | 格式标记 |
| 12 | 5 字节 `04 08 04 08 08` | **4 字节 `04 04 08 08`** | 少了 `sizeof(int)` |
| 16 | `LUAC_INT`(8) + `LUAC_NUM`(8) | 同（`0x5678` / `370.5`） | **头长 32 B**，body 从 `0x20` 起 |

⇒ 修表解析即可用标准 `load_proto` 逻辑读。

### 反汇编工具（已入仓）

| 脚本 | 用途 |
|---|---|
| `04_scripts/消消英雄2/xxh2_luadis.py` | 解析 + 反汇编整模块；首行打印 `consumed/total`（相等 = 解析精确到字节）。用法 `python3 xxh2_luadis.py m_xxx.lua.bin > dis.txt` |
| `04_scripts/消消英雄2/xxh2_luafn.py` | 从 dis.txt 按名字提取函数块。用法 `python3 xxh2_luafn.py dis.txt HasUnlockSpeed3 OnAutoPlayButtonClicked` |

两个易错点（都踩过）：

1. **模块里「函数名 ↔ proto 编号」**：class 方法表编译成 `CLOSURE R5 -> proto#N` 紧跟
   `SETTABLE R2 R2 "名字" R5` ⇒ **名字在 k 行，CLOSURE 在 k-1 行**（差一行就全错位）。
2. **`sBx` 偏移 = 131071**（`MAXARG_Bx>>1`），跳转目标打印成 `i + 1 + sBx`。
3. opcode 序**未混淆**：从包内 `libxlua.so`（未 strip）读 `luaP_opnames`@`0x666e8`（48 指针）与
   `luaP_opmodes`@`0x10888`（47 B）对完，就是标准 5.3 顺序（0 `MOVE` … 46 `EXTRAARG`）。
