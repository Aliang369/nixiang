## 你要的意思（已对齐）

不是抄他的 UI，而是：**开着他的无敌/秒杀/瞬清时，抓到他改游戏的那几行逻辑 → 原版照抄改点。**

## 结论：他改的是 Lua，不是 libil2cpp

| 检查 | 结果 |
|------|------|
| 内存 `libil2cpp.so` r-xp vs APK 文件 | **0 字节差异**（没 inline hook C#） |

| 开关变量 | 全局 `AN_1` / `AN_2` / `AN_3`（菜单 `lua_pushboolean` 设置） |

## 菜单三项 ↔ 代码

### AN_1 ≈ 秒杀（我方伤害 ×10）

在 `CFightSystem:DoAfterTaxDamage` 里，结算护盾前：

```lua
local isSide1Caster = skill:GetCaster():GetPlayer():GetSide() == CSide.Side1
if AN_1 and isSide1Caster then
    points = points * 10
    damagePoints = points
end
```

### AN_2 ≈ 无敌（敌方打我方伤害归零）

```lua
if AN_2 and not isSide1Caster then
    points = 0
    damagePoints = 0
end
```

（敌方攻击时 `isSide1Caster == false` → 伤害清零）

### AN_3 ≈ 瞬间结束战斗（加速 + 自动）

战斗开始 `FightBegan` → `_ApplyFastAutoSwitch()`：

```lua
function CFightSystem:_ApplyFastAutoSwitch()
    if not AN_3 then return end
    if InputManager.GetPlayerMode() ~= PlayerMode.SinglePlayer then return end
    -- 教程中跳过等...
    TimeScaleManager.SetTimeScale(TimeScaleType.TestFastPlay, 5)
    GameConfig.SetFastPlayMode(true)
    if InputManager.GetCurrentMode() == InputMode.Human then
        InputManager.SetCurrentMode(InputMode.Autoplay)
        InputManager.SetAutoCastSkill(true)
    end
end
```

（5 倍速 + 自动放技能，体感「瞬间打完」，不是直接改胜利协议。）

初始化：

```lua
AN_1 = AN_1 or false
AN_2 = AN_2 or false
AN_3 = AN_3 or false
```

壳注释（内存残缺还原）：`AN_1 Side1 x10` / `AN_2 Side2 归零` / `lua_pushboolean + lua_setfield`。

## 原版怎么借鉴（路线）

1. 找原版同版本 APK。  
2. 在 `assets` / bundle 里定位 **`CFightSystem`（或同名战斗 Lua）**。  
3. 在 `DoAfterTaxDamage` 同样位置插入 AN_1/AN_2 两段；在 `FightBegan` 路径挂 AN_3。  
4. 星光菜单三个 Toggle → 设置 Lua 全局（或改包内默认 `true`）。  
5. **注意**：若服端有 `ReplayInput.VerifyDamage` 校验，倍攻/锁血可能结算失败（与堡垒之战同类风险）。先单机/弱校验模式验证手感。
