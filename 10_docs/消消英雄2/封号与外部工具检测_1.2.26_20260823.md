## 1. 一句话结论

封号/「外部工具 / 小黑屋」**不是单一本地 so 检测**，而是多层叠加：

| 层级 | 组件 | 对星光包的风险 |
|------|------|----------------|
| SDK 环境检测 | **Mob/FlySDK**（`cn.fly`） | 🔴 Root/KSU、Magisk、Xposed、读 `/proc/self/maps` 搜 `xposed`、已装 hook 包名 |
| 渠道风控 | **TapTap Themis**（`libthemis.so`） | 🟡 设备指纹 / OneID 上报 |
| 玩法校验 | **Lua 战斗逻辑 + 服端**（热更脚本，非 il2cpp 明文） | 🔴 十倍伤害 / 锁血 / 5 倍速+自动战斗，易触发战斗重放或统计异常 |
| 注入特征 | **星光包本身** | 🔴 `libstarry_magic.so`、Dobby hook `LuaManager.Update`、悬浮窗 `MenuService`、重签 |

弹窗中文案在 **APK / XOR bundle / il2cpp 均未命中**，但已在 **登录后热更本地化表** 明文命中（见 §2.5）。

#### 6.2.3 本地环境任务（EnvTask，第二轮 2026-08-23 02:46）

```
AEventSceneEntered + SceneName == Scene.Main
    → CheckPlay / Judge
        前置：DeviceInfo.IsMinigame、上局 IsWin、ReplayUtility.IsModuleReady、IsLevelTypeReplayable
```

`EnvTask` 实际执行走 **`LuaManager.CreateEnvTaskRuntime(moduleName, inputStr)`**（il2cpp `PersistentLoader`），**不经过** `luaL_loadbufferx`，故 xlua Trace **抓不到** `Modules.EnvTask.Tasks.EnvTaskReplay` 本体。

第二轮真机（mod 全关、打完一局）：dump **53** 模块，含 `AntiCheatManager` / `EnvTaskManager` / `ReplayInput`；log **无** `[EnvTaskManager] RunTask`，说明 **未回到 Main 场景触发 CheckPlay**（仅进战斗不够）。
