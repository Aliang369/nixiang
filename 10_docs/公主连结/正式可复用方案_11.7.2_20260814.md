## 1. 一句话结论

**禁止对游戏包 `apktool b` / `inject_pcr_*.sh`。**  
必须走 **外科 zip**：官方 `classes.dex`～`classes12.dex` + `resources.arsc` 字节不变；只加 `classes13.dex`、替换二进制 Manifest、加 `libstarry_magic.so` / `libc++_shared.so` / `assets/certs`。  
只改 native 时：以外科成品为底 → `pcr_so_only.sh` 只换 so。

装机：**只覆盖** `pm install -r -d`，**禁止 uninstall**（热更约 10GB）。

## 4. 菜单挂机消失（已修，正式包含）

ColorOS 挂机时 `MainActivity` 会 **Stop→Start 闪断（数 ms）**，旧逻辑立刻 hide，且 ACTIVITY 模式 resume 后不再 `addView`。

修复（`MenuService.java`，已进正式包）：

- 后台 hide **防抖 600ms**；已 resumed 则跳过  
- ACTIVITY：resume 后主动 `setOverlayVisible(true)`  
- 清 `suppressShowUntilElapsed`

专项笔记：`挂机菜单消失_ACTIVITY闪断_20260814.md`。

## 5. 硬红线（复用时必守）

1. **游戏包禁止 `apktool b`**；apktool 只解小模板 `starry-mod-menu`。  
2. **禁止**用 apktool 路径做 `*_so_only`（曾误杀，归因到属性 hook）。  
3. **禁止 uninstall** 公主连结；脚本默认 cover install。  
4. 受保护文件：`classes0–12`、`resources.arsc` — 一个字节都不能变。  
5. `StarryApp` 须 **继承官方 `Lcom/bilibili/priconne/App;`**（脚本会 patch smali），否则 GSC/权限链崩。  
6. 会话结束跑：`./04_scripts/_common/cleanup_device_re_residue.sh`。
