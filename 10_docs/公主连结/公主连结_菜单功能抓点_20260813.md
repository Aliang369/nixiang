## 7. 闪退定位更正（2026-08-14）

### 现象链
1. 为补属性，`pcr_so_only.sh` 走 **apktool b 整包** + 试挂 `UnitParameter` getter → 启动约 1–2s 死。  
2. 曾见 `malloc(巨量)`，一度归咎属性 hook。  
3. **回退属性 hook 后仍死** → 主因不是属性代码。  
4. 改用 **外科底包** 只 zip 换 `libstarry_magic.so`（变速-only）干净重装 → **存活 25s+**；log：`[Pcr] ready … (attr hook disabled)`。

### 结论
| 项 | 判定 |
|----|------|
| 主因 | `apktool` 重建污染受保护 `arsc`/dex → **TSS ~1.5s 杀进程**（与 `闪退定位_dex完整性` 一致） |
| 次因/噪音 | 错误属性 getter hook 可另致堆损坏（`malloc` 巨量）；已禁用 |
| 正确 so 热更 | 以外科包为底，**仅替换 so + 重签**；禁止 apktool 整包 |
