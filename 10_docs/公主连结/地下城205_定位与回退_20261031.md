## 3. 试过的修法：地下城守门（已回退）

思路：钩 `DungeonBattleProcessor` 的 `.ctor`（argc 1/2）+ `FinishBattle` + `BattleRetire`，
进入地下城战斗期间把属性叠加**暂停**（原值透传），战斗结束立刻恢复。

实测结果（**失败**）：

```
[Pcr] dungeon guard hooks=4 (ctor1/ctor2/FinishBattle/BattleRetire)   ← 钩子全装上
[Pcr] 进入地下城战斗 → 属性叠加暂停（服务端校验战果，改值必 205）      ← 标记确实置位
[Pcr] 地下城战斗结束 → 属性叠加恢复
→ 用户实测：仍然 205
```

⇒ 说明「这场战斗里不叠加」还不够：205 更可能来自**上报侧的整场日志/数值与真实不符**
（`DungeonMylog*` 那套）或标记生效前的状态冻结，不是单点属性覆写能绕开的。
