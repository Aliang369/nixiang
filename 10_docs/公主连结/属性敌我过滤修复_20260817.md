## 2. 问题与根因

### 2.1 敌我双方同改（发他人复现）

旧逻辑：`ShouldBoostUnit` 在 **未登记己方时全放行**（为角色面板兜底）。  
他人常见路径：开属性 → 直接开战 → `n==0` → 敌我 `get_Total*` 一起被改。

### 2.2 热路径 SafeProbe 闪退

曾在 `get_Total*` 内 `SafeProbe` + 实时调 `IsPlayerUnit`。  
违反 `GAME_MOD_GUIDE`：热路径禁止 SafeProbe → 跨线程 SIGSEGV 可直接杀进程。  
**与全局加速无关。**

### 2.3 修闪退后属性失效

FieldOffset 解析不到 `UnitCtrl→UnitData` 时，敌我 side 表为空 → 失败关闭导致「全不改」。  
修复：首次 `IsPlayerUnit` **一次性**扫槽 `discover` 并缓存偏移（仅此处允许 SafeProbe）。

## 3. 定稿实现（规范对齐 Template / Archero2）

- 只 hook 具体方法：`Time.get_deltaTime` / `UnitData.get_Total*` / `UnitCtrl.get_IsPlayerUnit`
- 每个 hook 先调 `orig`
- `IsPlayerUnit` → 写入 `UnitData → isPlayer` side 表  
- `get_Total*` → **只读表**；未知 / 非己方 → 不改  
- Tick：同步开关 + 兜底 `InstallHooks`；数值变更日志去重（避免 200ms 刷屏）
