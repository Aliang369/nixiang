# 公主连结 — 挂机菜单消失定位（2026-08-14）

## 现象
游戏进程仍在，悬浮球/菜单没了。

## 真机证据（pid 17247）
```
18:29:27.753 onActivityStopped MainActivity
18:29:27.759 MenuService: app background → hide overlay
18:29:27.759 overlayVisible=false attached=false
18:29:27.763 onActivityStarted / onActivityResumed（数毫秒内又回前台）
```
ColorOS/挂机时宿主 Activity 会闪断 Stop→Start，并非用户真切后台。

## 根因（两处）
1. `onActivityStopped` 立刻 `post(hide)`，闪断来不及被 `onStarted` 取消。  
2. `syncOverlayForHost` 对 **ACTIVITY** 挂载直接 `return`：hide 只 `removeView`，`isAttached` 仍为 true → resume 后**永不** `setVisible(true)`。

## 修复（`MenuService.java`）
- 后台 hide 防抖 600ms；执行前若已 resumed 则跳过  
- resume 清 `suppressShowUntilElapsed`  
- ACTIVITY 模式在 resume 后主动 `setOverlayVisible(true)`
