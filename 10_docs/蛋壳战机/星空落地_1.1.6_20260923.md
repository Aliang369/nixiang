## 3. 免广告覆盖

沿用 1.1.5 契约（原版 `CheckAndPlayVideo` 存在直接以 `true` 调用 `onClose`
的成功分支）：

- 开启后用 `il2cpp_runtime_invoke` 调 `Action<bool>.Invoke(true)`；
- 回调无 managed exception 才返回成功；
- 解析或调用失败时回退原广告流程，不伪造成功；
- 技能与广告回调均使用 `thread_local` RAII 重入保护。

静态广告入口覆盖清单（12 项）沿用 1.1.5；各入口实际发奖仍为 `NOT PROVEN`，
需真机逐项验收。

## 5. 构建踩坑（重要，供其它游戏复用）

### 5.1 `Android_dkzj.mk` 过时导致 ld.lld 未定义符号

```text

ld.lld: error: undefined symbol: FgoBoot_InjectEarlyFromOnLoad
  referenced by MainModern.cpp:653 / :663  (JNI_OnLoad)

```

共享入口 `jni/MainModern.cpp:647-663` 自 2026-09-22 起**无条件**引用这两个符号，
但 `Android_dkzj.mk` 的 `LOCAL_SRC_FILES` 只列了
`MainModern.cpp Games/DkzjMod.cpp Games/DkzjEntry.cpp Unity/Il2CppApi.cpp`。
全仓只有 `Android_jjdm.mk`（`Android_jjdm.mk:43` 有明确注释）和
`Android_mygwzd.mk` 修过，其余约 28 个游戏 mk 同样过时。

本作采用 **B 类修法（no-op 兜底）**，新增
`mod菜单/starry-mod-menu/app/src/main/jni/Games/NoAceStubs.cpp`：

```cpp
extern "C" void SignalQuarantine_Start(void) {}
extern "C" void FgoBoot_InjectEarlyFromOnLoad(JNIEnv* /*env*/) {}
```

并在 `Android_dkzj.mk` 追加 `LOCAL_SRC_FILES += Games/NoAceStubs.cpp`。

判据：蛋壳战机**无 tprt 系 ACE**（包内只有 `libsecsdk.so`(442K)/`libsgcore.so`(88K)/
`libthemis.so`(853K)/`libBugly_Native.so`/`libtapsdkcore.so` 与字节加固
`libpanglearmor.so`(264K)，**无 `libtprt.so`**），不需要 seccomp 信号隔离；菜单类已在
`classes5.dex` 并由 Manifest 的 `StarryInitProvider` 拉起，不需要早期 dex 注入。

> ⚠️ 措辞订正：本节早期版本写作「蛋壳战机**无 ACE**」，不准确 —— 腾讯安全组件
> 确实存在，只是不是会「伪装崩溃静默击杀」的 `libtprt` 那一支。本次启动闪退
> **与这些安全组件无关**（崩溃时它们尚未装载），详见
> `故障复盘_启动闪退_1.1.6_20260923.md` §6。

### 5.2 两条会骗人的命令

- **`cmd | tail -40` 会吃掉退出码**：第一次构建显示 exit 0 但实际
  `ERROR: ndk-build rc=2`。必须 `cmd > log 2>&1; echo $?`。

## 8. 风险与卡点

- ~~**偷盗技能局内效果 NOT PROVEN**~~ → **已 PROVEN**（2026-09-23 21:03~21:04，
  pid 27511，三次真实三选一各 `granted=2 (of 3 candidates)`）。
- ~~启动即闪退~~ → **已修复**（启动期不再调 il2cpp 运行时 API），
  见 `故障复盘_启动闪退_1.1.6_20260923.md`。
- **启动期调 il2cpp API 是通用红线**：`il2cpp_init` 由 libunity 在 `nativeRender`
  里才跑，MOD 后台线程是裸 `std::thread`（未 `thread_attach`）。违反 = 静默
  SIGSEGV（无 tombstone / 无 crash buffer / 无 `am_crash`，只有
  `exit-info reason=2 status=11`）。改其它游戏时同规则适用。
- 官方包 `O=gorilla` 与星光包 `CN=StarryMagic` 异签；本次修复版是**同签覆盖**
  升级（存档保留）。若日后换签名密钥，仍需卸载清数据。
- 原包含腾讯安全组件（`libsecsdk.so` / `libsgcore.so` / `libthemis.so`）与字节
  加固 `libpanglearmor.so`。**本次故障与它们无关**（死亡时尚未装载），但
  「重打包是否会被其静默击杀」仍属 `NOT PROVEN`；元数据中存在
  `ErrorCode.BattleCheat=117`、`BattleCheatData=121`、`Tracker.SinglePlayerBattleEndMsg.is_cheat`
  及伤害总量/最大值/击杀数上报字段，服务端战斗校验与封号风险为 `NOT PROVEN`，
  测试应使用测试账号，避免高倍率结算。
- 免广告各入口实际发奖为 `NOT PROVEN`。
