## §4 最小复现

```bash
cd /Users/aliang/Documents/nixiang
# 1. 构建 mod so（需 NDK；产物 libs_dkzj/arm64-v8a/libstarry_magic.so）
bash 04_scripts/蛋壳战机/dkzj_build_so.sh
# 2. 外科组装（gradle 出 dex/smali → 改 Manifest → zip 外科合并）
bash 04_scripts/蛋壳战机/surgical_dkzj_1.1.7.sh
# 3. 签名（StarryMagic + 原包零改动硬校验）
bash 04_scripts/蛋壳战机/dkzj_sign_1.1.7.sh
# 4. 装机（同签 pm install -r -d；失败则卸载重装，不备份不回滚）
bash 04_scripts/蛋壳战机/install_dkzj_1.1.7.sh
# 5. 验证（判「启动成功」必须看 pidof / exit-info，不能只看 logcat 有日志）
adb -s f9a116a2 shell am force-stop com.survivor.acecn
adb -s f9a116a2 logcat -c
adb -s f9a116a2 shell monkey -p com.survivor.acecn -c android.intent.category.LAUNCHER 1
adb -s f9a116a2 shell pidof com.survivor.acecn
adb -s f9a116a2 logcat -d | grep -E '\[dkzj\]|MenuService|RegisterNatives'
adb -s f9a116a2 shell dumpsys activity exit-info com.survivor.acecn | head -20
```

> 装机脚本策略已改：① 先 `pm install -r -d --user 0` 同签覆盖；② 失败则 `pm uninstall`
> 完整卸载后 `pm install --user 0`；③ **不备份、不 `-k`、不 chown/restorecon、不自动回滚官方包**。
