## 二、挂点机制（为什么它能挂上）

1. `libunityhelper.so` **不含任何游戏类名/方法名字符串**（实测 `grep -c EntityCharacter/ChangeHp/ADModuleMgr/HotFix/Attack/Hero/Time/il2cpp_method_get_name …` 全为 **0**；全文件仅 99 条字符串）。
   它 dlsym 的 il2cpp API 只用于**委托调用**（`il2cpp_object_get_class` → `il2cpp_class_get_method_from_name(cls,"Invoke",N)` → `il2cpp_runtime_invoke`，失败打 `onShow invoke threw` / `onClose invoke threw`）。
2. 游戏函数是**硬编码 RVA**：在 `libil2cpp.so` 基址（`dlopen("libil2cpp.so")` + `dl_iterate_phdr`/`strstr` 定位，日志 `found libil2cpp.so base=0x%lx name=%s`）上直接加常量。
   反汇编 `libunityhelper.so` 的 `.text`（vaddr==file offset，地址 `0x57BC–0x6A18`），重建 `movz+movk` 常量得：

   ```
   0x09EF7400 0x09EF7408 0x09EF7428 0x09EF7478 0x09EF7490   ← CTRL 控制块（写进 il2cpp .bss 空隙）
   0x09CB7000                                              ← CTRL+0x18（icall cache 一类）
   0x06D39EB8 = HurtBase.FinalizeAttackResult + 0x10       ← ctrl+0x20
   0x06D203F4 = EntityHero.ChangeHp   + 0x10               ← ctrl+0x38
   0x06D22A54 = EntityHero.set_CurrentHp + 0x10            ← ctrl+0xD8
   0x043CBCBC = GameAdsManager.CheckAndPlayVideo + 0x10    ← ctrl+0x88
   0x06A8AFC0 = DropItemDetectPlayerInfo.CheckInRange + 0x10 ← ctrl+0xA0
   0x08D7A1BC = Application.set_runInBackground            （加速用，工作线程内）
   0x08DEDA94 = UnityEngine.Time.get_timeScale             （加速用）
   ```
   五个游戏目标**全部等于「方法起始 + 0x10」**（5/5，非巧合）。原因是 1.1.7 这些方法起始是
   **16 字节 IL2CPP 间接跳转桩**，真实函数体紧随其后：

   ```
   +0x00 adrp x16, #0x9EF3000
   +0x04 add  x16, x16, #0x400        ; 函数指针表基址 = RVA 0x9EF3400
   +0x08 ldr  x17, [x16, #0xNN]       ; NN 逐方法不同：0x10/0x30/0x80/0x98/0xD0
   +0x0C br   x17
   +0x10 <真实函数体>                  ; mod 记的就是这个地址
   ```
   ⇒ mod 的做法＝**改桩/改指针表把入口重定向到自己的实现，原函数体地址留在 CTRL 块里 tail-call 回去**。
   1.1.8 这些方法**已无 16 字节桩**（首指令直接是真实序言，见第一节表），所以星光版按"方法序言"直接 hook 即可。

3. CTRL 控制块（`base+0x9EF7400`）布局（`0x5AC8`–`0x5DCC` 装配，日志 `CTRL armed: ctrl=0x%lx dmg=0x%lx hp=0x%lx ad=0x%lx pick=0x%lx (enabled=%d hplock=%d adskip=%d pick=%d)`）：

   | 偏移 | 内容 |
   |---|---|
   | +0x10 / +0x30 / +0x80 / +0x98 / +0xD0 | 从 `.got`(0xACF0+) 抄来的 il2cpp API 指针（`get_class`/`get_method`/`invoke`/`domain`/`asm`） |
   | +0x18 | `base+0x09CB7000` |
   | +0x20 | `FinalizeAttackResult` 函数体 |
   | +0x38 | `EntityHero.ChangeHp` 函数体 |
   | +0x88 | `GameAdsManager.CheckAndPlayVideo` 函数体 |
   | +0xA0 | `CheckInRange` 函数体 |
   | +0xC0 | 来自 `.bss+0xDA0` 的 int（总开关相关） |
   | +0xD8 | `EntityHero.set_CurrentHp` 函数体 |
   | +0x28 / +0x78 / +0x90 | hplock / adskip / pick 布尔 |
   | +0xF0 | 常量 1 |

   JNI 侧（`classes5.dex` → `com.unity.plugin.UnityNative`）只收 int：
   `nativeSetDamage(I)`、`nativeSetHpLock(I)`、`nativeSetAdSkip(I)`、`nativeSetPick(I)`、`nativeSetSpeed(II)`、`nativeSetEnabled(I)`、`nativeTriggerWin()`，
   setter 直接把值写进 `base+0x9EF7428/0x9EF7478/0x9EF7490` 等 CTRL 槽位。

## 三、各功能的实现语义（字符串与日志证据，`.rodata` vaddr==file offset）

| 偏移 | 字符串 | 含义 |
|---|---|---|
| `0x0DB3` | `damage -> 0x%llx ; 生效开关=%d%s` | 伤害倍率写入 |
| `0x1164` | `  (数值=1 -> 原版伤害)` | **倍率=1 即原版**（与 mod 面板 EditText 正整数语义一致） |
| `0x10ED` | `  (数值=1，开关不生效)` | 开关 0/1 语义 |
| `0x10E0` | `hplock -> %d` | 锁血 |
| `0x0FA1` | `adskip -> %d` | 免广告 |
| `0x1181` | `pick -> %d` | 全屏吸取 |
| `0x1146` | `ad skip: onShow=%p onClose=%p` | **免广告＝拿到 onShow/onClose 委托后直接 invoke** |
| `0x0E5C` / `0x0EB7` | `onShow invoke threw` / `onClose invoke threw` | 委托调用失败分支 |
| `0x0F76` | `speed: set=%p get=%p icall_cache=%p` | 加速＝改 `Time.timeScale` 的 icall cache |
| `0x0FED` | `runInBackground -> true（切后台后引擎继续跑）` | 加速配套：切后台不停帧 |
| `0x0F51` / `0x1066` / `0x11AD` | `speed -> %dx %s` / `speed tick: on=%d lv=%d read=%llu` / `speed: 已还原 1.0x` | 倍速含还原逻辑 |
| `0x0EEA` | `CTRL armed: …` | 控制块就绪 |
| `0x0DB3` 附近的 `0x42C80000`（=100.0f） | 反汇编到 `mov w27, #0x42c80000` | 伤害倍率上限 **100×**（与星光版 slider 1-100 同） |

免广告的调用点签名是 **4 参数**：
`GameAdsManager.CheckAndPlayVideo(Action<bool> onClose, Action onShow, Action<string> onPlayFail, Func<string> getSource)`。
mod 的 hook 里不播放广告，而是**把游戏传进来的 `onShow` / `onClose(true)` 直接反射调用掉**，
让上层认为「广告已展示且观看成功」。这比星光版现役的 `ADModuleMgr.CheckAndPlayVideo(string, Action<bool>)`
**挂得更低**（`Framework` 层，所有广告入口都过这里），是用户要试的「他的挂点」。

## 四、一键胜利：**作者已停用**（关键事实）

1. `libunityhelper.so` 三个 JNI 入口 `nativeTriggerWin`(0x63A8, 0x2C 字节)、`nativeTriggerWin__`(0x6350)、
   `nativeTriggerWin__I`(0x637C) **都是同一段日志桩**：写 `__android_log_print` 后 `mov w0, wzr; ret`（返回 false），
   不做任何事。
2. 它们打印的字符串（`0x110C`，57 字节）是：
   **「一键通关已停用（按钮保留，不做任何事）」**
3. CTRL 控制块里**没有任何胜利相关目标地址**（5 个游戏目标已全部对应到上表 5 项功能）。
4. 云端面板（`dshk_helper.bin` → `helper.dex`）的按钮仍在：`o/r.smali:50` 调 `UnityNative.nativeTriggerWin()`，
   然后**无条件**把文字改成「已触发」（`postDelayed` 2.5s/0x9C4ms 复位），日志 `win trigger -> `。即面板是骗人的空转。
   ⇒ 「用他的一键胜利挂点」在本包里**无挂点可抄**，需要自建。
5. 星光版自建可选锚点（1.1.8 已核）：
   - `HotFix.BattleLogic.BattleWorldContext.SetWinPlayerId(int)` RVA `0x6ECE3D4` / file `0x6ECA3D4`（首指令 `0xF81D0FFE`）——**直接判定胜方 = 本地玩家**，最贴近"立即胜利"；
   - `BattleWorldContext.get_IsChapterComplete()` RVA `0x6ECB4E4` / file `0x6EC74E4`（只读判定，适合做保险）；
   - 现役实现走 `BaseSurvivalBattleManager.OnUpdateHook`（水瀑/波次推进）+ `Bsbm.CheckEnemyAllDie`，见 `Games/DkzjMod.cpp` 中的 `kFileBsbmOnUpdateHook` / `MaybeDriveInstantWin()`。

## 六、复现命令（本机可跑）

```bash
# 1) 解出 mod 的 so / 引导 dex
unzip -o -j 02_apks/弹壳战机_1.1.7.apk 'lib/arm64-v8a/libunityhelper.so' 'classes5.dex' -d /tmp/dkjmod
# 2) 反汇编 + 常量重建（capstone 5.0.7 已装；.text vaddr==file offset）
python3 /tmp/dkjmod/ann.py           # → /tmp/dkjmod/so_annot.asm
# 3) 游戏侧落点映射：把 so 里的常量拿去 dump.cs 反查属主类/方法
grep -n "0x6D39EA8" 06_dumped/蛋壳战机/il2cpp_dump_1.1.7_recheck/dump.cs
# 4) 建立 dump 索引（类/方法/RVA/file）：/tmp/dkjmod/idx.py <dump.cs> <out.tsv>
python3 /tmp/dkjmod/idx.py 06_dumped/蛋壳战机/il2cpp_dump_1.1.8/dump.cs /tmp/dkjmod/v18_index.txt
awk -F'\t' '$1=="EntityHero"' /tmp/dkjmod/v18_index.txt | head
# 5) 序言校验（1.1.8）
python3 - <<'EOF'
from capstone import *
md=Cs(CS_ARCH_ARM64, CS_MODE_ARM)
so=open('06_dumped/蛋壳战机/static_inspect_1.1.8/key_files/libil2cpp.so','rb').read()
for n,off in [('HurtBase.FinalizeAttackResult',0x6D39C44),('GameAdsManager.CheckAndPlayVideo',0x43C9720)]:
    b=so[off:off+8]; print(n, hex(off), ' '.join(f'{int.from_bytes(b[i:i+4],"little"):08X}' for i in (0,4)))
EOF
```

产物/工作副本：`/tmp/dkjmod/{libunityhelper.so,so_annot.asm,ann.py,idx.py,v17_index.txt,v18_index.txt,smali5/,smali_helper/,smali_payload/}`。
