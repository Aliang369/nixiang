## 3. IL2CPP 目标与 inline patch

抓取时运行态 IL2CPP 基址：

```text
libil2cpp.so text base = 0x7B948D2000
file offset 0x03630000 -> runtime 0x7B97F06000
```

三处运行态 `r-xp` 与 APK 内 `libil2cpp.so` 逐字节比较，仅有下列 12 字节差异。

### 3.1 EntityCharacter.ChangeHp

```text
HotFix.BattleLogic.EntityCharacter.ChangeHp(long hp)
RVA      0x6B76618
file     0x6B72618
runtime  0x7B9B448618
patch    b1 6a 25 90 31 e2 1e 91 20 02 1f d6
跳转      adrp x17, 0x7BE619C000; add x17, #0x7B8; br x17
替换函数  0x7BE619C7B8
```

用途：同时承载“百倍伤害”和“超级无敌”的基础 HP 变更 Hook。

关键逻辑：

- 非英雄调用路径读取开关 `[shell_bss_base + 0x14D8]`；开启时 `modified_hp = hp * 100`。
- 英雄调用路径读取开关 `[shell_bss_base + 0x14DC]`；命中运行时解析字段 `[shell_rw_base + 0x9C]` 且值 `< 0x3E9` 时，把 HP 变更量改为 `0`，否则保留/调整方向。
- 原始 `EntityCharacter.ChangeHp` 指针存于 `[shell_bss_base + 0x1518]`，抓取时值 `0x7DE6FB6084`。
- 英雄调用深度存于 `[shell_bss_base + 0x1538]`；主入口检查 `[shell_bss_base + 0x153C]` 总有效态。

注：菜单虽然显示参数 `1-100`，当前替换代码里倍率是硬编码 `0x64`，即固定 100 倍。

### 3.2 EntityHero.ChangeHp

```text
HotFix.BattleLogic.EntityHero.ChangeHp(long hp)
RVA      0x6C6B610
file     0x6C67610
runtime  0x7B9B53D610
patch    f1 62 25 f0 31 d2 1d 91 20 02 1f d6
跳转      adrp x17, 0x7BE619C000; add x17, #0x774; br x17
替换函数  0x7BE619C774
```

用途：标记“本次 HP 变更来自英雄”，供基础 `EntityCharacter.ChangeHp` 区分敌我。

关键逻辑：

- 入口先把 `[shell_bss_base + 0x1538]` 的调用深度 `+1`。
- 通过 `[shell_bss_base + 0x1520]` 调用原 `EntityHero.ChangeHp`，抓取时指针为 `0x7DE6FB6064`。
- 返回后调用深度 `-1`。

### 3.3 HeroComponentRandomSkill.OnAddSkill

```text
HotFix.BattleLogic.HeroComponentRandomSkill.OnAddSkill(int id)
RVA      0x6C509A4
file     0x6C4C9A4
runtime  0x7B9B5229A4
patch    d1 63 25 d0 31 92 32 91 20 02 1f d6
跳转      adrp x17, 0x7BE619C000; add x17, #0xCA4; br x17
替换函数  0x7BE619CCA4
```

用途：“偷盗技能”。

关键逻辑：

- 检查开关 `[shell_bss_base + 0x14E0]`、就绪标志 `[shell_bss_base + 0x1560]`、重入保护 `[shell_bss_base + 0x1564]`。
- 从三选一技能数据中取技能集合，遍历候选项。
- 跳过原参数 `id`，对每个其余技能直接调用：

```text
HotFix.BattleLogic.HeroComponentRandomSkill.AddSkillSurvior(int id)
RVA      0x6C5185C
file     0x6C4D85C
runtime  0x7B9B52385C
```

- `AddSkillSurvior(int)` 未被 patch；其函数指针存于 `[shell_bss_base + 0x1530]`，抓取时值即 `0x7B9B52385C`。
- 每次发放技能后累计 `[shell_bss_base + 0x1568]`，完成后恢复重入标志。

## 5. 免广告判断

斌哥菜单本身没有“免广告”项；但游戏内确有广告奖励入口，字符串与结构均命中：

- 体力广告按钮
- 复活广告按钮 / 广告复活
- 扫荡广告按钮
- 购买门票广告按钮
- 快速游猎广告奖励
- 游戏层广告管理器 `HotFix.ADModuleMgr`

后续星空版需要新增“免广告”。首选待验证锚点：

```text
HotFix.ADModuleMgr.CheckAndPlayVideo(string source, Action<bool> onClose)
RVA   0x7727920
file  0x7723920
```

候选思路：跳过广告播放，直接以真实成功路径调用 `onClose(true)`，并让方法返回成功；需在原版同版本上先验证所有广告奖励入口是否都集中走该方法。`TrackADReward`、`TrackADRelive`、`TrackAdButtonShow` 属统计/展示链路，不应当作奖励成功入口直接伪造。
