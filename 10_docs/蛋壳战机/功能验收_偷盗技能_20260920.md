# 功能验收卡：偷盗技能

- 游戏 / 版本：蛋壳战机 / 1.1.5 / vc25
- 菜单项：`Toggle_偷盗技能`
- 用户预期：三选一选择技能后，获得其余未选技能；相同技能重复出现时可升级。
- 当前状态：已知限制，用户决定记录、不修复。

## 实现点

- Hook：`HotFix.BattleLogic.HeroComponentRandomSkill.OnAddSkill(int)`
  file `0x6C4C9A4`
- 补授：读取 `RandomSkillResult.ShowSkills` 后逐项调用
  `AddSkillSurvior(int)` file `0x6C4D85C`
- 顺序：先调用原版 `OnAddSkill(selectedId)`，再按斌哥顺序补授其余候选。

## 已实证

- 真机日志命中 `steal selected=10000601 granted=2`。
- 菜单与 native 通道正常，`grant ok`，Hook 安装无启动崩溃。
- 详细证据见 `evidence_20260920/README.md`。

## 已知限制

- 真机可观察到补授调用，但重复同名技能不会产生等级提升。
- 与“相同技能选择多了可以升级”的预期仍有差异。
- 用户已决定本版不继续修复；后续只有用户重新点名时才进入根因分析。
