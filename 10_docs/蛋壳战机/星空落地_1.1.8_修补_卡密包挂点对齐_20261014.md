## 2. 本轮代码改动

### 2.1 `mod菜单/starry-mod-menu/app/src/main/jni/Games/DkzjMod.cpp`

1. **伤害倍率改挂 `HurtBase.FinalizeAttackResult(FP)`**（file `0x6D39C44`，序言 `0xF81D0FFE`）
   - `FP` 是 `struct { long RawValue; }`、`RAW_ONE=65536`（16.16 定点），AAPCS64 下 8 字节结构走 `x1` 入参 / `x0` 返回；
   - 新增 `Hooked_FinalizeAttackResult`：调原函数后按倍率乘，`t_hurtDepth` 防重入；
   - **新增友方过滤 `VictimIsHero()`**：读 `HurtBase.Entity`(0x60) → `object_class`/`class_name`，命中
     `Hero`/`Follower` 就**不乘**（否则敌人打我方的伤害也会翻倍。卡密包没做这个过滤，因为它默认同时开锁血，
     玩家察觉不到；星光版要能单独开上帝模式，必须自己过滤）；
   - 原 `EntityCharacter.ChangeHp` 的扣血倍率保留为**兜底**，条件改为 `hp < 0 && !g_dmgAtkHookLive`，
     即新挂点一旦上线就让位，避免两处都乘变成平方倍。
2. **上帝模式补 `EntityHero.set_CurrentHp(long)`**（file `0x6D227E0`，序言 `0xF81D0FFE`）
   - 原版只锁 `ChangeHp`（增量路径），属性 setter 路径会漏；现在 god 开启时若 `value < _currentHp`(0x198)
     则直接 return 不落值。
3. **免广告改挂框架层 `Framework.GameAdsManager.CheckAndPlayVideo` 4 参重载**（file `0x43C9720`，序言 `0xD10183FF`）
   - 新增 `InvokeDelegateNoArg()`（`object_class` → `GetMethod(klass,"Invoke",0)` → `runtime_invoke`）；
   - 开关开启时**不播广告**：先反射调 `onShow()`，再调 `onClose(true)`，任一成功即 `return true` 视为「已观看」，
     失败回落原函数；
   - 这层比原先的 `ADModuleMgr.CheckAndPlayVideo(string,Action<bool>)`（file `0x77E7A98`）**更低**，
     后者保留为兜底；重入用「保存-恢复」而非 RAII，因为 `InvokeActionBool` 内部也会动该标志。
4. **立即胜利新增 `BattleWorldContext.SetWinPlayerId(int)`**（file `0x6ECA3D4`，序言 `0xF81D0FFE`）
   - 卡密包无挂点可抄（§1），改用游戏自己的胜负判定入口：开关开启时把胜方 `playerId` 钉成**本地玩家 id**
     ⇒ 任何走到结算的路径结果必然是「胜」；
   - 新增 `LocalPlayerIdOrCache()`（缓存 `g_localPlayerId`，用既有 `GetCurPlayer` + `EntityHero.get_PlayerID` 解析），
     并在既有 phase-two 兜底处把解析到的 pid 回填缓存；
   - 既有的波次驱动（`MaybeDriveInstantWin`：推进波次 / 到期兜底 `OnBattleEnd`）**保留**，两者互补：
     驱动负责「把战斗推到结算」，`SetWinPlayerId` 负责「结算必须是赢」。
5. **拦截上报改为常开注入**（用户 m00392 第 2 条）
   - `g_blockReport` 默认值改 `true`；`Dkzj_OnFeatureChanged` 删除该 case；`Dkzj_Tick` 不再读 features 数组、
     恒 `store(true)`；`Dkzj_ForceClear` 也置 `true`（清空不关）；
   - hook 本体（`BattleRecordManager.IsNeedUploadSaveData`，file `0x74E1900`）与行为不变，只是不再有开关。

   ② 是否影响其它结算场景（多人的败方判定同样会被改写成我方，若在联机模式使用需谨慎）。
