## 0. 结论速览

1. **引擎**：Unity **2022.3.62f2** / IL2CPP，`global-metadata.dat` 版本 **31**，`sanity = 0xFAB11BAF`；资源走 **Addressables**（`assets/aa` + `assets/FullRes` 双区）。
2. **架构分层**：152 个程序集，其中 `HotFix.dll` / `HotFixBattle.dll` / `HotFixFalcon.dll` 为热更分层命名，包内同时含 **`HybridCLR.Runtime.dll`**；战斗为 **Photon Quantum**（`quantum.core/code.dll`、`PhotonDeterministic`、`FrameworkLockStep`）确定性帧同步。
3. **与既有 1.1.7 的关系（关键）**：本包四个既有改造锚点的 **file offset 与 `10_docs/_state/games/蛋壳战机.md` 记录的 1.1.7 值逐一字节相同**（`0x6EDE058` / `0x6C31EC0` / `0x6D1C3E4` / `0x77E2EF8`）⇒ **`libil2cpp.so` 与既有 1.1.7 底包同构建**，既有 RVA/offset 结论对本包同样成立（可直接复用，无需重定位）。
4. **但包体不是同一份文件**：签名者 = **`C=US, O=Android, CN=Android Debug`（Android 调试证书）**，非官方发布证书、也非本机 debug keystore（本机 `~/.android/debug.keystore` SHA-1 `DC:43:4A:D3:…`，本包 `68:76:C7:AA:…`），且**没有 TapTap 渠道库**（无 `libtapsdkcore.so`/`libthemis.so`）⇒ 判定为**第三方重签/二次分发的包**。dex 与 lib 侧未发现注入的 mod 菜单/破解类特征（未见悬浮菜单、外挂框架类名），但**"重签 + 换渠道"这一事实本身需要在装机前确认来源**。
5. **功能**：飞行射击（STG）+ 技能构筑 roguelite 的**重养成 + 重运营 + 强社交**手游；玩法系统 40+ 个，商业化系统齐全（6 家广告 SDK + 内购/订阅/战令/首充/月卡/转盘/大富翁）。分系统清单见 §5。
6. **可改面**：① AOT 代码可直接 hook（四锚点已复核）；② 存在热更分层程序集与 HybridCLR 运行时（但包内**未见**明文体热更 DLL，增量走 CDN）；③ 配置/UI 资源在 Addressables bundle 内，可替换；④ 购买/抽奖/背包等大概率服务端权威；⑤ 新增可利用面：包内集成 **SRDebugger 调试面板**（可切服务器 URL / 清缓存 / 登出 / 打开战斗回放），且 Manifest **已声明 `SYSTEM_ALERT_WINDOW`**（做悬浮菜单不需要额外授权）。
