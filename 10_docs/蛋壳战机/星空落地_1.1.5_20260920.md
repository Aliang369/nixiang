## 3. 免广告覆盖

原版 `CheckAndPlayVideo` 反汇编存在直接以 `true` 调用 `onClose` 的成功分支，
因此星空实现走同一契约：

- 开启免广告后，用 `il2cpp_runtime_invoke` 调用 `Action<bool>.Invoke(true)`；
- 回调无 managed exception 才返回成功；
- 解析或调用失败时回退原广告流程，不伪造成功；
- 技能与广告回调均使用 `thread_local` RAII 重入保护；
- 首次 `Action<bool>.Invoke` 解析失败不缓存失败结果，后续调用可重试。

## 4. 防闪退

已落实：

- 每处 hook 先按 file offset 定位并校验入口序言，失败再按类名/方法名解析；
- `DobbyHook` 安装使用互斥，失败挂点隔离，不阻断其他独立功能；
- orig 未发布时不进入替代逻辑，正常分支始终保留原函数调用；
- 战斗热路径不做堆扫描、对象遍历和字符串解析；
- 攻击倍率使用饱和乘法，1-100 截断；
- 技能候选读取做对象、容器和数组边界检查，最多处理 8 个；
- 技能补授和广告回调使用 C++ 异常兜底及同线程重入保护；
- 初始化失败有界重试，Tick 每 15 秒补装，针对“需多次重启才生效”问题；
- Java 菜单桥的开关、滑块、按钮和文本推送由 `ModBridge.safeCall` 统一捕获 `Throwable`。

仍不能把静态审计等同于运行稳定；实际冷启动、战斗、广告和长时间运行需真机验证。
