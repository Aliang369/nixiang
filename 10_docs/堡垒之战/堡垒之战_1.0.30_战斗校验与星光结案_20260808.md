## 2. 官方结算 / 校验链路

主逻辑：`assets/assets/main/index.js`（Cocos Creator 3.8.7，System.register 模块，基本未混淆）。

### 2.1 时序

1. `mgrVerifyBattle.beginBattle` → `VERRIFY_BEGIN_BATTLE`
2. 战斗中周期性 `verifyBattleProcess` → `VERRIFY_BATTLE_PROCESS`（帧命令 + `rInfo`）
3. 结束 `endBattle` → `VERRIFY_END_BATTLE`（`frame` + `rInfo`）
4. 各模式 `endStage` / settlement → `GAME_STAGE_END`（或副本对应结算 CMD）
5. 服端可能先回 `STAGE_VERIFY_WAITTING=116`，客户端轮询等待
6. 失败常见：`STAGE_VERIFY_FAILED=78` → UI 提示 **「结算失败」**

中途验证失败：`mgrVerifyBattle.onVerifyFail` → `MSG_GAME_BATTLE_BREAK`（`VerifyFail`）→ 「检测到数据异常」类踢局。

### 2.2 为何无敌/倍攻必炸

服务端（或服控模拟）以 **`bOnlyLogic`** 重放：

- `mgrDebug_attackHpScale()` → **强制按 1**
- `mgrFiringRange_bRoleInvincible()` → **强制 false**

客户端上报的 `getResultCompareInfo()` 至少含：

- `rowainHp` / `remainHp`（角色剩余血）
- `killCount` 等

有外挂时的击杀节奏、残血与无外挂重放不一致 → 结束验证或 `game_stage_end` 失败。

客户端对比助手看起来只严卡部分字段，**服端更严**；吞掉 `onVerifyFail` 只能挡踢局弹窗，**挡不住结算失败**。

### 2.3 已验证的「坑」功能

| 功能 | 客户端入口 | 服端/结算影响 |
|------|------------|---------------|
| 无敌 | `mgrFiringRange.bRoleInvincible` | 重放无无敌 → 残血/存活不一致 |
| 十倍攻击 | `_GameContext.attackHpScale` + `MSG_ROLE_TEN`（`onMsgRoleTen`：ATTACK/HP `*=10`） | 击杀数/帧序不一致；官方「清除倍攻」中途只 `scale=1`+`setRoleDataDirty`，不还原已叠属性 |
| 加速 | `mgrDebug.gameTimeScale` | **直接破坏结算**；关加速后奖励曾恢复正常 |
| 蓄力无 CD | `mgrDebug.bDebugXuliNoCd` | 包内几乎只见赋值、少见读取，收益存疑，仍可能扰动操作序列 |
| 解锁玩法 | `mgrPlayMethod._debugUnlockAll()` | 本地入口解锁；不保证服端进度/奖励 |
| GM 加道具 / `debug_pay` / `item_add_for_client` | 走服指令 | 需服白名单；客户端白 ≠ 服白 |
| 伪造 `game_stage_end` 成功 | 曾试验 | 假胜利无真奖励，关卡回滚；**禁止再做** |

## 3. 星光菜单最终功能表（收口时）

`game_id = blzz`  
实现：`mod菜单/starry-mod-menu/.../Games/BlzzMod.{h,cpp}`  
注入：`scripts/inject_blzz_1.0.30.sh`

| feat | UI | 行为 | 结算风险 |
|------|----|------|----------|
| 1 | Toggle_无敌 | `defineProperty` 锁 `bRoleInvincible` ← `__starryInv` | 高 |
| 2 | Toggle_十倍攻击 | 记基准 ATK/HP，叠 `*10`×3；关闭还原 | 高 |
| 3 | Toggle_蓄力无CD | 锁 `bDebugXuliNoCd` | 中/低（实现可疑） |
| 4 | Button_解锁所有功能 | `_debugUnlockAll()` | 低（仅 UI/入口） |

已移除（曾导致结算/无用）：加速、免支付、无限体力、打开 GM、伪造结算。

菜单关闭加固要点：

- 无敌/蓄力：`Object.defineProperty` getter 只认菜单标志
- 倍攻：`__starryAtkBase` 还原 + `GameController.update` 抓 `role`
- 会话失效 / 全关：`Blzz_ForceClear()` + Tick 周期性重同步 OFF

- 引擎：`libcocos.so` + `CocosJavascriptJavaBridge`；Creator 3 用 `globalThis` + `CocosJsBridge.evalOnGLThread`
