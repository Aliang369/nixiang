## 十一、遗留

1. so 只提供 arm64-v8a（`libs_mwdl/arm64-v8a/`）；雷电为 x86_64 + libhoudini 转译，纯 32 位 ABI 设备不适用。
2. 秒杀依赖后台 `feat_num=7` 登记 + enabled（票掩码 254）；后台未放行时 UI 与生效状态会不一致（显示 ON 不生效），只能靠 `[SW] d #7` 日志识别。
3. 秒杀在 `getHpBottom()>0` 保底、`AvoidDeath`、`Infinity` 状态、真实伤害路径（`Lj→qj`）四条路径上不生效。
4. `tick` 第二处命中（模块 `s2`）仍被白名单排除，只拼首个 —— 当前不影响英雄技能（`HJ extends _z` 显式调基类 tick）；要覆盖第二处需单独评估其类层级。
5. 反作弊只中和 `onStageCheat` 一处；`w()` 上报通道仍在（桩测确认未被调用，但通道本身未屏蔽）。
