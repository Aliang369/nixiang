## 十一、遗留

1. so 只提供 arm64-v8a（`libs_mwdl/arm64-v8a/`），32 位 ABI 设备不适用。
2. `main` 包（`216ed`，7,667 B / etag `d279f117…`）内容未变；main 换代时须按其自身锚点窗口重验一遍再出包。

4. 反作弊只中和 `onStageCheat` 一处；`w()` 上报通道仍在（语义桩确认其未被调用，但通道本身未屏蔽）。
