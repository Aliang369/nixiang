## 本会话已否定的方案（防重犯，承 hook-rules §22）

| 方案 | 否定理由 |
|---|---|
| 给伤害锚点保留旧 `i.target.damage=E}` 回退分支 | 该锚点尾部是**混淆局部变量名**，旧回退会拼出引用未声明变量 `P/E` 的 JS（静默或 ReferenceError），故伤害锚点只认当前 token 的变量名 |
| 只改 `MwdlMod.cpp` 不改 `check_hotfix_15.py` | 门禁会拿旧锚点校验新包 → 假失败；且两边 hook 文本漂移无法发现。已加 `cpp_hook_parity` 断言（逐字比对，不一致即 FAIL） |
| 用「文本 Manifest」直接进包 | `pre_install_gate` 查7 校验包内 AXML 头 `03 00 08 00`；已 PASS |
| 把 `RS` 全量替换为 `PS` | 新 bundle 中 `RS` 仍在使用（如 `RS.CRI_RATE` / `RS.CRI_DAMAGE_ADD`），全局替换会破坏原逻辑；只替换移速锚点自身文本 |
