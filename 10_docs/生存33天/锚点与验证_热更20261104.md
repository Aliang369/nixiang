## 6. 修复：fight 派生彻底去名字化

`Sc33DeriveFightVars` 重写为纯结构派生（不依赖任何被混淆的短标识符，符合 hook-rules §24）：

1. `prototype.FightChangeEntityHp = function(` 形参表 → `extra = ps[4]`、`dmg = ps[2]`（伤害量形参，不写死 `i`）；
2. 在 16 KB 窗口内找 `&& <X>.force, `，且其后紧跟 `<id> = <X> && <X>.trueDmg` ⇒ `opts = X`；
3. 找 `= <dmg> < 0,`，其前那个标识符 = `neg`；
4. 插入点 = 该 var 语句第一个 `;` 之后（不依赖尾项是不是 `= 0`）；
5. `em` = 窗口内第一个 `.EntityManager.Ins` 前的标识符（兼容 `Inst`/`Ins` 写法）。

变体表仍保留并补一行 v203 兜底：`{"var f = n && n.force, _ = n && n.trueDmg, m = i < 0, v = i > 0, I = 0;", "h", "m", "n", "o"}`。

离线复算（同逻辑 python，非 C++ 编译版）：`params=['t','e','i','n','o'] opts=n neg=m em=h`，
语句边界 = `var f = … I = 0;` ⇒ 与真机 C++ 一致。
