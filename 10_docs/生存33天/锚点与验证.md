## 6. 两处框架级修正

### 6.1 Sc33Hooks 缺 R8 keep

- 现象：模板 APK 与注入后的 `classes9.dex` 内 `com/starry/magic/cocos/Sc33Hooks` 命中 0，而注入的 `classes8.dex` 按全名 `invoke-static Lcom/starry/magic/cocos/Sc33Hooks;->getRet(I)Z / setRet(IZ)V / shouldSkipAd()Z`，JS 侧还有 `jsb.reflection.callStaticMethod("com.starry.magic.cocos.Sc33Hooks","getAtkMul","()I")`。
- 根因：`proguard-rules.pro` / `inject-dex-rules.pro` 曾用通配 `-keep class com.starry.magic.** { *; }`，规则收窄为逐类 keep + `-repackageclasses` 后，ZxrHooks/YsxzHooks/MfqlHooks/Zzbx2Hooks/CocosJsBridge 都补了，**唯独漏 Sc33Hooks** ⇒ R8 删类/改名 ⇒ 运行到 `get_ret` 即 `NoClassDefFoundError`。
- 修复：两个规则文件各加 `-keep class com.starry.magic.cocos.Sc33Hooks { *; }`（不带 allowobfuscation），并在出包脚本 `[3/7]` 与自检各加一道「classes9 内必须命中 Sc33Hooks」断言。
- 生效证据：修后 `classes9.dex` 649,516 B，`Sc33Hooks` 1 处、`getRet` 2 处、`shouldSkipAd` 1 处、`getAtkMul` 1 处；`classes8.dex` 的 3 处引用可解析。

### 6.2 TapSignKit 签名值必须是证书 MD5

- 现象：包启动后约 2 秒弹一条 Toast「授权失败 / 当前网络不可用，请稍后重试」，不可点击、自动消失；官方原版在同一设备、同一 root 环境不弹。
- 定位：无障碍事件直接读出 `ClassName: android.widget.Toast; Text: [确定, 当前网络不可用，请稍后重试, 授权失败]`（三行文本取自 `layout_open_network_error_dialog.xml`）；日志同时有 `E/TapInitializer: 应用的包名、签名未在 TapTap 开发者中心正确配置`。
- 根因：出包脚本把 `TapSignKit.getSign()` 的返回值填成了 **APK 文件 MD5**（`36a792f9afa349dcc9f4d6498349d4cd`）。该方法语义是返回 **APK 签名证书 MD5**，官方值 `8fa00ae1397609e5e09ff34cc43030e3`。值不匹配 ⇒ TapTap SDK 初始化失败 ⇒ 走它自己的失败提示。
- 修复：脚本拆成两个常量——`ORIG_MD5`（APK md5，只用于底包校验）与 `ORIG_SIGN_MD5="8fa00ae1…"`（只喂 `TapSignKit` patch）；`classes7.dex` 一律使用底包原版，不做任何弹窗屏蔽。
- 对照实验（每轮只改一个变量）：① 换回官方 `sq_plugin`（不 patch）仍弹；② 官方包零改动重签（StarryMagic）不弹，但 TapSDK 报"签名未配置"；③ 把该值改回证书 MD5 后提示消失——模拟器与真机 96F0D883 各验一次。


## 9. 已知限制

- 百倍伤害在 `FightChangeEntityHp` 与 `DamageCommonCalcFinal` 两条路各 ×100（叠加行为与 1.0.24 验收口径一致）。
- `viewAtk`（`GetViewFightTimeRate` 二次加成）本轮仍是「日志报 1 但未真正拼入」：`TryInsertViewAtkHook` 的守卫 `s.find("sc33_atk_mul", p)` 会因 atk 钩子先写入而提前 `return true`，`GetViewFightTimeRate` 字面量在明文 @2,244,801 早已存在 ⇒ 攻速只走 `CalcFinalAtkSpeedValue` 主路。属既存行为，本轮未改。
- `atk` 替换把 `e = Math.min(e, i);` 整行换掉（拼接后无 min 上限行），同样是 `TryInsertAtkHook` 的现状。
- 免广告只覆盖激励视频 `SdkManager.SdkShowAdReward`，不含插屏/横幅。
- 热更每翻一版，明文长度与偏移都会变；结构派生正常应自动跟随，若 miss 先看 `anchor miss snippet` 与 `fight hook 结构派生失败` 两条日志，再按 §4 判据复核。
