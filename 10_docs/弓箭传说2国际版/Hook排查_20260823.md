# 弓箭传说2国际版 Hook 排查（2026-08-23）

## 现象

用户反馈：三个功能均无效（首包误用 `gjc2` 与国服的 `Archero2Mod.cpp`）。

## log 根因（2026-08-23 22:38）

```
[Gjc2] method missing show=... add=... set=... try=... hp=... list=0x0
```

- HotFix 类已就绪（show/add/set/try/hp 均有指针）
- **`GetCachedCharacterList` 在 1.0.1 不存在**（`list=0x0`）
- 旧逻辑把 `fnList` 当作 hook 前置硬条件 → **整包 hook 未安装**

## 修复（gjc2intl 独立 Mod）

1. 新建 `STARRY_GAME_GJC2INTL` / `game_id=gjc2intl`
2. `Archero2IntlMod.cpp`：
   - `ResolveEntityListFn()` 多候选方法名
   - **列表方法缺失时仍安装** steal/invis 相关 hook
   - 全屏依赖列表方法，缺失时 log 警告，待 Trace 补名
3. 菜单与国服分离（`Category_国际版战斗` + `Toggle_国际_*`）

## 验证命令

```bash
adb logcat -s Mod_Menu:V StarryMagic:V | grep Gjc2Intl
```

期望：

- `[Gjc2Intl] hooked ShowSkills/AddSkill/SetTarget/TrySetTarget/UpdateHp list=...`
- 偷技能：`[Gjc2Intl] steal skills +N`
- 隐身：`[Gjc2Intl] invis block SetTarget`

## 二次反馈（2026-08-23 22:46）

- **隐身有效**（log 有 `invis block SetTarget`）
- **偷技能 / 全屏无效**
  - 偷技能：无 `steal skills` log → `g_lastShowSkills` 在 `AddSkillToCharacter` 时为空；国服实抓链为 `SelectSlotCommand.Exec` → `get_ShowSkills`
  - 全屏：`list=0x0`，`GetCachedCharacterList` 在 1.0.1 不存在

## 二次修复（so_only 22:48）

1. **偷技能**：Hook `SelectSlotCommand.Exec`；Exec 前从 command 读 `RandomSkillResult` 并调 `get_ShowSkills`；Exec 后批量 `AddSkillToCharacter`
2. **全屏**：`UpdateHp` 扩散时若列表方法为空，改读 `EntityManager` 字段（`_cachedCharacterList` 等）或偏移 `0x28`

期望 log：

- `[Gjc2Intl] hooked ... list=0x0 exec=0x...`（exec 非 0 则偷技能链就绪）
- `[Gjc2Intl] entity list field _cachedCharacterList off=...`（全屏字段命中）
- `[Gjc2Intl] steal via Exec +N skills`
- `[Gjc2Intl] aoe spread ...`

## 收尾定稿（2026-08-24 用户确认：三功能均 OK）

| 功能 | 最终挂点 / 做法 |
|------|-----------------|
| 偷技能 | `SelectSlotCommand.Exec` 后 `AddSkillToCharacter` 补全 `ShowSkills`；禁止 Hero `AddSkill` 双钩重复偷 |
