## 2. 已实现三个补丁（patch_js_dwdlm.py 实跑通过，node --check OK）

开关统一挂在 window.__nx（默认关闭 ⇒ 未注入时与官方一致）：

    window.__nx = { atkMul: 1, god: false, infSkill: false };

| 功能 | 文件:行 | 锚点 → 注入 | 说明 |
|---|---|---|---|
| 攻击倍率 | battleScript:2794 | te 计算完之后 te = ceil(te*atkMul) | 只放大**最终伤害**，不改输入属性 |
| 上帝模式 | battleScript:2794 | bt._Va === g（本地玩家受击）时 te = 0 | g = localPlayerId |
| 无限技能 | battleScript:2772 | Pt[20000] < 1 时放行 | 跳过技能 CD 门控 |

⚠ 为什么放大最终伤害是安全的：cheat5（battleScript:2797）只看**输入**（St/Zt/Ct/At/Tt/Dt/Mt/Kt），
不看 te。所以 atkMul 不会触发 cheat5 —— 除非倍率大到把战斗结果算崩（服务端另有结算校验，未验证）。
