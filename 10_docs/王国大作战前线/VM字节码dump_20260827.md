## VM 内嵌字符串（节选，@ VM 内偏移）

VM 自带字符串表（~`0x19958` 起），与 so rodata `0x926xx` 对应：

| 主题 | 字符串 |
|---|---|
| ART 拉起 | `ActivityThread` / `mInitialApplication` / `LoadedApk` / `attach` |
| 包路径 | `getPackageName` / `getPackageResourcePath` / `getApplicationInfo` |
| PM | `getPackageManager` / `()Landroid/content/pm/PackageManager;` |
| 抽 dex | `%s/classes.dex` / `%s/classes.dex!classes%d.dex` / `wholedex` |
| DexFile | `dalvik/system/DexFile` / `openDexFile` / `loadDex` / `dexElements` |
| 渠道 | `KWS_MAIN_APP` / `kvm_lemur_system_DexFile` |

**未发现**：`signature` / `Signature` / `Certificate` / `SHA256` / `GET_SIGNATURES` / `META-INF`（VM 明文表 + so rodata 均无）

→ 读签若存在，可能在：
1. **XOR 混淆 JNI 名**（`sub_3FFFC` @ `0x3FFFC`）运行时解密后再 `CallObjectMethod`
2. **numeric opcode** 比较 APK 二进制 / SigningBlock（无字符串）
3. **下游** `libKwProtectSDK` / jiagu（Q1 dex 不解出 → `ClassNotFound`）
