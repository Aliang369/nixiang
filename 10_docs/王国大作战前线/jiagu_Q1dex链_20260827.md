# jiagu / Q1 dex 链（2026-08-27）

## CLAIM

静态 + 实机厘清：TapTap 包内 Q1 SDK 藏在哪、`libkadp` VM 如何解出 `.jiagu/classes.dex`、改签后 `ClassNotFound: com.q1.sdk.*` 的根因。

## VERDICT

| 项 | 结论 |
|---|---|
| Q1 SDK 静态位置 | **PROVEN**：密文嵌在 **classes.dex 数据区**（2817 个 `Lcom/q1/sdk/*` 型字符串，**0** 条 `class_defs`） |
| 运行时 dex 来源 | **PROVEN**：`libkadp.so` VM 从 **当前 base.apk** 抽链 → 内存路径 `files/.jiagu/classes.dex`（+ `!classes2.dex`） |
| 磁盘 jiagu 缓存 | **PROVEN**：仅 **mini.dex**（292 B，`com/mixClass` 占位）；**classes.dex 不落盘** |
| 外科包 dex 完整性 | **PROVEN**：`classes.dex` MD5 与官方一致；`classes2~4` 字节未改；新增 **classes5**（星光） |
| 改签后缺失类 | **PROVEN**：`ChannelApplicationListener` 等渠道类 **不在** APK 任何 dex 的 `class_defs`，也 **不在** classes.dex 密文型串表 |
| 渠道 / SigningBlock | **FAILED（A 路线证伪）**：920B payload=官方前 920B；扩至 1600B 仍 ClassNotFound |
| Trace open 链 | **PROVEN**（22:00）：仅 `mini.dex` 落盘 open；`base.apk`/`libKwProtectSDK` 命中；无 `wholedex` |
| 进程退出路径 | **PARTIAL**：libc `_exit` hook 未触发；AM `Process has died`；疑 Java `System.exit(0)` |
| 运行时 dump 全量 jiagu dex | **BLOCKED**：无 Root；race pull `.jiagu/` Permission denied |

## 保护栈（与 dex 链关系）

```
StubApplication (classes.dex, kiwi)
  └─ loadLibrary("kadp")                    ← Xkd 解密 LibName
       └─ Kiwi VM (kadp_vm_bytecode.bin)
            ├─ System.setProperty("o0OO0Do0", "classes.dex")   ← Xkd @ StubApplication.<clinit>
            ├─ 从 base.apk 抽 dex（VM 串：%s/classes.dex / wholedex）
            └─ 内存 DexFile → files/.jiagu/classes.dex
                 ├─ load libkwsdataenc.so
                 ├─ load libKwProtectSDK.so
                 └─ 子 dex classes.dex!classes2.dex → libdata-trans-hub.so 等
                      └─ Q1 PluginManager → ClassNotFound: ChannelApplicationListener
```

星光注入（ACF + classes5 + 1s 延迟 so）在 **kadp 之后** 仍执行，但 Unity 未起。

## 静态：APK 内 dex 分工

| dex | 大小 | class 数 | Q1 `class_defs` | 说明 |
|---|---:|---:|---|---|
| **classes.dex** | 16 782 992 | 2697 | **0** | 仅 kiwi `StubApplication`/`Xkd` + androidx/kotlin 等；**密文含 6008× `com/q1/sdk` 字节引用** |
| classes2.dex | 6056 | 4 | 0 | Kotlin coroutine stub；**jiagu 不从这里读 Q1** |
| classes3.dex | 4 083 300 | 2882 | 0 | 游戏/support 库 |
| classes4.dex | 3 379 764 | 2138 | 0 | 同上 |
| classes5.dex | 305 964 | — | 0 | 外科新增：`com/starry/*`、`WgdzzAppComponentFact` |

**对照（官方 vs 外科 kwK1-1s）：**

```bash
# classes.dex 字节一致
md5 work/wgdzz_jiagu/apk/classes.dex
# cfa60a6abc6583de58e32506b3b83cdd
unzip -p 08_output/…/surgical-kwK1-1sSigned.apk classes.dex | md5
# cfa60a6abc6583de58e32506b3b83cdd
```

→ 崩溃 **不是** 改坏官方 dex，而是 **改签后 VM/渠道解密密文失败或不完整**。

### classes.dex 密文特征

- baksmali `list classes`：**无** `Lcom/q1/sdk/*`
- 原始字节：`Lcom/q1/sdk/...;` 型串 **2817** 条（含 `R$attr`/`R$dimen`/`R$anim` 等）
- **`Lcom/q1/sdk/channel/ChannelApplicationListener;` 不在密文型串表**（仅 1 处裸串 `ChannelApplicationListener`）
- 全 APK 仅 **classes.dex** 含该裸串

推论：TapTap **渠道插件 dex** 不在静态密文表内，由 **签名校验 / SigningBlock 渠道块** 决定是否追加解出。

### mini.dex（设备 .jiagu/）

| 文件 | 大小 | 类 |
|---|---:|---|
| mini.dex | 292 | `Lcom/mixClass;`（占位，与 libkadp 串 `mixClass.java` 一致） |

## 实机链（kwK1 + 1s 延迟，pid 30135 @ 17:03:02）

```
StarrySignSpoof → WgdzzAppComponentFact
→ libkadp.so load ok
→ DexFile（deprecated API）打开
→ caller=files/.jiagu/classes.dex → libkwsdataenc.so
→ libKwProtectSDK.so load ok
→ ClassNotFoundException: com.q1.sdk.channel.ChannelApplicationListener
→ Q1SDK-Plugin: PluginManager / CoreApplicationListener 仍部分执行
→ caller=…/classes.dex!classes2.dex → libdata-trans-hub.so
→ (1s) WgdzzSoLoader: delayed loadLibrary ok → StarryMagic JNI_OnLoad
→ ~2s 进程 exit(0)（KwProtect K1 已无 signal 9）
```

与 [B路线_kadp过签_20260827.md](./B路线_kadp过签_20260827.md) 一致：**零改动重签** 同样 `ClassNotFound: com.q1.sdk.*`。
