## 跨版本重定位证据（hook-rules §22 第 3 步 / §23）

- 旧表 23 条 RVA 在新 so 上**全部 DRIFT**（逐条序言不符，脚本 `/tmp` 一次性核对，未入库）。
- 新 RVA 来源：`Il2CppDumper`（`01_tools/Il2CppDumper`）对 1.1.56 的 `libil2cpp.so` + `global-metadata.dat` 出 `dump.cs`，按 **类短名 + 方法名 + 参数个数** 取 `RVA`/`Offset`；`RVA − Offset = 0x4000`（可执行段 `p_vaddr − p_offset`，实测程序头）。
- 23 条全部按名命中（0 条 MISSING），且**命名空间与类名逐条不变**（`Gameplay.Science/Item/Role/Family/Map`、`Core.Ad`、`GameLaunch`）⇒ 按名兜底路径可用。
- 序言交叉验证：21 条序言与 1.1.46 旧表**逐字节相同**；`ItemManager::TryRemoveItem` 两个重载（argc=1 `ItemPrice` / argc=2 `(long,int)`）的序言在 1.1.56 与旧表**互换**（旧表 argc1=0xD10183FF / argc2=0xF81F0FFE，1.1.56 实测 argc1=0xF81F0FFE / argc2=0xD10183FF）⇒ 新表以**实测值**为准（旧表该两条疑为口径互换，功能仍生效是因退回按名路径）。
