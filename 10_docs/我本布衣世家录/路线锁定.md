### 跨版本重定位证据（hook-rules §22 第 3 步 / §23）

- 23 条旧 RVA 在 1.1.66 上**全部漂移**（新 so 不同源，sha256 `8d27a4ff…` → `ce2d6551…`）。
- 新 RVA 来源：`Il2CppDumper`（`01_tools/il2cppdumper`，`ForceIl2CppVersion=false` 自动识别 v31）对 1.1.66 的 `libil2cpp.so` + `global-metadata.dat` 出 `dump.cs`，按 **类短名 + 方法名 + 参数个数** 取值；`RVA − Offset = 0x4000`（可执行段 `p_vaddr − p_offset`，与 1.1.56 相同）。
- **23/23 按名命中，0 MISSING**；命名空间与类名逐条不变（`Gameplay.Science/Item/Role/Family/Map`、`Core.Ad`、`GameLaunch`）。
- 序言交叉验证：21/23 与 1.1.56 旧表**逐字节相同**；2 条代码有变 —— `InitAd`（`0xF81D0FFE`→`0xA9BD5FFE`）、`TapAdnAdSDK::ShowRewardAd`（`0xF81D0FFE`→`0xF81A0FFE`）；新表一律以实测回填。
- **雷电 ARM 转译下的判据修正**：Houdini 把 `libil2cpp.so` 映射成 `r--p`（无 `x`），`VaInExecLib` 的「必须在可执行段」判据在模拟器上恒假 ⇒ 全表退回按名路径（日志 `@name`），功能实测全部生效（含 `OnLoginSuccess` 与 `ShowRewardAd intercepted`）。真机（有 `x` 段）仍走 `@rva` 快路径。
