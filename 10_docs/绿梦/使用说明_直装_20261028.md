# 星光魔法 使用说明（绿梦：时空之声 1.0.5 · 直装版）

> 形态：**直装包**（改装后的 APK 直接安装，装完就能玩）。不需要 root、不需要电脑、不需要框架、不需要 VPN。
> 适用：`com.zhuziplay.lvmengnew.op` **1.0.5**（TapTap 渠道）。版本不一致可能不生效。
> 生成/更新：2026-10-28（收官版 r3）；包文件：`绿梦_1.0.5_starry-releaseSigned.apk`（md5 `3d2e0290…`）

## 一、装之前先确认

1. 手机里如果已经装了**官方原版**，必须先卸载它 —— 本包与原版签名不同，无法覆盖安装。
   ⚠️ **卸载会一并删掉 `/Android/data/com.zhuziplay.lvmengnew.op/` 下的热更缓存（约 13 G）**，
   重装后首次进游戏需要重新下载；不想重下就先别卸载，等有 WiFi 再弄。
2. 手机剩余空间 **≥ 15 G**（13 G 热更 + 安装包）。
3. 只装本说明附带的这个 APK，不要装任何其它"改签包/解密版"。

## 二、第一次打开（会比较慢，正常）

1. 安装后直接点图标启动，**不要**用其它工具"注入"或"加速"。
2. 首次启动会自检并准备补丁：界面停在厂商 Logo / 加载页**久一点是正常的**（比官方包慢）。
3. 进到登录页后用你自己的账号正常登录（TapTap 登录，和官方一致）。
4. 登录后游戏会下载热更资源（若刚卸载过官方包，这里就是那 13 G）。
5. 进到游戏（主城/大厅）后，屏幕边缘会出现**星光悬浮球**，点开就是功能面板。

## 二·五、登录（TapTap 已改为网页授权）

- 点游戏里的 **TapTap 登录** → 会打开**网页授权页**（不是跳 TapTap 客户端 App），登录/授权完自动回到游戏。
- 首次进游戏**不会再弹**「TapSDK 未正确配置 / 包名·签名未在开发者中心配置」的提示（已在校验环节处理掉）。
- 如果网页授权页白屏或一直转圈，先确认手机网络正常，再重试一次；仍不行就强停重进。

## 三、功能怎么用

- 面板里的开关**即时生效**，改完不用重启：
  - 自定义血量（开关 + 数值）
  - 全局变速（倍率，100 = 原速）
  - 伤害倍率（倍率，100 = 原伤害）
  - 无限技能
  - 无限跳跃
- 设置会被记住，下次进游戏还是上次的值。
- 想全部关掉：把开关逐个关掉即可（或删掉状态文件，见下）。

## 四、退出游戏怎么退（重要）

因为本包内置了"防止游戏被检测机制强制清退"的保护，**游戏自己点退出会被挂住**（进程不退出）。
所以：

- 退出请用系统的**强行停止 / 清理后台**（设置 → 应用 → 绿梦 → 强行停止；或从最近任务划掉）。
- 看到"游戏卡在退出画面"不是你操作错了，是这个保护在起作用。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 装不上，提示签名冲突 | 先卸载官方原版（注意会清 13 G 缓存） |
| 启动比官方包慢一些 | 正常：包里多了一层输入伪装与防清退保护 |
| 悬浮球没出现 | 确认已经进到游戏主城/大厅；菜单在游戏内才显示 |
| 开关点了没效果 | 确认游戏版本是 1.0.5；退出重进一次 |
| logcat 里看到若干 `signal 31` 崩溃 | **正常现象**：是我们自己 shell 子进程（`getprop`/`pm path`/`logcat`）退出时被保护机制带走，不影响游戏 |
| 游戏提示更新 | 先别更新，等对应版本的包 |
| 在雷电等模拟器上玩 | **本作不支持模拟器**：模拟器里检测机制会把游戏进程清掉（真机不受影响），请用手机 |
| 点 TapTap 登录弹出网页 | 正常，这就是网页授权登录，登完自动回游戏 |
| 想彻底还原 | 卸载本包 → 重新安装官方原版（数据/缓存需重新下载） |
