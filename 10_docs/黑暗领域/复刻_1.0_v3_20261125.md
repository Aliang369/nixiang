## 3 复刻前必须先核的静态假设（都在 base JS 里验过）

- 模块寻址只认 `chunks:///_virtual/<Name>.ts`（裸名与 `.js` 候选永不命中）；`System.get` 表键是全串。
- `SdkRewardAdGuard` **没有** `showRewardAd`（旧代码那两处 install 是死钩子）；免广告主入口是 static `show` / `showBySysAdTimes`，插屏是 `Sdk.prototype.showInterstitialAd`。
- `handleSummonRequest`：`getSummonBatches(skillId, effect)` 的第一批**就是**事件里传的 effect，符文只追加 `modify_summon` ⇒ 自定义 effect 不会被官方值覆盖。
- `normalizeCloneAttackRatio`：`>1` 时 `/1e4`；`normalizeDurationSecond(t, default=6)`：`>100` 时 `/1e3`。
- 技能表在 `assets/assets/config/` 明文 JSON：`100203` 官方 3 个 / 12s / 0.36；`100901/902/903` 为 `trigger_type=2 + trigger_param=6`（每 6 次普攻），`100903` 官方 11 段 × 99%。
- 反作弊：`BattleIntegrityGuard` 只审计波次生成的怪，玩家与分身不在审计面；`SpeedHackDetector` 只钳 dt 校验。
- Tap：JS 走 `cc.native.reflection.callStaticMethod("com/TapTap/SdkBridge","call","(Ljava/lang/String;Ljava/lang/String;Ljava/lang/String;)Ljava/lang/String;")` ⇒ Java 侧类名不能改。

## 4 两个框架级必改点（本轮修的，换版本先核这两条）

1. `proguard-rules.pro` + `inject-dex-rules.pro` 都必须 `-keep class com.starry.magic.cocos.CocosJsBridge { *; }`。缺这条 R8 会 repackage 成 `com.starry.magic.o.X`，native `FindClass` 失败，日志只有 `[Haly] JS sync deferred (install=0)`，四项功能**全部静默不装**。
2. `HalyMod.cpp` 的 `EvalJs` 必须用 `FindAppClass()` 回退：MOD 后台线程是 `AttachCurrentThread` 的原生线程，`env->FindClass` 走 bootstrap classloader，找不到应用类（实测），回退 `ActivityThread.currentApplication().getClassLoader().loadClass(...)`。

## 5 构建（Git Bash，工作区内，两条命令）

```bash
bash 04_scripts/黑暗领域/haly_build_so.sh     # 编 so（自动 ASCII 暂存 13_scratch/haly_ndk，编完拷回）
bash 04_scripts/黑暗领域/haly_pack_win.sh     # gradle → classes4 → classes2 注入 → Manifest → 合并 → zipalign+sign
```

- 中文路径规则：ndk-build **读**中文路径没问题，**写**含中文的绝对输出路径会 `unable to open output file`（GNU Make 4.3 Win32 把 `mod菜单` 转成 `mod??`）⇒ 脚本把 `NDK_OUT/NDK_LIBS_OUT` 指到 `13_scratch/haly_ndk`（纯 ASCII）。详见 `04_scripts/_common/stages.md`「Windows 执行环境与中文路径硬规则」。
- gradle：仓库 `local.properties` 是 mac 路径且被 git 跟踪 ⇒ `haly_pack_win.sh` 会移走它并设 `ANDROID_HOME`，跑完还原。
- `classes2.dex` 注入三项：`TapSignKit.getSign` 回灌 `d639fb03a75167fbe77bc75e2b4a4304`、`ClientLoginUtils.isClientLogin` 强制 WebLogin、`AppActivity/PrivacyGateActivity/PrivacyActivity` 注入 `MenuService.start` 与生命周期。
- Manifest 注入：`android:name="com.starry.magic.StarryApp"` + `MenuService`（specialUse FGS）+ `SYSTEM_ALERT_WINDOW`/`FOREGROUND_SERVICE`/`FOREGROUND_SERVICE_SPECIAL_USE`。
- 合并断言：`resources.arsc`、`classes.dex`、`classes3.dex` 与原包**字节一致**；so 含 `[Haly]`。
