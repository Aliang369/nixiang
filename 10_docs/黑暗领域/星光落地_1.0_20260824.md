## 3. 实现要点（维护用）

### 3.1 路径

- JS 注入：`CocosJsBridge.evalOnGLThread` → `System.get("chunks:///_virtual/*.ts")`
- 玩家实体：`ECSManager.instance.scene.playerEntity`
- 无敌：`StatusEffectComponent.addEffect(1002, INVINCIBLE, 100, …)`
- 召唤：场景 `eventSystem.emitSync('skill_summon_request', { casterId, skillId:100203, effect })`
- 雷罚：同上 `skill_passive_trigger` + `skillId:100903`
- 表增强（可选）：`SkillConfigManager.parseSkillData` / `TableReaderService.readOne('base_skill')` 仍保留 `patchCfg`

### 3.2 反作弊

- `SpeedHackDetector.enabled`：开战斗向功能时软关（getter 返回 false）
- `BattleIntegrityGuard`：极端数值可能触发结算锁；当前实测四功能可用，若后续锁结算再单独加吞验证或降倍率

### 3.3 外科要点

- **禁止**对游戏原包 `apktool b` 整包重建
- 无自定义 Application → Manifest 设 `com.starry.magic.StarryApp`
- Activity 挂点：`AppActivity.onCreate`（SignSpoof + MenuService）；`PrivacyGateActivity` / `PrivacyActivity` 生命周期
- baksmali 的 `onCreate` 在 `return-void` 与 `.end method` 之间常有 `.line`，注入脚本已按此处理
- dex：`classes.dex`/`classes3.dex`/`resources.arsc` **字节不变**；只换 `classes2.dex` + 新增 `classes4.dex` + so
