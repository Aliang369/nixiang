# 物质与魔法 — TapTap 强制网页登录（2026-08-16）

## 现象

真机星光包（`com.huanshits.materialMagic` 6.03）改签后，本机装有 TapTap 客户端时走 **客户端 SSO**，签名不一致 → 登录失败。  
原注入脚本 `inject_wzym_6.03.sh` **未**做强制网页登录。

## 原因

旧版 Tap SDK（本包在 `classes8.dex`）：

- `LoginClient` 优先 `ActivityHandler.authorize` → 拉起 `com.taptap` 客户端
- 抛 `Exception`（含 `ActivityNotFoundException`）时才 fallback → `WebViewHandler`

## 修法

`ActivityHandler.authorize` 恒抛 `ActivityNotFoundException("starry_force_web_login")`  
→ 与迷雾大陆同锚点。

## 产物 / 脚本

| 项 | 路径 |
|----|------|
| 真机底包 | `02_apks/物质与魔法/物质与魔法_6.03_starry_from_device.apk` |
| 成品 | `08_output/物质与魔法/物质与魔法_6.03_starry-forceWebLogin-releaseSigned.apk` |
| 脚本 | `mod菜单/starry-mod-menu/scripts/wzym_force_web_login.sh` |

```bash
# 仅出包
bash mod菜单/starry-mod-menu/scripts/wzym_force_web_login.sh

# 覆盖安装
STARRY_INSTALL=1 bash mod菜单/starry-mod-menu/scripts/wzym_force_web_login.sh
```

仅替换 `classes8.dex`，其余（含 `libstarry_magic.so` / `resources.arsc`）保持字节一致。

## 验证

登录应出现 **内嵌 WebView / 网页**，不再跳转 TapTap App SSO。
