> 日期：2026-08-09  
> 方法：与消消英雄2 相同 —— KernelSU 读 `/proc/pid/mem`，dump `libSDKloading` 旁 `[anon:.bss]`；再对比内存 `libil2cpp.so` r-xp 与 APK 文件

## 你要的意思（已对齐）

不是抄他的黑块 UI（截屏抓不到字），而是：**开着他的三个功能时，抓到他改游戏的那几处 Hook → 原版照抄改点。**

---

## 结论：他 Hook 的是 IL2CPP，不是改 Lua

| 检查 | 结果 |
|------|------|
| 壳 | 同消消英雄2：`libSDKloading.so` + 旁路可执行 `[anon:.bss]` + **DobbyHook** + 完整 `il2cpp_*` API |
| 菜单开关持久化 | `shared_prefs/com.huanshits.materialMagic_preferences.xml`：`0/1/2` 三个 boolean（开菜单时全 `true`） |
| 内存 `libil2cpp` vs APK | **仅 2 处** prologue 被改成 `B` 跳板（Dobby inline hook） |
| `OnDamage` / `ReduceHp` 本身 | **未改指令**（走原逻辑；无敌靠官方 `wudi` 字段） |

### 两处 Hook（关键）

| 方法 | ELF RVA | 文件偏移 | 作用推断 |
|------|---------|----------|----------|
| `StatusC$$UpPhysicalDamage` | `0x162E6AC` | `0x162A6AC` | **秒杀**：放大物理伤害（原函数 `int UpPhysicalDamage(int tempDamage, StatusC atker)`） |
| `StatusC$$Update` | `0x163456C` | `0x163056C` | **无敌 / 全屏秒杀**：每帧逻辑（写 `wudi`、扫敌方扣血/`Death`） |

跳板目标约在 `0x7778a6f00c` / `0x7778a6f018`（小页 `r-xp` anon；本次 `dd` 读该页 I/O error，不影响确认 hook 点）。

壳内字符串旁证：`DobbyHook`、`已绑定函数：%s -> %p`、`IL2CPP函数映射`、`BW_MEMORYTOOL`、`改写 BYTE/DWORD 成功`。

## 菜单三项 ↔ 游戏逻辑（复刻用）

开关来自 prefs `0/1/2`（具体谁对应哪项，可用「关一项看 prefs 哪位变 false」最终标定；功能语义如下）。

### 无敌 ≈ 强制 `StatusC.wudi`

原版 `OnDamage` 已有：

```text
ldrb w8, [x19, #0x269]  ; wudi
cbnz → return           ; 无敌直接返回
```

官方还有 `OnWudi` / `BuffWuDi`。  
改包多半在 **`StatusC.Update` Hook** 里对 `isAlly/isHero` 单位循环 `wudi=1`（或刷 `inWudiTime`）。

字段：

| 字段 | Offset |
|------|--------|
| `isAlly` | `0x91` |
| `isHero` | `0x7D` |
| `isDead` | `0xD9` |
| `curHp` | `0x1E0` |
| `wudi` | `0x269` |

### 秒杀 ≈ Hook `UpPhysicalDamage`

在伤害结算放大器上动手（`tempDamage` 改大 / 返回极大值），比直接改 `OnDamage` 更贴近改包实际 patch 点。  
若技能走魔法伤，可能还需同样处理 `UpMagicDamage`（当前内存**未** hook 该方法，或许 Update 里另有补刀，或物理路径已够用）。

### 全屏秒杀 ≈ `Update` 里扫单位

在 `StatusC.Update` Hook 中：遍历非友军 `!isAlly && !isDead` → `ReduceHp(curHp)` / `Death()`。  
与 prefs 某一 bit 门控。

## 原版怎么借鉴（路线）

1. 下载同版本 **6.03 原包** → `02_apks/物质与魔法/`。  
2. 星光菜单三项 Toggle → 对应全局 flag（不必抄斌哥 prefs 编号）。  
3. 实现（任选，推荐 A）：  
   - **A. 运行时 Hook**（和改包同思路）：`UpPhysicalDamage` + `Update`  
   - **B. 静态 patch** 同 RVA（原包 so 需确认偏移一致）  
4. 无敌优先写 `wudi`，不要盲目 nop 整段 `OnDamage`。  
5. 过签单独做（`libqkcheck` / PM 伪装），与战斗 Hook 解耦。
