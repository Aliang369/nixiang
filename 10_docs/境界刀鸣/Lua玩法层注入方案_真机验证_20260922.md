## 2. 注入配方（编译期 .so 需要照抄的部分）

1. il2cpp 按名取类，不需要 RVA/注册表（MIRA 加密元数据不影响）：
   - 类：`GameFramework.LuaManager`（typeIndex=1905，11 字段 / 16 方法）
   - 字段：`m_LuaEnv`（XLua.LuaEnv 实例引用）；方法：`Update`（params=1）、`LateUpdate`（params=0）
2. hook `LuaManager.Update`（Dobby）→ 取 `lua_State*`：
   ```c
   void* luaManager = thiz;                                  // Update 的 this
   void* env  = ReadPtr(luaManager, off_m_LuaEnv);           // off 用 il2cpp FieldOffset 运行时取
   void* rawL = ReadPtr(env, 0x10);                          // XLua.LuaEnv.rawL（前两个字段是 static CSHARP_NAMESPACE/MAIN_SHREAD）
   ```
   - 参考实现：`mod菜单/starry-mod-menu/app/src/main/jni/Games/Match2Mod.cpp`（`g_offLuaEnv` 缺省 0x28，取不到就回退）
3. 用 libgame.so 的 C API 执行补丁（**不要用 il2cpp DoString，会 SIGSEGV**）：
   `luaL_loadstring(L, src)` + `lua_pcall(L, 0, LUA_MULTRET, 0)`，失败用 `lua_tolstring(L,-1,0)` 读错误
4. 幂等：补丁首行判 `__jjdm_v2` 全局；只注入一次

## 3. 补丁 Lua（已验证版本，与本仓库 `06_dumped/境界刀鸣/tools/jjdm_lua_patch.js` 中 `PATCH_LUA` 一致）

关键点（全部来自 `0326_combat_api_combatFunc.luac` 反汇编）：

- 实体查表入口是 **`worldImpl:GetEntityImplByUid(uid)`**（字节码 `SELF A B` 的接收者是 `R[B]` = `worldImpl`，不是 CombatFunc 的方法）
- 实体类型：`ei.m_ObjData:GetEntityType()`，与 `CTXDefine.ENTITY_TYPE` 比较：**HERO=2 / AID_HERO=11 / MONSTER=3**
- `CombatFunc.DoSubHp(self, worldImpl, uid, damage, attackUid, skillId, damageId)`：`damage` 是**正值**，函数内部算 `_oldHp - ceil(damage)` 后调 `self:ChangeHp(...)`
  - 伤害倍率：攻击方是 HERO/AID_HERO 时 `damage = damage * N`
  - 无敌：受击方是 HERO/AID_HERO 时直接 `return`（不调原函数）
- `CombatFunc.EnterSkillCd(self, worldImpl, uid, cdKey, ...)`（10 参数）：进入冷却的入口，对英雄 no-op 即无限技能
- `CombatFunc.SetSkillCdNum` 是「加技能点数」**不是**起 CD，禁止 no-op（早期误判已纠正）
