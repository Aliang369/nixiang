## 五、构建脚本与踩坑

脚本：`mod菜单/starry-mod-menu/scripts/surgical_jjdm_1.39.211507.sh`（6+1 步：ndk-build → gradle → apktool d → smali assemble classes15.dex → mini.apk 造二进制 Manifest → python 外科 zip 合并 → zipalign+apksigner）

两个坑（已修）：
1. `echo "… $INJECT_DEX（…"`：**变量后紧跟全角字符会被本机 bash 吞进变量名** → `unbound variable`。必须写 `${INJECT_DEX}（`。
2. 自检 grep 用了 `com/blade/bd`，但 smali 里是点号形式 `com.blade.bd` → 误报"证书常量缺失"。已改为双写法兼容 + 缺失时打印诊断。

环境坑（沿用）：gradle 必须能写 `~/.gradle`（沙箱 workspace-write 会被拒），ndk-build 的 `NDK_OUT/NDK_LIBS_OUT` 必须绝对路径。

| 风险 | 说明 | 观察点 |
