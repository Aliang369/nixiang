## 与原包差异（改包层面）

斌哥在 **原九游包** 上叠加，未替换游戏主逻辑 so：

| 类别 | 新增 / 修改 |
|------|-------------|
| 签名 | 重签为 binge2.keystore |
| Native | 注入 `libSDKloading.so`、`libtoolChecker.so` |
| Dex | 新增 `classes3.dex` 等 → `com.android.support.*`（Menu / Main / Preferences / BinGe / BUFF） |
| Application 链 | 原 `StubApplication`（百度）+ 乐变 `LBApplication` 保留；斌哥通过 `Main.Start` / `Menu` 浮窗挂载 |
| 菜单 | WebView 远程 HTML + `Preferences.Changes` native；prefs boolean `"0"`…`"N"` 门控 |
| 自检文案 | 启动弹窗含斌哥免责声明（见 `dialog_close_log.xml`） |

**未改**：`libil2cpp.so`、`global-metadata.dat`、`libunity.so` 仍为游戏本体（斌哥 hook 在运行时 Dobby 打桩）。

## 斌哥壳运行时注意

- `libSDKloading.so` 静态 strings 几乎无玩法明文（packed）；**Hook 点要靠 memdiff**，不能靠 strings
- 百度壳 + 乐变 + 易盾：动态优先 KSU `/proc/pid/mem`（`dump_binge_shell_mem.sh`），非 Frida 长挂
- 星光落地须 **原包外科组装**，禁止对游戏包 `apktool b`；定稿后 `WhrhxMod.cpp` + `surgical_*` / `*_so_only.sh`
