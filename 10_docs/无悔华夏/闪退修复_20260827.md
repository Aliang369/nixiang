`WhrhxMod.cpp` 从 ~1200 行 / 40+ hook 收成 **Trace 定稿最小集**：

| 开关 ON | Dobby hook（最多） | 说明 |
|---------|-------------------|------|

**已删除残留**：`CanAddArmy`、GetMaxCanSend*、CalcBattleResult/Encounter、OnBattleEnd、Effect SetBase/AddValue、set_timeScale 等全部 trace 0 hit 或未验收 hook。

六项全开上限约 **10 个 Dobby**（`IsPlayerCountry` / `Effect` 共用去重）。


## 根因 1（主因 · 大部分人）

**`MenuService` 前台服务超时**

```
ForegroundServiceDidNotStartInTimeException:
  startForegroundService() did not then call Service.startForeground()
  ServiceRecord{... com.starry.magic.menu.MenuService}
```

旧代码在 `onCreate()` 里先跑 `Preferences` / `ModBridge.syncAuthGameIdFromNative()`（会触发 native），**之后**才 `startForegroundCompat()`。  
无悔华夏 Application 链（百度 NIS + 乐变）很重，主线程被占满 → Android 8+ **5 秒**内未进前台 → 系统杀进程。

### 修复

| 文件 | 改动 |
|------|------|
| `MenuService.java` | `onCreate()` **第一行业务**即 `startForegroundCompat()`；Preferences/native 包 try/catch |
| `MenuService.java` | `onStartCommand()` 再调一次 `startForegroundCompat()` 兜底 |
| `StarryApp.java` | `MenuService.start()` 改 `Handler.post()`，避免与 `super.onCreate()` 抢主线程 |

---

## 根因 2（Native · 加重不稳定）

**`WhrhxMod.cpp` 启动即 bulk hook**

- 旧 `Whrhx_TryInit()`：`libil2cpp` 一旦加载就 Dobby **40+** 点，含已知 SIGILL 的 `CanAddArmy`
- 即使用户**未开任何菜单**，也改写 il2cpp 热路径 → 部分机型/时机 SIGSEGV/SIGILL

### 修复（延迟 + 分组）

| 机制 | 说明 |
|------|------|
| `g_libReady` | 仅表示 il2cpp 已映射，**不表示已 hook** |
| `Whrhx_SyncHooks()` | 按开关懒加载：`InstallEconomyHooks` / `Army` / `Pop` / `Battle` / `Speed` |
| 默认 | 全关 → **0 个 Dobby hook** |
| `CanAddArmy` | 注释明确禁用；军队走 `EffectData` + `GetMax*` |
| `Whrhx_Tick` / `OnFeatureChanged` | 开关变化时再 `SyncHooks` |

## 根因 3（次要 · 部分机型）

**乐变 SDK `AbstractMethodError`**

```
abstract method onMergeProgress(float) on receiver TpfLebianSdk$1
```

`EvenTrackHelper.UpdateCallBack` 接口新增方法，游戏内匿名类未实现。类在**运行时壳解密 dex**里，外科包不能改 `classes.dex`。  
本次未改 dex；若单独出现此崩溃，需乐变/渠道包对齐或运行时 Java 兼容层（待专项）。

## 紫色贴图 / 清数据后功能全失效（2026-08-28）

### 紫色资源（Unity 缺贴图）

| 项 | 实锤 |
|----|------|
| 现象 | 游戏内图片变深紫/洋红 |
| 设备证据 | `files/SYResRoot/DlcWorkSpace/*/Invalid_Version/` + `current_version.json` 内容为 `Invalid` |
| 根因 | **热更 DLC 资源校验失败**（改签名 APK + 清数据重下后，CDN/本地版本标记不一致） |
| 与 Mod hook 无关 | `classes.dex` / `resources.arsc` 字节未改 |

**恢复步骤（不要整包清数据）：**

1. 完全退出游戏
2. 删除仅资源目录：`/storage/emulated/0/Android/data/com.yhhy.whrhx.aligames/files/SYResRoot`
3. 重新开游戏，等 DLC 重新下载完成（保持 Wi‑Fi，勿中途清数据）
4. 若仍紫：需用**九游原包**做外科底包重装（勿用已 mod 过的 APK 当 ORIG）

### 清数据后 Mod 全失效

| 项 | 实锤 |
|----|------|
| log | 全开功能后 `prologue mismatch CostSingleRes got=0xF9401274 want=0xD10283FF` 循环 |
| 根因 | 运行时 `libil2cpp` 解密映射与静态 RVA/file-offset **不一致**；且本游戏 **strip 全部 il2cpp 导出**，`Il2CppApi` 无法 dlsym |
