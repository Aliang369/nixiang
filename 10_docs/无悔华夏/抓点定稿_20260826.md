**能复用的修改内容** = **菜单语义 + prefs/get_ret 对照**；星光需走 **原包 + 自注入 Trace** 验证候选，不能照搬本机失败的壳 stub。

## 三、壳自述（sdk_rx 字符串 · 实锤）

| 字符串 | 含义 |
|--------|------|
| `没有找到数据` | 绑定表/特征数据缺失（logcat 刷屏同源） |
| `没有找到可用的特征索引，请重新检查特征` | 签名/特征匹配失败 |
| `已安装%d个特征HOOK，等待真实IL2CPP调用命中` | 正常路径会装特征 hook |
| `安装特征索引:%d 地址:%lx` | 成功时有 RVA |
| `get_deltaTime` / `时间%p 设置速度%p` | **速度**意图钩 Time 相关 |
| `HOOK的地址：%lx` / `已绑定函数：%s -> %p` | 成功绑定时日志格式 |

本机失败 → 无「怪改血=0x…」类自检 RVA 可抄。

## 四、挂点 RVA（斌哥 vs 九游原包）

语义对齐 prefs。**原包列**来自运行时 `Il2CppCodeGenModule(Assembly-CSharp)` + metadata token（2026-08-26 真机 pid=11308）。**斌哥列仅供对照，禁止装机。**

| 功能 | 方法 | 斌哥 RVA | **九游原包 RVA** | 备注 |

| 无限金币/食物 | `CountryData$$CostSingleRes` | `0x31DF5F4` | **`0x4845388`** | token `0x060049C3` |
| 旁路 | `CountryData$$CostRes` | `0x31EE740` | **`0x4845200`** | token `0x060049C2` |
| 旁路 | `CountryData$$CheckRes` | `0x31EE92C` | **`0x48459C4`** | token `0x060049C5` |
| 无限军队 | `CountryData$$CanAddArmy` | `0x32004A4` | **`0x49F791C`** | token `0x06004A38` |
| 无限人口 | `CountryPopulationData$$SetTotalNum` | `0x3A971AC` | **`0x4D45234`** | token `0x06004AE4` |
| 瞬间胜利 | `BattleUtil$$OnBattleEnd` | `0x3BEF018` | **`0x43E06AC`** | token `0x06000A98` |
