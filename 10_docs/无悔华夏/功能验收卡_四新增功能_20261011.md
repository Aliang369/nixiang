## 5. 已知限制

- 现象：设备上 `/data/app/~~…/lib/arm64/libstarry_magic.so` **不可写**（incremental-fs，`setenforce 0` 无效），只有 lebian 副本可 `cp` 替换 ⇒ 调试期一律热换 lebian 副本；**换 apk 内的 so 必须重打包装机**。
- 现象：RVA 表现已**自动重标**到本机 `79adda77…`（`whrhx_rebaseline.sh` 生成 `WhrhxRvaGen.h`：42 站点、40 唯一解析、34 个枚举值重写、`kExpectGen` 33 条接受 + `kExpectStale` 8 条拒用），装钩**先按名**、RVA 只作加速；拒用名单命中时打 `rva stale … 已漂移 — 只走按名`。**判据只认日志里的 `@rva` / `@il2cpp-name`**。漂移源仍在：只要乐变换版的 `libil2cpp.so`，就重跑 `whrhx_rebaseline.sh --apply` + `whrhx_check_kexpect.py`（期望 `KEXPECT_RESULT=PASS bad=0`）。
- 现象：`selftest ok …` 只在**局内**出现；标题界面 `CountryDataMgr.m_countryDataDic` 为空（`count=0`），此时只有 `selftest reach`（证明身份链 + 0x10 偏移正确）。
- 出包/构建门禁的字符串断言必须只要求「代码真的会发出的字面量」：类名与方法名在 il2cpp 里是两条独立字面量（`"PolicyDataMgr"` / `"GetPolicyItemShowState"`），拼接串只在已删除的手写 tag 里存在过 —— 本轮 `whrhx_build_so.sh` 与 `whrhx_menu_latest_repack.sh` 都栽在这条上，现已各自拆成两条断言。
- 适用范围：仅九游 3.8.280（vc 280）；乐变负载若被换版，须重新 `whrhx_watch_hotupdate.sh` 校验 sha。
- 若继续修复，下一条最小区分实验：进局后跑 `whrhx_verify.sh --feat 10,11,12,13` 期望 `SUMMARY pass=7 fail=0`（4 项功能 + 身份 + 自检 + 装钩方式）。
