## 二、玩家身份权威来源（本轮核心发现）

**`CountryData$$IsPlayerCountry()` @ `0x31D98DC`**（无参实例方法；dump.cs `1108735`）
反汇编（LEB so）：

```
w19 = this->[0xE0]                    ; CountryData 国家 id 字段 = +0xE0（旧 0x38 错，作废）
x0  = [静态槽 0xb6412a0]              ; 某管理器单例
x0  = getter@0x6558b64(x0)            ; 链式取值
w8  = x0->[0x30]                      ; 玩家国家 id
ret  (w19 == w8)
```

- 判定本质 = **比较字段**，无副作用；v16/v17 崩溃根因是当时 RVA 漂移（0x3F0C3AC 是 211MB 官方 so 的 RVA，打在乐变 so 上=钩错函数）+ 经济钩用任意 `this` 调它。
- **身份设计（Round2）**：钩 `IsPlayerCountry`，`==true` 时缓存 `this->0xE0` → 玩家 id 随游戏自身判定自举、换国家自动更新，替代「首个国家」启发式。Trace 轮验证不崩后转正。
- 备选身份源（未定稿）：`BattleGeneralChallengeData.PlayerCountryId @0x38`（仅挑战模式）、`BattleAIMgr.m_playerCountryId @0x1C`（战斗侧）、`CountryDataMgr.PlayerExclusiveData @0x38`（Effect 字典，无 id）。
- 静态解槽位（0xb4f8900/0xb6412a0 → ScriptMetadata）未命中，getter 链太深 → 停（防钻牛角尖），Trace 直接实测。

## 六、Round2 晚间补充（真机实测发现，2026-08-29 深夜）

1. **双库与乐变内存补丁**：游戏每次启动加载哪个 libil2cpp 不确定（乐变应用了=190MB `b19435a5`；未应用=APK 官方 211MB）。且**乐变会对已加载的官方库做内存补丁**（同一 RVA 在两次官方态进程内容不同）——这是用户「时灵时不灵」的完整根因链。
2. **对策（全部落地 WhrhxMod）**：
   - 所有钩子三路径「官方 RVA → 乐变 RVA → 按名」+ **kExpect 序言逐点校验**（官方 pristine 序言已活体读出：StartBattle `D10143FF`/Update `D10143FF`/SetEnd `D10243FF`/delta `F81E0FF3`/EffectGetValue `F81E0FF3`/IsPlayerCountry `A9BE4FF4`）
   - 直写（pin）改 **process_vm 自进程读写**（`__NR_process_vm_readv/writev`）：坏地址返回失败，物理上不可能因直写闪退（粮食闪退根因=裸写坏指针，崩溃形态 memset SEGV_ACCERR）
   - pin 前校验 EffectData `m_type@0x10`(钱101/102 粮151/153) + `m_countryId@0x20`==玩家id；失败回退 Effect 钩按类型缓存指针
   - `IsPlayerCountry` 官方 `0x3F0C3AC` 活体复核通过（体结构=LEB 版：0xE0 国家id vs 单例链→+0x30）
3. **直写实测**：官方库上「无限金币」直写生效（9999999，用户确认）。
4. **so 切换开关**：`04_scripts/无悔华夏/whhx_so_switch.sh official|lebian|status`（chmod 000/755 lebian 目录）——本地适配用，发布不带。
5. **设计定稿**：身份=钩 `IsPlayerCountry`，true 时缓存玩家 CountryData 指针（5s TTL 防悬空）；金币/粮/军/人口=Tick 直写真实数值；Cost*/Effect 钩保留做兼容层。
