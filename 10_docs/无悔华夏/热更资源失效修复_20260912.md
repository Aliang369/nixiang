## 实现改动

文件：`mod菜单/starry-mod-menu/app/src/main/jni/Games/WhrhxMod.cpp`

- 玩家身份优先从 `CountryDataMgr.GetCountryDataById` 的 `this` 捕获，不再只依赖旧 `IsPlayerCountry` 字节链。
- 通过 IL2CPP API 运行时读取 `CountryDataMgr.<m_countryId>k__BackingField` 与 `CountryData.<m_id>k__BackingField` 的实际字段偏移；旧 `0x30 / 0xE0` 保留兜底。
- 玩家国家 ID 变化时清除旧国家与 EffectData 缓存，避免换国家后沿用旧对象。
- 增加 `CityDataMgr.GetCityData` 捕获钩；军队与人口优先使用实时捕获的城市管理器，旧静态槽链仅兜底。
- 资源与捕获钩改为可重试；人口开关也会安装经济钩，不再只由金币/食物/军队触发。
