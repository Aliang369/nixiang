## 静态 il2cpp 候选（⚠️ 推断 · 待 Trace / memdiff 验证）

游戏核心数据在 **`CountryData`**（策略层），战斗在 **BattleOnline / LBattleUtil** 域。

### 1–4 资源类（金币 / 食物 / 军队 / 人口）

| 菜单 | 候选类 / 字段 / 方法 | dump.cs 线索 |
|------|----------------------|--------------|
| 无限金币 | `CountryData.m_money`（`CountryResData` → `EffectData m_num`） | `@1107671` |
| 无限食物 | `CountryData.m_food` | `@1107672` |
| 无限军队 | `CountryData.m_armyData`（`CountryArmyData.m_totalNum` / `m_corpNum`） | `@1107687` |
| 无限人口 | `CountryData.m_populationData.SetTotalNum` | `@1107685` / `@1109423` |

GM 调试面板枚举（斌哥可能 hook 同类路径）：

```text
GMCampaignValuePanel.gmCampaignChangeType:
  CFood=6, CArmy=1, CArmyMax=2, CArmyHeart=3
  TimeFactor_Money=608, TimeFactor_Food=606, TimeFactor_Population=601
  TimeFactor_CArmyNum=614, TimeFactor_CArmyMax=613
```

HomeKingTour 模式另有：`HomeKingTourBaseData.AddMoney` @ `0x44242BC`、`AddFood` @ `0x4424388`、`AddArmy` @ `0x4424454`（是否用于主线需 Trace）。

### 6 输入速度（全局加速）

| 候选 | 说明 |
|------|------|
| `UnityEngine.Time.set_timeScale` | `get_timeScale` @ `0x433347` · `set_timeScale` @ `0x433350` |
| `GameLoopMgr` | 主循环 `Update`（logcat 崩溃前已在跑） |
| GM `TimeInput` + `NpRoundTimeRate` | GM 面板有时间输入 / 回合速率按钮 @ `995851` / `995877` |
| `eParameterType TimeFactor_*` | 各国资源随时间变化倍率（601–615），可能与「速度」相关 |

**用户猜测「全局加速」合理**：优先 Trace `Time.timeScale` 与 `GameLoopMgr` 时间步进；其次才是 `TimeFactor_*` 效果倍率。
