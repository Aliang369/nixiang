## 4. 业务 DEX

乐变用 `InMemoryDexFile` 加载，磁盘不落盘（`Anonymous-DexFile@*.vdex` 仅 92 B），只能从 `/proc/<pid>/mem` 捞：`04_scripts/无悔华夏/whrhx_mem_dex.c` 编译为**动态链接**（静态版 PT_TLS 对齐 8 < bionic 要求 64 会 Aborted），只读 `pread`，不 ptrace 不注入。

命中 74 份 → 19 份 ver 035 → 按 sha256 去重 **14 份**（5 组同内容双映射），`file_size` 与 adler32 逐份自洽：

`6934884 / 6155884 / 4343864 / 1632804 / 1108844 / 1099536 / 881528 / 833108 / 259568 / 126620 / 112856 / 74408 / 65180 / 9340`

首份含 `TPFApplication` / `GameActivity` / `LBApplication`（主 dex），末份 9,340 是 `com.google.androidgamesdk`（7 类）。ver 039 一律是 Android 16 boot dex，排除。

## 8. 装机与验收

装机只能卸载重装（硬约束 A#4：覆盖安装会保留乐变 `currVer` 且不重建负载，导致退回加密 so、所有 RVA 失效）。装机后核对：设备 base.apk md5 == 本地产物、`codePath/lib/arm64` 三件 so 与包内 md5 全等、`firstInstallTime` 为新时间。

装机前门禁 `pre_install_gate.sh`（JNI 配套 / 门禁串 / Manifest AXML / so+metadata 与底包一致 / 菜单 dex 新鲜度）六项 PASS 才可装机。
