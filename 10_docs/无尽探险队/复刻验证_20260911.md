## 0.1 免广告（新增功能，2026-09-11 用户实测通过）

- **广告链**：JS `openadsdk.ts` → `bridge.sendToNative("adVideo")` → Java `Play800Bridge.adVideo()` → `WXRewardVideoAd.loadAndShow("通关双倍",cb)` → `onRewarded()` → `JsbBridge.sendToScript("onAdResult","success")` → JS 发奖
- **免广告实现**（官方 dex 零改动，纯运行时 splice）：把 `b.bridge.sendToNative("adVideo")` 替换为星光注入 IIFE——`getRet(3)` 开关 ON → 调 `WjtxdHooks.fakeAd()`（Java 端直接 `sendToScript("onAdResult","success")`）；OFF → 原样 `sendToNative("adVideo")`
- **两个坑（已闭环）**：
  1. **必须无条件 splice**（不能 gate 在开关）：`index.jsc` 只在启动 eval 一次，开关开启后不会再来 eval → gate 在 g_adfree 则广告点永远不被替换（真广告仍拉起，2026-09-11 实测）
  2. **注入点位于逗号表达式内**（`console.log(...), sendToNative("adVideo")`），以 `var` 开头注入 = `a,var b=1` 语法错误 → openadsdk 注册失败 → **游戏卡加载页**（2026-09-11 实测）。必须 IIFE 包裹：`...,(function(){...})()`

## 1. 关键链路（踩坑实录）

### 1.1 引擎脚本执行入口（最大坑）
- 初版只 hook JNI `Java_com_cocos_lib_CocosJavascriptJavaBridge_evalString` → **计数 0**（游戏脚本不走 JNI 桥）
- 斌哥注入点 = C++ `se::ScriptEngine::evalString`（Creator 3.8.75，符号被 strip）
- 定位法：rodata 字符串 `ScriptEngine::evalString catch exception:`(0x1bc3ce) → 反汇编找 xref → 函数体 RVA **0xC086D8**（序言 `d10503ff`）
- 修复：`WjtxdFileOffToVa` 按 file_off 扫 RX 段定位 + 序言校验 + DobbyHook（双路径框架同构）
- 注：`DobbySymbolResolver` 在 28MB 多段映射库上会踩特殊段 **SIGBUS**（tombstone#17 实锤）→ 一律改用 `dlsym(RTLD_DEFAULT)` / 自扫 maps

### 1.2 TapTap 网页登录强制（新版 SDK）
- 本包 TapSDK 新版：`com.taptap.sdk.login.impl.ui.activity.TapTapLoginActivity`（Kotlin，`fragmentProvider`/`DefaultTapLoginFragmentProvider` 路由，≠ 终末地旧版 `loginHandlers` 数组）
- 方案（TapLoginForceWeb 扩展新版分支）：
  - ① onActivityPreCreated：反射改 intent extra `LoginRequest.loginType` → `"embedded_web"`（首建直接 WebLoginFragment）
  - ② onActivityCreated 兜底：fragment 非 WebLoginFragment 时反射调 `fallbackToWeb(request)`
  - 白名单加入 `com.wjtxdtt.zy`
- 实锤日志：`"tapsdk_login_type":"embedded_web"` + `authorizationCodeSuccess` + `action:success`

### 1.3 StarryInitProvider 未注册（无声失效）
- 初版外科 Manifest 只加了 MenuService，**漏注册 StarryInitProvider** → SignSpoof/Tap 强制网页全未执行，手机号登录报「访问出错,请联系运营配置联调开关」
- 修复：外科脚本 Manifest 追加 `com.starry.magic.StarryInitProvider`（authorities=`com.wjtxdtt.zy.starryinit`）

### 1.4 SignSpoof 缺本包证书
- 初版 SignSpoof 证书表无 `com.wjtxdtt.zy` → 补官方证书（ZUIJIAZH，CN=Unknown，2026-09-10 官包导出）
