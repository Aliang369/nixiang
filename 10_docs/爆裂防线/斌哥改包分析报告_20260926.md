### 2.1 不是 so inline hook
- `diff_il2cpp_mem.py --apk … 06_dumped/爆裂防线/mem_20260926`：
  `overlay_total_bytes=40656896 / patch_regions=1`，唯一差异 `file_off=0x213e900 va=0x2142900 len=4`（`file=fe0f1df8 mem=00000016`），与功能无关。

## 六、已排除的机制（避免移植时走错路）

| 假设 | 排除证据 |
|---|---|
| so 静态改写 | `libil2cpp.so` DT_NEEDED 不含 `libSDKloading` |
| Dobby inline hook | il2cpp 全代码段跳桩命中 **0** |
| vtable / 函数指针重定向 | data 段仅重定位噪声；无任何指向壳地址区的 8 字节指针 |
| AOT 元数据改名 | metadata 内 0 命中上述名字 |
| 壳新增 dex 类 | 壳内建 Dobby（`sdk_rx_2.bin` 含 `DobbyHook`/`DobbyCodePatch`/`dobby_enable_near_branch_trampoline`）+ 980K 匿名 r-xp 池含完整 `il2cpp_*` API 名表 |

**工作假设（待移植时定案）**：壳用反射按名找到 `zbMonster.ChangeHp` / `zbCombatSpeed.SetSpeed` 的 `MethodInfo`，再改 `methodPointer`（指向壳 exec 池内的原生替代函数）或改热更程序集内存中的 IL —— 两者都不在 il2cpp 磁盘/内存 diff 留痕。**定案手段：`原版 DLL vs 斌哥 DLL` 差分，或 `运行时匿名内存中的热更镜像 vs DLL` 差分。**
