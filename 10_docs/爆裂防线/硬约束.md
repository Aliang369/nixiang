## D 技术事实与已验证经验

| # | 内容 | 适用条件 | 证据 |
|---|---|---|---|
| D1 | 本作「包名、签名错误」判定在 TapSDK **native 层**（`libtapsdkcore.so`，日志 TAG `TapInitializer`），Java/dex 补丁对它无效；只能在 `PackageInfo.CREATOR` 层替换签名 | 1.02.01 TapSDK 4.x 新版路径 | logcat：改 dex 后仍 `E TapInitializer: TapSDK: 包名、签名错误`；补 killer 后归零 |
| D2 | killer 模板（取自冒险与征途 `classes4.dex`）的 `.super` 指向原包桥接类 `com/mxyzt/gzmy/wuJvNQvtpQZhnd`，跨包复用必须改成 `Landroid/app/Application;`（含 `<init>` 调用），否则 `ClassNotFoundException` 静默跳过 | 复用任何游戏抽取的 killer dex | logcat 首版 `SignatureKiller absent`；改后 `mounted` |
| D3 | 本作 HybridCLR 热更程序集内部分发不走 `MethodInfo->methodPointer` ⇒ Dobby hook 永久无效（装桩 rc=0、hits 恒 0），功能只能走字段写入 | 全部版本 | `移植记录_星空版_1.01.06_20260926.md` 机制要点 |
| D4 | `zbSafeLong` 双副本协议（`_obfValue@0 _key@8 _shadowObf@16 _shadowKey@24`）必须同写，只写一份触发 `ReportCheat` 主动上报 | 写 curHp/maxHp 时 | 同上 |
| D5 | Windows 侧 `pm install <文件>` 会 `INSTALL_FAILED_MEDIA_UNAVAILABLE: Failed to restorecon`；改 `adb install -r` 流式可行 | 本机 adb/Android 14 | 本轮 install 日志 |
| D6 | Git Bash 会把 adb 远端路径 `/data/...` 改写为 `C:/Program Files/Git/data/...`；adb 调用需 `MSYS_NO_PATHCONV=1` | 所有 MSYS 环境 adb 调用 | 本轮 `remote secure_mkdirs failed` 报错 |
