## 3. Replacement（`0x2CC560`）语义

伪代码（按反汇编还原，寄存器对应 ABI：`x3` = 受作用单位、`x4` = 数值容器）：

```c
void changeLife_hook(IKHOBFONGIE* self, void* a1, void* a2,
                     HJGEAPMLNAF* unit,        // x3
                     LJMJLLJNEMK* value,       // x4
                     void* a5, void* a6, ...) {
  if (flag_ready /*0x169C518*/ != 1) goto orig;
  if (flag_dmg /*0x169C4C0*/ == 0 && flag_inv /*0x169C4C4*/ == 0) goto orig;
  if (!self || !unit || !value) goto orig;

  float (*get)(void*, void*) = PTR_GET;  // [0x169C500]
  void (*set)(void*, void*, float) = PTR_SET; // [0x169C508]
  if (!get || !set) goto orig;

  player = *(HJGEAPMLNAF**)((char*)self + FIELD_PLAYER); // [0x169A00C] = 0x68
  enemy  = *(HJGEAPMLNAF**)((char*)self + FIELD_ENEMY);  // [0x169A010] = 0x70

  bool hit_player = (flag_inv && unit == player);
  bool hit_enemy  = (flag_dmg && unit == enemy);
  if (hit_player || hit_enemy) {
      float v = get(value, nullptr);          // 走 XOR 解密读值
      if (v > 0.0f) {
          if (hit_player) set(value, nullptr, 0.0f);          // 玩家无敌：伤害清零
          else            set(value, nullptr, v * MULTIPLIER); // 十倍伤害：×[0x169A014]
      }
  } else {
      // 第三方单位：仅按计数器打日志（[0x169A034]），不修改数值
  }
orig:
  return trampoline(self, a1, a2, unit, value, a5, a6, ...);  // tail-call 原函数
}
```

要点：

1. 两个功能共用同一个 hook（不是两处 patch）。il2cpp 侧磁盘↔内存差分全量比对**只有这一处 12 字节 patch**。
2. 判定的是「受作用单位」的引用是否等于 self 上的玩家/敌人字段；第三方单位只打日志（壳文案有「打到玩家 / 打到敌人 / 第三方单位 / 原伤害」）。
3. 只处理 `v > 0`（正伤害）；≤0（治疗/零）直接放行。
4. 修改通过容器自身的取值/设值方法，保证 XOR 加密一致。

## 5. 取值/设值容器（反作弊细节）

`LJMJLLJNEMK : BLEKKHPIOKN<float>`（TypeDefIndex 3553），值是 **XOR 加密** 存储：

- getter：`LJMJLLJNEMK.JDMGBLEBMAJ()`，RVA `0x5F3EAE8`（文件偏移 `0x5F3AAE8`，Slot 4）
  - `ldr w19,[x19,#0x10]` → `eor w0, w19, key` → 转回 float 返回
- setter：`LJMJLLJNEMK.JBEFILOFEKD(float)`，RVA `0x5F3EB5C`（文件偏移 `0x5F3AB5C`，Slot 5）
  - float 转 int 位 → `eor w20, key` → `str w8,[x19,#0x10]`

结论：**移植时不能直接写 `[value+0x10]`**，必须调用 getter/setter（或自行复刻同样的 XOR key 逻辑；key 为静态字段 `BLEKKHPIOKN<T>.GLPHIMJAADJ` 运行时生成，静态不可预知，故推荐调方法）。

## 7. 给「星空版」移植的要点（下一步等原版 APK）

1. 目标：同版本官方 `1.45.3`。先核对官方包 `libil2cpp.so` / `global-metadata.dat` 哈希是否与斌哥包一致；一致则可直接复用 RVA `0x5F55968`，不一致则用 `dump.cs` 的类名/方法名（`IKHOBFONGIE::OGFLOMPOMCI`）重新定位。
2. 移植实现建议：复刻 replacement 语义 —— `DobbyHook(原函数, replacement, &trampoline)`，replacement 内读单位、判玩家/敌人、调 `JDMGBLEBMAJ/JBEFILOFEKD` 读写值，最后 tail-call `trampoline`。
3. 若官方包混淆名变化，壳自带的定位路径（其日志原文）：
   `SF3.Fight.MachineLearning.Core.PlayerState.Hp` → 反查读血函数 → 找到「只有 5 个方法的血量读写小类」→ 反查改血调用者。
4. 玩家/敌人字段偏移（`0x68`/`0x70`）与取值/设值方法在官方同版本下大概率一致；移植时应运行期校验（偏移有效性 + getter/setter 非空），不一致则拒绝启用（壳同样策略：「绝不猜地址」）。
5. 功能开关/倍率只是壳内存状态，星空版用自己的菜单状态通道即可，不依赖壳布局。
