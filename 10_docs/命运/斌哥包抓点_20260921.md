## 四、壳的 IL2CPP 解析机制（已确认）

- 壳 `libSDKloading.so` 使用 Dobby（字符串中可见 `DobbyHook`、`DobbySymbolResolver`、`Dobby-20210616-223aabc`）。
- 壳按 IL2CPP 运行时 API 按名解析方法，字符串表可见：
  - `il2cpp_class_from_name`
  - `il2cpp_class_get_method_from_name`
  - `il2cpp_method_get_param_count`
  - `il2cpp_method_get_return_type`
  - `il2cpp_method_get_name`
  - `il2cpp_method_get_param`
- 运行时 API 表位于 guest 进程匿名段 `0x6f85600000` 起的一段内存中（已导出并核验），其中包含完整 `il2cpp_*` 解析表。
- 因此壳的 hook 不依赖磁盘 so 的固定 RVA；方法由运行时按 `image / class / method` 名称解析后再安装 Dobby hook。
