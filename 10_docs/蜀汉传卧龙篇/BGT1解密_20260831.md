## 2. 文件布局

```
[0x00] "BGT1"                          (4B magic)
[0x04] u32 version = 1                 (LE)
[0x08] u32 原始总大小(含头)
[0x0C] u8  校验字节 = XOR(b[0..11])
[0x0D] u8  K2 混淆字节
[0x0E] key2 密文, K2 字节              (K2 = b[13] ^ XOR(keyA), 实测范围 1..0x21)
[0xE+K2 ] u32 payload 大小             (双钥 XOR 后读出)
[0x12+K2] u32 格式标签 = "enc2"
[0x16+K2] payload (双钥 XOR 加密)
```

## 3. 解密算法（从 sub_9439D0 + sub_943884 逆向）

- **keyA（全局）** = `"gYjhBMzjNtSaVYDV"`，16 字节，明文存于 dump `0x1708970`
  （旁边有错误串 `parseDataToMap wrong`；key 由 `sub_9441D4` ctx_init 装入 std::string @ctx+0x18）
- **key2（每文件）**：`key2[i] = file[0x0E+i] ^ K2 ^ keyA[i mod 16]`，`K2 = file[0x0D] ^ XOR(keyA)`
- **stream_xor(ctx, byte, mutate_flag)**（sub_943884，ctx=[0]=key, [8]=int8 keyLen, [0x18]=wrap 计数, [0x1C]=pos）：
  1. `byte ^= key[pos]; pos++`
  2. `pos == keyLen` → `pos=0`；若 mutate_flag≠0：`c=++wrap计数; key[c % keyLen] = (key[c % keyLen] + 7*c) & 0xFF`（**key 每绕回一圈自Mutation 一位**）
- **payload 解密**：每字节先过 bufA(keyA) 再过 bufB(key2)，两路独立 pos/计数，**mutate_flag=1**
- payload 前 8 字节在解密前先作为两个 u32 被双钥读取（size + "enc2" 标签），随后 close() 还原 key、pos、计数归零
- 校验：`file[0x0C] == XOR(file[0..11])`；`total@8 == K2 + 0x16 + payload_size`（校验字节与实测个别不符，不影响解密，仅验证用）
