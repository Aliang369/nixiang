## 二、Hook 链

```
WebView menu (1160.html / initGame(exp))
  → prefs boolean "0".."3"
  → get_ret(n) 读 SharedPreferences
  → libil2cpp @ 0xBAAB0C 单跳板（HybridCLR 解释器公共路径）
  → 过滤热更方法名 → 改 DamageHandle / Invincible / SkillCD
```

- **全关 vs 任一功能 ON**：il2cpp / shell / sdk dump **字节级 identical**（patch 数量不变）
- 与造梦西游/霓虹 **BSS 差分** 不同；本游戏 **纯 prefs 门控**

## 三、热更实现候选（ilspycmd `hotfix.decompiled.cs`）

| 功能 | 优先挂点 | 推断行为 |
|------|----------|----------|
| 秒杀 | `BattleServer.HpHandle` / `CreateDamage` | 玩家打怪时放大 `DamageHandle.finalDamage` 或一击致死 |
| 全屏秒杀 | 同上 + 范围/team 判定 | 对 `BattleTeamFlag` 非玩家单位批量高伤 |
| 无敌 | `HpHandle` 入口或 `BuffKind.Invincible` | 玩家受击 `finalDamage→0` 或给玩家挂 Invincible |
| 无限技能 | `ReSetSkillCD` / `UnResetSkillCD` / `ReCalSkillCD` | CD 置 0 或跳过冷却检查 |

核心结构：

- `DamageHandle.finalDamage` @ `BattleServer.HpHandle(DamageHandle)` ~L129932
- `GameCalculator.DamageCalculator` ~L129772
- 无敌 buff 示例：`RecordKind(BuffKind.Invincible, 9999)` ~L117596
- 技能 CD：`ReSetSkillCD()` / `UnResetSkillCD()` ~L263834

> 斌哥壳内 **过滤的具体方法名字符串** 在 anon stub（~4KB r-xp）内，默认 memdump 未包含；星光落地可用 **同名运行时解析 + 跳板过滤** 对齐。
