## 五、斌哥实现方式（推断 + 待验证）

按 `skill/re-extract/binge-memdiff.md` 与同引擎案例（长生/魂坠）：

```
WebView 菜单 Toggle
  → prefs boolean "0".."N"
  → libSDKloading BSS 旗标 (+0x???? 待差分)
  → get_ret(n) JNI
  → libil2cpp 内 Dobby stub（mem 与磁盘 libil2cpp 差异）
  → HybridCLR 公共跳板：method_get_name 过滤
  → 改 DamageHandle / 短路 PaymentService 等
```

**基线 memdump（全关，关卡内，2026-08-19 17:30）**

- 目录：`06_dumped/弹力果冻/mem_base_all_off/`
- il2cpp mem vs APK：**仅 1 处** prologue `B` stub → `file_off=0xBAAB0C`（典型 HybridCLR **单跳板**；四功能 likely 共用 + BSS 旗标门控）
- prefs：尚无 boolean `"0"`…（可能走 shell 内存旗标，待 ON 差分）

**仍缺**

1. 单项 ON memdump ×4（秒杀 / 无敌 / 全屏秒杀 / 无限技能）
3. `diff_il2cpp_mem.py` → prologue `B` stub RVA 列表
4. 官方 `com.ginicat.sweet` 2.4.0 APK → 原版 cert + 外科底包
