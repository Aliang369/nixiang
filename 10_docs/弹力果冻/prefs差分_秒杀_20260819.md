# 弹力果冻 — prefs / memdiff（秒杀 ON）

> 2026-08-19 · 基线全关 vs **仅秒杀 ON**（关卡内）

## prefs（实锤）

| prefs 键 | 全关 | 秒杀 ON | 功能 |
|----------|------|---------|------|
| `"0"` | 无 | **`true`** | 秒杀 |
| `"1"` | 无 | 无 | 无敌 |
| `"2"` | 无 | 无 | 全屏秒杀 |
| `"3"` | 无 | 无 | 无限技能 |

约定：`get_ret(n)` ↔ prefs `"n-1"`（1-based JNI）

## il2cpp memdiff

| 状态 | patch 数 | RVA |
|------|----------|-----|
| 全关 | 1 | `file_off=0xBAAB0C` → `B` stub |
| 秒杀 ON | 1 | **同址、同 stub** |

→ 四功能 **共用一条 HybridCLR 跳板**；开关 **不增删** patch。

## BSS / sdk_rw

基线 vs 秒杀 ON：**全部 bin 字节级 IDENTICAL**（含 `shell_rw_bss` / `shell_rx_bss` / `sdk_rw`）。

→ 本游戏功能门控 **走 Java prefs**（或 hook 内实时 JNI 读 prefs），**不是** neon/造梦式 BSS int32 旗标差分。

## 跳板 stub 位置

- Hook 点：`libil2cpp.so` **`0xBAAB0C`**
- `B` 目标 runtime ≈ **`0x72ADFE0004`**（4KB `[anon] r-xp`，默认 dump 脚本**未包含**，后续需补 dump）

## 热更 Hook 候选（静态，待跳板内方法名过滤实锤）

| 功能 | 热更符号候选 |
|------|----------------|
| 秒杀 / 全屏秒杀 | `BattleServer.HpHandle` / `CreateDamage` / `GameCalculator.DamageCalculator` → 改 `DamageHandle.finalDamage` |
