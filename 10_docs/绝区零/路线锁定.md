### 其它 3.3.0 否证记录（防重犯）

- 「旧 RVA + 区段位移」「16B/64B 字节指纹」「归一化序列相似度整函数」「方法序号(methodPointers)对齐」四条对四个站点全部失效（0/146、0/53、1/101 等命中率远低于 16% 基线）。
- `0x120ffcfc`（曾以 161 条同形块入选）实测 **0 个调用者**、frida watch 0 次 ⇒ 是共享样板代码，不是目标函数。
- `0x1aae4d08`（早期定怪候选）是 `bl`×4 递减分支链，非函数入口。
- .eh_frame 起点对这几族函数多为**内部块**（无敌偏差 +0x74、Tick 首指令非序言），装钩必须用「methodPointer/调用图入口 + uniq32 指纹」双条件。
- IG5 本机 build 无 bindiff 能力（capabilities 无 bindiff、工具代理未注入），且 490MB so 只做得到 3.8% 部分分析（61,427/1,632,716 函数）⇒ 不能作为跨版本匹配手段。
