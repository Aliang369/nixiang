## 7. P6 落地细节（第七处）

- 原声明：`.method public static native getSignInfo(Ljava/lang/Object;)[Ljava/lang/String;` + 紧接 `.end method`（**无 .locals、无方法体**）。
- 新实现：同签名同返回类型，仅去掉 `native`，`.locals 3`，`new-array` 4 槽后依次 `aput-object`。
- **前置核查（全部实测）**：
  - 引用点全包仅 3 处（`net/a:6056` / `net/a:6107` / `QGSdkUtils:1190`），jadx 侧 0 处，无反射；
  - `libqkcheck.so` **无** `JNI_OnLoad` / `RegisterNatives` 串（纯静态 `Java_com_game_apkverify_Check_*` 命名）⇒ 去 `native` 不留注册悬空；
  - `getAPKCharacteristic` 保持 native（仍需要 so 存在，`QuickSdkApplication` 的 exists 判断不变）。
- **为什么必须改这里**：`net/a:6107` 直接取 `[3]=sign_sha1`，不经 `QGSdkUtils.getApkSign` ⇒ P5a 覆盖不到；P6 一次覆盖 subject/issuer/md5/sha1 四字段。

## 8. 证书四字段取值命令（可复现，换版本重跑即可）

```bash
cd "$NIXIANG"
T=$(mktemp -d)
unzip -o -q 02_apks/鹦鹉团_1.0.7_orig.apk 'META-INF/*.RSA' -d "$T"
openssl pkcs7 -inform DER -in "$T/META-INF/AIAUTION.RSA" -print_certs -out "$T/cert.pem"
openssl x509 -in "$T/cert.pem" -outform DER -out "$T/cert.der"
wc -c < "$T/cert.der"                                                  # 720
openssl x509 -in "$T/cert.pem" -noout -subject -nameopt RFC2253        # subject=C=CN,L=SH,CN=Meta48
openssl x509 -in "$T/cert.pem" -noout -issuer  -nameopt RFC2253        # issuer=C=CN,L=SH,CN=Meta48
md5 -q "$T/cert.der" | tr a-f A-F                                      # 27C2D8CA4E5703D9AD2A1EE39D2A859D
shasum -a 1 "$T/cert.der" | cut -d" " -f1 | tr a-f A-F                 # 35A8E7B1B9FFE25F3413BE2955C9A06B022992C9
/Users/aliang/Library/Android/sdk/build-tools/36.0.0/apksigner verify --print-certs 02_apks/鹦鹉团_1.0.7_orig.apk
```

## 9. 踩过的坑（供后续脚本参考）

- `say "$d（…）"` 变量紧跟全角括号会被并入变量名（`d�: unbound variable`）⇒ 一律 `${d}`；已全量排查 2 处。
- `bash script | head` 会吃掉脚本退出码 ⇒ 校验 rc 时重定向到文件再 `echo rc=$?`。
- `python3 - a b c` 的切片要按实际参数个数（15 个就 `sys.argv[1:16]`）。
- `assert_anchor "…->loadGatekeeperSuccess:Z"` 会命中 3 次（2 iput + 1 iget）⇒ 语义锚点写整条指令。
- smali 非 native 方法**必须有 `.locals`**：P6 首版漏了，`smali assemble` 直接报错；已在 body 首行补 `.locals 3`。
- P6 的幂等比较要用「声明到 `.end method` 之间」整段比，不能复用 `body_span`（它要求 `.locals` 且会跳过注解，导致误判「已是 Java 但体不符」）。
