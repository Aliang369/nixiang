# 鹦鹉团 星光版 native 重编（1.0.7，2026-11-25）

> 目的：星光版必须用**当次新编译**的原生产物，禁止复用 11-21 的 `libs_ywt/arm64-v8a/libstarry_magic.so`（旧产物缺 11-22 框架侧修复）。
> 范围：只重编 native（`Android_ywt.mk`）。菜单 dex 另有人负责；不打包、不签名、不装机。

## 2 ABI 判定

```
$ python3 04_scripts/_common/detect_abis.py 02_apks/鹦鹉团/鹦鹉团_1.0.7_taptap原版.apk

底包带 `lib/x86_64` ⇒ 按 `Android_ywt.mk` 头注释「★ABI」条，一次构建同时产出两套 so（雷电原生 x86_64 直跑必备；缺 x86_64 会 `dlopen libstarry_magic.so` 恒失败）。本次产出 arm64-v8a + x86_64 两套，交付/组包用 arm64-v8a。

```

```bash

cp -f app/src/libs_ywt/arm64-v8a/libc++_shared.so    libs_ywt/arm64-v8a/libc++_shared.so
cp -f app/src/libs_ywt/x86_64/libstarry_magic.so     libs_ywt/x86_64/libstarry_magic.so
cp -f app/src/libs_ywt/x86_64/libc++_shared.so       libs_ywt/x86_64/libc++_shared.so
```

构建日志每条前有 `fcntl(): Bad file descriptor`（macOS 下 ndk-build 的已知无害告警，exit 0，产物完整），不影响结果。
