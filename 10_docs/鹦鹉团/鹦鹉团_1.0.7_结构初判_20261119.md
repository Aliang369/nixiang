1. **dump 方案**：libil2cpp.so（arm64，141 MB，stripped 但导出 il2cpp_init）+ global-metadata.dat（v31）→ Il2CppDumper（需支持 metadata v31；v31 落在 Unity 2022.3 区间，用 v6.7.x 以上或 Il2CppDumper-net8）→ 产出 dump.cs + script.json + il2cpp.h，落 06_dumped/鹦鹉团/（当前为空）。
2. **命名可读性**：global-metadata.dat 内字符串实测命中 Dance×838、Perfect×213、Judge×2 ⇒ 疑未全量混淆，**先按语义名 grep 定位类型，再用 RVA / 交叉引用校验**，不许只凭名字下结论。
3. **xLua 支线**：metadata 命中 XLua×561 ⇒ 部分逻辑（很可能含热更/玩法参数）在 Lua。APK 内 0 个 .lua ⇒ 需从 assets/Android/*.unity3d（明文 UnityFS）抽 TextAsset：UnityPy / AssetStudio 扫 assets/Android/ + AssetMap.json + FileList.json，找 .lua / .luac / *.lua.txt。
   【待验证】Lua 是否参与判定 —— 抽到之前既不能说「判定在 Lua」也不能说「只在 C#」。
4. **顺序铁律**：先 dump 出类型/字段 → 再定挂点。无 dump 不给 RVA。
