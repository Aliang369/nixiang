## 1. 现行口径判定树（先判定，再选路线）

```
包内 grep 到 Lcom/taptap/sdk/ 且 smali 可读？
├─ 是 → 改包法（A 轨）：静态改游戏 dex
│        ① 初始化门闩恒放行  ② 验签弹窗掐掉
│        ③ 登录入口恒 Web     ④ 签名回灌（必需）
└─ 否（加密 payload / 壳内动态装载，搜不到也改不了）
         → 运行时 SPI（B 轨）：games/<game_id>/GameHookImpl 调 core.TapTapWebLogin
```

- 两条路线**不叠加**。判定依据只有「可达性」一条，不看引擎、不看渠道名。
- 签名侧不因走 SPI 路线而豁免：SPI 只解决「不拉起 TapTap 客户端」，服务端仍按
  `GateKeeperRequest(platform, packageName, signature)` 比对证书指纹 ⇒ 改签包必须回灌。
- 反例（不要踩）：`isTapTapInstalled` 改了无效（那是渠道安装判断，不是 SSO 判定）。

**SPI 约定（写实现类时照抄 yntt/wxsj 两例）**：

```java
public final class GameHookImpl implements GameHook {
    private static final String PKG = "com.jinsaina.auditionsgo.gw";
    @Override public void onActivityPreCreated(Activity a) { if (isTarget(a)) TapTapWebLogin.onPreCreated(a); }
    @Override public void onActivityCreated(Activity a)     { if (isTarget(a)) TapTapWebLogin.onCreated(a); }
    @Override public String targetPackage() { return PKG; }
    private static boolean isTarget(Activity a) { return a != null && PKG.equals(a.getPackageName()); }
}
```

四条硬性要求（缺任一条补丁静默失效）：
1. `app/proguard-rules.pro`（第 74 行）与 `app/inject-dex-rules.pro`（第 72 行）**都必须**有 `-keepnames class com.starry.magic.games.**`——本机已核实两处均存在。
2. 不改 `StarryApp` / `StarryInitProvider`（`check_framework_isolation.sh` 会挡）。
3. 不加包名白名单（`TapTapWebLogin` 内白名单已于 2026-11-11 删除，判据唯一＝谁的 GameHookImpl 调了它）。

## 6. 证据分级

**实测事实（本机源码/文档直读）**
- `core/GameHook.java`、`core/GameHooks.java`、`core/TapTapWebLogin.java`、`sign/TapLoginForceWeb.java`、
  `sign/SignatureKillerBootstrap.java` 的类名、方法签名、行号（§2 全部）。
- 两个 `-keepnames com.starry.magic.games.**` 规则存在（`proguard-rules.pro:74`、`inject-dex-rules.pro:72`）。
- `games/` 下 9 个实现；`GameConfig.h` 无 `ywt`。
- 截稿时 `02_apks/`、`03_decompiled/` 内无鹦鹉团产物。

**证据支持的推断**
- 走 SPI 时用 `core.TapTapWebLogin` 而非 `sign.TapLoginForceWeb`：源码注释自述 + 2026-11-18 lead 裁决 + 群侠传实机日志三方一致。
- `TapTapWebLogin` 只认三个登录 Activity 类名 ⇒ 若本包用第四种形态（自研 TapTap 桥/shell 内 Activity 改名），SPI 会静默失效（「覆盖范围别夸大」）。

**待验证假设（缺证据，不得当结论用）**
- 本包 TapSDK 是否可达（未拆包）。
- 是否有 `GatekeeperRepository` / `TapSignKit` / `libtapsdkcore.so`。
- 业务服是否二次校验签名。
- 引擎类型与登录态下发位置。
