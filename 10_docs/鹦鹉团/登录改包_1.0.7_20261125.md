- 锚点：`smali_classes11/com/taptap/sdk/initializer/repository/GatekeeperRepository.smali:431`
  副本 `smali_classes2/com/taptap/sdk/initializer/repository/GatekeeperRepository.smali:431`（两份逐字节相同；ART 按 dex 顺序解析，**classes2 先命中**，必须一起打）

```

### P2 验签失败弹窗掐掉 —— classes11 + classes2

- 锚点：同文件 `:319` `.method private final showErrorToast(Lcom/taptap/sdk/common/network/throwable/TapNetworkException;)V`

### P3 登录入口恒 Web —— classes11

- 锚点：`smali_classes11/com/taptap/sdk/login/impl/ui/fragment/DefaultTapLoginFragmentProvider.smali:94`
  `.method public provide(Lcom/taptap/sdk/login/impl/data/model/LoginRequest;)Landroid/app/Fragment;`，关键指令 `:184` `aget v2, v3, v2`（全文唯一）。

- 回读证据（连续 7 条）：

```

invoke-virtual {v2}, .../LoginTypes;->ordinal()I

- 语义自检：v2 恒 3 ⇒ `if-eq v2,v3(1)` 不跳、`if-eq v2,v3(2)` 不跳、`if-ne v2,v3(3)` 不成立 ⇒ 落 `sget-object ...WebLoginFragment$Companion` 分支，永不进 ClientLoginFragment / CloudGameFragment / NoWhenBranchMatchedException。

### P4 TapTap 签名回灌（小写 MD5）—— classes11 + classes2

- 锚点：`smali_classes11/com/taptap/sdk/kit/internal/utils/TapSignKit.smali:59`
  `.method public final getSign(Landroid/content/Context;)Ljava/lang/String;`（classes2 同文件副本同步）

### P5a QGSDK 每请求必带的 signMd5（大写 MD5）—— classes7
