# 魂坠深境 — 热更后全功能失效修复（2026-08-15）

## 现象

2026-08-15 18:08 游戏 HybridCLR 云更（无换包）：秒杀/无敌/无限卡牌/无限金币/无限魂晶全部失效或异常。
用户实测：秒杀失效；金币显示变 0、魂晶显示 999，商店按钮假死无法购买。

## 根因 1：字段布局全量重排

从热更 bundle（`files/Asset/hotfix`，AssetBundle，内含 19 个 HybridCLR DLL）抽出
`Assembly-CSharp.dll`，逐类核对新布局：

| 字段 | 旧 1.0.5 | 新（热更后） |
|------|---------|-------------|
| DamageCommand.baseDamage | 0x10 | 0x00 |
| DamageCommand.targetBFT | 0x38 | 0x28 |
| BattleFieldTransform.isPlayer | 0x5c | 0x4C |
| BattleFieldTransform.gameState | 0x50 | 0x40 |
| ItemRequirement.costCount | 0x18 | 0x08 |
| Item.cooldown | 0x20 | 0x10（名） |
| GameSkill.cooldown | 0x10 | 0x00（名） |

日志实锤：`GD#5160 pre=6 isP=255 wr=0`（旧 0x38 读不到 targetBFT）。

## 根因 2：货币 ProtectedInt 防篡改结构

热更把 `PlayerGameStateInfo.coinCount/crystalCount` 从普通 int 升级为
`ProtectedInt`（12 字节三字段）：

```csharp
struct ProtectedInt {
    int _salt;     // 随机盐
    int _encoded;  // value ^ _salt
    int _check;    // value ^ _salt ^ 0x5A17C0DE
}
```

`Decode()`：全零→返回 0；否则 `v=_encoded^_salt`，校验 `_check==v^_salt^0x5A17C0DE`，
不符则 `ProtectedValueGuard.ReportTamper()` → `CheatSuspected=true` + 触发 `OnFirstTamper`（反作弊回调，封号风险）。

旧 so 只写首 4 字节（`_salt`）→ 校验必失败 → UI 乱数 + 商店 `HasEnoughCoin` 假死；
crystal 显示 999 是「写坏 salt 后 Decode 恰好返回 999999 被 UI clamp 到 999」的巧合，非正确写入。

## 修复（`Games/HzsjMod.cpp`）

1. **全部字段运行时 `il2cpp_field_get_offset` 按名解析**（旧常量仅兜底）：
   `DamageCommand.baseDamage/targetBFT`、`BattleFieldTransform.isPlayer/gameState`、
   `PlayerGameStateInfo.bft/coinCount/crystalCount`、`ItemRequirement.costCount`、
   `Item.cooldown/owner`、`ItemContainer.owner`、`GameSkill.cooldown`。
   → 字段名不变则热更自适应。
2. **货币写 12 字节自洽三元组** `WriteProtectedInt`（固定盐 + 编码 + 校验），
   不再裸写 4 字节。
3. **字段解析禁止一次性门控**（第二次踩坑）：
   - 现象：`GDdiag off{base=16 bft=56 isP=92}` = 旧默认值 → 字段解析失败后永远锁旧值
   - 根因：libil2cpp 映射早于热更 DLL 注册，首轮 `FindClassExact` 必失败；
     `g_fieldsDone` 一次性门控把失败锁死；货币没事是因为它走「找到为止」循环
   - 修法：按类缓存指针 + 每 tick 重试，全部类解析成功才打 `fields` 日志
4. **性能优化**（用户报开启功能掉帧）：
   - 原因：invoke 跳板拦所有方法调用，功能开启时每次做 `il2cpp_method_get_name`
     字符串解析 + 多次 SafeProbe（每次装/卸信号处理器 = 系统调用）
   - 修法：`MethodInfo*` 指针分类缓存（64 项线性扫，会话内稳定）；
     `BingePatchDamage` 三次 SafeProbe 合并为一次；`ClearSkillCds` 整循环单 SafeProbe；
     全关 + PGSI 已缓存时零开销直通
