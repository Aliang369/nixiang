## 1. 菜单功能（定稿）

| feat | 名称 | 做法（勿改路线） |
|------|------|------------------|
| 1 | 秒杀 | HybridCLR **公共 invoke 跳板**上滤方法名 `GenerateDamage`；`params[0]`=`DamageCommand`；敌方 `baseDamage@0x10 *= 100`（封顶 999999） |
| 2 | 无敌 | 同上；玩家 `baseDamage = 0` |
| 3 | 无限卡牌 | 同跳板对齐斌哥：`Item::IsCooldownCastAble`+玩家→`Item+0x20=0`；`ItemRequirement::GetFinalCostValue`→`+0x18=0`；`GameSkill`→`+0x10=0`（+Tick）。**勿改返回值** |
| 4 | 无限金币 | 跳板白名单方法上 Soft 写 `PlayerGameStateInfo.coinCount@32`，**再调 orig** |
| 5 | 无限魂晶 | 同上写 `crystalCount@36` |

白名单方法名：`HasEnoughCoin` / `HasEnoughCrystal` / `HasEnoughSoulCrystal` / `get_coinCount` / `get_CoinCount` / `get_crystalCount` / `get_CrystalCount`。

## 2. 钉死的偏移与跳板（1.0.5）

| 项 | 值 | 备注 |
|----|-----|------|
| 公共 invoke 文件偏移 | `0x28B90B0` | + ELF load bias `0x4000` → hook RVA `0x28BD0B0` |
| `DamageCommand.baseDamage` | `+0x10` | 只改这里，**不要**写 BFT.health（否则未出牌怪就死） |
| `DamageCommand.targetBFT` | `+0x38` | |
| `BFT.isPlayer` | `+0x5c`（92） | 非 0 = 玩家 |
| `BFT.gameState` | `+0x50`（80） | 声明类型是 **GameStateInfo**，不是 PGSI；**勿**当金币对象 |
| `BFT.health` | `+0x58`（88） | 勿加 HYBRIDCLR field bias 误算 |
| `GameSkill` CD | `+0x10` | 见该类任意方法时写；Tick 再清缓存 |
| `Item` 冷却相关 | `+0x20` | **仅** `IsCooldownCastAble`；玩家链 `+0x88→+0x28→+0x5c` |
| `ItemRequirement` 费用字段 | `+0x18` | **仅** `GetFinalCostValue`（调用前写） |
| `PGSI.coinCount` / `crystalCount` | `+32` / `+36` | Tick 直写；`FieldOffset` 可运行时校正 |

堆指针：`SoftPtr` 用约 `0x10_0000_0000 … 0x80_0000_0000`（旧 `0x70–0x80` 会漏 `0x6f` 堆 → 秒杀永远判不到敌方）。

## 3. 游戏更新后怎么复用（检查清单）

0. **热更适配（2026-08-15 起）**：本游戏 HybridCLR 云更会重排字段布局 + 给货币加 `ProtectedInt`
   防篡改结构。当前 `HzsjMod.cpp` 已全部改为**运行时按名 FieldOffset 解析 + 12 字节自洽写入**，
   字段名不变即自适应。热更失效排查与修复详见同目录 `热更后全功能失效修复_20260815.md`。
1. **切游戏**：`Android.mk` → `STARRY_GAME_HZSJ` + `STARRY_AUTH_GAME_ID=hzsj`（见 `SWITCH_GAME.md`）。
2. **跳板 RVA**：新包 `libil2cpp.so` 用 IDA/字符串或斌哥差分重定位 HybridCLR invoke；更新 `FILE_INVOKE` / `ELF_BIAS`。
3. **热更 / HybridCLR**：玩法方法多半不在 AOT dump；进局后 Frida 按类名确认：
   - `DamageCommand` 字段：`baseDamage` / `targetBFT`
   - `BattleFieldTransform`：`isPlayer`
   - `PlayerGameStateInfo`：`coinCount` / `crystalCount` / `HasEnoughCoin`
4. **MethodPointer**：`IsCastAble` / 多数 getter 常共解释桩 → **禁止**按 C# 签名乱钩。卡牌费用只写字段，**禁止** Dobby 把 `GetFinalCostValue` 返回值改成 0。
5. **仍用跳板按方法名**，不要堆扫 `PlayerGameStateInfo` / `BattleFieldTransform`（扫堆已多次闪退）。
6. **过签**：原版 cert MD5（当前 TapSign）`a3e3c07b81aa322215f6315d7e60b151`；注入点 `BasePrivacyActivity` / `BasePlayerActivity` + SignSpoof。  
7. **TapTap 强制网页登录**：`ClientLoginUtils.isClientLogin` → 恒 `false`（装有 TapTap 客户端时否则走 SSO，改签后必失败）。`inject_hzsj_1.0.5.sh` 已含；2026-08-13 真机补丁包：`08_output/魂坠深境/魂坠深境_1.0.5_starry-forceWebLogin-releaseSigned.apk`。
7. 构建：改菜单/smali → `inject_hzsj_*.sh`；只改 `HzsjMod` → `hzsj_so_only.sh`。

卡牌详备：`斌哥无限卡牌_壳handler钉死_20260814.md`。

期望 log：`auth game_id synced from native: hzsj`、`[Hzsj] ready softptr+card(binge)`、`GD#…`、`CARD#…`、`CURR#…`。

## 4. 禁止项（已实锤会崩或无效）

| 禁止 | 后果 |
|------|------|
| 跳板对货币 `return (void*)1` / Box 顶替且不调 orig | HybridCLR 把 `1` 当指针 → SIGSEGV（`x0=1`） |
| 对 `method_get_name` 结果直接 `strcmp`（野指针） | 崩在 `libstarry_magic` |
| `ScanInstances(PlayerGameStateInfo)` | 开货币即崩 |
| `BFT.gameState` + field bias 当 PGSI | 落到 `health`，乱写必挂 |
| 对 `Item` **所有**方法写 `+0x20` | 对局结束 SIGSEGV |
| 改 `GetFinalCostValue` 返回值（Box / nullptr / ret+0x10） | 开功能或出牌闪退 |
| 秒杀写 `BFT.health=0` | 未出牌怪死 / 预览 GD |
| 类名二次 `IsOurClass` 过滤 Command | 秒杀/无敌写不上 |
| SoftPtr 仅 `0x70–0x80` | 永远 `isP=255` / 无敌方 |
