# 魂坠深境 — 局内 Frida 定位与修法（2026-08-12）

## 根因（对照用户反馈）

| 现象 | 原因 |
|------|------|
| 访问所有设备日志 | 装机脚本 `pm install -g` 把官方 Manifest 里的 `READ_LOGS` 一并授予 |
| 秒杀/无敌/卡牌无效 + 闪退 | 对 HybridCLR **共用解释桩**按 C# 签名 Dobby（`IsCastAble`/`CoolDowned`/`HasEnoughCoin`），ABI 错乱 |
| 货币闪退 | 同上 `HasEnoughCoin` 共桩钩 + 误扫写 |

## 实锤字段（Frida `il2cpp_field_get_offset`）

- `Damage`：`finalDamage@40` `targetBFT@104`；`GenerateDamage` **static argc=3**，methodPointer **独立**
- `BattleFieldTransform`：`health@88` `isPlayer@92` `maxHealth@96` `tempHealth@112` `gameState@80`
- `PlayerGameStateInfo`：`bft@24` `coinCount@32` `crystalCount@36`
- `GameSkill`：`cooldown@16` `owner@24`
- `ItemRequirement.GetFinalCostValue` methodPointer 与 `GetBaseCostValue` 不同，可钩

## 现行实现（`HzsjMod.cpp`）

> 16:36 二次修复见 `出门自查_待你回来验证_20260812.md`（log：`currency wrote=38` 写错池；`GD# final=0` 只改 final 无效）。

1. **秒杀/无敌**：`GenerateDamage`/`GetFinalDamage` 钩里 **直写 `targetBFT.health`** + BFT 扫描 Tick
2. **无限卡牌**：`GetFinalCostValue→0` + Tick 清玩家 `GameSkill.cooldown`
3. **金币/魂晶**：只写 **玩家 bft 关联** 的 PGSI / `BFT.gameState`，**不钩** `HasEnoughCoin`
4. 装机：**去掉 `-g`**（避免授予 `READ_LOGS`）
