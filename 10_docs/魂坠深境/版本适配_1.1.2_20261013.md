- `mod菜单/starry-mod-menu/scripts/surgical_hzsj_1.1.1.sh`：一份脚本管两代 —— `VERSION="${HZSJ_VERSION:-1.1.2}"`；1.1.1 分支保持原样（BASE `魂坠深境_1.1.1_device.apk` / md5 `f191e461…` / DEX_ADD_NAME `classes6.dex` / `LEGACY_MENU_DEX=1`）；1.1.2 分支 `BASE=魂坠深境_1.1.2_device_official.apk` / md5 `4890e805…` / `DEX_ADD_NAME=classes5.dex` / 跳过旧菜单清理。
