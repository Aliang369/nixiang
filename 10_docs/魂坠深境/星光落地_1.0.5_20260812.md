## 机制（定稿）

Unity IL2CPP + **HybridCLR**。玩法走公共 **invoke 跳板**（RVA `0x28BD0B0`），按方法名分流；**禁止堆扫** PGSI/BFT。

| 菜单 | 实现 |
|------|------|
| 秒杀 / 无敌 | `GenerateDamage` → `DamageCommand`：`baseDamage@0x10` + `targetBFT@0x38` → `isPlayer@0x5c` |
| 无限卡牌 | `GameSkill` CD；`ItemRequirement` 仅 Cost 系；可选独立 MP 的 `GetFinalCostValue` |
| 无限金币 / 魂晶 | 白名单方法上写 `coinCount@32` / `crystalCount@36` 后 **必须** `origInvoke` |

## 注入点

- `BasePrivacyActivity` / `BasePlayerActivity`
