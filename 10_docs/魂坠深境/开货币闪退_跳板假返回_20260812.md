# 开货币闪退 — 跳板假返回（2026-08-12 23:03）

## 现象

开无限金币/魂晶后约数秒 SIGSEGV；tombstone 在 `libil2cpp` UnityMain，**不在** `libstarry_magic.so`。

## 证据

| 项 | 值 |
|----|-----|
| log | `23:03:25 [Hzsj] CURR HasEnoughCoin -> true` |
| tombstone | `23:03:29` pid 29877，`signal 11`，`x0=1` |
| 代码 | 跳板命中后 `*outRet = (void*)1` 并 **不调** `origInvoke` |

HybridCLR 解释调用把返回值当对象/句柄继续用；`1` 被当指针 → 崩溃。

## 修法

- **禁止**跳板对货币方法提前 `return` / `BoxInt32` 顶替
- 仅在白名单方法名（`HasEnoughCoin` / `get_coinCount` 等）上对 `params[0]` Soft 写 `coinCount@32` / `crystalCount@36`，再 **照常** `g_origInvoke(...)`
- 仍禁止堆扫 `PlayerGameStateInfo`
