# 魂坠深境 — 稳定优先路线（2026-08-17）

## 目标（用户定标）

不闪退、不掉帧、不因「扫不到/缓存过期」突然失效。

## 现行做法

| 功能 | 路线 |
|------|------|
| 货币 | `SceneInfoSingleton.instance → gameState → playerState`，每 Tick 重取 + ProtectedInt 直写；**不挂跳板** |
| 秒杀/无敌/卡牌 | 功能开启才晚挂 invoke；进游/功能关零开销 |
| 进游 | **禁止**常驻 Dobby 挂公共 invoke（否则 HybridCLR 死循环） |

## 为何不用「跳板拦一切」

HybridCLR 热更下玩法无稳定原生钩点，跳板是不得已的调用瞬间拦截；挂在热路径上会掉帧/闪退。货币有静态入口链，应按 GG 方式直写。

## 验证

- [ ] 只开货币：log 有 `currency path SceneInfoSingleton`，无 `invoke @`；进出副本仍有效
- [ ] 功能全关进游不崩
- [ ] 局内再开秒杀：出现 `late-install dmg/card only`，生效且不掉帧崩溃
