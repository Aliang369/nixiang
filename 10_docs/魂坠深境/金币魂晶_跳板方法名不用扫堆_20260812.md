# 金币/魂晶：不用堆扫（2026-08-12 22:53）

## 结论

**不必扫堆。** 扫 `PlayerGameStateInfo` 会闪退。

## 现行（与秒杀同套路）

跳板 `0x28BD0B0` 按方法名：

| 方法 | 行为 |
|------|------|
| `HasEnoughCoin` | 返回 `true`（可买） |
| `HasEnoughCrystal` / `HasEnoughSoulCrystal` | 同上 |
| `get_coinCount` / `get_crystalCount` | 返回 `999999` |
| 顺带 | 若 `this` 是 PGSI，写 `coinCount`/`crystalCount` 字段 |

已删除：Tick 堆扫、BFT.gameState 误写、对 PGSI 全方法乱写。
