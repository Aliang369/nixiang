## 1. 钩点（与秒杀同跳板）

| 项 | 值 |
|----|-----|
| `libil2cpp` file | `0x28B90B0` |
| 本机 VA（ASLR） | `0x72198d10b0` → `b` 到 Dobby 页 → `adrp+add+br` |
| 壳 handler VA | `0x72dbe38380`（`shell_rx_bss` + `0x44380`） |
| ABI | `x0` 保留；`x1=MethodInfo*`；`x2=params`；`params[0]=this` |

秒杀/无敌仍在同 handler 后半：`Damage+0x10`，旗标 `menu+0x1728` / `+0x172c`。

## 2. 无限卡牌旗标

菜单 rw BSS（本机 `0x72dbef4000`，文件 `menu_rw_152k.bin`）：

| 偏移 | 本局 | 含义 |
|------|------|------|
| `+0x1728` | 0 | 秒杀 |
| `+0x172c` | 0 | 无敌 |
| `+0x1730` | **1** | **无限卡牌**（prefs `"2"`） |

handler：`ldrb [menu_page+0x730]` ≡ **`menu_base+0x1730`**，为 0 则整段卡牌逻辑跳过。

## 4. 卡牌写点（壳汇编死条件）

在 `flag+0x1730≠0` 且 `params[0]≠0` 时：

### 4.1 `Item` + `IsCooldownCastAble`

```
this+0x88 → +0x28 → ldrb +0x5c   // 与伤血相同的 isPlayer
若 isPlayer≠0:
  str wzr, [this, #0x20]          // Item+0x20 = 0
```

**禁止**对 `Item` 任意方法写 `+0x20`（对局结束闪退旧坑）。

### 4.2 `ItemRequirement` + 费用方法 → `+0x18=0`

```
str wzr, [this, #0x18]
```

**Frida 实锤（本局卡牌 ON）**：

```text
ItemRequirement::GetFinalCostValue  DIFF +18:2→0
```

同窗口其它 `ItemRequirement`（如 `CheckTargetAccept`）**未**清 `+0x18`。  
→ 应对齐：**仅 `GetFinalCostValue`（及确有写点的 Cost 方法）**，不要全类乱写。

### 4.3 `GameSkill` → `+0x10=0`

```
str wzr, [this, #0x10]
```

壳内有完整分支；本局 BSS 方法槽为空，Frida 窗口未抓到 `GameSkill` 写差分。  
星光侧可保留：**见 `GameSkill` 时清 `cooldown@0x10`**（与旧定稿一致），但单独不够（见 §5）。

## 5. 对星光的纠正

| 旧做法 | 斌哥实锤 | 结论 |
|--------|----------|------|
| 乱改 `GetFinalCostValue` **返回值** | 壳**不改 retval**，只写字段 | 返回值路线淘汰（已崩） |
| `ItemRequirement` 凡 Cost 都写 `+0x18` | 至少 **`GetFinalCostValue`→+0x18=0** | 收窄到该方法（可再扩已证实锤的 Cost 名） |
| `GameSkill` Tick 清 `+0x10` | 壳有写 `+0x10` | 保留，但非唯一 |
| `Item` 多方法写 `+0x20` | **仅 `IsCooldownCastAble` + isPlayer** | 必须按方法名过滤 |
| 死磕 `UpdateCoolDown` / `AddCost` arg2 | 壳 handler **无此逻辑** | 停 |

---

## 6. 建议星光实现（对齐斌哥）

同跳板 `0x28BD0B0`，`g_infCard` 时：

1. `class==Item && method==IsCooldownCastAble`  
   - 读 `this+0x88 → +0x28 → +0x5c`，非 0 则 `WriteI32(this, 0x20, 0)`
2. `class==ItemRequirement && method==GetFinalCostValue`  
   - `WriteI32(this, 0x18, 0)`（调用 orig **前**）
3. `class==GameSkill`  
   - `WriteI32(this, 0x10, 0)` + 可选 Tick 缓存  
4. **不要** Dobby/`Box`/改返回对象；**不要**对 `Item` 其它方法写 `+0x20`
