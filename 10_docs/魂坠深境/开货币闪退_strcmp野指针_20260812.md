# 开货币闪退：strcmp 野指针（2026-08-12 23:01）

## 栈

```
strcmp ← libstarry_magic.so ← libil2cpp 跳板
```

开金币/魂晶后，跳板对每个调用 `il2cpp_method_get_name` 再 `strcmp`；名字指针无效即崩。

## 修

- 方法名先 `SafeProbe` 拷进本地 `nameBuf`
- 货币只匹配白名单：`HasEnoughCoin` / `get_coinCount` 等，直接改返回值
- **不再** `PatchCurrency`/`ObjClassName`（易对野 `this` 再崩）
- MethodInfo 不用 `SoftPtr` 过滤
