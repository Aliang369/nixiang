## 2. 反向判据（出现即挂点失效，不是功能没开）

| 日志串 | 含义 | 处置 |
|---|---|---|
| `fields wait bftCore=.. enemyChain=.. cardChain=.. (cls…=0x0 …)` 持续 | 类/字段名未解析到 | 看哪个 `cls…=0x0`；先排除热更未加载（重试仍在跑），再抽 `Assembly-CSharp.dll` 复核对名字 |
| `CURR wait SceneInfoSingleton.gameState.playerState` 持续 | 货币链断 | 专查 `_gameState/playerState` |
| `PROT_WRITE_BAD#%u … want=%d got=%d` | ProtectedInt 三元组写坏/被回改 | 立即停：偏移错或字段语义变了（不是 salt 问题） |
| `INV_SKIP#%u maxHp=%d` 连续 | maxHealth 解码异常/越界 | 查 `maxHealth` 偏移是否失效 |
| `core api missing (xdl+dynsym) …` | 导出面被改名/保护 | 停并回报（静态 34/34 命中，出现即环境异常） |

## 3. 不参与正式包的探针块

`BRIDGE_FILE_GD / ICCA / GFCV / GS`（`HzsjMod.cpp:34-41`）与 `BRIDGE_FILE_DD / EXECUTE`（`:130,132`）只服务 `STARRY_HZSJ_PROBE` 探针与 OTA 键，**正式包不编译**；日志出现 `OTA_*` 即说明误编了探针块。

1. 类/字段名（9 类 23 字段）—— 抽 `assets/Asset/hotfix` 里的 `Assembly-CSharp.dll` 做 NUL 精确串核验。
2. `il2cpp_*` 导出面 34 条 —— `llvm-readelf -sW --dyn-syms libil2cpp.so` 一遍可判。
3. A 轨锚点 `com.taptap.sdk.action`（`smali_classes3/…/Actions$CN.smali:65`，唯一 1 命中，等长 21 B）。
