## 2. 反向判据（出现即"挂点失效"，不是"功能没开"）

| 日志串 | 含义 | 处置 |
|---|---|---|
| `[Hzsj] fields wait bftCore=.. enemyChain=.. cardChain=.. (cls…=0x0 …)` 持续 | 类/字段名未解析到 | 对照 §1 表格里哪个 `cls…=0x0`；先怀疑热更未加载（重试仍在跑），再看名字是否变了（抽 `Assembly-CSharp.dll` 复核） |
| `[Hzsj] CURR wait SceneInfoSingleton.gameState.playerState` 持续 | 货币链断 | 同上，专查 `_gameState/playerState` |
| `[Hzsj] PROT_WRITE_BAD#%u … want=%d got=%d` | ProtectedInt 三元组写坏/被回改 | 立即停：偏移错或字段语义变了（不是 salt 问题） |
| `[Il2Cpp] core api missing (xdl+dynsym) …` | 导出面被改名/保护 | 停并回报（1.1.7 静态核验 34/34 命中，出现即环境异常） |

## 3. 不参与正式包的遗留（不要照抄进验收）

`BRIDGE_FILE_GD / ICCA / GFCV / GS`（`HzsjMod.cpp:34-41`）与 `BRIDGE_FILE_DD / EXECUTE`（`:130,132`）只服务 `STARRY_HZSJ_PROBE` 探针与 OTA 键，**正式包不编译**；日志 `[Hzsj] OTA_*` 出现即说明误编了探针块。
