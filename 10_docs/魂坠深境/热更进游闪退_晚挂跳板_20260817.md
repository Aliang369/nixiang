# 魂坠深境 — 2026-08-17 热更进游闪退修复

## 现象

今日 HybridCLR 云更后，星光包进游戏 SIGSEGV（功能全关也会崩）。

## 根因（A/B 实锤）

- 栈：`libil2cpp` HybridCLR 解释器 `0x2737774`↔`0x2737998` 死循环
- **关掉 invoke 跳板 Dobby 后不崩**；常驻挂跳板即崩
- 崩前旧 so 仍打出 `CARD#`（旧逻辑常驻 hook）

## 修法（`Games/HzsjMod.cpp`）

1. **晚挂跳板**：`Hzsj_TryInit` 不 `DobbyHook`；仅当任一玩法功能开启才 `InstallInvoke`
2. Hook 内功能全关时零开销直通（不 `SafeProbe`、不解析方法名）
3. 字段全部 `FieldOffset` 按名解析；今日实抓兜底：
   `bftIsP@108`、`coin@32`、`cry@44`（ProtectedInt 间距）等
4. 货币写 **ProtectedInt** 12 字节自洽三元组（`0x5A17C0DE`）

- [ ] 晚挂包：功能全关进游不崩
