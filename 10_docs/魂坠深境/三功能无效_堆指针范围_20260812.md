# 三功能无效根因（2026-08-12 22:32）

## 日志事实

- 无敌：`pre=7 post=0 isP=1 wr=1` 已写成，但**局内仍掉血** → 多半是预览路径；真结算 BFT 被拒
- 秒杀：统计 **`isP=0` 次数 = 0** → 从未走进敌方分支
- 卡牌：未走斌哥跳板三分支，只靠 `GetFinalCostValue`（HybridCLR 常不进）

## 根因

`IsValidHeapPtr` 限制在 `0x70–0x80`，真机大量对象在 **`0x6f…`**，敌方 `targetBFT` 被当成非法直接跳过。

斌哥只 `cbz` 判 null，不判堆段。

## 修复

1. `SoftPtr`：`0x10_0000_0000 … 0x80_0000_0000`
2. 改 `baseDamage` + **兜底写 `BFT.health`**
3. 同跳板按类名抄卡牌：`GameSkill+0x10` / `ItemRequirement+0x18` / `Item+0x20`
