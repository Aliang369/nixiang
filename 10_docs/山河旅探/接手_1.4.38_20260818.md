## 解锁点

Android 用 `DefaultPurchasedManager`（服务端 `/profile` 的 `chapters` / `skins`）。

| 方法 | 改后 |
|---|---|
| `IsChapterPurchased` | `return true` |
| `IsSkinPurchased` | `(inShop: true, isPurchased: true)` → 直接「使用」 |
| `IsActivityLimitedSkin` | `false`（不挡 Tap 限定皮） |
| `SaveManager.CheckChapterStageIsUnlocked` | `true` |
| `AchievementManager.GetAchievementUnLock` | `true`（西装/衬衫等成就皮） |

`CheckChapterIsUnlocked` 在 Android 上官方已经恒 `true`，章节闸门是购买判定。`IsChapterPurchased` 在 `UserProfile` 为空时会 NRE 并被 catch 成未购买。

## 实现

1. **缓存补丁**（CDN 正在用的包）：`06_dumped/山河旅探/1.4.38/hotfix/patched_2025-02-14-1015/`  
   脚本：`mod菜单/starry-mod-menu/scripts/shlt_patch_hotfix.py`  
   必须写进 `CacheFiles/{md5[:2]}/{md5}/__data` 并改 `ManifestFiles` 里 **2025-02-14-1015** 的 hash/crc/size。只推 APK 内 1.4.38 缓存无效。
2. **LoadAssembly 钩**（防下次 CDN 再盖）：`Games/ShltMod.cpp` 钩 `ILRuntime.Runtime.Enviorment.AppDomain.LoadAssembly`（启动加载 DLL 一次）。**不 hook `ILIntepreter.Execute`**。
3. 只换 so：`scripts/shlt_so_only.sh`  
   外科：`scripts/surgical_shlt_1.4.38.sh`

菜单开关目前只打日志；IL 在加载时已改，关开关不会恢复购买判定。

## 封号

客户端改购买/关卡标记。进付费章可能仍要下资源；云存档/服务端若校验 DLC 会失败。属客户端 IAP 旁路，🟡 中危。

## 登录

`ActivityHandler.authorize` 抛 `starry_force_web_login` → WebView。SignSpoof 在 Activity onCreate 最早装。

## 装机

覆盖 `pm install -r -d`。`Android/data/.../files/yoo` 禁止用 root 创建后不 chown，否则 YooAsset 写 `CRILocalAsset` 失败会黑屏。

后台需有 `games.game_id=shlt`（或全游戏卡）。
