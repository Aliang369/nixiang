## 3. 文档菜单 → 星光对照（玩法）

来源：`10_docs/milthm/milthm_菜单功能抓点_20260809.md` §9–§10（用户确认：斌哥菜单**仅一项「自动跳舞」**）。

| 斌哥 UI | prefs | 行为 | il2cpp（6.0.1 改包 RVA，仅参考） |
|---------|-------|------|----------------------------------|
| **Toggle「自动跳舞」**（唯一项） | `game.taptap.morizero.milthm_preferences` 键 **`"0"`** = true | 总开关：4 处 Dobby 同时生效 | 见下表 |

| # | 方法（稳定符号） | 6.0.1 file_off（参考） | 星光角色 |
|---|------------------|------------------------|----------|
| 0 | `Milthm.Judgements.JudgeResult$$AddJudge` | `0x42E1A8C` | **P0 核心**：注入 Perfect 判定 |
| 1 | `Milthm.Judgements.PlayJudgements$$PlayHitSnd` | `0x42E3BB4` | 捆绑：判定音 |
| 2 | `Milthm.Judgements.PlayJudgements$$ShowJudgeAnimation` | `0x42E3E9C` | 捆绑：判定动画 |
| 3 | `UnityEngine.Time$$get_deltaTime` | `0x4F0AEE8` | 捆绑：时间缩放/变速 |

**星光菜单建议（对齐改包体验）：**

- UI：**一个 Bool「自动跳舞」**（不要拆成 4 个开关，除非后续要单独调速）
- ON：挂齐 4 个 hook，逻辑与壳一致（AddJudge 写 Perfect；其余配套）
- OFF：hook no-op / 卸钩
- **不要**假设 `shell_config` 有多键（改包也是空 map，只靠 preferences `"0"`）

远程菜单：`1145.html`（加密 `GetFeatureList`，无明文「自动跳舞」）。

## 4. 过检对照（原版必做，与玩法分离）

| 层 | 改包结论 | 原版 6.0.5 含义 |
|----|----------|----------------|
| il2cpp | **无** `BuildPassCheckInfo` 类过检 stub | 星光**勿**按霓虹找托管过检点 |
| `libSDKloading` | load-time `JNI_OnLoad` + Dobby 旁路 | 原版**无此壳** → 星光需**自建**签名/PM 旁路（TapSign / Killer 等价），不能「不装壳就等价改包」 |
| `libtoolChecker` | RootBeer `checkForRoot` | 原版若仍加载 → hook 返回未 root；或确认未 dlopen |

优先级：P0 玩法 4× hook（RVA 按 6.0.5 重算）+ P0 独立过检（壳/签名/RootBeer）。

## 6. 装机排障（2026-08-09）

| 现象 | 原因 | 处理 |
|------|------|------|
| 日志停在 `初始化 milthm / 自动跳舞 Hook...`，无 `init ok` / 无重试 | `Milthm_TryInit` 里 `Il2Cpp::Api::Load` → `dlopen(libil2cpp, RTLD_NOW)` 在超大 so 上卡死/loader 锁 | **已去掉** Load；只走 RVA+Dobby |
| logcat 滤 `Milthm` 看不到 LOGI | Logger 标签是 **`Mod_Menu`**，正文才含 `[Milthm]` | 用 `-s Mod_Menu StarryMagic` 或 `grep Milthm` |
| MenuService ClassNotFound | 曾把 smali 写进不存在的 `smali_classes20` | inject 脚本写入**已有最高** `smali_classesN` |
| 过检 | 原版无 `libSDKloading`；需 TapSignKit MD5 + RootBeer | inject 已做官方 MD5 `9ca4f0f7…` |

验证：开菜单 → **自动跳舞** → 进谱面；期望 log：`hooked AddJudge` → `init ok`。

### 闪退（2026-08-09）

进谱面 SIGILL@`Erode+8` / SIGSEGV@`ShowJudgeAnimation+0x10`（`10_docs/milthm/crash_logcat_20260809.txt`）。  
**处理：** 只挂 **`AddJudge`**；暂不挂 Erode / ShowJudgeAnimation / PlayHitSnd / get_deltaTime（Dobby trampoline 在 Android 16 + PAC 设备上炸）。
