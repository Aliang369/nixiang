# 复现说明 —— 我的勇者 7.6.5（vc214）IL2CPP dump（2026-11-24）

> 本目录是**可复现产物**：下面每条命令都能从底包重跑出同一份 `dump.cs`（sha256 见 §4）。

## 1. 输入与指纹（实测，与真机 7.6.5 vc214 指纹一致）

| global-metadata.dat | `assets/bin/Data/Managed/Metadata/global-metadata.dat` | 30,808,312 | `5ba8f5f6ad50bc1a9060256846e77849b187b1e9de1109497b49a0799060af3b` |

## 2. 取 so / metadata（外科式 zip 抽取）

`04_scripts/_common/decode_apk.sh <游戏> <apk> [版本]` 是 **jadx + apktool 整包反编译**（落 `03_decompiled/`），
对 1.5 GB 底包会跑很久且产物对 IL2CPP dump 无用；dump 只需要两个包内文件，故用 zipfile 直取（只读 APK，不改底包）：

```bash
cd /Users/aliang/Documents/nixiang
mkdir -p 06_dumped/我的勇者/7.6.5_il2cpp/_input
python3 - <<'EOF'
import zipfile, hashlib, os
out='06_dumped/我的勇者/7.6.5_il2cpp/_input'
targets=['lib/arm64-v8a/libil2cpp.so','assets/bin/Data/Managed/Metadata/global-metadata.dat']
z=zipfile.ZipFile('02_apks/我的勇者/我的勇者_7.6.5_base.apk')
for t in targets:
    p=os.path.join(out, os.path.basename(t))
    with z.open(t) as src, open(p,'wb') as dst:
        h=hashlib.sha256()
        while True:
            c=src.read(1<<20)
            if not c: break
            dst.write(c); h.update(c)
    print(p, os.path.getsize(p), h.hexdigest())
EOF
```

输出两条 sha256 与 §1 完全一致（`_input` 共 165 MB）。APK 内还有 `lib/armeabi-v7a/libil2cpp.so`（126,727,020 B），本 dump 未使用。

## 3. dump 命令（Il2CppDumper）

```bash
cd /Users/aliang/Documents/nixiang
dotnet 01_tools/Il2CppDumper/Il2CppDumper.dll \
  06_dumped/我的勇者/7.6.5_il2cpp/_input/libil2cpp.so \
  06_dumped/我的勇者/7.6.5_il2cpp/_input/global-metadata.dat \
  06_dumped/我的勇者/7.6.5_il2cpp
```

实测日志（exit 0）：

```
Initializing metadata...
Metadata Version: 31
Initializing il2cpp file...
Applying relocations...
WARNING: find JNI_OnLoad
ERROR: This file may be protected.
Il2Cpp Version: 31
Searching...
CodeRegistration : 7d06c88
MetadataRegistration : 7f5ef30
Dumping...
Done!
Generate dummy dll...
Done!
```

`WARNING: find JNI_OnLoad` + `ERROR: This file may be protected.` 是 stripping 后的常态噪声：**只要 CodeRegistration /
MetadataRegistration 都搜到且 `Dumping... Done!`，dump 有效**。本次两者均命中，方法 RVA 246,617 条非零。

Il2CppDumper 配置：`01_tools/Il2CppDumper/config.json`（`DumpMethod/DumpField/DumpFieldOffset/DumpMethodOffset/
DumpTypeDefIndex/GenerateDummyDll=true`，`GenerateStruct=false` ⇒ **不产出 il2cpp.h**；本版本亦不产出 script.json）。
