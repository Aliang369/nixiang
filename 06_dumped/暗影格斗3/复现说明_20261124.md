# 暗影格斗3 1.45.3 v39 dump 复现说明（2026-11-24）

本目录曾经的 `dump.cs` / `script.json` / `libil2cpp.so` / `global-metadata.dat` 已在
**2026-11-24 收尾清理**时删除（可重建的大件，合计约 344 MB）。本文给出把它们**逐字节重建**所需的
全部输入指纹与命令；重建后 sha256 不匹配即说明底包或工具漂移，不得据此继续用旧锚点。

与官方包不同即产物不合法，与 dump 无关。

## 2. dump 工具

- 源：`xy0-dev/Il2cppDumper_v39`，commit `cff612af1331bf46d1eabb2390f8a46dbec7ea27`。
- 为什么不用 `01_tools/il2cppdumper`（Perfare 6.7.46）：对 metadata **version 39** 直接抛
  `System.NotSupportedException: ERROR: Metadata file supplied is not a supported version[39]`
  （原文另存 `dump_20261124/dumper.log`，该失败运行是历史事实，保留）。
- 本机构建方式：该 fork 的 `dotnet build` 在 Windows 上 NuGet restore 报
  `Value cannot be null (Parameter 'path1')`，改用 **dotnet-sdk8 自带的 Roslyn `csc`** 直接编
  （编译产物当时放在 `13_scratch/sf3_remake/tools/Il2cppDumper_v39/`，随草稿区清理；按 commit 重编即可）。
