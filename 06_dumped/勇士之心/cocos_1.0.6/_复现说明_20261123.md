> 本目录是**可复现产物**：下面每条命令都能在雷电 emulator-5554（root）上重跑出同一份文件。

## 2. 拉取命令

```bash
adb -s emulator-5554 exec-out cat \
  /data/data/com.fightingstars.games.warrior/no_backup/mlib/arm64-v8a/libcocos2djs.so \
  > 06_dumped/勇士之心/cocos_1.0.6/libcocos2djs.so

CP=$(adb -s emulator-5554 shell dumpsys package com.fightingstars.games.warrior | sed -n 's/.*codePath=//p' | tr -d '\r')
adb -s emulator-5554 exec-out cat "$CP/lib/arm64/libsecret.so" \
  > 06_dumped/勇士之心/cocos_1.0.6/libsecret.so
```

前置：游戏必须**冷启过一次**（否则 mlib 目录不存在）；本机 `adb shell id` 已是 uid=0。

## 3. 分析命令（NDK r27 llvm 工具）

```bash
B=C:/Users/Administrator/AppData/Local/Android/Sdk/ndk/27.0.12077973/toolchains/llvm/prebuilt/windows-x86_64/bin
"$B/llvm-readelf.exe" -h -S -l -d -W libcocos2djs.so            # .text off==vaddr==0x1f5000（首个 LOAD 恒等映射）
"$B/llvm-readelf.exe" --dyn-syms -W libcocos2djs.so > dynsyms.txt
"$B/llvm-strings.exe" -a -t x libcocos2djs.so > strings_all.txt
"$B/llvm-objdump.exe" -d --start-address=0x2c1264 --stop-address=0x2c12f4 libcocos2djs.so   # JNI 桥 → bl 0x31418c
"$B/llvm-objdump.exe" -d --start-address=0x31418c --stop-address=0x3141b0 libcocos2djs.so   # evalString 序言
```
