## 2. dump 命令（原文）

输入已在盘上，**不跑** `04_scripts/追迹迷城/dump_zjmc.sh` 的 [1/3] jadx+apktool 整包反编译（1.1 GB 底包，产物对 dump 无用）；
按该脚本 [2/3] 的同一姿势：把 dumper + 依赖 + `config.json` 复制到 `1.0.20261111_il2cpp.tool/`，再对 inputs 直跑。

```bash
cd /Users/aliang/Documents/nixiang
ROOT=$PWD; GAME=追迹迷城; VERSION=1.0.20261111
DUMP_ROOT="$ROOT/06_dumped/$GAME"; OUT="$DUMP_ROOT/${VERSION}_il2cpp"; TOOL_DIR="$OUT.tool"
rm -rf "$OUT" "$TOOL_DIR"; mkdir -p "$OUT" "$TOOL_DIR"
cp "$ROOT/01_tools/Il2CppDumper/Il2CppDumper.dll" \
   "$ROOT/01_tools/Il2CppDumper/Il2CppDumper.deps.json" \
   "$ROOT/01_tools/Il2CppDumper/Il2CppDumper.runtimeconfig.json" "$TOOL_DIR/"
cp "$ROOT/01_tools/Il2CppDumper"/Mono.Cecil*.dll "$TOOL_DIR/"
# config.json（与 dump_zjmc.sh 逐字段相同）
cat > "$TOOL_DIR/config.json" <<'JSON'
{
  "DumpMethod": true, "DumpField": true, "DumpProperty": true, "DumpAttribute": false,
  "DumpFieldOffset": true, "DumpMethodOffset": true, "DumpTypeDefIndex": true,
  "GenerateDummyDll": true, "GenerateStruct": true, "DummyDllAddToken": true,
  "RequireAnyKey": false, "ForceIl2CppVersion": false, "ForceVersion": 16,
  "ForceDump": false, "NoRedirectedPointer": false
}
JSON

cd "$TOOL_DIR"
dotnet "$TOOL_DIR/Il2CppDumper.dll" \
  "$DUMP_ROOT/inputs/libil2cpp.so" \
  "$DUMP_ROOT/inputs/global-metadata.dat" \
  "$OUT"
```
