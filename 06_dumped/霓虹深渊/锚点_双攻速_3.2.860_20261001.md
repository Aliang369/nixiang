## 2. 远程：间隔 = 60 / RPM（该协程唯一一次 yield）

```
ldr  x8,[x19,#0x20]      ; <>4__this = Gun
ldp  x0,x1,[x8,#0x1a8]   ; Gun.RPM (PlayerStateFloat)
bl   0x30D99A4           ; PlayerStateFloat::op_Implicit → float
ldr  s0,[0x7823AFC]      ; 常量 60.0f（文件字节 00007042 已核）
fdiv s0,s0,s8            ; 60 / RPM
bl   0x5249C6C           ; UnityEngine.WaitForSeconds::.ctor(float)
str  x20,[x19,#0x18]     ; <>2__current
```

- `UnityEngine.WaitForSeconds`：唯一字段 `internal float m_Seconds; // 0x10`。
- 字段表：`Gun.<shootingInterval>d__96 { <>1__state 0x10; <>2__current 0x18; Gun <>4__this 0x20 }`（无 timer）。
- 负证据：`Gun::UpdateAttr 0x3962904` 只算 ShakeAmplitude（读 BulletSize `0x148` / RPM `0x1A8` + `BulletSize2Amplitude 0x270` / `BulletRPM2Amplitude 0x268` → fsub → Mathf.Clamp），**不写** RPM；`GunAttackRoutine` 的 MoveNext 内无 shootingInterval / WaitForSeconds 引用。

## 3. 近战：冷却落在协程局部量 `<timer>5__2`

```
ldrb w8,[x20,#0xc0]      ; GunBase.InstigatorIsPlayer（只对玩家武器）
bl   0x3960208           ; Gun::JudgeCanKnifeAttack
bl   0x3961F28           ; Gun::Melee
;（普通刀）0x292A174  ldr s0,[x20,#0x370] ; Gun.BaseMeleeCD
;                     ldr s1,[x20,#0x374] ; Gun.ExtraMeleeCD ; fadd
;（Kanon 刀）0x292A1F0 ldr s0,[x20,#0x30] ; GunBase.kanonBaseMeleeCd
;                     ldr s1,[x20,#0x374] ; fadd
0x292A1FC  fcmp s0,#0.0 ; str s0,[x19,#0x28]   ; → <timer>5__2 = 冷却秒数
0x292A04C/0x292A068  <timer> -= Time::get_deltaTime ; 逐帧 yield null
; 归零 → mov w0,wzr 结束协程
```

- 字段表：`Gun.<MeleeCheck>d__85 { <>1__state 0x10; <>2__current 0x18; Gun <>4__this 0x20; float <timer>5__2 0x28 }`。
- 反面结论：`Gun::JudgeCanKnifeAttack 0x3960208`（876 B）体内不读 `0x370`/`0x374`，走 `CapabilityControl_Melee::MeleeStatusOn 0x3BE30C8` / `NEONPlayerState::get_weaponType 0x28895D0` / `Gun::get_ps 0x395D97C`。
- 为什么写局部量而不写 `Gun+0x370/0x374`：`ResetExMeleeMult` 会在同一流程里重置 `ExtraMeleeCD`，写字段会被冲掉或连乘；写状态机局部量零残留、可随时关。
