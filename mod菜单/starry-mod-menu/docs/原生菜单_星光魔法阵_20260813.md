# 星光菜单 — 全原生「星光魔法阵」

> 更新：2026-08-14（**去资源化结案**：`MagicRes` 纯 Java；花藤 WebP q90 base64）  
> 主题：星光魔法阵（色板见 `设计风格美术规范.md` v2.3）  
> 入口：`MenuService` → `NativeMenuController`（全原生）

## 1. 架构与路径

| 项 | 说明 |
|----|------|
| 主路径 | Activity `TYPE_APPLICATION`（**无悬浮窗权限**） |
| 备用 | 已授权时 `TYPE_APPLICATION_OVERLAY` |
| 入口 | `NativeMenuController`：法阵悬浮球 + 展开面板 |
| 皮肤 | **`MagicRes.java` 唯一视觉实现**（禁止再扩 `res/drawable/magic_*`） |
| 功能表 | `FeatureListParser` ← native `g_featureList`（`Toggle_` / `Category_` / `Slider_名:min:max` 等） |
| 卡密 | 原生账号页 → `AuthClient` + `Preferences`；过期展示用 **`card.expire_at`**（上海时区） |
| Bootstrap | **每局启动只拉一次**（无轮询/心跳）；按 `card_auth_enabled` / `menu_enabled` 切门控 |
| 自测授权 | debug：`STARRY_GAME_SELF` → 映射 `starry_self`（见 `SWITCH_GAME.md`） |
| 桥接 | `ModBridge` toggle/slider/button 返回 `boolean`，未授权时 UI 回滚 |

### 关键文件

- `menu/NativeMenuController.java` — 全量原生 UI
- `menu/MagicRes.java` — 色 / drawable 工厂 / 花藤 b64（去 arsc）
- `menu/FeatureListParser.java`
- `bridge/ModBridge.java` / `Preferences.java`
- `MenuService` / `MainActivity`（自测 layout 可留工程 R，不进注入菜单路径）

设计规范：`设计风格美术规范.md` §1.1（客户端硬约束）。

## 2. 本轮 UI 调整（2026-08-13）

### 2.1 面板结构与交互

- **拖动**：展开后面板靠标题栏拖；收起后悬浮球可拖
- **收起**：标题栏右侧圆环短横芯片
- **标题**：主标题 + **授权状态作副标题**（紧贴，约 2dp）
- **Tab**：功能 / 账号 / 设置在底栏；内容区 **WRAP + 上限约 260dp**
- **节奏**：`SPACE=8`、`SPACE_TIGHT=4`、`ROW_PAD_V=7`；标题下 / Tab 上细分割线（hairline）
- **行分割线**：功能 / 账号已登录 / 设置页 **末项不画** row divider，避免与 Tab 顶线叠成双线
- **功能列表**：扁平行；`Category_` 可折叠
- **高度**：折叠分类、切 Tab、**登录/退出切换账号页**后 `requestPanelRelayout()` 按内容实测高度写入 WM（`WRAP_CONTENT`  alone 常不回缩）

### 2.2 四角花藤

- `MagicRes.vineCorner()` ← WebP q90 **base64**（`VINE_WEBP_B64`），挂 shell 四角，elevation 高于面板
- 换图只更新 b64，不放回 assets / drawable

### 2.3 面板背景

- **无星空水印**（已删除 `magic_panel_starfield` 与 `StarfieldBackdrop`；纯半透明底 + 双描边更干净）
- `MagicRes.panelBg()`：半透明底 + 双描边；card `clipToOutline` 圆角 16dp

### 2.4 控件样式

- **Switch**：自定义轨道 + **五角星滑块**（非系统样式）
- **Button**（登录 / 复制QQ / 执行 / 解绑 / 退出）：**镂空描边胶囊**；危险操作为红色描边
- **Spinner 下拉**：触发器（值 + 箭头）+ 品牌描边弹出菜单（对齐 HTML `.mod-dropdown`），非系统 AlertDialog
- **Toast**：安卓自绘 WM 浮层（渐变底 + 描边 + 图标）；菜单未附着时回退系统 Toast
- **远程公告**：安卓自绘卡片（星光底 + 藤蔓角 + 关闭/前往），非系统 AlertDialog

### 2.5 悬浮球

- `magic_fab_circle.xml` 法阵环 + 光晕呼吸；收起态旋转

### 2.6 Bootstrap 门控（对齐 HTML 1235，无轮询）

- **账号 Tab**：`card_auth_enabled=false` 时隐藏；若正停在账号页则切回「功能」
- **关卡密 → 开放模式**：`saveNetworkBootstrap` + grant 同步 native；副标题为「开放模式 · 已授权」，不再引导去账号
- **开卡密**：清会话 / grant，提示「请登录后使用」，重新显示账号 Tab
- **`menu_enabled=false`**：Toast「游戏维护中，功能已关闭」+ `lockAllFeatures`；副标题维护中；开功能被拦时同文案
- **单项 `features[].enabled=false`**：原生 `enforceServerFeatureFlags` → `forceFeatureOff`（按 Toggle/Slider/Input 规格复位，禁止对滑块写 boolean）
- **`lockAllFeatures` / 未授权回落 / HTML 门控**：统一走 `forceFeatureOff`；偏好读写容错 ClassCast
- **刻意不做**：周期 bootstrap 轮询、15s 心跳常驻（改为展开菜单 / 功能被拦时 **按需续票**；硬失败才踢）

### 2.7 按需续票 + 过期硬踢（2026-08-13）

| 时机 | 行为 |
|------|------|
| 展开面板 | `POST /v1/auth/heartbeat`（卡密）或 `GET /v1/bootstrap`（开放模式）续 grant |
| 功能被拦 | 触发同路径续票；Toast 提示续期/重登 |
| 硬失败（会话无效/封禁/过期） | `clearAuthSession` + 锁功能 + 刷新 UI |
| 纯网络错误 | 不踢；本地票仍有效则继续，否则再踢 |

节流：成功路径约 45s 内不重复；**无 live session 时强制续**。

### 2.8 自测功能表（`STARRY_GAME_SELF`）

当前 `Android.mk`：仅 `-DSTARRY_GAME_SELF`（`GameConfig.h` → `starry_self`）。功能 Tab 覆盖：

| feat | 规格 |
|------|------|
| 1 | `Toggle_测试开关` |
| 2 | `CheckBox_测试勾选` |
| 4 | `Slider_测试滑块:1:10` |
| 5 | `SeekBar_测试滑轮_0_100` |
| 7 | `Spinner_难度:简单,普通,困难` |
| 9 | `InputText_备注` |
| 10 | `InputValue_100:数量` |
| 12 | `Button_测试执行` |

后台须对 **`starry_self`** 同步同编号功能；改别的游戏的开关不会作用到本 APK。种子模板见 `auth-server/app/menu_catalog.py`（已有库需后台「同步菜单」或 JSON 导入更新）。

## 3. 自测构建
