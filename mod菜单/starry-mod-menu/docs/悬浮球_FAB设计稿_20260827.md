| **AI 概念图 PNG** | ❌ 不能像素级复刻 | 出图是风格参考，没有矢量 path、没有 dp 标注，无法自动转成 Android Drawable |

## 3. 设计目标（概念图 vs 现码）

概念图里悬浮球好看的核心：

1. **双层光晕**：外圈柔和 bloom + 内圈贴近法阵
2. **法阵可读**：双实线环 + 六芒星（双三角）+ **中心实心小星**
3. **呼吸感**：光晕明暗周期慢、不抢戏
4. **收起态慢速旋转**：魔法阵在转，光晕不转

现码（2026-08-27）已具备 1–3 的大部分；与概念图/规范差距见 §6。

## 4. 结构（由外到内）

```
WindowManager 窗口 80×80 dp（baseLayoutParams）
└─ FrameLayout fab 72×72 dp（buildFab）
   ├─ ImageView glow 72×72  ← MagicRes.fabGlowOval() 径向渐变
   └─ ImageView fabRing 56×56 CENTER ← MagicRes.fabCircle() FabCircleDrawable
```

| 层级 | 尺寸 | 职责 |
|------|------|------|
| WM 窗口 | 80×80 dp | 拖拽热区、留边给光晕溢出 |
| 光晕层 | 72×72 dp | 径向 `#AA→#55→#00` brand 紫，alpha 呼吸 |
| 法阵层 | 56×56 dp | 矢量法阵，收起态旋转 |

## 6. 光晕（fabGlowOval）

现码：

- 形状：OVAL 径向渐变
- 色标：`#AA9B7ED8` → `#559B7ED8` → `#009B7ED8`，stops 0 / 0.5 / 1
- gradientRadius：36 dp
- 动画：`ObjectAnimator` alpha **0.55 ↔ 0.95**，周期 **2500ms**，REVERSE 无限

设计稿对齐：

| 项 | 现码 | 设计稿 |
|----|------|--------|
| 呼吸 | 仅 alpha | alpha + 可选 scale 0.96↔1.04（glow 层） |
| 周期 | 2.5s | **3s**（更慢、更「星灵」） |
| 双层 bloom | 无 | 见 §5.1 |

## 7. 动效

| 状态 | 行为 | 现码 | 设计稿 |
|------|------|------|--------|
| 收起 | 法阵旋转 | 14s/圈 linear | **48s/圈**（对齐 `设计风格美术规范.md` §六 40–60s） |
| 收起 | 光晕呼吸 | 2.5s alpha | 3s alpha（+ 可选 scale） |
| 收起 | 出现 | scale 0.85→1，180ms | 保持 |
| 展开 | 法阵 | 隐藏 + stopFabSpin | 保持 |
| 展开 | 面板 | scale 0.92→1 + alpha，220ms | 保持 |
| 过检倒计时 | FAB 警示 | 无 | 外环改 `#FFB86C` 琥珀色，旋转加快 20s（P2） |

## 8. 交互（不变）

- 收起态：**整球拖拽** + 点击展开（`onWindowDrag` TAP_SLOP 24px）
- 默认位置：x=12dp, y=120dp
- 展开态：球 GONE，面板标题栏拖拽
