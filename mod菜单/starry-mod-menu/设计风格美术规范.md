# 星光魔法 · 设计风格美术规范

> **版本**：2.3  
> **更新日期**：2026-08-14  
> **适用范围**：客户端原生菜单（`NativeMenuController` + `MagicRes`）+ 运营后台（`auth-server/static/admin`）  
> **品牌**：星光魔法（原「星屑」已统一更名）

本文是视觉与交互的**唯一主规范**。其它文档（`DESIGN_SPEC.md`、`design-spec.md`、去资源化交接）以本文为准；冲突时改其它文档对齐本文。

## 一、设计主题

**星光魔法** — 深邃星空为底，薰衣草紫为品牌主色，魔法阵 + 五角星为符号系统。  
整体：「暗色系魔法幻想」——神秘、精致、沉浸；运营台在同色系上叠加更强毛玻璃与星空底，偏「星空控制室」。

| 表面 | 定位 | 关键文件 |
|------|------|----------|
| 客户端菜单 | 游戏内浮层，轻量装饰、高可读 | **仅** `NativeMenuController` + `menu/MagicRes.java`（纯 Java 绘制） |
| 运营后台 | 桌面工作台，星空底 + 毛玻璃面板 | `auth-server/static/admin/index.html` |

### 1.1 客户端实现硬约束（2026-08-14 起）

菜单视觉已**去 arsc / 去 drawable 扩展**。以后改菜单 UI：

| 允许 | 禁止 |
|------|------|
| 在 `MagicRes` 增改色常量、`GradientDrawable` / `Path` / `StateListDrawable` | 新增 `res/drawable/magic_*`、`res/color`、vector XML |
| 在 `NativeMenuController` 组布局与交互 | 再往宿主合并菜单相关 `resources.arsc` |
| 极小位图仅 **Java 内嵌**（现：花藤 WebP q90 → `MagicRes.VINE_WEBP_B64`） | 新加 `assets` 菜单贴图（鉴权证书除外） |
| 后台继续用 CSS / HTML | 恢复 HTML WebView 菜单 |

注入交付形态：**星光 dex（含 MagicRes）+ so + Manifest**（+ 可选 `assets/certs`），不依赖游戏 `resources.arsc` 菜单资源。

## 二、色彩系统

### 2.1 核心色板（两端共用）

| Token | 色值 | 用途 | 客户端 Java（`MagicRes`） |
|-------|------|------|---------------------------|
| `--bg` | `#1A1B3A` | 主背景（星空蓝） | 渐变/底内嵌 ARGB |
| `--bg-deep` | `#0E0F23` | 深层底 / 星空最深处 | 同左 |
| `--surface` | `#252650` | 实色表面 | `SURFACE` |
| `--surface-2` | `#2D2E5F` | 次级表面 / 控件底 | `SURFACE_2` |
| `--brand` | `#9B7ED8` | 品牌主色（薰衣草紫） | `BRAND` |
| `--brand-bright` | `#B8A0F0` | 品牌亮色（渐变高光） | 控件内嵌 |
| `--brand-glow` | `rgba(155,126,216,0.4)` | 辉光 | `BRAND_GLOW` 等 |
| `--star` / `--ink` | `#E8E8F5` | 主文字 / 星光白 | `INK` |
| `--ink-2` | `#B8B8D4` | 次级文字 | `INK_2` |
| `--ink-3` | `#7A7A9E` | 辅助文字 | `INK_3` |
| `--line` | `rgba(155,126,216,0.15~0.22)` | 边框 / 分割线 | `LINE` |
| `--line-bright` | `rgba(184,160,240,0.4)` | 强调描边（后台面板） | 后台专用 |

> 客户端**唯一色源**：`MagicRes` 常量与工厂方法内的 ARGB。勿再维护平行的 `colors.xml` magic 色。

### 2.2 语义色（仅语义，不作装饰）

| Token | 色值 | 语义 | 客户端 |
|-------|------|------|--------|
| `--success` / `--state-success` | `#7EE0A0` | 成功 / 启用 | `OK` |
| `--warning` / `--state-warning` | `#FFE5B4` | 警告 | 按需内嵌 |
| `--error` / `--state-error` | `#E07E7E` | 错误 / 危险 | `ERROR` |
| `--info` / `--state-info` | `#7EB8E0` | 信息 | 按需内嵌 |

### 2.3 毛玻璃层（后台主用，菜单可复用）

| Token | 建议值 | 用途 |
|-------|--------|------|
| `--glass` | `rgba(37,38,80,0.52)` | 面板 / 顶栏 |
| `--glass-strong` | `rgba(22,20,48,0.68)` | 侧栏 / 登录 / 弹窗 |
| `--blur` | `blur(20px) saturate(1.3)` | 标准毛玻璃 |
| `--blur-sm` | `blur(12px) saturate(1.15)` | 轻毛玻璃 |

```css
background: var(--glass);
border: 1px solid var(--line);
backdrop-filter: var(--blur);
-webkit-backdrop-filter: var(--blur);
box-shadow: var(--shadow-2), inset 0 1px 0 rgba(255,255,255,.08);
```

菜单侧无系统 blur：用半透明 `GradientDrawable` 近似（见 `MagicRes.panelBg` / `announceBg`）。

### 2.4 使用原则

1. **品牌紫是唯一主交互色**：开关开、主按钮、激活态、焦点环。  
2. **状态色只表语义**，不铺大面积装饰。  
3. **层次**：`--bg-deep` < `--bg` < `--surface` < `--surface-2` / glass。  
4. 透明度控件（菜单面板）建议 **≥ 0.2**，保证可读。  
5. 禁止：纯黑大面积、霓虹彩虹、与品牌无关的青绿/橙色主题。

## 五、UI 控件规范（运营台强制）

两端视觉统一；**运营台控件尺寸如下（必须遵守）**：

| 控件 | 高度 | 字号 | 圆角 | 水平内边距 |
|------|------|------|------|------------|
| 输入框 / 下拉 / 主按钮 | **40px** (`--ctrl-h`) | 14px | 8px | 12px |
| 小按钮 `.btn.sm` | **32px** (`--ctrl-h-sm`) | 12.5px | 7–8px | 10px |
| 侧栏导航项 | 40px | 14px | 12px | — |
| 多行文本 | min-height 104px | 14px | 8px | 12px |

### 按钮变体

| 类名 | 样式 |
|------|------|
| `.btn` | 品牌紫渐变 + 内高光 + 外辉光 |
| `.btn.ghost` | 透明底 + `--line` 描边 + 轻毛玻璃 |
| `.btn.danger` | 浅红底 + `--error` 字色 |
| `.btn:disabled` | opacity 0.45，禁交互 |

菜单侧对应：`MagicRes` 的 `btnExec` / `btnDanger` / 公告按钮等，**新增按钮样式只加 `MagicRes` 工厂**。

### 焦点

- `box-shadow: var(--focus-ring)`（品牌紫 3px 环）  
- 可点击元素必须有 `cursor: pointer`  
- 支持键盘 `:focus-visible`

### 表格

- 斑马纹：偶行 `rgba(brand, ~0.05)`  
- 悬停：`rgba(brand, ~0.1)`  
- 选中：左侧品牌色竖条 + 浅紫底  
- 表头可 sticky + 轻毛玻璃  
- 外层 `.table-wrap`：圆角 12px + 细边框

## 六、动效

| Token | 值 |
|-------|-----|
| `--ease` / `--ease-out` | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| `--dur-hover` | 140–180ms |
| `--dur-state` | 280ms |

| 动画 | 周期 / 说明 |
|------|-------------|
| 星星闪烁 | 2.2–3.8s，错落 opacity/scale |
| 星云漂移 | ~28s alternate |
| 流星 | ~9s（后台装饰，克制） |
| 魔法阵旋转 | 40–60s linear（菜单悬浮球） |
| 页面切入（后台） | 350ms 轻上移淡入 |
| Toast | ~2.2s 自动消失 |
| 公告入场 | ~320ms scale/alpha（`NativeMenuController`） |

**必须**尊重 `prefers-reduced-motion: reduce`（关闭闪烁/流星/漂移）——后台强制；菜单按场景克制循环动画。

## 七、核心视觉元素

### 7.1 魔法阵

结构：外环 → 虚线环 → 双三角（六芒星感）→ 内环 → 中心点 / 顶点星点。  
- **菜单**：`MagicRes.fabCircle` / `fabGlowOval`（Canvas `Path`，非法阵 XML）。  
- **后台**：SVG。  
透明度：悬浮球完整可见；Toast 图标略弱。

### 7.2 星空

- **原生菜单（现行）**：面板**无**星空水印，仅半透明底 + 双描边 + 花藤；详见 `docs/原生菜单_星光魔法阵_20260813.md`。  
- **旧 HTML 菜单**：已删除，勿恢复。  
- **后台**：全屏 `.sky`（星云 + 3 层星点 + 克制流星），内容层 `z-index ≥ 1`。

### 7.3 五角星

路径统一（菜单 Switch 滑块 / Toast）：与历史 vector pathData 一致，由 `MagicRes` `Path` 绘制。  
填充：`--star` / `--ink`，可加辉光。**禁止**改回 `res/drawable` vector。

### 7.4 花藤角饰

- 现行：`MagicRes.vineCorner()` ← 内嵌 WebP q90 base64（`VINE_WEBP_B64`）。  
- 四角 ImageView + scale 镜像，挂 shell，elevation 高于面板。  
- 换图：压 WebP → 更新 b64 常量；**不要**再丢 `assets/` 或 `drawable-*`。

### 7.5 空状态

后台 `.empty`：上方小五角星 + 弱文案；忌 emoji。

## 八、组件要点

### 客户端菜单

- **现行**：全原生 `NativeMenuController` + **`MagicRes` 纯 Java 皮肤**；结案见 `docs/原生菜单_星光魔法阵_20260813.md`、`docs/去资源化_实施计划与对照清单_20260814.md`。  
- 面板半透明底 + 双描边、四角花藤、底栏 Tab：功能 / 账号 / 设置  
- Toggle（五角星滑块）/ Slider / 悬浮球 / Toast / 远程公告：一律 `MagicRes` 工厂  
- 远程公告：自绘卡片（eyebrow「公告」+ 标题单行截断 + hairline + 正文按行数对齐 + 「我知道了」/「关闭」+「前往」）  
- **扩展新控件**：先在 `MagicRes` 加 drawable 工厂与色，再在 `NativeMenuController` 挂视图；不新增 XML 资源

### 运营后台

| 模块 | 规范 |
|------|------|
| 侧栏 | 毛玻璃强层、品牌魔法阵标、导航激活带星点辉光 |
| 顶栏 | 毛玻璃、标题渐变字 |
| 统计卡 | 毛玻璃、角部光斑、可点击跳转 |
| 弹窗 | 强毛玻璃 + 顶边高光线 |
| 登录 | 四角魔法阵 + 星、强毛玻璃卡片 |

导航顺序：**看板 → 游戏 → 卡密 → 功能门控 → 公告 → Toast → 设置**

功能门控：按游戏 master-detail；编号来自 `menu_catalog.py`，运营只开关。

## 九、无障碍与技术

- `lang="zh-CN"`（后台）  
- 文字对比：主文字相对深底 ≥ 4.5:1（银白 on 星空蓝）  
- 图标：菜单用 `MagicRes` Path；后台用 SVG / Lucide；**不用 emoji 当图标**  
- 菜单：**禁止**再扩 `res/drawable` / WebView HTML；后台单页 `index.html`  
- 品牌文案统一「星光」，禁止残留「星屑」  
- 自测 App（`MainActivity` layout）可保留工程 `R.layout`，**不进注入包菜单路径**

## 十、AI / 协作改 UI 检查清单

- [ ] Token 是否来自本文色板（未引入无关主色）  
- [ ] **菜单改动是否只动 `MagicRes` / `NativeMenuController`（未新增 magic XML / arsc）**  
- [ ] 后台控件高度是否 40 / 32  
- [ ] 面板是否毛玻璃 + `--line` 描边（后台）/ 半透明双描边（菜单）  
- [ ] 动效是否可被 `prefers-reduced-motion` 关闭（后台）  
- [ ] 新游戏功能是否同步 `menu_catalog.py`  
- [ ] 空状态 / 按钮 / 表格是否仍像「星光魔法」而非通用 Admin 模板  
- [ ] 花藤若更换：WebP + b64 更新，未放回 assets/drawable
